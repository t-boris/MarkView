# Back-edges between domain folders (AR-20, AR-21): `<types> <layer>/<from> -> <layer>/<to>  # why it stays`. The layering, lowest
# first, is Appearance, Shared, AI, the feature domains, Workspace (tools/lint/domain-dependencies.py): a domain may name its own
# rank and the ranks below, so an edge up the layering is a back-edge, and so is one side of two feature domains that name each
# other (the lighter one, or the one named here). The types are the ones <from> names that <to> declares
# (tools/lint/domain-dependencies.py --layer <layer> --why <from> <to> lists them). A ratchet that only falls: remove the dependency
# (a protocol in the lower domain, or move the type) and run --tighten; the goal is an empty list. A new back-edge is written here
# by a person, with the reason it stays.
