# Task 8: AI Tools menu integration

## Required Skills

Перед выполнением задачи загрузи:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Add a new menu entry "🧭 Recursive Insight" to the AI Tools dropdown in the ContentView toolbar so the user can launch a Recursive Insight tab from a folder of `.md` files. The button lives inside the existing `Section("Analysis")` group, immediately after "📚 Generate Full Documentation". It is wired directly to `WorkspaceManager.startRecursiveInsight()` (added in Task 7) — NOT through `runAITool(named:)`, because that path routes to AI Console which is the wrong dispatch for Recursive Insight (per Decision and code-research §11).

The button is disabled when no folder is open (`workspaceManager.rootNode == nil`) or when the open folder contains no `.md` files (`!workspaceManager.hasMarkdownFiles`, computed property added in Task 2). This prevents the user from launching an empty insight session.

This task is a small, isolated UI change. All wiring (`startRecursiveInsight`, `hasMarkdownFiles`) already exists by the time Wave 3 runs — Task 8 only adds the SwiftUI Button declaration.

## What to do

1. Open `MarkView/Views/ContentView.swift` and find the AI Tools menu at L114-134.
2. Inside `Section("Analysis")` (L124-130), after the existing `Button("📚 Generate Full Documentation") { workspaceManager.runAITool(named: "fulldocs") }` line, insert a new `Button("🧭 Recursive Insight")`.
3. The new button's action calls `workspaceManager.startRecursiveInsight()` directly (do NOT use `runAITool(named:)`).
4. Apply `.disabled(...)` to the new button so it is greyed-out when:
   - `workspaceManager.rootNode == nil` (no folder open), OR
   - `!workspaceManager.hasMarkdownFiles` (folder open but contains zero `.md` files).
5. Build with `xcodebuild` and verify zero errors and no new warnings in `ContentView.swift`.
6. Run the app and manually verify behavior per the User verification step below.

## Details

**Files:**
- `MarkView/Views/ContentView.swift` — current state: AI Tools `Menu` at L114-134 contains `Section("Diagrams")` (L116-123) with 6 diagram tools and `Section("Analysis")` (L124-130) with 5 existing analysis tools, all wired via `workspaceManager.runAITool(named: "...")`. Insert one new `Button` inside `Section("Analysis")` after the "fulldocs" button. Add the `.disabled(...)` modifier to the new button only — do not touch existing buttons.

**Dependencies:**
- Task 7 (Wave 3 prerequisite) — provides `WorkspaceManager.startRecursiveInsight()`.
- Task 2 (Wave 1, transitively) — provides `WorkspaceManager.hasMarkdownFiles` computed property.

**Edge cases:**
- Folder with zero `.md` files but other files present → button disabled (covered by `!hasMarkdownFiles`).
- Folder open then closed → `rootNode` becomes `nil` → button disabled.
- Folder open contains only files in `.dde/` subfolder → `hasMarkdownFiles` should return `false` (relies on Task 2's helper which already skips hidden + `.dde`).
- A single `.md` file opened (not a folder) → `rootNode` may be non-nil but `hasMarkdownFiles` semantics depend on Task 2's implementation. The disabled predicate should still resolve correctly via the OR clauses.

**Implementation hints:**
- The exact snippet from code-research §11:
  ```swift
  Button("🧭 Recursive Insight") {
      workspaceManager.startRecursiveInsight()
  }
  .disabled(workspaceManager.rootNode == nil || !workspaceManager.hasMarkdownFiles)
  ```
- Place this snippet right after the existing line: `Button("📚 Generate Full Documentation") { workspaceManager.runAITool(named: "fulldocs") }`.
- Do NOT call `runAITool(named: "insight")` or similar — `runAITool` routes to AI Console which is wrong dispatch for Recursive Insight (it requires its own tab kind, see Decision 1 + 4 in tech-spec).
- Do not modify the `Diagrams` section or any other part of the toolbar.
