# Agent Instructions

The project guide for all coding agents is `CLAUDE.md` in the repository root.
Read it before any work and follow all of it: project layout, working rules, Git
workflow, versioning, and verification.

The most important rule: every feature and bug fix goes through a pull request.
Work on a branch, open a pull request into `main`, and merge it after verification
as part of completing the task, unless Boris asks to leave it open. Never commit,
merge, or push to `main` directly. For app changes, finish with a local Release
build and DMG installer from the merged commit. See "Git Workflow" and
"Completion" in `CLAUDE.md`.
