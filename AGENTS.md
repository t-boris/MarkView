# Agent Instructions

The project guide for all coding agents is `CLAUDE.md` in the repository root.
Read it before any work and follow all of it: project layout, working rules, Git
workflow, versioning, and verification.

The most important rule: every feature and bug fix goes through a pull request.
Work on a branch, open a pull request into `main`, and merge it only when Boris
asks. Never commit, merge, or push to `main` directly unless Boris explicitly
says so for that change. See "Git Workflow" in `CLAUDE.md`.
