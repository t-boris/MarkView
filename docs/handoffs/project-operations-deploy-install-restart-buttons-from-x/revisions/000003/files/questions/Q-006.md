## Question

Где должна находиться кнопка «Deploy» с выбором окружения?

## Why it matters

В запросе сказано «где-нибудь». От места зависит, доступен ли запуск развёртывания только при открытом X-Ray или из любого места проекта, и без этого нельзя написать требование к кнопке. Список операций в панели деталей уже входит в объём; вопрос только о кнопке Deploy. Это открытое решение №2 из обзора.

## Options

- **A**: В панели инструментов X-Ray: кнопка видна, когда открыт X-Ray, в любом его представлении.
- **B**: В панели инструментов окна проекта: кнопка видна всегда, когда у проекта найдена операция развёртывания.
- **C**: Только в панели деталей X-Ray: отдельной кнопки нет, Deploy — первая из операций в списке представления Deployment.
- **D**: В панели инструментов X-Ray и в панели инструментов окна проекта одновременно.

## Answer

D. В панели инструментов X-Ray и в панели инструментов окна проекта одновременно.
