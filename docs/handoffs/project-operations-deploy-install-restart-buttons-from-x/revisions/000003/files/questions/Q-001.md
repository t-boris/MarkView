## Question

Каким способом должна выполняться выбранная операция (deploy / install / restart)?

## Why it matters

От механизма выполнения зависят почти все остальные требования: как показывается вывод и состояние, как работает отмена, как обрабатываются интерактивные запросы (пароли, подтверждения), какие защитные меры возможны для production и как формулировать критерии приёмки. Без этого решения требования к запуску написать нельзя.

## Options

- **A**: Вставлять команду во встроенную вкладку терминала (PTY) и запускать там.
- **B**: Запускать отдельный подпроцесс с собственной панелью вывода, статусом и кнопкой отмены.
- **C**: Передавать задачу терминалу AI-агента, который сам выполняет команду.

## Answer

B. Запускать отдельный подпроцесс с собственной панелью вывода, статусом и кнопкой отмены.
