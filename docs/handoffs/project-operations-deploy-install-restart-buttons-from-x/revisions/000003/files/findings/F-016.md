## Finding

The overview lists as unknown 'whether the feature must work for folder X-Rays or only for the project X-Ray'; this was never decided. It determines which root holds the operations file, what 'project root' means in REQ-004 and REQ-006, and which operations the project window toolbar button shows when the workspace root and the X-Ray root differ or when a window contains several projects. The relation of an operation to deployment nodes (DEC-009) is also fragile: node ids are AI-generated and the Deployment view is remapped when config files change, so stored relations can point to nodes that no longer exist; there is no rule for this and no way stated for the user to set the relation for a user-added operation.

> the system shall list all project operations in the X-Ray details panel

## Possible interpretations

- Only the project X-Ray (workspace root) is supported; folder X-Rays show no operations.
- Each X-Ray root has its own operations file; the window toolbar uses the workspace root's file.

## Resolution

AI: В первой версии операции принадлежат только проекту (корню рабочего пространства окна): один файл операций, folder X-Ray операций и кнопки Deploy не показывает. Связь с узлом необязательна, хранится как id и имя узла, задаётся пользователем в форме правки; связь с несуществующим узлом игнорируется при показе. — see DEC-027.
