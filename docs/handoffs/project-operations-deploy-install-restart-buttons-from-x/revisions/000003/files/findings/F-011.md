## Finding

The operations file can change at any moment (UI edit, hand edit, version-control update, re-discovery). Not defined: whether a running operation can be edited or deleted; what its panel shows if the entry disappears or its command changes; how the no-duplicate rule works if the operation's identifier changes in the file while it runs; and whether the command is re-read after confirmation. REQ-003 requires 'The command executed is exactly the command shown in the confirmation', which needs an explicit rule that the run uses the snapshot shown, not the file content at start time.

> shall not start a second run of the operation that is already running

## Possible interpretations

- A run uses a snapshot taken when the confirmation opened; later file changes affect only future runs.
- Editing and deleting are disabled while the operation runs (cannot be enforced for hand edits).

## Resolution

AI: Запуск использует снимок операции, сделанный при открытии подтверждения: выполняется ровно показанная команда, файл повторно не читается. Правка и удаление во время выполнения разрешены и влияют только на будущие запуски; панель помечает, что определение изменилось или удалено. — see DEC-022.
