## Finding

The file path, name, format and schema are not specified, although the file is a public, hand-editable, team-shared contract. REQ-007 depends on details that are missing: (1) how a user deletion is recorded so that 'an operation deleted by a user does not reappear' (a tombstone entry is implied but not stated); (2) how user-edited vs discovered state is recorded, and how a hand edit in the file is recognised as a user edit; (3) what identifies an operation across re-discovery runs, since AI-generated ids and labels are not guaranteed to be stable, which leads to duplicates or to overwriting the wrong entry; (4) behaviour on version-control merge conflicts and on simultaneous UI write and external edit; (5) schema versioning. DEC-004 also leaves as an 'Open assumption' what happens when re-discovery proposes a different command for a user-edited operation. In addition, provenance (REQ-005) includes absolute paths outside the project root; stored in a committed file this publishes local folder names of one user to the team.

> shall persist the operations list with these changes in a single file inside the project that can be committed to version control and edited by hand

## Possible interpretations

- A YAML or JSON file under `.dde/` (next to existing project state) with explicit `origin` and `deleted` fields per operation.
- A file under `docs/` so it is visible alongside the documentation.
- Provenance of external paths is stored in the shared file as-is, or is reduced to a non-identifying form, or is kept machine-local (contradicts 'No part of the operations list is stored only in machine-local state' unless provenance is declared not part of the list).

## Resolution

AI: Файл операций — `.markview/operations.json` в корне проекта (не в `.dde/`, которая в .gitignore), с версией схемы, стабильным id-slug, полем origin и явными tombstone-записями для удалений. Provenance хранится в файле, но пути вне проекта записываются в неидентифицирующем виде (относительно корня проекта или через `~`). — see DEC-017.
