## Finding

Not defined: what happens when the user clicks the notification (bring MarkView forward and open that operation's output panel, or nothing), when the macOS notification permission is requested (on first launch, or on first operation start), and whether the notification identifies the project when several projects are open. The 'cancelled' notification case requires cancel to happen while MarkView is in the background, which the spec provides no means for; the criterion can only be met in a race (cancel, then switch away before the process ends).

> the system shall post a macOS system notification that names the operation, its environment (if any) and the outcome

## Possible interpretations

- Clicking the notification activates MarkView and opens the operation's output panel.
- Permission is requested when the first operation is started.

## Resolution

AI: Клик по уведомлению активирует MarkView, выводит вперёд окно нужного проекта и открывает панель вывода этой операции; разрешение на уведомления запрашивается при первом запуске операции, а в тексте уведомления указывается имя проекта. Состояние «на переднем плане» проверяется в момент завершения процесса, поэтому случай «cancelled» остаётся и относится к отмене, завершившейся уже в фоне. — see DEC-029.
