## Context

REQ-005 requires confidence to be shown but defines no scale, so the criterion is not testable. The overview asks for low-confidence operations to be visibly marked. The overview's operation fields include prerequisites, which no requirement covers. REQ-005 does not say what a user-edited operation shows instead of confidence.

## Alternatives

1. Three levels (high / medium / low); low is visually marked in the list and in the confirmation.
2. Numeric score (0-100) with a threshold for low.
3. Prerequisites are informational text shown in the confirmation only.
4. Prerequisites are checked automatically before a run.
5. Prerequisites are out of the first version.

## Decision

(1) Confidence has exactly three values. high: the command appears verbatim in a file inside the project root. medium: the command was assembled from files inside the project root, or appears verbatim in a referenced folder outside the project root. low: any part of the command comes from a web source or is not supported by a verbatim source. (2) Discovery must assign the level by these rules; an operation with a web source can never be above low. (3) Operations with low confidence carry a visible mark in the operations list, in the Deploy picker and in the run confirmation. (4) No extra gate is added for low confidence: the confirmation before every run (DEC-002) is the review. (5) A user-edited operation shows the mark 'user-edited' in place of the confidence level; the discovered confidence and source remain stored as origin information and are shown only as 'originally discovered from ...'. A user-added operation shows 'user-added' and no confidence. (6) Prerequisites are an optional list of short text items per operation, produced by discovery and editable by the user. They are shown in the operation's details and in the run confirmation. The system does not check them and does not block a run because of them.

## Reason

Three levels with source-based definitions are testable and explainable to the user, unlike a numeric score produced by an AI. Automatic prerequisite checks would require executing probes, which is a separate feature and conflicts with read-only discovery.

## Consequences

REQ-005 gets the scale and marking criteria; REQ-003 shows the low mark and prerequisites; the operations file schema (DEC-017, proposed) needs the fields confidence and prerequisites. The overview sentence 'never run without review' is satisfied by DEC-002 and needs no separate rule. AI inference: the level is assigned by the AI pass, so the source type rules should also be verified natively where the source is recorded.
