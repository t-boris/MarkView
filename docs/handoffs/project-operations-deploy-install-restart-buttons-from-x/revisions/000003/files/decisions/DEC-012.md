## Context

The feature is marked ready, but overview.md still contains acceptance criteria that contradict DEC-002, DEC-003, DEC-008, DEC-009 and REQ-003, lists seven already decided items as open decisions, and carries an out-of-scope list marked 'proposed, not yet decided'. An implementer reading the overview would build a different product than the requirements describe.

## Alternatives

1. A: Requirements and decisions supersede the overview; rewrite the overview to match them and drop non-carried criteria until they are decided separately
2. B: Treat overview criteria as still binding wherever no requirement explicitly contradicts them
3. C: Leave the overview as a historical document and add a note that it is outdated

## Decision

Option A. Approved requirements and accepted decisions are the single source of truth. The overview is rewritten: the five contradicting criteria are replaced by text consistent with DEC-002, DEC-003, DEC-008, DEC-009 and REQ-003; the 'OPEN DECISIONS' section is removed and replaced by references to DEC-001..DEC-011 and the decisions made for F-002..F-008; the out-of-scope list (authoring deployment configuration, secrets management, remote monitoring after exit, scheduling or chaining, rollback unless discovered as a command) is recorded as confirmed for the first version. Overview criteria that have no corresponding requirement (e.g. low-confidence marking, refresh on source change) are not binding; each is either turned into a requirement or dropped when F-012 and F-017 are resolved.

## Reason

Two competing sources of acceptance criteria make the feature untestable. Requirements and decisions were produced from explicit user answers, while the overview predates them. The out-of-scope list was confirmed here by the facilitator on the team's delegation, not by a direct user statement; none of the accepted decisions contradicts it.

## Consequences

The overview must be edited before implementation starts; until then the feature status 'ready' is not accurate. Production-specific confirmation, node-filtered operation lists and first-run-only confirmation are no longer described anywhere. Criteria dropped from the overview remain open through F-012 and F-017. If the user disagrees with any out-of-scope item, it must be reopened as a separate decision.
