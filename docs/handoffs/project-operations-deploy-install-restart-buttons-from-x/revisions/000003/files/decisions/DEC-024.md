## Context

REQ-004 requires an operation with no usable command to be reported as not determined, but not where. REQ-008 shows the Deploy button when at least one deploy operation exists. The overview criterion that the Deployment view explains that no runnable procedure was found has no requirement. DEC-016 (proposed) places the discovery actions in the Deployment view details panel.

## Alternatives

1. A 'not determined' operation is a list entry without a command; it cannot be started and does not count for the Deploy button until the user supplies a command.
2. It is shown only in the discovery result summary and is not persisted.

## Decision

(1) Every entry in the operations file has a non-empty command; 'not determined' results are never written to the file. (2) After discovery, the discovery report in the Deployment view details panel lists each 'not determined' result with its presumed kind, environment (if any), what was investigated and why no command was proposed. (3) Each such item offers 'Add command', which opens the add-operation form prefilled with kind, environment and label; saving creates a user-added operation. (4) The report, including 'not determined' items, stays available in the details panel until the next discovery run or until the user dismisses it; it is machine-local. (5) 'Not determined' items do not count as operations: they do not appear in the Deploy picker and do not make the Deploy button visible. (6) Empty state: when the project has no operations, the Deployment view details panel shows an explanation that no runnable procedure is known, with the actions 'Discover operations' (or 'Re-discover') and 'Add operation'. When discovery ran and found nothing, the text says so. (7) The project window toolbar shows no Deploy button and no explanation when there is no deploy operation.

## Reason

Keeping the file limited to runnable operations keeps the schema, the Deploy button rule and the run path simple, and avoids committing empty placeholders to the team's repository. The report plus a one-step 'Add command' still lets the user complete the result.

## Consequences

Team members do not see another member's 'not determined' results; they see them only after running discovery themselves. REQ-004 gets criteria for the report; a new requirement is needed for the empty state. The toolbar gives no hint that discovery is possible; the entry point is the Deployment view only.
