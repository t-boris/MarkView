## Statement

While an operation is running, the system shall allow the user to start any other operation of the same project, and shall not start a second run of the operation that is already running.

## Acceptance Criteria

- [ ] With one operation running, starting a different operation of the same project (after the confirmation defined in REQ-003) launches a second subprocess and both run at the same time.
- [ ] Deploy operations for two different environments can run at the same time.
- [ ] The start control of a running operation is unavailable at every entry point (both Deploy buttons and the operations list) and shows that the operation is running.
- [ ] After the running operation ends (succeeded, failed or cancelled), it can be started again.
- [ ] The end of one operation, including failure or cancel, does not change the state of the other running operations.
