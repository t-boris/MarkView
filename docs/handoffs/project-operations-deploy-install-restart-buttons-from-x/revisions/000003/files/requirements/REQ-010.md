## Statement

While the Deployment view is shown, the system shall list all project operations in the X-Ray details panel, and when a deployment node is selected, shall show the operations related to that node first and visually highlighted, followed by all remaining project operations.

## Acceptance Criteria

- [ ] With the Deployment view open and no node selected, the details panel lists every project operation, grouped by kind.
- [ ] With a node selected that has related operations, those operations appear at the top of the list, visually distinguished from the rest, and every other project operation appears below them.
- [ ] With a node selected that has no related operations, the details panel lists every project operation with no highlighted section.
- [ ] No operation is hidden from the list because of the node selection.
- [ ] An operation without a node relation, including a user-added one, always appears in the list.
- [ ] Each listed operation can be started from the list and follows the same confirmation and run rules as any other start point.
