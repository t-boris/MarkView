## Statement

When the user requests to run any operation, the system shall ask for explicit confirmation before starting the subprocess, showing the operation label, the environment (if any), the exact command and the working directory, for every run, every operation kind and every environment.

## Acceptance Criteria

- [ ] Requesting a run of any operation (from the Deploy button or the details panel) opens a confirmation showing the operation label, environment if any, exact command and working directory.
- [ ] No subprocess is started until the user confirms; dismissing or cancelling the confirmation starts nothing and leaves the operation state unchanged.
- [ ] The confirmation appears on every run, including repeated runs of the same operation, for all operation kinds and all environments.
- [ ] The confirmation offers no option to skip it for future runs.
- [ ] The command executed is exactly the command shown in the confirmation.
