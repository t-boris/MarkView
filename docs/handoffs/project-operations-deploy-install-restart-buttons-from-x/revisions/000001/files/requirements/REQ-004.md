## Statement

When operation discovery cannot determine an operation's command from the project's own files, the system shall investigate automatically, first in local folders outside the project root and then on the web, without asking the user for permission.

## Acceptance Criteria

- [ ] Given a project whose install procedure lives in another local folder, discovery reads that folder and proposes a command without showing any permission prompt.
- [ ] Given tooling that discovery does not recognise and that local folders do not explain, discovery performs a web search and proposes a command or reports that none was found.
- [ ] Local folders are investigated before any web search is made.
- [ ] Discovery only reads: it does not execute commands and does not create, modify or delete files.
- [ ] When investigation finds no usable command, the operation is reported as not determined instead of being shown with a guessed command.
