## Statement

When operation discovery runs again, the system shall keep user-edited operations, user-added operations and user deletions recorded in the project operations file unchanged, regardless of which team member or machine made them, and shall add or update only operations the user has not changed.

## Acceptance Criteria

- [ ] After re-discovery, an operation whose command or working directory was edited by a user keeps the edited values.
- [ ] After re-discovery, a user-added operation is still in the list and unchanged.
- [ ] After re-discovery, an operation deleted by a user does not reappear.
- [ ] User changes that arrived through the shared operations file from another machine are preserved in the same way as changes made locally.
- [ ] Re-discovery adds newly found operations and updates unchanged discovered operations in the project operations file.
