## Statement

While the project has at least one deploy operation, the system shall show a Deploy button with an environment picker in the X-Ray toolbar, in every X-Ray view, and in the project window toolbar, and both buttons shall offer the same environments and start the same deploy operations.

## Acceptance Criteria

- [ ] With at least one deploy operation in the project operations list, the Deploy button is visible in the X-Ray toolbar in every X-Ray view and in the project window toolbar.
- [ ] With no deploy operation in the list, neither button is shown.
- [ ] Both buttons list exactly the environments of the deploy operations in the operations list; with a single deploy operation no picker step is required.
- [ ] Adding, editing or deleting a deploy operation is reflected in both buttons without restarting the app.
- [ ] Starting a deploy from either button goes through the confirmation defined in REQ-003 before the subprocess starts.
- [ ] While a deploy operation is running, both buttons indicate that an operation is running.
