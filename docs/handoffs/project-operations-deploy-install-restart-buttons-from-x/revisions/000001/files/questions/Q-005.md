## Question

Кому принадлежит список операций проекта: только текущему пользователю на этой машине или всей команде через файл в репозитории?

## Why it matters

После ответа C список операций стал данными пользователя: в нём есть правки и собственные команды. Если список общий, команда, написанная одним человеком, будет запускаться у другого — это меняет требования к хранению, к пометкам происхождения и к доверию перед запуском. Это открытое решение №6 из обзора.

## Options

- **A**: Только локально: операции и правки хранятся в локальном состоянии проекта на этой машине и не попадают в репозиторий.
- **B**: Общий файл проекта: операции хранятся в файле внутри проекта, который можно закоммитить и править вручную.
- **C**: Общий файл плюс локальные переопределения: общий список в репозитории, личные правки хранятся локально поверх него.

## Answer

B. Общий файл проекта: операции хранятся в файле внутри проекта, который можно закоммитить и править вручную.
