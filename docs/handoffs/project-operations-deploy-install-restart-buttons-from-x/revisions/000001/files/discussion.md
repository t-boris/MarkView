# Discussion — Project operations: Deploy / Install / Restart buttons from X-Ray Deployment

### Answer to Q-001 · 2026-09-29

Каким способом должна выполняться выбранная операция (deploy / install / restart)?

B. Запускать отдельный подпроцесс с собственной панелью вывода, статусом и кнопкой отмены.

### Answer to Q-002 · 2026-09-29

Какие защитные меры нужны перед запуском операции в production-подобном окружении?

D. Подтверждение перед каждым запуском любой операции в любом окружении.

### Answer to Q-003 · 2026-09-29

Что этап обнаружения операций может делать без отдельного разрешения пользователя, когда инструмент незнаком или процедура лежит вне проекта

A. Всё автоматически: обнаружение само читает папки вне корня проекта и ищет в вебе, затем сообщает, что и где нашло.

### Answer to Q-004 · 2026-09-29

Может ли пользователь исправлять найденные операции, и что происходит с его правками при повторном обнаружении?

C. Как B, плюс пользователь может добавлять собственные операции и удалять найденные.

### Answer to Q-005 · 2026-09-29

Кому принадлежит список операций проекта: только текущему пользователю на этой машине или всей команде через файл в репозитории?

B. Общий файл проекта: операции хранятся в файле внутри проекта, который можно закоммитить и править вручную.

### Answer to Q-006 · 2026-09-29

Где должна находиться кнопка «Deploy» с выбором окружения?

D. В панели инструментов X-Ray и в панели инструментов окна проекта одновременно.

### Answer to Q-007 · 2026-09-29

Что должно происходить, когда запущенная операция запрашивает ввод у пользователя (пароль, подтверждение y/n, код 2FA)?

A. Панель вывода принимает ввод: пользователь может печатать в неё, и текст передаётся процессу.
