## Finding

DEC-005 notes 'Working directories outside the project root may not exist on other machines', but no requirement says whether working directories are stored relative to the project root, whether absolute or home-relative paths are allowed, or how an operation whose working directory does not exist on this machine is presented before the run (REQ-001 only covers failure at start). Discovery that finds an install procedure in another local folder (REQ-004) will by design produce such machine-specific paths and commit them to the shared file.

> edit the command and working directory of a discovered operation

## Possible interpretations

- Paths inside the project are stored relative to the project root; paths outside are stored as written and marked as machine-specific.
- Operations with a missing working directory are shown as unavailable with the reason, before the user tries to run them.

## Resolution

AI: Рабочие каталоги хранятся относительно корня проекта (допускается ../ для соседних репозиториев); пути вне корня, которые так не выразить, — через ~ или абсолютно, с пометкой «machine-specific». Операция с отсутствующим на этой машине каталогом показывается недоступной с причиной ещё до запуска. — see DEC-025.
