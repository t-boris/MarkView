## Context

The original request said the Deploy button with an environment picker should be 'somewhere'. The placement determines whether a deployment can be started only with X-Ray open or from anywhere in the project, and where the operation output must be visible. The operations list in the X-Ray details panel is already in scope and is not affected.

## Alternatives

1. A: X-Ray toolbar only; visible in any X-Ray view while X-Ray is open.
2. B: Project window toolbar only; visible whenever the project has a deploy operation.
3. C: No separate button; Deploy is the first operation in the details panel list of the Deployment view.
4. D: Both the X-Ray toolbar and the project window toolbar.

## Decision

Option D: the Deploy button with the environment picker is shown in the X-Ray toolbar and in the project window toolbar. Both buttons start the same deploy operations and reflect the same state.

## Reason

The user chose D: deployment must be reachable both from the deployment map and from anywhere in the project.

## Consequences

Largest scope of the four options. The two entry points must stay consistent (same environments, same visibility rule, same running state). The operation output panel must be reachable outside X-Ray, which refines REQ-002. A potentially dangerous action is permanently visible in the project window; the only safeguard is the confirmation before every run (DEC-002, REQ-003).
