## Statement

When operation discovery runs, the system shall propose every operational command it finds for the project and shall classify each one as exactly one of the kinds deploy, install, build, clean, restart or other.

## Acceptance Criteria

- [ ] Given a project whose files define deploy, install, build, clean and restart commands, when discovery completes, then the operations list contains an operation of each of these kinds.
- [ ] Given a project with an operational command that fits none of the named kinds (for example a database migration), when discovery completes, then the command is listed as an operation of kind "other".
- [ ] Each discovered operation has exactly one kind, and the kind is shown in the operations list.
- [ ] Given several environments found in the project, when discovery completes, then there is one deploy operation per environment.
- [ ] An operation of kind "other" can be run, edited and deleted in the same way as operations of any other kind.
