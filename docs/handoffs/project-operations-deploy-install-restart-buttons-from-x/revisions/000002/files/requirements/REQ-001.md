## Statement

When the user starts a discovered operation, the system shall run its command as a dedicated subprocess in the operation's working directory, separate from the embedded terminal tabs and from the AI agent terminal, shall execute exactly the command the user reviewed, and shall run it so that the command can prompt for and receive interactive input from the operation's output panel.

## Acceptance Criteria

- [ ] Starting an operation launches a subprocess with the operation's command and working directory; no terminal tab is opened and no AI agent is involved in execution.
- [ ] The executed command is identical to the command shown to the user for review.
- [ ] The operation state is shown as running while the process is alive, including while it waits for input, succeeded when it exits with code 0, and failed with the exit code displayed when it exits with a non-zero code.
- [ ] If the process cannot be started (e.g. working directory or executable missing), the operation is shown as failed with the reason.
- [ ] A command that prompts only when it is attached to a terminal (e.g. a password prompt from sudo or ssh) prompts when run as an operation and receives the answer typed in the output panel.
