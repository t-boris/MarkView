# Assistant call sites

Every place MarkView calls an assistant (Claude Code, Codex, Antigravity; Copilot CLI left out at Boris's request), the button or
automatic step behind it, how many calls one action makes, and whether independent calls run at the same time. Audited at `main`
`e0925e07` (7.14.0, 2026-11-27) in three read-only passes, one row per call site or wrapper caller with file:line evidence; line
numbers in the tables are at that commit. Rows found unbounded or sequential there were changed in 7.15.0 (below).

## How each assistant runs independent work

One-shot runs go through `AIOperation` -> `CLICompletion` -> the provider's `launch`. A request with `readableFolder` may read files;
without it the call is text in, text out, with no tools, and nothing inside the call can run in parallel.

| Assistant | One-shot run with a readable folder | Prompt into an agent session |
|---|---|---|
| Claude Code | `--tools Read,Grep,Glob,Agent`: it may start subagents (probe: two Explore subagents at once); X-Ray's code analysis and traces run without `Agent` (7.21.1) | `ParallelWork`: subagents with the Agent tool; for a list, "use a workflow" |
| Codex | read-only sandbox; since 7.16.0 the run keeps its session and is asked to start subagents for independent parts, and the session is deleted when the run ends (`codex delete --force`); without a folder `--ephemeral`, subagents off; except X-Ray's code analysis and traces (7.21.1, BUG-135: `subagents = false`, `--ephemeral`, agents off), whose subagents re-read the code (1.3M input tokens instead of 60-300k) | an explicit request to start subagents (Codex starts them only when asked) |
| Antigravity | `read_file` allowed; `-p` starts `invoke_subagent` subagents (probe) | its `invoke_subagent` mechanism |
| Copilot CLI | not changed (Boris: "skip copilot agent") | not changed |

Goals (7.20.0, PR #467, Boris 2026-11-27 "add /goal to every agent"): Fix with AI, the bug basket, a feature hand-off and a
`markview_agent_send` goal are sent in each assistant's own goal command, so it goes on until the work is done: Claude `/goal`, Codex
`/goal` (0.172; an objective over 4000 characters is moved by its TUI to `goal-objective.md`), Antigravity `/goal` (1.5.18, "Run until
the specified goal is completely finished"), Copilot `/autopilot <objective>` (1.0.114). Cline has no goal command and keeps the
numbered request. The prompts go to terminals, not ACP, so the slash commands work.

- Prompts into sessions: 11 `sendToAssistant` starts and 4 `ParallelWork.ask` calls all append the provider's sentence; the Cockpit
  step prompt has its own (delegation when allowed and marked, DEC-038); `markview_agent_send` adds it for a goal and, since 7.15.0,
  for `work: parts|items`. A plain send (an answer, a follow-up) is pasted as written.
- Codex in one-shot runs (probe, codex 0.172): `--ephemeral` keeps no session, so a subagent cannot start ("no rollout"). Without it,
  two subagents ran at the same time (children 45.7-56.0 s and 49.5-67.2 s), `codex delete --force <id>` removed the session and its
  children, and `resume --last` skips such sessions unless `--include-non-interactive`. Boris chose (2026-11-27) to keep the session
  for the run and delete it afterwards (7.16.0, `KeptSessions` in `CLICompletion.swift`): it is noted under Application Support while
  the run lasts, deleted after an answer, an error, a timeout or a stop, and a crash's leftovers are deleted at the next launch. Live
  on the app's command line: three independent modules, four `collab_tool_call` (`wait`) items, the session gone after the delete.

### Assistant call audit, group 1: X-Ray models (MarkView/Models/Architecture), DiagramAI and every caller, Book PDF, and the Workspace AI tool runs and DocumentTranslator (main @ e0925e07)

How to read the table:
- **Repairs.** `AIOperation.execute` (AIOperation.swift:270-305) asks again only after it rejects an answer, and the repair prompt contains the rejected answer. "+<=N repair" means up to N conditional retries of the same call. They are not counted as separate calls.
- **Cache.** `ArchitectureStore.xrayCall` (ArchitectureStore.swift:606-656) caches each answer under `.dde/cache/xray`, keyed by tool, model, prompts and schema (:615-619). Repeating an action can therefore make 0 calls. xrayCall itself runs no tools and only reads the request. `assistantCall` (:1942-1944) is a thin pass-through to xrayCall (protocol `ArchitectureHost`).
- **Limit.** `CLICompletion.sideBySide = 3` (CLICompletion.swift:19).
- **Wrapper rows.** The wrappers (`xrayCall`, `assistantCall`, `DiagramAI.generate`, `runMarkdownCall`/`markdownCall`, `auditDiagram`, `BookPDFAssistant`, `ImportanceRater.operation`, `FilterSearch.terms`) have no row of their own. Each of their callers has a row.
