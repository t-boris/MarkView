## Question

Какие защитные меры нужны перед запуском операции в production-подобном окружении?

## Why it matters

Теперь запуск — это нажатие кнопки, а не ввод команды в терминале, поэтому случайный деплой в production становится проще. От ответа зависят требования к подтверждению запуска и критерии приёмки для кнопки Deploy. В объёме уже есть просмотр команды перед первым запуском, но не решено, что происходит при повторных запусках и чем production отличается от dev.

## Options

- **A**: Без дополнительных мер: достаточно просмотра команды перед первым запуском, одинаково для всех окружений.
- **B**: Диалог подтверждения перед каждым запуском в production-подобном окружении, с показом команды и окружения.
- **C**: Для production-подобного окружения пользователь должен ввести имя окружения, чтобы запустить операцию.
- **D**: Подтверждение перед каждым запуском любой операции в любом окружении.

## Answer

D. Подтверждение перед каждым запуском любой операции в любом окружении.
