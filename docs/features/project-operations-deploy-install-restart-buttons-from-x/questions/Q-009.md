## Question

Какие операции показывает панель деталей X-Ray, когда выбран конкретный узел развёртывания?

## Why it matters

Список операций в панели деталей входит в идею функции, но требования на него ещё нет. Для вида Deployment без выбранного узла всё ясно — показывается весь список. Для выбранного узла не решено, сужается ли список. Факт проекта: в схеме развёртывания узлы не связаны с командами, а в списке полей операции (обзор, Scope) нет ссылки на узел. Вывод ИИ: сужение по узлу потребует, чтобы обнаружение определяло связь операции с узлом, и эта связь может быть ошибочной или отсутствовать.

## Options

- **A**: Всегда весь список операций проекта, сгруппированный по виду (deploy, install, build и т.д.), независимо от выбранного узла.
- **B**: При выбранном узле — только операции, связанные с этим узлом; если для узла связей нет, показывается весь список.
- **C**: При выбранном узле связанные с ним операции показываются первыми и выделены, ниже — остальные операции проекта.

## Answer

C. При выбранном узле связанные с ним операции показываются первыми и выделены, ниже — остальные операции проекта.
