## Question

Как пользователь должен узнавать о завершении операции, если панель вывода не видна или MarkView не на переднем плане?

## Why it matters

Факт проекта: операции долгие и могут выполняться параллельно (DEC-008), а состояние сейчас показывается только в панели вывода (REQ-002). Вывод ИИ: без решения об оповещениях пользователь может пропустить неудачный deploy; это последнее незакрытое решение владельца продукта.

## Options

- **A**: Только внутри приложения: состояние в панели вывода и индикатор на кнопке Deploy / в списке операций. Системных уведомлений нет.
- **B**: Индикаторы внутри приложения плюс системное уведомление macOS о любом завершении (ус��ех, ошибка, отмена), когда MarkView не на переднем плане.
- **C**: Индикаторы внутри приложения плюс системное уведомление только при ошибке.

## Answer

B. Индикаторы внутри приложения плюс системное уведомление macOS о любом завершении (ус��ех, ошибка, отмена), когда MarkView не на переднем плане.
