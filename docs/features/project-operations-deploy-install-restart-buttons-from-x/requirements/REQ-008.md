## Statement

While the project has at least one deploy operation, the system shall show a Deploy button with an environment picker in the X-Ray toolbar, in every X-Ray view, and in the project window toolbar, both buttons shall offer the same environments and start the same deploy operations, and both shall indicate which deploy operations are currently running.

## Acceptance Criteria

- [ ] With at least one deploy operation in the project operations list, the Deploy button is visible in the X-Ray toolbar in every X-Ray view and in the project window toolbar.
- [ ] With no deploy operation in the list, neither button is shown.
- [ ] Both buttons list every non-deleted deploy operation, grouped by environment; unnamed environments appear first, and multiple targets in one environment remain separate entries. With one deploy operation no picker step is required.
- [ ] Adding, editing or deleting a deploy operation is reflected in both buttons without restarting the app.
- [ ] Starting a deploy from either button goes through the confirmation defined in REQ-003 before the subprocess starts.
- [ ] While at least one deploy operation is running, both buttons indicate that a deploy is running.
- [ ] In the picker of both buttons, each running operation and its environment group are marked as running; that operation cannot be started again while other operations remain startable.
- [ ] From a running operation in either button, the user can open that operation's output panel.
- [ ] A dispatched remote-trigger operation is labelled "dispatched" with a note that the remote run is not tracked.
