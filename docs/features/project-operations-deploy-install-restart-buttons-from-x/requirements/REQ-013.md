## Statement

When an operation ends as succeeded, failed or cancelled while MarkView is not the frontmost application, the system shall post a macOS system notification that names the operation, its environment (if any) and the outcome.

## Acceptance Criteria

- [ ] Given MarkView is in the background, when an operation succeeds, a macOS notification is posted with the operation label, the environment (if any) and the outcome succeeded.
- [ ] Given MarkView is in the background, when an operation fails, the notification states the failure and the exit code.
- [ ] Given MarkView is in the background, when an operation is cancelled, a notification states that it was cancelled.
- [ ] Given MarkView is the frontmost application, when an operation ends, no system notification is posted.
- [ ] Given several operations end while MarkView is in the background, one notification is posted per operation.
- [ ] Given the user has denied notification permission, operations still run and end normally and the in-app indicators show the final state.
- [ ] A successful remote trigger notification says dispatched and states that the remote run is not tracked.
