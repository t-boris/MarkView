## Statement

A discovered operation with low confidence shall be visibly marked before it can run.

## Acceptance Criteria

- [ ] The Deployment operations list marks an unedited low-confidence command.
- [ ] Both Deploy pickers identify low-confidence deploy commands.
- [ ] The confirmation shows low confidence and the command's provenance.
- [ ] After the user edits the command, the UI identifies it as user-edited rather than applying discovery confidence to the edited command.
