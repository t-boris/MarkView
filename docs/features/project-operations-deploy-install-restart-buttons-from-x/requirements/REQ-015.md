## Statement

The app shall remain responsive while one or more operations stream output, including high-volume output.

## Acceptance Criteria

- [ ] While an operation produces continuous output, the user can switch tabs, edit a document and use X-Ray.
- [ ] Two concurrent operations keep separate output and neither blocks interaction.
- [ ] Output is bounded in memory; when older output is removed, the panel displays an explicit marker.
