## Statement

When a source file recorded for a discovered operation changes or disappears after discovery, the Deployment details panel shall show a non-blocking source-change hint next to Re-discover.

## Acceptance Criteria

- [ ] A changed or removed recorded project or external source displays a source-change hint.
- [ ] Changing an unrelated file does not display that hint.
- [ ] The hint does not change, disable, or remove operations and never starts discovery automatically.
- [ ] After successful re-discovery, the hint clears. Source fingerprints remain machine-local.
