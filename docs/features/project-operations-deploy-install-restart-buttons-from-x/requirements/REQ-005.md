## Statement

When operation discovery completes, the system shall show for each discovered operation where its command came from, including every location outside the project root that was read and every web source that was used, together with the confidence of the result; the system shall visibly distinguish operations whose command was edited or added by the user from operations whose command is exactly as discovered.

## Acceptance Criteria

- [ ] Each discovered operation shows the source file and line, or the web source, its command was derived from.
- [ ] Each operation derived from outside the project root or from the web is visibly marked as such.
- [ ] The user can see the list of folders outside the project root that discovery read and the web sources it consulted.
- [ ] Each discovered operation shows its confidence.
- [ ] The provenance and confidence of an operation are visible before the user confirms its first run.
- [ ] An operation whose command or working directory was edited by the user is marked as user-edited and does not present the discovery confidence as applying to the edited command.
- [ ] An operation added by the user is marked as user-added and shows no discovery source or confidence.
