## Statement

While an operation is running and after it ends, the system shall show the operation's state on its entry in the operations list and on both Deploy buttons, independently of whether the operation's output panel is visible.

## Acceptance Criteria

- [ ] Given a running operation whose output panel is hidden, its entry in the operations list shows the running state.
- [ ] Given a running deploy operation, both the X-Ray toolbar Deploy button and the project window toolbar Deploy button show a running indicator.
- [ ] When an operation ends, its entry in the operations list shows the final state: succeeded, failed or cancelled; a successful remote trigger shows dispatched and states that the remote run is not tracked.
- [ ] Given several operations running at the same time, each entry in the operations list shows its own state.
