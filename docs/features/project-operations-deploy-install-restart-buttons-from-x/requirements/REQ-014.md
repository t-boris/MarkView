## Statement

A running operation shall have no default elapsed-time limit. It ends through its own exit, explicit cancellation, or confirmed project close or app quit.

## Acceptance Criteria

- [ ] An operation that runs longer than 60 seconds remains running and accepts input.
- [ ] No existing AI or noninteractive runner timeout ends an operation.
- [ ] Cancel and confirmed close or quit still terminate the process group.
