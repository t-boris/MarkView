## Statement

Discovery shall start only from an explicit Discover or Re-discover action and shall expose phase progress and cancellation.

## Acceptance Criteria

- [ ] Opening a project or running X-Ray analysis does not start operation discovery.
- [ ] The details panel shows the project-files, external-folders, or web phase while discovery runs.
- [ ] Cancelling or failing discovery leaves `.markview/operations.json` byte-for-byte unchanged and gives a reason.
- [ ] Successful discovery updates the shared file once after validation, preserving user changes.
