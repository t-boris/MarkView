## Statement

The Deployment details panel shall explain when no runnable procedure is known and retain the discovery report's undetermined findings.

## Acceptance Criteria

- [ ] The empty Deployment details panel states that no runnable procedure is known, including before an AI deployment map exists.
- [ ] An unresolved procedure appears only in the discovery report with its reason and investigated sources; it has no runnable button.
- [ ] The user can add a command from an unresolved report item.
