## Statement

The system shall let the user edit the command and working directory of a discovered operation, add their own operations, and delete operations from the list, and shall persist the operations list with these changes in a single file inside the project that can be committed to version control and edited by hand.

## Acceptance Criteria

- [ ] Editing, adding or deleting an operation in the UI changes the project operations file, and the change is still present after the application restarts.
- [ ] The operations file is located inside the project root and is plain text that a person can read and edit.
- [ ] An operation changed, added or removed by editing the file by hand, or by a version control update, appears accordingly in the operations list without running discovery.
- [ ] A fresh clone of a repository that contains the operations file shows the same operations list without running discovery.
- [ ] No part of the operations list is stored only in machine-local state.
- [ ] When the operations file cannot be read or is invalid, the system shows an error that names the file, and does not overwrite the file.
