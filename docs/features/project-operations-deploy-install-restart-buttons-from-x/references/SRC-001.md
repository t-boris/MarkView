## Summary

The original spoken request from the user asking that X-Ray's deployment analysis also discover how the project is deployed and expose those procedures as buttons: a Deploy button with an environment picker, plus further operation buttons (clean, install, restart, etc.) shown on the right when the deployment is selected. It stresses that deploy and install can be complex, long-running processes, and that unknown tooling or an install living in another project must be investigated via the web or local folders before deciding how to run it. Placement, the exact operation list and the execution mechanism are left open.

Но иногда install, он может использовать некоторые утилиты, которые ты не знаешь, тогда тебе надо сначала будет посмотреть в интернете, либо в локальных фолдерах, знаешь, иногда бывает install — это вообще какой-то другой проект. То есть это надо будет поискать и решить, как всё-таки делать install или деплой.
