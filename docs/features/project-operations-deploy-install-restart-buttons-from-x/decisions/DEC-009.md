## Context

The X-Ray details panel must show project operations for the Deployment view and for a selected deployment node. The deployment schema has no link between nodes and commands, so any operation-to-node relation comes from discovery or from the user and may be wrong or missing.

## Alternatives

1. A: Always show the full project operations list grouped by kind, regardless of the selected node.
2. B: With a node selected, show only operations related to that node; fall back to the full list when the node has no related operations.
3. C: With a node selected, show related operations first and highlighted, followed by the remaining project operations.

## Decision

Option C: when a deployment node is selected, the details panel shows the operations related to that node first and visually highlighted, and below them all remaining operations of the project. With no node selected in the Deployment view, the full list is shown.

## Reason

User choice. No operation is ever hidden because of a wrong or missing node relation, while node selection still helps to find the relevant operation.

## Consequences

Each operation needs an optional relation to one or more deployment nodes, determined by discovery. A wrong or missing relation only affects ordering and highlighting, never availability. The list can stay long in projects with many services.
