## Context

The overview said the Deploy button appears in every view of the project X-Ray. The pull-request X-Ray tab shows the project's architecture, but every operation bridge handler is limited to the project and folder scopes, so the tab has no Deploy button and cannot list or run operations (BUG-038). Boris was asked whether this is intended.

## Alternatives

1. Add the Deploy button and operations list to the pull-request X-Ray tab (needs the bridge handlers to accept the pull-request scope).

## Decision

The pull-request X-Ray tab has no operations UI: no Deploy button, no operations list and no way to run an operation from it. The project window toolbar and every other view of the project X-Ray keep their Deploy controls.

## Reason

That tab is for reviewing the changes of a pull request, not for running project operations; the operations stay one click away in the project window toolbar and the project X-Ray. Decided by Boris in the conversation of 2026-11-02.

## Consequences

The overview's Implementation contract is reworded to name this exception. BUG-038 is closed without a code change. DEC-027 (operations belong to the workspace root only; folder X-Rays have no operations UI) is unchanged.
