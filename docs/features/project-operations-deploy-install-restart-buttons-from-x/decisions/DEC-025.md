## Context

The operations file is shared through version control (DEC-005). Discovery may find procedures in folders outside the project root (DEC-003), producing paths that may not exist on other machines. REQ-001 covers a missing working directory only as a failure at start.

## Alternatives

1. Paths inside the project are stored relative to the project root; paths outside are stored as written and marked as machine-specific.
2. Only paths inside the project root are allowed as working directory.
3. Store absolute paths and let the run fail at start.

## Decision

(1) A working directory is stored as a path relative to the project root, with '.' for the root itself, whenever the target is inside the project root. (2) A target outside the project root is stored relative to the project root using '../' when it is within two levels above the project root, otherwise home-relative with '~' when it is under the user's home folder, otherwise absolute. (3) Only '~' is expanded; environment variables in the working directory are not expanded. (4) The UI accepts any of these forms in the edit form and normalises on save by the rules above. (5) An operation whose working directory resolves outside the project root is marked 'outside project'; one stored home-relative or absolute is additionally marked 'machine-specific'. (6) When the operations list or the Deploy picker is shown, and again when the confirmation opens, the system checks that the working directory exists. If it does not, the operation is shown as unavailable with the resolved path and the reason, its start control is disabled, and editing remains possible. (7) The check is repeated whenever the list is refreshed; no file change is made by the check.

## Reason

Relative paths make the common cases (project root, sibling repository) work on every team member's machine; an early, explained unavailability is better than a failed run after confirmation.

## Consequences

Machine-specific paths may still be committed; the mark makes this visible but does not prevent it. No per-user override of the working directory exists in the first version, because REQ-006 forbids machine-local parts of the operations list. REQ-006 and REQ-001 need added criteria; the schema of DEC-017 (proposed) must state the path forms. Open assumption: the two-level limit for '../' is a product choice.
