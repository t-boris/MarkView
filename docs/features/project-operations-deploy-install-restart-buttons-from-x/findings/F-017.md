## Finding

Several overview acceptance criteria that do not conflict with any decision are not covered by REQ-001..REQ-013 and would be lost in implementation and testing: no default timeout for operations (project fact: the existing non-interactive runner has a 60 s default); 'the UI remains responsive, and the user can keep working in other tabs while it runs'; the explanation shown when no deploy procedure is found; refresh of operations when source files change and a manual re-discover action; visible marking of low-confidence operations.

> Operations running longer than 60 seconds are not terminated by a default timeout.

## Resolution

AI: Добавляем недостающие требования: операции не имеют таймаута по умолчанию, интерфейс остаётся отзывчивым во время выполнения, низкая уверенность помечается визуально, пустой результат объясняется, есть ручное «Re-discover». Автоматическое обновление при изменении исходных файлов не делаем (это противоречит DEC-016) — вместо него показываем ненавязчивую пометку «источники изменились» с предложением запустить повторное обнаружение. — see DEC-028.
