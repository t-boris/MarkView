## Finding

The confidence scale (levels or number) and its meaning are not defined, so the criterion is not testable. The overview requires 'low-confidence operations are visibly marked and never run without review', but no requirement defines a low-confidence threshold or marking. The overview's operation fields include 'prerequisites', which appear in no requirement: it is unknown whether they are displayed, checked before a run, or dropped. REQ-005 also says a user-edited operation 'does not present the discovery confidence as applying to the edited command' without saying what is shown instead.

> Each discovered operation shows its confidence.

## Possible interpretations

- Three levels (high / medium / low); low is visually marked in the list and in the confirmation.
- Prerequisites are informational text shown in the confirmation only.
- Prerequisites are out of the first version.

## Resolution

AI: Уверенность — три уровня (high / medium / low) с фиксированными определениями; low визуально помечается в списке и в подтверждении. Предварительные условия — информационный текст в деталях операции и в подтверждении, без автоматической проверки; у отредактированной операции вместо уверенности показывается метка «user-edited». — see DEC-023.
