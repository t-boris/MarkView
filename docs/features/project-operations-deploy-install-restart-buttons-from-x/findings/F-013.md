## Finding

It is not defined where and how a 'not determined' operation is reported: as a non-runnable entry in the operations list and file (which the user can complete by editing), or only in a discovery report. If it is an entry, its effect on the Deploy button (REQ-008 counts deploy operations) is undefined. The empty state is also missing from the requirements: the overview criterion 'the Deployment view explains that no runnable deployment procedure was found' has no requirement, and the project window toolbar has no place for such an explanation.

> When investigation finds no usable command, the operation is reported as not determined instead of being shown with a guessed command.

## Possible interpretations

- A 'not determined' operation is a list entry without a command; it cannot be started and does not count for the Deploy button until the user supplies a command.
- It is shown only in the discovery result summary and is not persisted.

## Resolution

AI: «Не определённая» операция не записывается в файл операций и не учитывается для кнопки Deploy: она показывается в отчёте об обнаружении с действием «Add command», которое создаёт пользовательскую операцию. Пустое состояние объясняется в панели деталей представления Deployment; в тулбаре окна кнопки просто нет. — see DEC-024.
