## Finding

The Git ownership test failed after waiting only for the second requested ignore entry and then immediately checking both. The first operation may still be running: the implementation starts separate tasks, and the test did not wait for the first to finish. See `/tmp/markview-ci-qa-editor-failure.log` and [CI run 44310136371](https://github.com/t-boris/MarkView/actions/runs/44310136371).

## Resolution

The test now waits for both entries before asserting the result, retaining the requirement that neither operation is lost. The focused test passed locally with the ARM-only hosted configuration in 8.4 seconds (`/tmp/markview-editor-arm-ci-fixes.log`). CI verification remains pending; if both entries still do not arrive the production implementation must be investigated.
