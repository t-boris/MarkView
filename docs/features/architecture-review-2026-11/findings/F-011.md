## Finding

The networking scenario failed four assertions on CI: background mapping had completed before the test observed the ready page, so the test's expected preparation and group ordering did not occur. The same test passed locally in 43.6 seconds. See `/tmp/markview-ci-studio-network-failure.log` and [CI run 44302387150](https://github.com/t-boris/MarkView/actions/runs/44302387150).

## Resolution

The isolated assistant fixture now holds the relevant groups until the page's first request is prepared and the categories request is observed waiting; the test then releases them and checks the original mapping outcomes. The fixture's automatic categories request is disabled only for this scenario so the test triggers it after the group begins. The gate is released on cleanup. The networking group passed locally in 44.6 seconds (`/tmp/markview-studio-network-gated.log`) and in [CI run 44310136371](https://github.com/t-boris/MarkView/actions/runs/44310136371).
