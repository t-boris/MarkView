## Finding

The CI build job directly invoked `tools/tests/phase0-safety-tests.sh` after its checks had moved into `EditorHostTests.testEditorBaselineSecurity` and the script had been removed. The next CI run would fail at that command. The same build step also ran `window-session-tests`, which the pure-test matrix already schedules.

## Resolution

The obsolete build step was removed. The hosted CI matrix runs the general app-host suite containing the migrated safety test, while the pure-test shards include `window-session-tests` exactly once. Architecture lint now rejects missing literal test paths in GitHub workflow files; a deliberate missing-path probe failed as intended and the unchanged workflows passed. The final CI run remains outstanding.
