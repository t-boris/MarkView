## Finding

The ARM64 CI job started at 12:16:45 UTC on 2026-11-18 and timed out after the suite's 600-second limit. The hosted test started at 12:23:45 UTC, after the cold build, and did not finish before the suite was killed. Its WebKit page reported `visibility: hidden`. The same test passed locally in 54.5 seconds (`/tmp/markview-gui-final-candidate.log`). The retained CI job log is `/tmp/markview-ci-research-failure.log`; the job is part of [run 44302387150](https://github.com/t-boris/MarkView/actions/runs/44302387150).

## Resolution

The test's per-check JavaScript error-count query was replaced with asynchronous error messages from the existing page recorder; the final page-error assertions and all behavior checks remain. A focused local rerun passed in 55.5 seconds (`/tmp/markview-research-ci-speed-pilot.log`), compared with 54.5 seconds previously, so there is no demonstrated local speedup. A progress message every 50 checks is now forwarded by the manifest runner while the suite runs; runner regression checks passed (`/tmp/markview-runner-progress-research.log`). The CI timeout cause and improvement on the CI runner remain unverified.

The repeat CI reached 450 checks before the 600-second suite timeout (`/tmp/markview-ci-research-repeat.log`); its page reported hidden visibility. Ordering an ordinary borderless window behind other windows and outside all displays passed locally in 53.8 seconds but still reported `hidden` (`/tmp/markview-research-visible-arm.log`), so it did not establish a visible rendering clock. The fixture now uses the shipping `QAWebWindow`, which is designed to keep off-screen WebKit rendering, and asserts visible page state, no screen intersection and no focus. The focused ARM-hosted run passed in 51.1 seconds and reported `visible` (`/tmp/markview-research-qawindow-arm-repeat.log`); CI verification remains pending.

Open. Identify why progress stalls in CI and fix the test or actual behavior without reducing its coverage. Verify the fix locally and in CI. This run also exceeds the eight-minute end-to-end limit in DEC-019.
