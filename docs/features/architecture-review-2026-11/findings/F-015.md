## Finding

The general hosted QA job failed because an isolated WebKit page did not report its title within the fixture's fixed two-second limit. The error did not identify the failed readiness condition. The same suite passed locally. Evidence: `/tmp/markview-ci-qa-general-failure.log` and [CI run 44310136371](https://github.com/t-boris/MarkView/actions/runs/44310136371).

## Resolution

The fixture now waits for the actual title with a bounded 15-second deadline, closes the actor on timeout and reports the missing readiness condition. The normal fast path polls readiness and does not sleep for the full deadline. The focused ARM-hosted test passed locally in 0.5 seconds (`/tmp/markview-qa-fault-arm-fix.log`); CI verification remains pending.
