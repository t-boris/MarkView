## Finding

The 150-diagram editor test recorded a 5.632-second gap in its page timer on the GitHub runner, exceeding its five-second responsiveness requirement; the case took 114 seconds. It had passed locally in 23.3 seconds. The same suite later timed out before all editor tests completed. Evidence: `/tmp/markview-ci-qa-editor-failure.log` and [CI run 44310136371](https://github.com/t-boris/MarkView/actions/runs/44310136371).

## Resolution

Open. Identify whether the delay is caused by actual main-thread rendering work or runner scheduling before changing behavior or the five-second requirement. With the ARM-only, unoptimized hosted build, the focused local test passed in 24 seconds with a 0.9-second maximum timer gap (`/tmp/markview-editor-arm-ci-fixes.log`). A GitHub rerun passed the diagram case with a 2.5-second gap (`/tmp/markview-ci-editor3-arm-failure.log`), but that does not establish the cause of the earlier outlier.
