## Finding

The inherited-writer GitHub command test timed out after two seconds on the ARM CI runner before its Python fixture produced output. The test's purpose is to prove that a command exits without waiting for an inherited pipe writer; its background writer stays alive four seconds. Evidence: `/tmp/markview-ci-editor3-arm-failure.log` and [CI run 44317758173](https://github.com/t-boris/MarkView/actions/runs/44317758173).

## Resolution

The inherited-writer case now starts the same four-second background writer directly from a small shell fixture, avoiding a Python interpreter launch before the assertion. The original two-second deadline, output and exit-status assertions remain. Other command cases still use their Python fixture. The focused prebuilt ARM test passed locally in 3.4 seconds overall (`/tmp/markview-gh-command-prebuilt-fix.log`). CI verification remains pending; the earlier CI log alone does not prove interpreter startup was the only cause.
