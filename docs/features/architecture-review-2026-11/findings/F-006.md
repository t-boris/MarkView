## Finding

Hosted-test logs showed that `LifecycleLog.shared` read the installed application's shared lifecycle evidence file. Its default initializer used the production Application Support path even in the hosted-test build, so tests recording through that singleton could also append to the user's log. A count-only inspection found no temporary-project records dated 2026-11-18; that limited observation does not prove that no earlier test wrote there. The user's log was not modified during the inspection.

## Resolution

In the hosted-test build only, the singleton now uses a unique temporary JSON-lines file and removes it on normal process exit. Normal Debug and Release builds retain the production path; test-only lifecycle symbols were found in the hosted image and not in either normal image. Three hosted tests passed, including recording, reading and deleting an event in the temporary file (`/tmp/markview-lifecycle-isolation-regression.log`), and no temporary lifecycle file remained after host exit. Debug and unsigned Release 7.0.11 built with zero ratcheted warnings; architecture and SwiftLint checks passed, and unused-import analysis of the changed source reported zero warnings. The app source now selects the hosted GUI suite in the manifest. Full GUI and final CI verification remain open.
