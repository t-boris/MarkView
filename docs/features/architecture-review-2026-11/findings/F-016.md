## Finding

The isolated persistent remote fixture failed after 30 seconds: both home endpoints reported waiting, both work endpoints remained connecting, no fixture process had started and no output was received. This scenario passed locally and in earlier separate hosted runs. The failure does not establish whether the relay, workspace setup or runner scheduling caused the delay. Evidence: `/tmp/markview-ci-qa-arm-failure.log` and [CI run 44317758173](https://github.com/t-boris/MarkView/actions/runs/44317758173).

## Resolution

The isolated relay fixture now records only method, sanitized route and response status; headers, tokens, queries and bodies are excluded. The wrapper prints the last events only on failure and removes the temporary fixture afterward. A local probe confirmed that path, query, header and body secrets are not logged. The real persistent-remote test passed locally against the prebuilt ARM host both on its own in 14.5 seconds (`/tmp/markview-persistent-prebuilt.log`) and in the complete split general QA run in 14.7 seconds (`/tmp/markview-prebuilt-qa-general.log`), including both terminal streams. The CI failure's cause remains open; retain the 30-second requirement and verify with the new diagnostic on CI.
