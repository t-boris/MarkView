## Finding

[CI run 44046110367](https://github.com/t-boris/MarkView/actions/runs/44046110367) stopped the app-hosted suite after the GUI runner's default 600-second limit. The log shows the Workflow layout test still running; it does not show an assertion failure before termination. The other CI jobs passed.

## Resolution

The manifest gives this full app-hosted suite a 900-second limit, leaving other suite limits unchanged. [CI run 44047894716](https://github.com/t-boris/MarkView/actions/runs/44047894716) passed all jobs, including the hosted suite. The next change splits the long UI Studio session and workflow layout suites into separate parallel hosted jobs; their CI timing and success remain to be verified.
