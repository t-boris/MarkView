## Finding

[CI run 44046110367](https://github.com/t-boris/MarkView/actions/runs/44046110367) stopped the app-hosted suite after the GUI runner's default 600-second limit. The log shows the Workflow layout test still running; it does not show an assertion failure before termination. The other CI jobs passed.

## Resolution

In progress: the manifest gives this full app-hosted suite a 900-second limit, leaving other suite limits unchanged. A new CI run must verify it completes within that limit.
