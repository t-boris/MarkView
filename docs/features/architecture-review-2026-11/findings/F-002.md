## Finding

[CI run 44046110367](https://github.com/t-boris/MarkView/actions/runs/44046110367) stopped the app-hosted suite after the GUI runner's default 600-second limit. The log shows the Workflow layout test still running; it does not show an assertion failure before termination. The other CI jobs passed.

## Resolution

The manifest gives this full app-hosted suite a 900-second limit, leaving other suite limits unchanged. [CI run 44047894716](https://github.com/t-boris/MarkView/actions/runs/44047894716) passed all jobs, including the hosted suite. A later three-way split in [CI run 44050803050](https://github.com/t-boris/MarkView/actions/runs/44050803050) passed the workflow job, but the UI Studio session job exceeded its 1,200-second suite limit. The UI Studio scenarios now form three independently runnable groups. All 51 stages passed locally in three tests (182, 42 and 139 seconds). The network group also passed when selected separately by the CI wrapper; final CI verification remains open. Boris requested no further intermediate CI runs.

Separately, the local GUI run spent more than three minutes at full CPU sweeping thousands of mouse coordinates in the welcome-screen test; a sample showed SwiftUI/AppKit hit testing. The stopped test was replaced with native clicks on each tile's accessibility frame and passed on its own in 309 seconds. No completed before/after timing exists, and this local test is not identified as the cause of the CI timeout.

A local full hosted run on the subsequent code executed 66 tests with 2 optional profiling tests skipped and 0 failures in 139.3 seconds. The seven scenarios in `UIStudioLifetimeHostTests.testLifetime` took 25.3 seconds. The general hosted wrapper includes that class, and the local GUI tier also has a separate lifetime wrapper, so those checks are duplicated in a complete local GUI run. The current CI matrix runs the general wrapper but does not separately schedule the lifetime wrapper, so this duplication does not explain the 20-minute CI timeout. A process sample identified the active lifetime scenario; its raw sample was removed. Final CI verification remains open.

The migrated editor CSP test exposed another local delay: its expected-failure frame probe used 40 short timers, which hidden WebKit stretched to 31.4 seconds. Waiting for the same readiness event with one four-second timeout reduced the probe to 4.4 seconds; the complete focused test passed in 38.7 seconds before and 11.3 and 11.2 seconds after. This is a measured local improvement, not the identified cause of the earlier UI Studio CI timeout. Final CI remains pending.

A later full general host run, after additional standalone checks were moved into it, passed 103 tests with 2 optional skips and 0 failures in 272.3 seconds. The terminal-links test passed in 30.6 seconds and UI Studio lifetime in 23.1 seconds; these are local measurements, not proof of CI resolution. The package test run was active concurrently for part of the host run, so this timing is not directly comparable with the earlier host-only run. Final CI remains open.

A migrated bug validity test took 34.1 seconds locally. A process sample showed the test enumerating the whole shared temporary directory to check failed-export cleanup. Recording the exact export path and checking its absence retained the cleanup assertion; the warm focused repeat passed in 5.2 seconds. This is a local test improvement, not evidence of the cause of the earlier UI Studio timeout.

A later full general host run passed 166 tests with 2 optional skips and 0 failures in 303.0 seconds, after a cold test-app build. This is local evidence only; the final CI run is still outstanding.

The pure matrix now skips two remote-workspace child suites inside the aggregate wrapper because both are scheduled individually. The terminal-child check remains in the wrapper because it is GUI-tier. The focused wrapper passed locally, including terminal-child and 16 Node checks with 3 optional skips; a guard rejects a missing pure child suite. No final CI timing is claimed.

The remote Codex context child has since moved to the general hosted suite. The pure matrix continues to skip only the separately scheduled relay-settings child; terminal-child remains in the aggregate wrapper.
