## Finding

The 6.30.144 full GUI run's general host suite executed 213 tests with three optional skips and one failure. `TerminalLinkHostTests.testEditorLineLinks` failed the check that a code-line navigation queued while the viewer loads scrolls to the requested line. The diagnostic reported a 456-pixel scroller with 2,984 pixels of content and scroll position zero. The earlier focused check passed, so the reason for the difference is not established. The remaining GUI run was stopped after the failure so the cause can be fixed before repeating it.

## Resolution
