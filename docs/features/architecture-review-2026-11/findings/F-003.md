## Finding

The first migrated window-state test run crashed the isolated HostedTests app during XCTest autorelease-pool teardown with `objc_release` and `EXC_BAD_ACCESS`. The crash report identifies the test app under `/private/tmp`; the installed app remained running. The test fixture closes retained `NSWindow` objects without disabling release-on-close, a plausible over-release. The prior standalone test exited directly and did not exercise the same XCTest teardown.

## Resolution

The fixture now sets `isReleasedWhenClosed = false` before retaining and closing its windows. The focused rerun passed in 2.2 seconds. A subsequent full-host run passed all 73 tests, with 2 optional profiling tests skipped and 0 failures; this test passed in 1.7 seconds. Final CI verification remains pending. The crash is not attributed to the earlier installed-app accessibility failures.
