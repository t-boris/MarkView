## Finding

The welcome screen test failed on CI because the hosted view reported animation disabled for every animated backdrop and the sampled frames did not change. The view's `isAnimating` depends on `NSWorkspace.accessibilityDisplayShouldReduceMotion`, but the test assumed the machine's setting was off. See `/tmp/markview-ci-welcome-failure.log` and [CI run 44302387150](https://github.com/t-boris/MarkView/actions/runs/44302387150).

## Resolution

The isolated test host now controls the system getter while exercising the animated cases and restores its original implementation afterward. Its existing dedicated Reduce Motion test still exercises both setting values. This does not change the user's system preference or application code. Both welcome tests passed locally; the screen scenario took 296.6 seconds (`/tmp/markview-welcome-controlled-motion.log`). CI verification is pending; the logs alone do not rule out an additional rendering limitation on the CI machine.
