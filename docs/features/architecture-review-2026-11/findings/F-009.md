## Finding

The general hosted GUI suite failed the first off-screen dialog entrance check after a fixed 0.8-second wait, then timed out at its 900-second suite limit before reaching all its isolated follow-up checks. In the same run, `EditorHostTests` took 318 seconds; the suite's initial hosted build also consumed substantial time. See `/tmp/markview-ci-qa-failure.log` and [CI run 44302387150](https://github.com/t-boris/MarkView/actions/runs/44302387150).

## Resolution

The dialog test now waits up to five seconds for its actual animation-complete condition rather than sleeping a fixed interval; it still asserts the same final state. Its focused local rerun passed in 2.1 seconds (`/tmp/markview-ci-qa-dialog-fix.log`). The timeout and the eight-minute overall CI target remain unresolved; CI verification is pending.

The CI wrapper is split into an EditorHostTests job and a general-host job; both use the same app-hosted target and the general job retains the seven isolated follow-up checks. The default local wrapper remains the complete combined run. The editor part passed all 215 tests locally in 205.2 seconds (`/tmp/markview-qa-editor-split.log`); a fake-command probe confirmed that the editor part rejects a zero-test result and invalid mode. The general part passed 91 tests (3 optional skips) in 178.4 seconds and all seven follow-ups (`/tmp/markview-qa-general-split.log`), covering the same 306 main tests as the earlier combined run. CI timing remains unverified.
