## Context

Section 7 and Section 13 #1 of architecture-review-2026-11.md ask whether MarkView should support loadable plugins or stick to registries and data files.

## Alternatives

1. Loadable runtime plugins or script plugins

## Decision

Accept registries and data files only, with no loadable plugins.

## Reason

Owner decision #1: keeps security, sandboxing, and type safety intact while eliminating scattered switch statements.

## Consequences

Extension points use compile-time registries (ToolRegistry, BackdropRegistry, AssistantProvider, MCPToolHandler) and validated JSON data files (themes, layout presets).
