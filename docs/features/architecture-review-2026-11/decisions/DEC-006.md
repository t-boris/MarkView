## Context

Section 11 (AR-44 step 2) and Section 13 #6 ask for owner approval to introduce Packages/MarkViewCore as the first local Swift package dependency of the app target.

## Alternatives

1. Keep all Swift files in the single MarkView app target

## Decision

Approve introducing Packages/MarkViewCore as a local Swift package dependency of the MarkView app target.

## Reason

Owner decision #6: enables fast incremental compilation, compiler-enforced module boundaries, and native swift test execution.

## Consequences

Create Packages/MarkViewCore (and MarkViewTestSupport) linked by the MarkView target and verified via swift test.
