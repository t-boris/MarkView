## Decision

An assistant request owns an immutable JSON snapshot of its schema, rather than retaining a dictionary that may contain mutable Foundation objects. A schema that cannot be encoded as JSON fails before the assistant runner is invoked or an X-Ray cached answer is returned. Operations accept only Sendable input values.

## Reason

An assistant operation crosses isolation boundaries while retaining its original input for validation and repair. A mutable schema dictionary can otherwise be shared across those boundaries. The snapshot makes valid requests safe to transfer, and explicit rejection prevents an invalid schema from being silently treated as absent. App-host tests covered mutation isolation, `UInt64.max`, invalid schemas, a runner that must not be called, and the X-Ray rejection path; all 32 affected pure suites and five affected GUI suites passed. Final CI and release verification remain open.
