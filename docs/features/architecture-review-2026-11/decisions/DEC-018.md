## Decision

Boris specified that only ARM is needed. Build, test and release the macOS application for Apple Silicon (`arm64`); do not add an Intel macOS build or test matrix. Platform-independent tooling may continue to run on Linux.

## Evidence

The Debug, Release and HostedTests Xcode configurations set `ARCHS = arm64`. The Release workflow has an `arm64`-only matrix, and GitHub documents `macos-latest` as an ARM64 runner. The installed and published application still require verification as part of the release.
