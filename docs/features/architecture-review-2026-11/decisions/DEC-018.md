## Decision

Boris specified that only ARM is needed. Build, test and release the macOS application for Apple Silicon (`arm64`); do not add an Intel macOS build or test matrix. Platform-independent tooling may continue to run on Linux.

## Evidence

The Debug, Release and HostedTests app configurations set `ARCHS = arm64`. The Release workflow has an `arm64`-only matrix, and GitHub documents `macos-latest` as an ARM64 runner. A later CI log nevertheless showed that the Swift package dependency of HostedTests compiled for both `arm64` and `x86_64`; the app-target setting did not cover it. The hosted test build must explicitly constrain all dependencies to ARM. The installed and published application still require verification as part of the release.

The corrected shared hosted build in [CI run 44317758173](https://github.com/t-boris/MarkView/actions/runs/44317758173) succeeded; its log showed only ARM64 Swift drivers, no x86_64 Swift driver and an unoptimized MarkViewCore test build (`/tmp/markview-ci-hosted-arm-build.log`).
