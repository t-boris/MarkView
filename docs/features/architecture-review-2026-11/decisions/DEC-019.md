## Decision

Boris requires all CI runs to take no more than eight minutes end to end. Measure the full elapsed time including runner queuing, setup, build and tests; do not treat a per-step timeout as meeting this requirement. Preserve the required automatic coverage and the ARM-only macOS application decision. External GitHub runner availability can affect elapsed time and must be reported separately when it prevents the target.
