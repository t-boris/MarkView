## Decision

Run the automated `pure` and `gui` tiers for this work. Leave the five `live` scenarios manual; do not run them as part of the all-tier request. The real Antigravity check embedded in the project AI choice suite is also manual: it requires `MARKVIEW_LIVE_ANTIGRAVITY=1`.

## Reason

A1 requested `run.sh --all`, but C5 leaves live-assistant scripts manual. Four live scripts require arguments absent from `--all`, and `book-pdf-live.sh` uses a real provider by default. Boris resolved the conflict in favour of the automated tiers.

## Implementation status

On 2026-11-17 the project AI choice suite moved from `pure` to an isolated app-hosted `gui` test. The real Antigravity call remains manual and still requires the same explicit opt-in; the automated suite does not call it.

On 2026-11-18 the native QA script's fixture-app interaction was reclassified from `pure` to manual `live`: it drives a real application through accessibility and may activate its test window. Its 86 non-interactive behavior checks run automatically in the app-hosted GUI suite. This adds a sixth manual live suite to the five identified when the decision was recorded; the decision to run pure and GUI automatically and leave live scenarios manual is unchanged.
