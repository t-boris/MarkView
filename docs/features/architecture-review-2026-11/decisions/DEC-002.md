## Context

Section 7.2 (AR-33) and Section 13 #2 ask which layout presets ship and whether automatic triggers are wanted.

## Alternatives

1. Automatic layout preset switching based on file or activity triggers

## Decision

Ship Writing, Review, QA, and Cockpit layout presets with explicit user selection only and no automatic triggers.

## Reason

Owner decision #2: each window preserves its own layout state; automatic triggers would unexpectedly override user panel choices.

## Consequences

Ship Writing, Review, QA, and Cockpit layout presets triggered only by explicit user selection in the toolbar/menu; per-window state is preserved without automatic overrides.
