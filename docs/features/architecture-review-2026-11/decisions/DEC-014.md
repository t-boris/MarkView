## Decision

For B1's first step, use an ordered entry manifest and esbuild's classic-script transform, preserving the shared global scope. The app injects the guarded early portion of the same bundle at document start; the page loads the complete bundle after the vendor scripts, where the guard skips its already-executed early portion. Convert to ES imports and exports only under the separate approval already required by B1 step 4.

## Reason

The existing scripts share top-level bindings and public functions across classic script tags. Wrapping them in a module or an asynchronous callback changes their scope or execution timing. In an isolated WebKit comparison, a callback-wrapped prototype omitted 129 window properties; the classic-scope prototype retained all measured window properties and kept the early theme and bridge available during document loading. Full app and regression verification remains required.
