## Context

Section 2 (AR-01) and Section 13 #7 ask whether to sanitise raw HTML in Markdown or isolate the preview in a frame without the bridge.

## Alternatives

1. Isolate rendered Markdown in a separate frame without the native bridge; leave raw HTML unsanitised

## Decision

Sanitise rendered HTML in Markdown after parsing and tighten the preview Content-Security-Policy to remove 'unsafe-inline' from script-src.

## Reason

Owner decision #7: prevents untrusted Markdown documents from executing script or invoking native bridge handlers while keeping preview features intact.

## Consequences

Sanitise rendered Markdown HTML before DOM insertion (stripping script tags, event handler attributes, and javascript:/vbscript: URLs in dangerous contexts) and remove 'unsafe-inline' from script-src in the preview CSP.
