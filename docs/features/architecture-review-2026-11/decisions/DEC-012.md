## Decision

- D1: Remove the tracked TestFiles and presentation after checking their consumers; retain EmbeddingClient while its key helpers are used.
- D2: Introduce SwiftLint in warning mode with a shrinking allow-list; defer SwiftFormat.
- D3: Enable hardened runtime in Debug and Release if the harness works; otherwise Release only.
- D4: Bundle existing JavaScript without changing load order, add incremental checkJs and extract inline CSS. Defer module conversion and a view registry.
- D5: Preserve DEC-009 and DEC-011: no separate socket-level by_user confirmation. Investigate and harden client-supplied working-directory trust without claiming the contradictory confirmation acceptance criterion is satisfied.
- D6: Cut AgentTools' dependency on Workspace using a narrow window protocol and injected window creation.
- D7: Add an app-hosted test target after D6, moving a real suite and removing its stand-ins.
- D8: Log row counts for the unused tables first; drop only empty tables in a later release and a new migration.
- D9: Adopt complete concurrency checking with zero warnings, reducing justified unchecked sites.

## Reason

Boris delegated these decisions to the implementing agent. The recommendations in the remaining-tasks record are adopted where compatible with earlier binding decisions. DEC-009 and DEC-011 explicitly reject a separate socket-level confirmation and take precedence over the contradictory proposal in D5.
