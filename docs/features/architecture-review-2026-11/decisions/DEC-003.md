## Context

Section 7.2 (AR-32) and Section 13 #3 ask whether user theme files in Application Support are allowed and whether web tokens may be derived from native colours.

## Alternatives

1. Hardcoded Swift theme switches only; requiring full 30-token web definitions in user themes

## Decision

Allow user theme JSON files in Application Support and automatically derive web CSS tokens when only native colours are provided.

## Reason

Owner decision #3: removes 16-way theme switches and makes authoring custom themes simple.

## Consequences

Built-in themes load from bundled JSON resources; user themes load from ~/Library/Application Support/MarkView/themes/*.json and may specify only native palette colours with web CSS tokens derived automatically when omitted.
