## Statement

The system shall decompose WorkspaceManager responsibilities, eliminate broad objectWillChange forwarding, introduce protocol-backed dependencies, and manage async task lifecycles (Phase 4).

## Acceptance Criteria

- [x] AR-14: WorkspaceManager responsibilities (window chrome/layout, file tree navigation, git operations, modal sheets, semantic index coordination) are decomposed into focused controllers/coordinators.
- [x] AR-15: Broad child-to-parent objectWillChange forwarding is replaced with scoped observation so leaf state changes do not re-render the entire window chrome.
- [x] AR-16 & AR-17: Service protocols and a WindowDependencies composition container decouple stores and sessions for testing.
- [x] AR-19: Background tasks and watchers are tracked in a cancellable TaskBag/scheduler cleaned up on window close and folder switch.
