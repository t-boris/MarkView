## Statement

Harden `SchemaVersionedStore` (`FU-04`) and adopt it in `WindowSessionStorage`, delete unused `SemanticDatabaseExecutor` until Step E, and fix all `FU-03` control socket token/UID defects under token-only auth (`DEC-009`, `DEC-011`).

## Acceptance Criteria

- [x] FU-04, FU-14, AR-23 (helper and first user only): `SchemaVersionedStore` (`MarkView/Models/Workspace/SchemaVersionedStore.swift`) rejects newer schema versions without overwriting, ignores legacy payload `"version"` fields (`SchemaVersionProbe`), rotates `.corrupt` backups without clobbering, and is used by `WindowSessionStorage` (its only user), including legacy `version > 1` overwrite protection.
- [x] FU-01 (deletion only): the unused `SemanticDatabaseExecutor` and `SQLiteMigration` are removed. AR-37 and AR-38 are not delivered by this: `SemanticDatabase` is still `@MainActor` and still deletes the database on a schema mismatch.
- [x] FU-03, DEC-009, DEC-011 (browser control socket only): the token is not exported via `setenv`, `verifyToken` fails closed with a constant-time comparison, `serve` rejects a `nil` peer UID, the client reads only the per-socket mode-0600 `.token` file (`MARKVIEW_CONTROL_TOKEN` fallback removed), socket and token are removed on quit, and the unused `byUserConfirmationGate` is removed.
- [ ] AR-40 (rest): the Cockpit and Remote sockets have no token or peer check (`MarkView/Models/Cockpit/CockpitHostBridge.swift:31-44`, `MarkView/Models/Remote/RemoteToolBridge.swift:17-22`). Status: in progress (feat/architecture-review-finish).
- [ ] FU-15 and FU-21: a session file judged newer is logged, but quit can still be refused every time (`MarkView/Models/Workspace/WindowSessionController.swift:202-213`, `MarkView/App/MarkViewApp.swift:78-85`); the refusal must be shown once. Status: in progress (feat/architecture-review-finish).
- [ ] AR-36 and AR-39: 23 files hand-roll JSON stores and 67 `try? decode` sites remain (counts at 6.26.0; `SchemaVersionedStore` has 1 user). Status: in progress (feat/architecture-review-finish).
- [ ] AR-37 and AR-38: SQLite off the main actor, and a real migration list. Status: in progress (feat/architecture-review-finish).
- [ ] AR-42 and AR-43: main-thread file checks, and strict-concurrency cleanup (`SWIFT_STRICT_CONCURRENCY = targeted` is on; the 6.26.2 build had 189 distinct warnings). Status: in progress (feat/architecture-review-finish).
- [ ] AR-41 (not claimed above; name-only per follow-up section 3): hardened-runtime setting, navigation policy, `img-src`. Not named in the plan in `tasks/todo.md`.
