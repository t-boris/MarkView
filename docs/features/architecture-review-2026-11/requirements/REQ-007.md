## Statement

Harden `SchemaVersionedStore` (`FU-04`) and adopt it in `WindowSessionStorage`, delete unused `SemanticDatabaseExecutor` until Step E, and fix all `FU-03` control socket token/UID defects under token-only auth (`DEC-009`, `DEC-011`).

## Acceptance Criteria

- [x] FU-04, FU-14, AR-23 (helper and first user only): `SchemaVersionedStore` (`MarkView/Models/Workspace/SchemaVersionedStore.swift`) rejects newer schema versions without overwriting, ignores legacy payload `"version"` fields (`SchemaVersionProbe`), rotates `.corrupt` backups without clobbering, and is used by `WindowSessionStorage` (its only user), including legacy `version > 1` overwrite protection.
- [x] FU-01 (deletion only): the unused `SemanticDatabaseExecutor` and `SQLiteMigration` are removed. AR-37 and AR-38 are not delivered by this: `SemanticDatabase` is still `@MainActor` and still deletes the database on a schema mismatch.
- [x] FU-03, DEC-009, DEC-011 (browser control socket only): the token is not exported via `setenv`, `verifyToken` fails closed with a constant-time comparison, `serve` rejects a `nil` peer UID, the client reads only the per-socket mode-0600 `.token` file (`MARKVIEW_CONTROL_TOKEN` fallback removed), socket and token are removed on quit, and the unused `byUserConfirmationGate` is removed.
- [x] AR-40 (Cockpit and Remote sockets): Measured 2026-11-15 at the merge tip `ac3001ba` (base 6.26.2 `6facd9f`): `CockpitHostBridge` and `RemoteToolBridge` both require `PrivateSocket.peer(of:).isCurrentUser` and `listener.accepts(token:)` (a 256-bit token in a mode-0600 file, constant-time compare) before they read a request, as the browser control socket does.
- [ ] AR-40 (client-supplied fields): `cwd`, `folderDeclared` and `cwdTrusted` (default true) still come from the request in `AgentToolServer`, and `by_user` is still a boolean the agent supplies; `DEC-009` records that no native confirmation is wanted.
- [ ] FU-15 and FU-21: Measured 2026-11-15 at the merge tip `ac3001ba` (base 6.26.2 `6facd9f`), by reading and not run: `WindowSessionController.saveBeforeTermination` is best-effort (`MarkViewApp.applicationShouldTerminate` always replies true after it) and a refused autosave is announced once per launch through the banner (`announceRefusedSave`). Not ticked until the quit path is driven.
- [ ] AR-36 and AR-39: Measured 2026-11-15 at the merge tip `ac3001ba` (base 6.26.2 `6facd9f`): `SchemaVersionedStore` users 1 -> 14 files (17 sites: Cockpit, Deployments, Discussion, Lifecycle, QA, UI Studio and Workspace stores); `try? decode` 98 -> 93 sites; file locking is still in exactly one file (`CockpitResults.swift`), so there is no cross-process coordination.
- [x] AR-37 and AR-38: Measured 2026-11-15 at the merge tip `ac3001ba` (base 6.26.2 `6facd9f`): `SemanticDatabase` is an `actor` (lint `semantic-database-actor` passes) and `SemanticSchema.migrations` is an ordered list (versions 1 and 2) applied by `SQLiteSchema.open` against `PRAGMA user_version`; `SQLiteSchemaTests.swift` exists in the package and was not run in this pass.
- [ ] AR-42 and AR-43: Measured 2026-11-15 at the merge tip `ac3001ba` (base 6.26.2 `6facd9f`), partial. AR-42: `hasMarkdownFiles` is a stored flag set by a background walk, directory walks in `Views/` 2 -> 0, `waitUntilExit` 11 -> 0; nothing was profiled. AR-43: `SWIFT_STRICT_CONCURRENCY = targeted` is set, `Packages/MarkViewCore` uses the `StrictConcurrency` feature, and 40 `@unchecked Sendable` and `nonisolated(unsafe)` sites are each justified (lint `unchecked-sendable`: exit 0); the build-warning ratchet runs in CI against an empty allow-list, and the branch's commit messages say app-target warnings fell from 105 to 0, but no build was run in this pass (189 distinct warnings at 6.26.2), so the count is unverified.
