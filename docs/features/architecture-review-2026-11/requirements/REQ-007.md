## Statement

Harden `SchemaVersionedStore` (`FU-04`) and adopt it in `WindowSessionStorage`, delete unused `SemanticDatabaseExecutor` until Step E, and fix all `FU-03` control socket token/UID defects under token-only auth (`DEC-009`, `DEC-011`).

## Acceptance Criteria

- [x] AR-36, AR-39, FU-04, FU-14, FU-15, AR-23: `SchemaVersionedStore` (in `MarkView/Models/Workspace/SchemaVersionedStore.swift`) rejects newer schema versions without overwriting, ignores legacy payload `"version"` fields (`SchemaVersionProbe`), rotates `.corrupt` backups without clobbering, and is adopted by `WindowSessionStorage` (including legacy `version > 1` overwrite protection) with logged refusals/errors in `WindowSessionController`.
- [x] AR-37, AR-38, FU-01: Unused `SemanticDatabaseExecutor` and `SQLiteMigration` are removed until their Step E PRs.
- [x] AR-40, FU-03, DEC-009, DEC-011: Control socket token is not exported via `setenv`, `verifyToken` fails closed using constant-time comparison, `serve` rejects `nil` peer UID, client reads only the per-socket mode-0600 `.token` file (`MARKVIEW_CONTROL_TOKEN` env fallback removed), socket/token are removed on quit, and unused `byUserConfirmationGate` is removed.
- [ ] Step E (future PRs per DEC-011): Remaining JSON stores (`AR-36`), off-main-actor SQLite & real migrations (`AR-37`, `AR-38`), main-thread file checks (`AR-42`), and strict concurrency warnings cleanup (`AR-43`).
