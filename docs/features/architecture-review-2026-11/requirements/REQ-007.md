## Statement

The system shall harden persistence, SQLite concurrency and migrations, control socket authentication, main-thread responsiveness, and strict concurrency checking (Phase 6).

## Acceptance Criteria

- [ ] AR-36 & AR-39: Persistent JSON files carry schemaVersion and write atomically via a shared JSONStore/AtomicFile helper; paths in Application Support are unified.
- [ ] AR-37 & AR-38: SQLite access is serialised off the main thread with numbered PRAGMA user_version migrations and a single vector extension loader.
- [ ] AR-40 & DEC-009: Control socket connections verify a per-instance/per-window token (stored with 0600 permissions and passed to spawned tools) and require native confirmation for by_user mutations.
- [ ] AR-41..AR-43 & DEC-010: Main-thread blocking calls (FileConflictMonitor hashing, synchronous git/shell calls) are moved off the main actor, and targeted strict concurrency checking is enabled.
