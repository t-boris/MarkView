## Statement

The system shall provide shared Core infrastructure (Subprocess, AtomicFile, FileWatcher, ContentHash, AppLogger, SettingsRegistry, JSCall/WebHost) and the local Swift package Packages/MarkViewCore (Phase 2).

## Acceptance Criteria

- [ ] AR-24: Shared Core utilities provide atomic file writing, FSEvents/dispatch source file watching, SHA-256 hashing, and unified os.Logger diagnostics.
- [ ] AR-25: A unified Subprocess runner handles executable resolution, environment setup, concurrent stdout/stderr draining, timeout, and cancellation.
- [ ] AR-18: UserDefaults keys and notification names are centralised in a typed SettingsKey / AppSettings registry with zero raw string key drift.
- [ ] AR-04 & AR-27: A shared JSCall / WebHost helper handles JSON-encoded JS evaluation and WKWebView configuration.
- [ ] AR-44 step 2 & DEC-006: Packages/MarkViewCore is integrated as a local Swift package with swift test coverage for pure domain/core types.
