## Statement

The system shall provide shared infrastructure in Packages/MarkViewCore linked directly into the MarkView target (no duplicate MarkView/Core copy), with FU-04 helper defects fixed and initial production callers wired (the remaining call-site migrations, AR-18, AR-24, AR-25 and AR-27, are in progress (feat/architecture-review-finish)).

## Acceptance Criteria

- [x] AR-44 step 2 & DEC-006: Packages/MarkViewCore is linked into the MarkView app target in MarkView.xcodeproj, duplicate MarkView/Core/ is deleted, and swift test tests the exact shipping package code.
- [x] FU-01/FU-04 (helper work only): `AtomicFile` sets file permissions before the rename and keeps an existing file mode when `permissions` is nil; `ProjectPaths` is wired into `DocumentFiles` and `SemanticDatabase`; unused `CoreDigest`, `RotatingJSONLinesFile`, `AppLogger` and `SettingsRegistry` are removed.
- [ ] AR-24: the finding is open. `AtomicFile.write` has 3 uses and `ProjectPaths` 4; the follow-up counted, at 6.26.0, 113 `.write(to:`, 117 `NSLog`, 56 `".dde` literals and six private digest helpers. FU-23: saving a document through `AtomicFile` replaces a symlink by a regular file, drops extended attributes and hard links, and leaves `.name.tmp-UUID` files in the project folder. Status: in progress (feat/architecture-review-finish).
- [x] FU-01/FU-04 (helper and first caller only): `Subprocess` merges the environment, respects `settings.cli.extraPATH`, bounds pipe reading, fixes the pre-`run()` cancellation race, drops the unused `runBlocking`, and is used by `InsightArchiveExporter` (its only caller: 1 `Subprocess.run` site).
- [ ] AR-25: the finding is open: 17 `Process()` creations in 15 files outside `Subprocess` (target 0). FU-22: the process-group kill never runs (`Packages/MarkViewCore/Sources/MarkViewCore/Subprocess.swift` signals the group only if the child leads one, and nothing puts the child in its own group); follow-up section 11 listed it as fixed, which section 12.4 corrects. Status: in progress (feat/architecture-review-finish).
- [x] FU-01 (helper and first caller only): `WeakScriptMessageHandler` in `MarkViewCore` is used by `EditorView` (the unused `WebHost` wrapper is removed).
- [ ] AR-27: the finding is open: 10 `WKWebViewConfiguration()` creations remain and the editor is the only user of the weak handler. Status: in progress (feat/architecture-review-finish).
- [ ] AR-18: all `UserDefaults` literal keys (79 `forKey:` literals and 50 `static let …Key` at 6.26.0) behind one registry and one defaults observer (`SettingsRegistry` was deleted as unused in 6.26.1). Status: in progress (feat/architecture-review-finish).
