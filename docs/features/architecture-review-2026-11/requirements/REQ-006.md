## Statement

The system shall unify assistant provider metadata in an AssistantProvider registry and run structured AI tasks through a shared AIOperation pipeline (Phase 5).

## Acceptance Criteria

- [ ] AR-26: AIOperation encapsulates prompt rendering, CLI invocation, JSON extraction, schema validation, and cancellation across AI features.
- [ ] AR-35: AssistantProvider registry unifies CLI binary paths, flags, usage parsers, and capabilities for Claude, Codex, Gemini, Copilot, and Cline.
