## Statement

Keep `AssistantProviderRegistry` and `AIOperation`/`AIJSONSalvage`, and route `ArchitectureStore.xrayCall` through `AIOperation` as the first production caller. Moving the remaining `CLICompletion.run` callers onto it is in progress (feat/architecture-review-finish).

## Acceptance Criteria

- [x] AR-26 (first caller only): `ArchitectureStore.xrayCall` is the single `AIOperation` call site (`MarkView/Models/Architecture/ArchitectureStore.swift:806`); X-Ray and the book annotation requests built by `BookAnnotator` run through it. `BookAnnotator` itself is not an `AIOperation` caller, and `BookPDFAssistant` and `BookPDFExportModel` still call `CLICompletion.run` directly.
- [x] AR-35 (first step only): 9 `CLITool` properties delegate through `AssistantProviderRegistry`.
- [ ] AR-26: 55 `CLICompletion.run` calls in 28 files outside `AIOperation` (target 0; 1 `AIOperation` call site), with hand-written repair loops in 12 files (at 6.26.0). Status: in progress (feat/architecture-review-finish).
- [ ] AR-35: about 28 switches over the assistant in 13 files, three duplicate enums, and the registry itself is a switch (counts at 6.26.0). Status: in progress (feat/architecture-review-finish).
