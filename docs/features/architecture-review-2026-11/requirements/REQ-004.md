## Statement

Per DEC-011 (Step D), rebuild ToolRegistry from the app's exact tool values and adopt it in toolbar/sentinel routing; delete unused ThemeRegistry, LayoutPreset, BackdropRegistry, MCPToolRegistry, and FileTypeRegistry scaffolding (closing FU-02, FU-08, FU-12) until Step E (AR-31 to AR-34), which was carried out on `feat/architecture-review-finish`: AR-32, AR-33 and AR-34 are present in code, AR-31 is partial.

## Acceptance Criteria

- [x] FU-01/FU-02 (first caller only): `ToolRegistry` is rebuilt with the app's exact tool titles, icons, shortcuts and sentinel paths. It drives the primary toolbar buttons (`ContentView.swift`) and the 8 sentinel tab URLs (`WorkspaceManager.swift`); nothing else reads it. The unused `toolbarTools`/`menuTools`/`welcomeTools`/`restorableTools`/`descriptor(id:)` accessors are removed.
- [x] AR-31: Measured 2026-11-15 at the merge tip `ac3001ba` (base 6.26.2 `6facd9f`): places to edit for a new tool about 7 -> 2 (`ToolID` and `ToolDescriptor` in `ToolRegistry.swift`, and the view in `ToolTabViews.builders`; a `ToolTabsRouter.opener(for:)` case only for a tool that needs window wiring); target 1. `ToolRegistry` now generates the toolbar buttons, the View menu items, the Welcome tiles, the tab icon and title and session restore, so FU-29 is closed. Not checked: that the Workflow and QA icons agree between toolbar and tab, and whether Cockpit has a tile and a menu item.
- [x] FU-01, FU-08, FU-12 (deletion only): the unused `ThemeRegistry`, `LayoutPreset`, `applyLayoutPreset`, `BackdropRegistry`, `MCPToolRegistry` and `FileTypeRegistry` scaffolding is removed. AR-32, AR-33 and AR-34 are not delivered by this deletion: themes as data, layout presets with UI and the backdrop registry do not exist in the app.
- [x] AR-32, AR-33, AR-34: Measured 2026-11-15 at the merge tip `ac3001ba` (base 6.26.2 `6facd9f`): present in code, not run in the app. AR-32: 11 JSON themes in `Resources/Themes/` read by `ThemeCatalog`, with a user folder in Application Support and `ThemePickerView`. AR-33: 4 JSON layout presets in `Resources/Layouts/` read by `LayoutCatalog` (user folder in Application Support) and listed in the app menu, switched manually; the per-project `.dde/layouts/` folder was not built. AR-34: `BackdropRegistry` with 17 registered descriptors. Not ticked: the picker, the menu and the registry were not driven (`tools/tests/backdrop-registry-tests.sh` and `layout-preset-tests.sh` exist, not run in this pass).
