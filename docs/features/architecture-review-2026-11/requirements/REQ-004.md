## Statement

Per DEC-011 (Step D), rebuild ToolRegistry from the app's exact tool values and adopt it in toolbar/sentinel routing; delete unused ThemeRegistry, LayoutPreset, BackdropRegistry, MCPToolRegistry, and FileTypeRegistry scaffolding (closing FU-02, FU-08, FU-12) until Step E (AR-31 to AR-34), which is in progress (feat/architecture-review-finish).

## Acceptance Criteria

- [x] FU-01/FU-02 (first caller only): `ToolRegistry` is rebuilt with the app's exact tool titles, icons, shortcuts and sentinel paths. It drives the primary toolbar buttons (`ContentView.swift`) and the 8 sentinel tab URLs (`WorkspaceManager.swift`); nothing else reads it. The unused `toolbarTools`/`menuTools`/`welcomeTools`/`restorableTools`/`descriptor(id:)` accessors are removed.
- [ ] AR-31: View menu items, tab icons, tab titles, the session-restore switch and Welcome tiles are still hand-written lists; adding a tool edits about 7 lists (target 1). Workflow and QA have different icons in the toolbar and in the tab; Cockpit has no tile and no menu item. FU-29: `ToolSurface.viewMenu`, `.welcomeTile` and `.sessionRestore` are set on every descriptor and read nowhere. Status: in progress (feat/architecture-review-finish).
- [x] FU-01, FU-08, FU-12 (deletion only): the unused `ThemeRegistry`, `LayoutPreset`, `applyLayoutPreset`, `BackdropRegistry`, `MCPToolRegistry` and `FileTypeRegistry` scaffolding is removed. AR-32, AR-33 and AR-34 are not delivered by this deletion: themes as data, layout presets with UI and the backdrop registry do not exist in the app.
- [ ] AR-32, AR-33, AR-34: JSON theme data with a user folder and picker (AR-32), explicit layout presets with UI (AR-33) and a backdrop registry (AR-34). Status: in progress (feat/architecture-review-finish).
