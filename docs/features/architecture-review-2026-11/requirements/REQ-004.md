## Statement

The system shall replace scattered switch statements with declarative registries and data files for tools, themes, layout presets, backdrops, file types, and MCP handlers (Phase 3).

## Acceptance Criteria

- [ ] AR-31 & DEC-001: ToolRegistry defines all window tools in one descriptor table driving toolbar, menu, shortcuts, and persistence without drift.
- [ ] AR-32 & DEC-003: Theme palettes and web CSS tokens are loaded from data files with support for user themes in ~/Library/Application Support/MarkView/themes/ and automatic web token derivation.
- [ ] AR-33 & DEC-002: Layout presets (Writing, Review, QA, Cockpit) are data-driven and selectable by the user without automatic triggers.
- [ ] AR-34: BackdropRegistry defines welcome screen backdrops in a uniform descriptor table.
- [ ] MCP tool handlers and file type mappings use structured descriptor registries.
