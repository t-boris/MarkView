## Statement

The system shall resolve all Phase 0 safety and correctness findings (AR-01 through AR-13) across Markdown rendering sanitisation, Insight iframe isolation, vendored libraries, JS bridge encoding, async git/subprocess handling, credential storage, and error surfacing.

## Acceptance Criteria

- [x] AR-01 & FU-13: Shipped in 6.26.1 and 6.26.2: fail-closed DOMPurify HTML and Mermaid SVG sanitisation in `mvKit.sanitizeHtml` / `mvKit.sanitizeMermaidSvg`, Mermaid `securityLevel: 'strict'`, escaped TOC headings and D3 layout errors, strict CSP on `index.html`, `book.html`, `discussion.html` and `terminal.html` (external `markview-terminal.js`). Measured 2026-11-15 at the merge tip `ac3001ba` (base 6.26.2 `6facd9f`): FU-20 is addressed in the code (`sanitizeMermaidSvg` keeps Mermaid's `<style>` after `sanitizeScopedStylesheet` rebuilds it rule by rule; `tools/tests/MermaidSvgWebTests.swift` exists and was not run in this pass) and FU-24 is addressed (the browser's own CSS parser serialises the declarations, no regex on raw text). Not accepted: FU-25 (cached and exported Insight HTML keeps `'unsafe-inline'` in its CSP, `MarkView/Models/Insight/InsightHTMLTemplate.swift:137`; the two script sinks named at 6.26.2 were not re-checked) and no run against a hostile document in the app.
- [x] AR-02 & FU-10: Shipped: null-origin sandbox for the Insight iframe (`sandbox="allow-scripts"` without `allow-same-origin`), dead `blob:` URL code removed, nonce-only `script-src` failing closed to `'none'`, `EditorWindowPrefs` and `__markviewInsightNonce` injected via `WKUserScript`, CSP nonce injected by regex in `EditorView`. Measured 2026-11-15 at the merge tip `ac3001ba` (base 6.26.2 `6facd9f`): `allow-same-origin` appears 0 times outside comments and vendored code; FU-26 is addressed in code (a nonce miss is logged by `EditorPage`; `tools/tests/EditorPageCSPTests.swift` exists, not run in this pass). Not accepted: the Insight frame was never run live (FU-10), and cached or exported Insight HTML still carries `'unsafe-inline'` (FU-25).
- [x] AR-03: Vendor Turndown and turndown-plugin-gfm locally under Resources/Editor/vendor/js and remove cdn.jsdelivr.net from index.html and CSP.
- [x] AR-04: `EditorView` selection results use `JS.call` and `jsString` is removed (done). Measured 2026-11-15 at the merge tip `ac3001ba` (base 6.26.2 `6facd9f`): `JS.call`/`JS.sequence` 6 -> 39 sites, `evaluateJavaScript` 57 -> 27 sites in 7 files; the lint `js-interpolation` (no script built by string interpolation) passes, so the defect is closed. Not accepted: the target "every one through `JS.call`" is not met (the remaining 27 are constant scripts or `JS.call`).
- [x] AR-05: Move startup ready/init trigger from markview-d3-mermaid.js into markview-init.js after init is defined.
- [x] AR-06: Run ArchitectureStore git show off the main actor asynchronously with a 15 s timeout.
- [x] AR-07: Run InsightArchiveExporter zip process via unified async Subprocess with `-q`, discarded stdout, timeout scaling (`FU-16`), and bounded stderr draining.
- [x] AR-08: Escalate timed-out processes in CLICompletion from SIGTERM to SIGKILL just like cancellation does.
- [x] AR-09: Stop logging dictated speech text in WhisperClient (log character count only) and keep bridge logging DEBUG-only without /tmp/markview-insight-diag.log writes.
- [x] AR-10: Store the OpenAI API key in Keychain in WhisperClient using `SecItemUpdate` first (falling back to `SecItemAdd` on `errSecItemNotFound`), only calling `SecItemDelete` when clearing an empty key, and removing the UserDefaults copy only on Keychain write success.
- [x] AR-11: Remove the `NSAppleScript` `do script` fallback in `FileTreeView.openTerminal(at:)` and log any `NSWorkspace` launch error cleanly.
- [x] AR-12: `developerExtrasEnabled` is gated on `#if DEBUG`, SSH control sockets live in a per-user 0700 directory, and the Finder Quick Action open-path reader checks `O_NOFOLLOW` and the uid in the temp folder and in `/tmp`.
- [x] FU-09: No writer of that open-path file exists in the repository; the handoff was not checked with the real Quick Action.
- [x] AR-13: Surface write failures via a non-blocking banner in `ContentView` bound to `WorkspaceManager.lastSaveError`, replace modal save `NSAlert` with `lastSaveError` + `AtomicFile.write` in `saveFile(at:)`.
