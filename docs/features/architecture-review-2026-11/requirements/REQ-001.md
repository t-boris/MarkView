## Statement

The system shall resolve all Phase 0 safety and correctness findings (AR-01 through AR-13) across Markdown rendering sanitisation, Insight iframe isolation, vendored libraries, JS bridge encoding, async git/subprocess handling, credential storage, and error surfacing.

## Acceptance Criteria

- [x] AR-01 & FU-13: Sanitize rendered Markdown HTML via DOMPurify (failing closed if unavailable) across editor preview, find/jump preview, canvas, code preview, book.html, and discussion.html; remove 'unsafe-inline' from script-src across index.html, book.html, and discussion.html.
- [x] AR-02 & FU-10: Isolate the Insight iframe as a null-origin sandbox (sandbox="allow-scripts" without allow-same-origin), sanitize model HTML via DOMPurify, verify postMessage source and origin, execute libraries without CSP breakage, and inject EditorWindowPrefs without inline script tags.
- [x] AR-03: Vendor Turndown and turndown-plugin-gfm locally under Resources/Editor/vendor/js and remove cdn.jsdelivr.net from index.html and CSP.
- [ ] AR-04: Replace unescaped Swift-to-JS string interpolations with a JSON-encoded JS.call helper across remaining evaluateJavaScript call sites (deferred remainder to Step E per DEC-011).
- [x] AR-05: Move startup ready/init trigger from markview-d3-mermaid.js into markview-init.js after init is defined.
- [x] AR-06: Run ArchitectureStore git show off the main actor asynchronously with a 15 s timeout.
- [x] AR-07: Run InsightArchiveExporter zip process via unified async Subprocess with `-q`, discarded stdout, timeout, and bounded stderr draining.
- [x] AR-08: Escalate timed-out processes in CLICompletion from SIGTERM to SIGKILL just like cancellation does.
- [x] AR-09: Stop logging dictated speech text in WhisperClient (log character count only) and keep bridge logging DEBUG-only without /tmp/markview-insight-diag.log writes.
- [x] AR-10: Store the OpenAI API key in Keychain in WhisperClient without losing the UserDefaults key if Keychain write fails.
- [ ] AR-11: Replace remaining AppleScript do script fallback in FileTreeView or harden all terminal/shell paths cleanly (deferred to Step E per DEC-011).
- [x] AR-12 & FU-09: Gate developerExtrasEnabled on #if DEBUG, move SSH control sockets to per-user 0700 dir, and verify O_NOFOLLOW + uid on Finder Quick Action open-path handoff across temp locations.
- [ ] AR-13: Surface write failures clearly without abandoned write-only state (lastSaveError) (deferred to Step E per DEC-011).
