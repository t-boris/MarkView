## Statement

The system shall resolve all Phase 0 safety and correctness findings (AR-01 through AR-13) across Markdown rendering, path containment, JS bridge encoding, subprocess pipe handling, and bounds safety.

## Acceptance Criteria

- [x] AR-01: Rendered Markdown HTML is sanitised before DOM insertion and preview CSP removes unsafe-inline from script-src.
- [x] AR-02: UIStudioServer HTML interpolation escapes title and raw strings, and innerHTML interpolations in editor.js/ui-studio.js/qa.js/mind-map.js escape untrusted fields.
- [x] AR-03: Prototype FileServer resolves symlinks before checking containment within rootDir.
- [x] AR-04: Native-to-JavaScript string arguments use JSON-encoded parameters via a shared JS call helper rather than manual backslash/quote escaping.
- [x] AR-05: Shell commands in terminal sessions use POSIX shell quoting instead of raw double-quote interpolation.
- [x] AR-06: Process pipes are drained concurrently before waitUntilExit in Git, GitHub, and CLI helpers to prevent deadlocks over 64 KB.
- [x] AR-07: Force unwraps and unguarded string/index slicing in production Swift code (SemanticSearchEngine, MarkdownFileSystem, LineDiff, FeatureLifecycle, UIStudioSession, CockpitRuntime, FileConflictMonitor) are replaced with safe bounds checks.
- [x] AR-08: Silent try? and empty catch blocks on state-corrupting paths log diagnostics via a structured logger.
- [x] AR-09..AR-13: Deinit/timer cleanup, SQLite SQLITE_TRANSIENT bindings, URL Encoding, and error recovery paths are hardened and covered by automated tests.
- [x] AR-01: Sanitize rendered Markdown HTML before innerHTML assignment and remove 'unsafe-inline' from script-src in index.html CSP (moving inline scripts and on*= handlers to listeners).
- [x] AR-02: Isolate the Insight iframe as a null-origin sandbox (sandbox="allow-scripts" without allow-same-origin) with required script libraries provided safely.
- [x] AR-03: Vendor Turndown and turndown-plugin-gfm locally under Resources/Editor/vendor/js and remove cdn.jsdelivr.net from index.html and CSP.
- [x] AR-04: Replace unescaped Swift-to-JS string interpolations (setDocumentBase, scrollToHeading, etc.) with a JSON-encoded JS.call helper.
- [ ] AR-05: Move startup ready/init trigger from markview-d3-mermaid.js into markview-init.js after init is defined.
- [ ] AR-06: Run ArchitectureStore.prFileURL git show off the main actor asynchronously with a timeout.
- [ ] AR-07: Pass -q and drain/discard stdout in InsightArchiveExporter zip process so large exports cannot block on a full pipe.
- [ ] AR-08: Escalate timed-out processes in CLICompletion from SIGTERM to SIGKILL just like cancellation does.
- [ ] AR-09: Stop logging dictated speech text in WhisperClient (log character count only) and remove /tmp/markview-insight-diag.log writes from WebViewBridge.
- [ ] AR-10: Store the OpenAI API key in Keychain in WhisperClient with a one-time migration from UserDefaults.
- [ ] AR-11: POSIX/AppleScript-quote paths in FileTreeView Open in Terminal and avoid unquoted shell interpolation in SystemProbe.
- [ ] AR-12: Gate developerExtrasEnabled on #if DEBUG in EditorView and UIStudioSession, and move /tmp/markview_open_path.txt and SSH control sockets to the per-user temporary directory with 0600/0700 permissions.
- [ ] AR-13: Surface write failures in UIStudioSession conflict markers, WorkspaceManager document save, and FeatureIntake bug issue rewrite through user-visible notice/error channels.
