## Statement

The system shall resolve all Phase 0 safety and correctness findings (AR-01 through AR-13) across Markdown rendering sanitisation, Insight iframe isolation, vendored libraries, JS bridge encoding, async git/subprocess handling, credential storage, and error surfacing.

## Acceptance Criteria

- [ ] AR-01 & FU-13: Shipped in 6.26.1 and 6.26.2: fail-closed DOMPurify HTML and Mermaid SVG sanitisation in `mvKit.sanitizeHtml` / `mvKit.sanitizeMermaidSvg`, Mermaid `securityLevel: 'strict'`, escaped TOC headings and D3 layout errors, strict CSP on `index.html`, `book.html`, `discussion.html` and `terminal.html` (external `markview-terminal.js`). Not accepted: FU-20 (the sanitiser strips Mermaid's `<style>`, so every Mermaid diagram loses its stylesheet; the test asserts the strip), FU-24 (CSS filter is a regex) and FU-25 (`MarkView/Resources/Editor/js/markview-canvas.js:497-498`, `MarkView/Resources/Editor/js/markview-insight-srcdoc.js:524`, cached Insight HTML keeps `'unsafe-inline'`). Status: in progress (feat/architecture-review-finish).
- [ ] AR-02 & FU-10: Shipped: null-origin sandbox for the Insight iframe (`sandbox="allow-scripts"` without `allow-same-origin`), dead `blob:` URL code removed, nonce-only `script-src` failing closed to `'none'`, `EditorWindowPrefs` and `__markviewInsightNonce` injected via `WKUserScript`, CSP nonce injected by regex in `EditorView`. Not accepted: the Insight frame was never run live (FU-10), the nonce injection misses silently and has no test of the app's own path (FU-26), and cached or exported Insight HTML still carries `'unsafe-inline'` (FU-25). Status: in progress (feat/architecture-review-finish).
- [x] AR-03: Vendor Turndown and turndown-plugin-gfm locally under Resources/Editor/vendor/js and remove cdn.jsdelivr.net from index.html and CSP.
- [ ] AR-04: `EditorView` selection results use `JS.call` and `jsString` is removed (done). `JS.call` has 6 call sites; 57 `evaluateJavaScript` calls in 8 files remain (target: every one through `JS.call`). Status: in progress (feat/architecture-review-finish).
- [x] AR-05: Move startup ready/init trigger from markview-d3-mermaid.js into markview-init.js after init is defined.
- [x] AR-06: Run ArchitectureStore git show off the main actor asynchronously with a 15 s timeout.
- [x] AR-07: Run InsightArchiveExporter zip process via unified async Subprocess with `-q`, discarded stdout, timeout scaling (`FU-16`), and bounded stderr draining.
- [x] AR-08: Escalate timed-out processes in CLICompletion from SIGTERM to SIGKILL just like cancellation does.
- [x] AR-09: Stop logging dictated speech text in WhisperClient (log character count only) and keep bridge logging DEBUG-only without /tmp/markview-insight-diag.log writes.
- [x] AR-10: Store the OpenAI API key in Keychain in WhisperClient using `SecItemUpdate` first (falling back to `SecItemAdd` on `errSecItemNotFound`), only calling `SecItemDelete` when clearing an empty key, and removing the UserDefaults copy only on Keychain write success.
- [x] AR-11: Remove the `NSAppleScript` `do script` fallback in `FileTreeView.openTerminal(at:)` and log any `NSWorkspace` launch error cleanly.
- [x] AR-12: `developerExtrasEnabled` is gated on `#if DEBUG`, SSH control sockets live in a per-user 0700 directory, and the Finder Quick Action open-path reader checks `O_NOFOLLOW` and the uid in the temp folder and in `/tmp`.
- [ ] FU-09: No writer of that open-path file exists in the repository; the handoff was not checked with the real Quick Action.
- [x] AR-13: Surface write failures via a non-blocking banner in `ContentView` bound to `WorkspaceManager.lastSaveError`, replace modal save `NSAlert` with `lastSaveError` + `AtomicFile.write` in `saveFile(at:)`.
