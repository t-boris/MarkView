## Statement

For a prototype made from code, Prototype Studio shall find the themes of the original application in the stylesheets copied into the prototype and record the root attribute, the theme ids and the default theme.

## Acceptance Criteria

- [ ] Themes are found by reading the copied stylesheets for root attribute selectors such as [data-theme="x"]; no assistant run is needed.
- [ ] The ids are listed in the order of first appearance, without duplicates; an attribute that selects only one value is not a theme switch.
- [ ] The default theme is the one the build recorded from the application's source; when none was recorded the picker offers the themes without marking a default and the prototype keeps the look it has.
- [ ] A prototype without copied stylesheets, or whose stylesheets hold no theme selector, records no theme and offers no picker.
- [ ] The record is saved in the prototype's manifest and refreshed by a build and by a sync.
