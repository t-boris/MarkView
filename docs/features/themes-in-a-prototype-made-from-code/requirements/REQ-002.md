## Statement

Prototype Studio shall show a theme picker for a prototype with themes, apply the default theme when the preview opens, apply the chosen theme to the preview, and remember the choice with the prototype.

## Acceptance Criteria

- [ ] The toolbar has a theme picker listing the themes found; it is absent when there are none.
- [ ] Choosing a theme changes the preview at once without reloading its state and without an assistant run.
- [ ] The choice survives a reload of the preview, a new version and reopening the prototype.
- [ ] The theme is applied to the page of every screen, including the isolated view of a component.
- [ ] Pointing at an element, a request and a screenshot of the element use the chosen theme.
- [ ] The picker does not depend on any generated file: it works when the Appearance screen of the prototype is a stub.
