## Context

Q-001 asked whether bootstrap should create a project or only prepare a plan. The answer confirms the creation path already reflected in accepted decisions DEC-002, DEC-005, and DEC-006.

## Alternatives

1. Create a local project folder, initial specification files, and a Git repository, with optional GitHub repository creation.
2. Produce a project plan and instructions; the user creates the project separately.

## Decision

Bootstrap creates a local project folder with initial files containing the confirmed brief, decisions, and requirements, and initializes local Git. The user may create and connect a GitHub repository during the flow or later.

## Reason

Boris selected project creation for Q-001.

## Consequences

Bootstrap must create a usable local workspace. GitHub remains optional, and the specific file templates remain outside this specification.
