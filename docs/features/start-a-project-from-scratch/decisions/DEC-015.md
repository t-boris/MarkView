## Context

REQ-002 starts clarification before a workspace exists, while the current feature intake stores objects inside an open repository.

## Alternatives

1. Keep clarification only in memory.
2. Create the destination project folder when clarification starts.
3. Persist a local draft outside any project until bootstrap.

## Decision

Persist pre-bootstrap clarification as a local app draft and transfer confirmed content into the project during bootstrap.

## Reason

This supports recovery without creating a project before the user confirms its intent and destination.

## Consequences

The flow needs draft persistence, resume and discard controls, and a transfer step that avoids losing the draft if bootstrap fails.
