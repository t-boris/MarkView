## Context

REQ-004 requires local Git initialization, while REQ-003 does not define whether files are committed or published.

## Alternatives

1. Commit and push generated files automatically during bootstrap.
2. Leave files uncommitted until the user explicitly proceeds with publication.
3. Treat adding a remote as a complete connection.

## Decision

Keep the bootstrap files uncommitted until the user proceeds with GitHub publication; define completed connection as a successful linked push.

## Reason

The user can inspect generated content before publishing, and “connected” has an observable completion state.

## Consequences

GitHub connection needs a commit review, remote conflict handling, push verification, and separate states for local creation and publication.
