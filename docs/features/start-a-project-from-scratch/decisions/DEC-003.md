## Context

The bootstrap workflow needs a defined point at which local project creation becomes available.

## Alternatives

1. A. Clarify the idea and record decisions before offering to create the local project.
2. B. Create an initial local project from the short idea, then clarify and revise it.

## Decision

## Reason

Boris selected option A for Q-005.
