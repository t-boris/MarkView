## Context

The user may start with only a broad idea, and the clarified intent must be confirmed before local creation.

## Alternatives

1. Use an adaptive conversation and present a summary for confirmation.
2. Use a short, fixed questionnaire and present the completed brief for confirmation.

## Decision

Clarify project intent through an adaptive conversation. Present the resulting project brief for user confirmation before offering to create the local project.

## Reason

Adaptive questions can address what is missing from each idea without requiring a fixed set of prompts to fit every project.

## Consequences

The clarification flow may take several rounds. Local project creation is offered only after the user confirms the summary.
