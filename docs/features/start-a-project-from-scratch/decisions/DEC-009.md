## Context

REQ-004 requires bootstrap to create a local project folder, but does not specify its destination, name, or behavior when the destination already exists. An existing path may contain user data, even if it appears empty.

## Alternatives

1. Use a fixed default location and generate a unique folder name automatically.
2. Allow bootstrap into an existing empty folder.
3. Ask the user to choose a parent folder and project name; require the resulting path to be unused.

## Decision

Before bootstrap, show the proposed folder name and let the user choose its parent directory. Create the project only at a path that does not exist. If that path exists when creation is attempted, preserve it and ask the user to change the name or parent directory.

## Reason

Explicit destination selection makes the result predictable. Requiring a new path gives a clear rule that protects existing user data, including data added between confirmation and creation.

## Consequences

The flow needs a location picker, an editable project name, path validation, and a collision check immediately before creation. On collision, bootstrap pauses for a new name or location without modifying the existing path.
