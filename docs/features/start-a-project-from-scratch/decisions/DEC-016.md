## Context

REQ-002 requires confirmation before bootstrap, but an adaptive dialogue has no defined stopping point.

## Alternatives

1. Require every project decision to be resolved before confirmation.
2. Allow confirmation of any brief, including missing bootstrap inputs.
3. Require only the decisions needed to create the agreed foundation.

## Decision

Gate bootstrap on a clear goal and resolved foundation-critical decisions, while allowing other questions to remain open.

## Reason

This gives the dialogue a testable completion rule without forcing premature technology or implementation choices.

## Consequences

The assistant must identify and explain blocking bootstrap inputs, while preserving nonblocking questions for later work.
