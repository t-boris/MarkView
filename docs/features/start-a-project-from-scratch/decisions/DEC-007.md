## Context

Q-002 asked how to clarify a broad project idea at the start of the workflow.

## Alternatives

1. A. Adaptive dialogue until the project intent is clear, then record decisions and requirements before proposing a project structure.
2. B. Propose an initial structure from a short description and let the user revise it.

## Decision

Use an adaptive dialogue to clarify project intent. Record decisions and requirements before proposing a project structure.

## Reason

The product owner selected the dialogue-first option.

## Consequences

The assistant must clarify the idea and record the resulting decisions and requirements before proposing a structure or offering to create the local project.
