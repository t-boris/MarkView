## Context

Q-008 asked what content constitutes the local project foundation at bootstrap.

## Alternatives

1. A. Brief only — save the confirmed project brief and initialize local Git.
2. B. Specification foundation — save the confirmed brief, decisions, and requirements gathered during clarification, then initialize local Git.

## Decision

Choose B. Specification foundation.

## Reason

The project foundation should carry forward the specification produced during clarification.

## Consequences

Bootstrap must preserve the confirmed brief and the decisions and requirements gathered during clarification in the created local workspace. It still initializes local Git; GitHub connection remains optional.
