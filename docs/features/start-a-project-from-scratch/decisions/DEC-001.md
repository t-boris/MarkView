## Context

The initial workflow includes both project bootstrap and a path to GitHub connection.

## Alternatives

1. The project can be created locally and connected to GitHub later.
2. Completing the bootstrap flow requires creating or connecting a GitHub repository.

## Decision

GitHub connection is optional when starting a project. A locally created project can be connected to GitHub later.

## Reason

The product owner selected the optional GitHub path.

## Consequences

A user can complete the local project bootstrap without GitHub authorization or network access. GitHub connection remains available later.
