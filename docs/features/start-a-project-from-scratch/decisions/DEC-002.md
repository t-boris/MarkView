## Context

The bootstrap outcome for the first version was unresolved in Q-004.

## Alternatives

1. A. Bootstrap produces a project plan but does not create a local project.
2. B. Bootstrap creates a usable local project; GitHub can be connected later.

## Decision

Bootstrap creates a usable local project. GitHub connection remains optional and can happen later.

## Reason

Boris selected option B for Q-004.

## Consequences

The first version must create a local project that the user can open and continue using without GitHub. The minimum project contents remain an implementation choice within the agreed scope.
