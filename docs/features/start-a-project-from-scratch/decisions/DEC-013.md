## Context

DEC-002 calls for a usable local project, while the agreed scope leaves the technology stack and generated source templates undecided.

## Alternatives

1. Require a runnable application at bootstrap.
2. Create a specification workspace that can be opened and developed further.

## Decision

Define the bootstrap outcome as an openable specification workspace with local Git, not a runnable application.

## Reason

This makes “usable” testable within the agreed scope and preserves a path to implementation after the specification is ready.

## Consequences

Success criteria must check that MarkView can open and continue the workspace, without requiring a build or run command.
