## Statement

After confirmation, create a usable local project folder with initial files preserving the confirmed brief, decisions, and requirements, and initialize a local Git repository.

## Acceptance Criteria

- [x] After the user confirms the clarified project intent and chooses to bootstrap, MarkView creates a local project folder that can be opened as a workspace.
- [x] Initial files in the folder preserve the confirmed brief and the decisions and requirements gathered during clarification.
- [x] A local Git repository is initialized in the folder.
- [x] The user can complete bootstrap without connecting GitHub.
