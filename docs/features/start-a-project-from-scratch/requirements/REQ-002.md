## Statement

Guide the user through an adaptive dialogue about their project idea, record the resulting decisions and requirements, and present the clarified intent for confirmation before proposing a project structure or offering to bootstrap a local project.

## Acceptance Criteria

- [x] Given a broad project idea, the assistant asks follow-up questions to clarify the user's intent.
- [x] The assistant records decisions and requirements established during the dialogue before proposing a project structure.
- [x] The assistant presents the clarified intent for user confirmation before offering to bootstrap a local project.
