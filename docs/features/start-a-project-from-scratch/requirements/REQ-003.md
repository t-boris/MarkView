## Statement

Offer optional GitHub repository creation and connection during the initial project flow, and allow the created local project to be connected later.

## Acceptance Criteria

- [x] A user can complete creation of a usable local project without signing in to GitHub or connecting a repository.
- [x] During the initial flow, the user can create a GitHub repository and connect the local project to it.
- [x] The created local project offers the same connection path later.
