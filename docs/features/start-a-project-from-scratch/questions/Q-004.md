## Question

Что должно быть результатом bootstrap в первой версии: план проекта или созданный локальный проект?

## Why it matters

От этого зависит, что пользователь получает при завершении сценария и какие требования к созданию проекта можно зафиксировать.

## Options

- **A. Только план**: Bootstrap produces a project plan but does not create a local project.
- **B. Локальный проект**: Bootstrap creates a usable local project; GitHub can be connected later.

## Answer

B. Локальный проект. Bootstrap creates a usable local project; GitHub can be connected later.
