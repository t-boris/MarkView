## Question

Должен ли bootstrap сразу создавать локальный Git-репозиторий или делать это при подключении GitHub?

## Why it matters

Это определяет, что пользователь получает после создания проекта и какие шаги остаются для подключения GitHub.

## Options

- **A. Local Git repository**: Bootstrap creates a local project workspace, saves the confirmed brief, and initializes a local Git repository.
- **B. Workspace first**: Bootstrap creates a local project workspace and saves the confirmed brief; Git is initialized when the user chooses to connect GitHub.

## Answer

A. Local Git repository. Bootstrap creates a local project workspace, saves the confirmed brief, and initializes a local Git repository.
