## Question

Что должно означать «bootstrap проекта» в первой версии: реальное создание проекта или подготовка плана?

## Why it matters

Ответ определяет главный результат сценария и границу между спецификацией и автоматическим выполнением.

## Answer

Создать проект. MarkView creates a local project folder, initial files, Git repository, and optionally a GitHub repository.
