## Question

Как пользователь должен уточнять общую идею перед созданием проекта: через адаптивный диалог или краткую анкету?

## Why it matters

Это определяет основной путь от общей идеи к подтверждённому замыслу проекта.

## Options

- **A. Диалог**: Use an adaptive conversation to clarify the idea, then present a summary for user confirmation.
- **B. Краткая анкета**: Use a short, consistent set of prompts, then present the completed brief for user confirmation.

## Answer

AI: Выбираю адаптивный диалог: он поможет уточнить исходную идею с учётом конкретного проекта. Перед созданием локального проекта пользователь увидит итоговый замысел и подтвердит его.
