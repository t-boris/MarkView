## Question

GitHub обязателен для завершения старта проекта или его можно подключить позже?

## Why it matters

Это определяет поведение при отсутствии авторизации, сети или готовности публиковать проект.

## Answer

GitHub по выбору. The project can be created locally and connected to GitHub later.
