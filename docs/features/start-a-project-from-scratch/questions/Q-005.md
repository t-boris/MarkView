## Question

Когда создавать локальный проект: после уточнения и подтверждения замысла или сразу по краткой идее?

## Why it matters

Ответ определит порядок ключевых шагов и момент создания файлов.

## Options

- **A. Сначала уточнить**: Clarify the idea and record decisions before offering to create the local project.
- **B. Сначала черновик**: Create an initial local project from the short idea, then clarify and revise it with the user.

## Answer

A. Сначала уточнить. Clarify the idea and record decisions before offering to create the local project.
