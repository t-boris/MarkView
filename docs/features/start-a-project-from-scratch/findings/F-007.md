## Finding

Initializing Git does not establish whether generated files are committed or pushed. GitHub connection also needs defined behavior for adding a remote, handling an existing remote, and publishing local history. Without this, “connected” has no testable completion state.

> A local Git repository is initialized in the folder.

## Resolution

AI: Initialize local Git during bootstrap with the generated files uncommitted, and show that state clearly. When the user chooses GitHub connection, require or create an explicit initial commit with their approval, add the selected repository as origin only when no conflicting origin exists, and push the current branch; report connection complete only after the remote and local branch are linked and the push succeeds. — see DEC-018.
