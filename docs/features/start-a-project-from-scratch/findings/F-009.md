## Finding

The documented GitHub integration is disabled by default through `settings.github.enabled` and detects repositories from Git remotes. The specification does not say whether the new-project flow enables that setting, offers sign-in, or merely adds a remote. A remote alone may leave the user without the promised MarkView GitHub connection.

> The created local project offers the same connection path later.

## Possible interpretations

- Connection means adding a GitHub remote only.
- Connection also enables MarkView’s GitHub features and completes required authentication.

## Resolution

AI: GitHub connection includes enabling MarkView’s GitHub integration after the user explicitly opts in, completing or verifying GitHub authentication, and detecting the selected repository from the configured remote. Offer the same connection flow from the local project later; report connection complete only when MarkView recognizes the repository and its GitHub features are available. — see DEC-020.
