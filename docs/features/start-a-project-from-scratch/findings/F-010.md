## Finding

The existing New Feature intake can create a GitHub issue when GitHub integration is enabled. It also assumes an open workspace. The new flow needs an explicit boundary for reusing that intake so that clarification before local creation does not require a repository or publish the user's idea as an issue unexpectedly.

> Guide the user through an adaptive dialogue about their project idea

## Resolution

AI: Уточнение замысла до создания проекта должно работать без открытой папки и репозитория. Публикация идеи в GitHub возможна только после подключения репозитория и отдельного действия пользователя. — see DEC-021.
