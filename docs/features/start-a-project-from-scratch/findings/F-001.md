## Finding

The flow does not define where the new folder is created, how its name is chosen, or what happens if that path already exists. These choices determine whether bootstrap can create the workspace without overwriting user data.

> After the user confirms the clarified project intent and chooses to bootstrap, MarkView creates a local project folder that can be opened as a workspace.

## Resolution

AI: Пользователь выбирает родительскую папку и подтверждает имя проекта до bootstrap. MarkView создаёт новую папку только по свободному пути; если путь уже существует, предлагает выбрать другое имя или расположение и ничего в существующей папке не меняет. — see DEC-009.
