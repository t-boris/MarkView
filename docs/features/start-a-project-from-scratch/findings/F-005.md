## Finding

The point at which intent is sufficiently clear is undefined. An adaptive dialogue could end after a brief summary or require all blocking project decisions to be resolved; these lead to different bootstrap eligibility and acceptance tests.

> Guide the user through an adaptive dialogue about their project idea, record the resulting decisions and requirements, and present the clarified intent for confirmation

## Possible interpretations

- The user may confirm a brief with unresolved decisions.
- All decisions needed to create the specified foundation must be resolved before confirmation.

## Resolution

AI: Allow confirmation when the brief clearly states the project goal and all decisions required to create the specification workspace are resolved. Record other unresolved choices as open questions in the new project; they do not block bootstrap. — see DEC-016.
