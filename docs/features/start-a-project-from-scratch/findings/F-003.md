## Finding

The specification requires preserving the brief, decisions, and requirements but does not define their file locations or format, or whether they use MarkView’s existing feature object model. The documented feature workflow stores objects under `docs/features/<slug>/`; this choice affects discoverability and later editing.

> Initial files in the folder preserve the confirmed brief and the decisions and requirements gathered during clarification.

## Resolution

AI: Сохранять основу проекта в `docs/project/`: подтверждённый замысел — в `overview.md`, каждое решение и требование — в отдельном Markdown-файле с метаданными. Использовать формат существующих объектов MarkView, но учитывать их как документы проекта, не как вымышленную первую функцию. — see DEC-012.
