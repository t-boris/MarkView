## Finding

The specification does not say how bootstrap or GitHub connection handles partial success: folder created but file write or Git initialization fails, remote repository created but remote setup or push fails, or the user retries. This risks duplicate repositories or an apparently complete but unusable project.

> MarkView creates a local project folder that can be opened as a workspace.

## Resolution

AI: Treat bootstrap and GitHub connection as separate resumable operations with visible stages. If local creation fails, retain the draft and identify the incomplete new folder for retry or cleanup; if GitHub creation succeeds but remote setup or push fails, retain the repository identity and resume connection to that same repository instead of creating another. — see DEC-019.
