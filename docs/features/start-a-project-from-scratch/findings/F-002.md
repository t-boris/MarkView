## Finding

“Usable local project” could mean a specification workspace or a runnable application. The scope excludes a technology stack and file templates, while DEC-002 says the project can be opened and continued. The expected outcome needs an explicit boundary.

> Bootstrap creates a usable local project.

## Possible interpretations

- A MarkView workspace containing the confirmed specification and local Git is sufficient.
- Bootstrap also creates application source files that can be built or run.

## Resolution

AI: Для первой версии «пригодный к работе проект» — это локальная папка, которую MarkView может открыть как рабочее пространство: в ней сохранены подтверждённое описание проекта, решения и требования, а также создан локальный Git-репозиторий. Создание запускаемого приложения в bootstrap не входит. — see DEC-011.

## Resolution

AI: Bootstrap creates an openable MarkView workspace with the confirmed specification foundation and a local Git repository. A runnable application is not required for this version. — see DEC-013.
