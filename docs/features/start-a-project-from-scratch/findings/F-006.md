## Finding

The flow promises repository creation and connection but leaves the GitHub owner/account, repository name, visibility, and behavior when a repository already exists unresolved. Visibility is explicitly out of scope, yet it is a required input to creating a repository.

> During the initial flow, the user can create a GitHub repository and connect the local project to it.

## Resolution

AI: Пользователь выбирает владельца и имя репозитория, явно подтверждает видимость, затем подтверждает создание и подключение. Если репозиторий с таким именем уже существует, предложить выбрать другое имя или подключить существующий репозиторий после проверки доступа и отсутствия конфликтующего remote; ничего не перезаписывать автоматически. — see DEC-010.

## Resolution

AI: Before creating a GitHub repository, show the authenticated owner, editable repository name, and an explicit private or public visibility choice; require the user to confirm those values. If that owner/name already exists, offer to connect to it only after verifying access and a safe history match, or let the user choose another name; never overwrite it. — see DEC-017.
