## Context



## Alternatives

1. Tag statuses with specification stages so Explore, Review and the handoff work in any flow

## Decision

A flow template is a complete workflow in the existing format (statuses with roles, transitions built from the roles, processes). Explore, Review, the handoff and the project tools keep moving a feature by the status ids exploring, draft, review and ready; in a flow without those stages they run and leave the status as it is.

## Reason

Boris chose this on 2026-11-09. Tagging statuses with specification stages would touch every AI step and is a separate piece of work; the roles already map onto Jira, Linear and Azure DevOps categories, so the stored format does not change.

## Consequences

A new project on Kanban gets no status change from Explore or Review. New items take the entry status of the flow.
