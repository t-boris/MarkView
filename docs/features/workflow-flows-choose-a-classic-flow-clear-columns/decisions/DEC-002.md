## Context



## Alternatives

1. Keep the MarkView flow with specification as the default for new projects

## Decision

A project with no workflow file and no features or bugs adopts the Kanban template; any other project without a file adopts the MarkView flow as before, and a stored workflow is never replaced.

## Reason

Boris chose Kanban as the default for new projects on 2026-11-09 and wants existing projects unchanged.

## Consequences

The project's items must have been read before the choice is made; until then the project is treated as existing.
