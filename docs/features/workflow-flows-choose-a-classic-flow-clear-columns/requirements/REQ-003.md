## Statement

The system shall let a person load a classic flow into the draft of the Workflow tab from a menu: MarkView with specification, Kanban, Scrum, Linear, GitHub Projects, Azure DevOps Agile, Shape Up and Kanban with Bugzilla-style bug triage, each with its statuses and roles for features and bugs, its transitions and processes whose delivery settings follow the project's Definition of Done.

## Acceptance Criteria

- [ ] Every template passes the workflow validation and has statuses with the roles not-started, active and completed for both features and bugs
- [ ] Choosing a template changes only the draft: nothing is stored until Save, and Reload from file drops it
- [ ] Saving a template that removes statuses asks for a replacement of each status in use through the existing replacement choices
- [ ] The template's processes keep the ids standard-feature and standard-bug so items already assigned keep a process
- [ ] The stored file format (workflow.json) is unchanged
