## Statement

The system shall let a person load a classic flow into the draft of the Workflow tab from a picker: MarkView with specification, Kanban, Scrum, Linear, GitHub Projects, Azure DevOps Agile, Shape Up and Kanban with Bugzilla-style bug triage, each with its statuses and roles for features and bugs and its transitions, keeping the delivery settings of the processes the project already has.

## Acceptance Criteria

- [ ] Every flow passes the workflow validation and has statuses with the roles not-started, active and completed for both features and bugs
- [ ] Choosing a flow changes only the draft: nothing is stored until Save, and Reload from file drops it
- [ ] Saving a flow that removes statuses asks for a replacement of each status in use through the existing replacement choices
- [ ] Processes that follow the transitions of their type keep their settings and ids (standard-feature, standard-bug); a process with transitions of its own is left out
- [ ] The picker shows each flow's origin, purpose and columns, and marks the one in use
- [ ] The stored file format (workflow.json) is unchanged
