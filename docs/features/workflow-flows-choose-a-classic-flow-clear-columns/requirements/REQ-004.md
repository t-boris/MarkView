## Statement

The system shall adopt the Kanban flow in a project that has no workflow file and no features or bugs yet, keep the existing MarkView flow in every other project, and give a new feature or bug the entry status of the workflow when the status the app would write by name does not exist in it.

## Acceptance Criteria

- [ ] A project without a workflow file and without items adopts Kanban; one with items adopts the MarkView flow as before
- [ ] A feature created in a flow without 'idea' or 'exploring' gets the first status of the flow, not an unknown status
- [ ] Explore, Review and the project tools still run in a flow without their stages and leave the status as it is
- [ ] Existing projects and their stored workflow are not changed
