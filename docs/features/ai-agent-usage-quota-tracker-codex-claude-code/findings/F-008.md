## Finding

This criterion needs to be scoped to the fallback path only. Otherwise it could be read as conflicting with the official path, which uses OAuth credentials to make network requests.

> Usage is read only from local files; no API keys are requested.

## Possible interpretations

- Applies to the fallback path only
- Applies to the whole feature

## Resolution

AI: Ограничить критерий только резервным путём: в резервном режиме (REQ-005) использование считается исключительно по локальным логам CLI, без сетевых запросов и без запроса каких-либо ключей или учётных данных у пользователя. Использование сохранённых OAuth-учётных данных для официального пути регулируется только DEC-005/REQ-006. — see DEC-013.
