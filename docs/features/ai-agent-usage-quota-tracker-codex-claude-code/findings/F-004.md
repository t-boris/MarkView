## Finding

Access tokens expire. Because refreshing is forbidden, behaviour on a 401 response is undefined. It is also unclear whether the app may refresh in memory without persisting the result. Reading credentials may require access to the macOS Keychain (a prompt to the user), which REQ-006 does not mention.

> The app never modifies or refreshes-and-overwrites the agent's stored credentials.

## Possible interpretations

- Fall back to the local estimate on 401
- Refresh in memory only, never persisting the new token

## Resolution

AI: Приложение не обновляет токен вообще — даже в памяти: при 401/403 или отсутствии токена официальные данные помечаются как недоступные, и агент переходит на локальную оценку (DEC-007/REQ-005) с пометкой «официальные данные недоступны — откройте агент, чтобы обновить вход». Токен перечитывается из хранилища при каждом опросе, поэтому, когда CLI сам обновит его, официальные данные вернутся автоматически. Доступ к Keychain — только чтение, а отказ пользователя обрабатывается так же, как 401. — see DEC-011.
