## Finding

'Configured' is not defined: detection could be automatic (the CLI is installed, or ~/.claude exists) or manual. This criterion also overlaps with DEC-003 (no limit means absolute usage plus a hint) and REQ-005 ('usage unavailable'). The distinct states and their precedence need to be listed together.

> Agents with no data are shown as unavailable rather than zero

## Possible interpretations

- Auto-detected installed CLIs
- User-enabled list in settings

## Resolution

AI: Агент считается поддерживаемым, если он есть во встроенном списке (Claude Code, Codex) и обнаружен автоматически: найден CLI или папка ~/.claude / ~/.codex. В настройках его можно скрыть. Состояния агента взаимоисключающие, проверяются по приоритету: официальный лимит → лимит, заданный пользователем → только абсолютное использование с подсказкой → «данные недоступны». Агенты, которые не обнаружены, не показываются. — see DEC-012.
