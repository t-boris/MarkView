## Finding

The spec does not say where the settings live or how a window is expressed. A countdown (REQ-003) needs an anchor time, which a duration alone does not provide.

> the user shall be able to enter a quota limit (tokens or money) and reset window per agent

## Possible interpretations

- Rolling duration starting from the first usage
- Fixed anchor time plus a period

## Resolution

AI: Окно задаётся как фиксированная точка отсчёта (дата/время) плюс период (5 ч, день, неделя, месяц); следующий сброс вычисляется как anchor + n·period. Настройки лимита вводятся в поповере агента (ссылка «Задать лимит» из подсказки DEC-003), а хранятся в настройках приложения MarkView. — see DEC-014.
