## Finding

No thresholds are defined, so the colour criterion cannot be tested. It is also unclear whether the colour follows absolute percent or pace (percent used versus share of the window elapsed), which is the stated purpose in SRC-001.

> coloured by usage level (normal, warning, critical)

## Possible interpretations

- Fixed thresholds, e.g. 80%/95%
- Relative to pace within the window

## Resolution

AI: Цвет определяется по абсолютному проценту использования с фиксированными порогами: normal — меньше 80%, warning — от 80% до 95%, critical — 95% и выше (или лимит исчерпан). Показатель темпа (использовано в сравнении с прошедшей долей окна) цвет не меняет: он выводится отдельной строкой в поповере. — see DEC-008.
