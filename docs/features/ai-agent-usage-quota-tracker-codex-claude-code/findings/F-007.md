## Finding

Official data gives a percentage without a token limit, so 'tokens remaining' cannot be computed on that path. Mixing tokens counted from local logs with an official percentage could give inconsistent numbers. The popover in REQ-004 says 'where available', but the accepted fact is unconditional.

> The display must show tokens remaining until the next reset.

## Possible interpretations

- Remaining tokens are only shown on the fallback path
- Remaining tokens are derived from the official percentage and local counts

## Resolution

AI: Остаток в токенах/деньгах показываем только когда лимит известен в абсолютных единицах (fallback-путь с лимитом, введённым пользователем). На официальном пути остаток показываем как оставшийся процент (100% − использовано), а израсходованные токены из локальных логов выводим отдельно, как информацию. Абсолютный остаток из официального процента и локальных подсчётов не вычисляем. — see DEC-015.
