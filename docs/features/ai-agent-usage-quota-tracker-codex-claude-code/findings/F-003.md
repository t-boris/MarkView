## Finding

No refresh interval, rate limiting, caching or staleness display is defined for official requests or log parsing. Aggressive polling of undocumented vendor endpoints risks throttling. Old values may be shown without any indication that they are stale.

> requested using the agent's locally stored credentials

## Resolution

AI: Официальные данные запрашиваются не чаще раза в 5 минут для каждого агента: при открытии панели, по ручному обновлению (с ограничением в 60 секунд) и после 429/ошибки с экспоненциальной паузой до 30 минут. Локальные логи пересчитываются при изменении файлов, но не чаще раза в 30 секунд. Последнее значение кэшируется в памяти и показывается с отметкой «обновлено N мин назад»; если оно старше 15 минут, отображается как устаревшее. — see DEC-010.
