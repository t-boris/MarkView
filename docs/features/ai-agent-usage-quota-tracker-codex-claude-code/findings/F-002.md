## Finding

Claude Code and Codex subscriptions have several limits at once, such as a 5-hour session window and a weekly limit (AI inference, not verified here). The spec assumes one window per agent. It does not say which window is the headline, or whether several are shown.

> For the current quota window, the system shall show, per agent, the percentage of the limit used

## Possible interpretations

- Show the most constrained window
- Show all windows in the compact indicator
- Show the short window and put the others in the popover

## Resolution

AI: В компактном индикаторе показываем окно, которое сейчас ближе всего к исчерпанию: у него самый высокий процент использования, при равенстве берём окно с более поздним сбросом. По нему же выбираются цвет и время до сброса. Во всплывающем окне перечисляем все окна агента (например, 5-часовое и недельное), у каждого свой процент и время до сброса. — see DEC-009.
