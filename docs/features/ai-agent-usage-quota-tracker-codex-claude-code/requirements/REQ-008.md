## Statement

The system shall show the GitHub Copilot quota windows (monthly Plan budget in AI credits or premium/chat requests, plus 5-hour Session and Weekly rate limits when present, with percent used and reset time) in the top bar and its popover beside Claude Code, Codex, and Antigravity, read from the Copilot CLI's own headless JSON-RPC interface without reading any GitHub credential and without spending model tokens or AI credits.

## Acceptance Criteria

- [x] With Copilot signed in, a chip `Copilot` appears in the usage bar showing the most constrained window (`% used`, `plan` / `5h` / `week` label, countdown to reset), and the popover lists every finite window (`Plan (used / limit AIC)`, `5-hour session`, `Weekly`) with a progress meter and the `Official` badge.
- [x] Signed out: the chip says usage is unavailable and the popover says to open Copilot to refresh sign-in.
- [x] `copilot` missing, timing out, or returning an unrecognised payload shows `usage unavailable` with the reason, never zero.
- [x] Each poll runs `copilot --headless --no-auto-update --log-level none --log-dir /dev/null --stdio`, creating no session and leaving no log file in `~/.copilot/logs`.
- [x] Settings includes a `Show Copilot usage` toggle; `AssistantProviderHostTests` covers the parser and interpreter across token-based billing, legacy request billing, free tier, rate limits, signed-out responses, and errors.
