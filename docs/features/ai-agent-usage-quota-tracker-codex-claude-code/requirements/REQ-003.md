## Statement

The system shall show the time left until the agent's quota window resets, using the official reset time when available, otherwise the reset window configured by the user.

## Acceptance Criteria

- [ ] Official reset time is used when provided
- [ ] Otherwise the countdown follows the user-configured window
- [ ] Estimated reset times are marked as estimated
