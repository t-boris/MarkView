## Statement

The system shall read Claude Code / Codex stored credentials only locally and use them only to request official limit data from the respective agent vendor.

## Acceptance Criteria

- [ ] Credentials are never written to app storage, logs, or crash reports.
- [ ] Credentials are sent only to the respective agent vendor's endpoint.
- [ ] The app never modifies or refreshes-and-overwrites the agent's stored credentials.
