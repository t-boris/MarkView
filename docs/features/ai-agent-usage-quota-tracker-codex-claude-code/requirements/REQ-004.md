## Statement

The system shall show a compact per-agent progress indicator (percent of limit used and time until reset) in the MarkView AI terminal panel, coloured by usage level (normal, warning, critical); clicking it shall open a popover with details (used/remaining tokens or money where available, reset time, data source: official or local estimate).

## Acceptance Criteria

- [ ] The AI terminal panel shows a compact indicator for each supported agent with percent used and time until reset.
- [ ] Indicator colour changes between normal, warning and critical as usage rises.
- [ ] Clicking the indicator opens a popover with per-agent details, including whether data is official or a local estimate.
- [ ] For an agent without limit data, the compact area shows absolute usage and a 'set a limit' hint instead of a progress bar.
