## Statement

For agents without official limit data, the user shall be able to enter a quota limit (tokens or money) and reset window per agent; usage against that limit is computed from the agent's local CLI logs and sessions (~/.claude, ~/.codex) within the configured window.

## Acceptance Criteria

- [ ] Given a user-entered limit and window for an agent without official data, the indicator shows percent used computed from local log usage inside the current window.
- [ ] Usage is read only from local files; no API keys are requested.
- [ ] If local logs cannot be read or parsed, the agent shows 'usage unavailable' instead of a number.
- [ ] Money is shown only when the local logs record cost; otherwise only tokens are shown.
