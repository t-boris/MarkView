## Statement

For the current quota window, the system shall show, per agent, the percentage of the limit used as the headline metric, taken from the agent's official limit data (requested using the agent's locally stored credentials) when available, otherwise estimated from local usage data against the user-configured limit.

## Acceptance Criteria

- [ ] When the agent's stored credentials are present and the official request succeeds, the shown percentage matches the official value.
- [ ] When credentials are missing or the official request fails, the percentage is estimated from local usage and the configured limit, and is marked as an estimate.
- [ ] The display indicates whether each value is official or estimated.
