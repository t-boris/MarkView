## Context

DEC-003 shows absolute usage when no limit is known, but did not say over which period the local logs are summed.

## Alternatives

1. Last 5 hours
2. Today (since local midnight)
3. Last 7 days

## Decision

In the no-limit state the chip and the popover show the tokens (and cost, when logged) recorded since local midnight, labelled "today".

## Reason

A calendar day is easy to understand and cheap to scan.

## Consequences

The popover also shows today's usage in the other states as information.
