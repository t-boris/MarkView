## Context

Official percent-used and reset time (DEC-002) are generally only available to an authenticated agent session. The user decided whether the app may reuse the stored Claude Code / Codex OAuth credentials.

## Alternatives

1. A: Read the agents' stored credentials locally, only to request limit data
2. B: Use only what the agent itself outputs (status line, JSON output, logs), never read credentials
3. C: Ask explicit per-agent user consent before reading credentials

## Decision

The app reads the locally stored Claude Code / Codex credentials and uses them solely to request the agent's official limit data (percent used, reset time). Credentials are never copied, persisted by the app, logged, or sent anywhere other than the agent vendor's own endpoint.

## Reason

Gives accurate official data without manual input; the user is a single individual on their own machine.

## Consequences

Depends on undocumented vendor endpoints that may change; on failure the app falls back to the local estimate per DEC-002. Handling of sensitive tokens must be strictly limited.
