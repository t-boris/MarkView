## Context

For agents without official limit data and without a user-entered limit, no percentage can be computed.

## Alternatives

1. A: Show absolute usage (tokens/money) plus a 'set a limit' hint
2. B: Hide the agent until a limit is set
3. C: Show a 'no data' state linking to settings

## Decision

Show the absolute usage available from local data (tokens and/or money) and a hint prompting the user to set a limit; no progress indicator is shown in this state.

## Reason

Gives useful information immediately and nudges the user toward configuration, unlike hiding or an empty state.

## Consequences

The per-agent view needs a distinct no-limit state; the progress indicator and percentage appear only once a limit is known.
