## Context

DEC-006 places the indicator in the AI terminal panel. The panel is the right panel's Terminal tab; its header row already shows the AI cost figure.

## Alternatives

1. Chips in the Terminal tab header row
2. A separate row between the terminal tab bar and the PROMPTS bar

## Decision

One compact chip per shown agent sits in the Terminal tab header, between the title and the cost figure. Each chip shrinks (full → percent only → minimal) when the panel is narrow. Clicking a chip opens the detail popover.

## Reason

Uses space that is already there and keeps the terminal area unchanged.

## Consequences

The chips are visible only while the Terminal tab is selected, which also bounds polling (DEC-010).
