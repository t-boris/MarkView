## Context

Q-006: should the user be warned when approaching the limit, or is the visual indicator enough?

## Alternatives

1. A: No notifications — indicator only, colour changes at high usage
2. B: System notification at fixed thresholds (e.g. 80% and 95%)
3. C: Warning when usage runs ahead of pace (percent used > share of window elapsed)

## Decision

No notifications of any kind. The progress indicator changes colour as usage rises (normal / warning / critical).

## Reason

Simplest option and non-intrusive; the user chose the indicator as sufficient for pacing.

## Consequences

No notification permissions or threshold settings are needed. The user may miss an approaching limit if the indicator is not in view.
