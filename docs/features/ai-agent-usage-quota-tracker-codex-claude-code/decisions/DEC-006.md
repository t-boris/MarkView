## Context

Q-008: where to show per-agent usage in MarkView.

## Alternatives

1. Status line in the AI terminal panel only
2. macOS menu bar icon with agent dropdown
3. Compact indicator in the AI terminal panel plus detail popover on click

## Decision

Show a compact per-agent indicator in the AI terminal panel; details open in a popover on click.

## Reason

Visible while working with agents, uses minimal space, and keeps details available on demand without a new UI surface.

## Consequences

Usage is not visible when the AI terminal panel is closed; the menu bar surface is out of scope.
