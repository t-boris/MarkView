## Context

Percent of limit requires knowing the limit. Claude Code exposes cost/usage and rate-limit data; Codex exec output only gives per-turn token usage without a limit.

## Alternatives

1. A: Official agent rate-limit data only
2. B: Local log/session counting plus a user-entered limit
3. C: Official data where available, otherwise local estimate with user-entered limit

## Decision

Use official agent-provided limit data (percent used, reset time) when available; otherwise fall back to counting usage from local logs/sessions against a limit and window entered by the user. Each displayed value indicates whether it is exact (official) or estimated.

## Reason

Covers every agent while keeping provider-accurate numbers where they exist.

## Consequences

Two data paths must be maintained; UI must mark precision; the fallback requires a per-agent user setting for limit and reset window.
