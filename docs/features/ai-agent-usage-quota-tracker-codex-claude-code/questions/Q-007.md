## Question

Можно ли приложению использовать сохранённые учётные данные Claude Code / Codex (OAuth-токены), чтобы запрашивать официальные данные о лимитах?

## Why it matters

Официальные проценты и время сброса (DEC-002) обычно доступны только с авторизацией агента; от этого зависит, сколько данных будут точными, а сколько — оценкой.

## Options

- **A**: Да, читать токены агентов только локально и только для запроса лимитов
- **B**: Только то, что агент сам выводит (status line, JSON-вывод, логи), без чтения токенов
- **C**: Спрашивать явное согласие пользователя для каждого агента

## Answer

A. Да, читать токены агентов только локально и только для запроса лимитов
