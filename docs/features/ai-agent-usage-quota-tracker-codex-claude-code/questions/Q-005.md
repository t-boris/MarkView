## Question

Что показывать для агента, у которого нет официальных данных о лимите, а пользователь ещё не ввёл лимит?

## Why it matters

Без лимита процент посчитать нельзя — нужно решить, что видит пользователь в этом состоянии.

## Options

- **A**: Показывать только абсолютный расход (токены/деньги) и подсказку «задайте лимит»
- **B**: Скрывать агента, пока лимит не задан
- **C**: Показывать состояние «нет данных» со ссылкой на настройки

## Answer

A. Показывать только абсолютный расход (токены/деньги) и подсказку «задайте лимит»
