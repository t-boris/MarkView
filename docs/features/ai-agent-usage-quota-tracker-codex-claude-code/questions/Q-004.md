## Question

Откуда брать процент лимита и время до ресета для каждого агента?

## Why it matters

Процент требует знать лимит. В проекте видно: claude отдаёт total_cost_usd/usage, codex — только токены за ход, без лимита. От источника зависят точность, безопасность и поведение при отсутствии данных.

## Options

- **A**: Официальные данные агента о лимитах (напр. rate-limit данные из status line Claude Code / Codex), где доступны
- **B**: Подсчёт по локальным логам/сессиям плюс лимит, введённый пользователем вручную
- **C**: A, где доступно, иначе B как запасной вариант

## Answer

C. A, где доступно, иначе B как запасной вариант
