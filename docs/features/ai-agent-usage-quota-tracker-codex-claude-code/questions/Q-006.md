## Question

## Why it matters

## Options

- **A**: Без уведомлений — только индикатор (цвет меняется при высоком расходе)
- **B**: Системное уведомление при фиксированных порогах (напр. 80% и 95%)
- **C**: Предупреждение, если расход опережает темп (процент больше доли прошедшего окна)
