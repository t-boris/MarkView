## Summary

The user's original request, dictated by voice: for AI coding agents such as Codex and Claude Code, they want to see how much money or how many tokens remain in the current quota window. They want a progress view of tokens used and left before the reset and the time until the reset, so they can tell whether they are pacing their usage well. Some agent names are probably speech-to-text errors ("для кода", "compile", "AC line"). They may mean Claude Code and possibly other CLI agents.

## Content

Я хочу сделать такую фичу, чтобы для, например, кодекса, для кода, для compile, это AC line, я видел, сколько у меня либо денег осталось, либо токенов осталось. То есть я должен видеть прогресс. То есть до ресета сколько токенов у меня осталось или времени до ресета осталось, сколько я израсходовал до ресета токенов и так далее. То есть мне нужно видеть, насколько я придержался с токенами.
