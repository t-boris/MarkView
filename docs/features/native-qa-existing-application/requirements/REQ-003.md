## Statement

The system shall preserve user-owned processes while releasing QA resources.

## Acceptance Criteria

- [ ] Never terminate an attached process, including on failure, cancellation or repeated cleanup.
- [ ] Sequential branches for the same player reuse the intended process; independent players cannot share it.
