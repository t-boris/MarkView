## Finding

The panel has separate collapsible Features and Bugs sections. It's unclear whether sorting applies within each section or merges them into one list. The spec also doesn't say how the filter interacts with the free-text Filter (presumably AND) or what empty sections and empty results look like.

## Possible interpretations

- One merged list
