## Finding

REQ-002 AC 'single common priority scale' can't be tested because nothing defines the value sets for feature priority and bug severity, how they map to each other, or how unknown values are handled. Q-002 also says features may not have a priority field today.

> A priority/severity mapping must be defined by the implementer.

## Resolution

AI: Ввести общую 4-уровневую шкалу critical > high > medium > low. Для багов значение severity сопоставляется напрямую, blocker считается critical. Для фич берётся необязательное поле priority: те же слова или P0–P3. Отсутствующие или нераспознанные значения считаются пустыми и всегда идут в конец списка. — see DEC-007.
