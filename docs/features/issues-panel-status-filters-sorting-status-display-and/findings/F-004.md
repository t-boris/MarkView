## Finding

DEC-003 falls back from updated directly to mtime, while REQ-002 adds created in between. The spec also doesn't define the date format to parse, whether invalid dates count as missing, or a tie-breaker.

> Date = `updated` front-matter field, else `created`, else file modification time.

## Resolution

AI: Выровнять DEC-003 с REQ-002: updated → created → mtime; даты в формате ISO YYYY-MM-DD (или ISO 8601 с временем), невалидные считаются отсутствующими; при равенстве — по заголовку, затем по id. — see DEC-011.
