## Finding

The spec never says how selected filters combine. Open+Closed, Bugs only+Features only, and Bugs only+Implemented all give different results under AND, OR, or AND-across-groups/OR-within-group. DEC-002 assumes AND ('combining them yields implemented features'), but REQ-001 never states it. The source fact also marks this as unspecified.

> combinable filters: Open, Closed, Bugs only, Features only, Implemented features, Not-implemented features

## Possible interpretations

- AND across all selections (Bugs only + Features only = empty)
- OR within a group (status / type / implementation) and AND across groups
- Single-select radio items

## Resolution

AI: Фильтры разбиваются на три группы: Статус (Open/Closed), Тип (Bugs/Features) и Реализация (Implemented/Not-implemented). Внутри группы выбранные значения объединяются через OR, между группами — через AND. Пустая группа не ограничивает выборку. Если выбрать Implemented или Not-implemented, тип сужается до фич, поэтому сочетание с Bugs only даёт пустой список, и об этом сообщается явно. — see DEC-006.
