## Statement

The Issues panel shall be horizontally resizable using the same mechanism and limits as the other left sidebar panels.

## Acceptance Criteria

- [x] Dragging the divider changes the panel width
- [x] Min/max widths match the other left panels
- [x] Width persists across switching panels and app restarts, like the other panels

## Verified mechanism (DEC-013)

Files and Issues are one pane: `LeftPanelView` in `ContentView`'s `HSplitView`. It already resized,
but only between 180 and 350 px. With the user (2026-09-26) the limits became 180–800 px (default 220), and the
width is stored in `layout.leftPanelWidth` and restored on launch by `LeftPanelWidthKeeper`, because `HSplitView`
ignores `idealWidth`. Switching Files/Issues keeps the width because it is the same pane.
