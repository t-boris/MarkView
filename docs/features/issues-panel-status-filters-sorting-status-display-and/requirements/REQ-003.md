## Statement

Each feature and bug row shall show its status as visible text or a badge, not only in a tooltip.

- [x] Bug rows show status (e.g., open/closed) without hovering
- [x] Feature rows keep a status label that uses FeatureVocabulary
- [x] Status stays readable at the minimum panel width
