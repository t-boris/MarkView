## Statement

The Issues panel shall provide a funnel menu next to the Filter text field with combinable filters: Open, Closed, Bugs only, Features only, Implemented features, Not-implemented features. Open/Closed use one shared mapping: feature Closed = implemented/done/rejected/cancelled, bug Closed = closed/fixed, and any other or missing status = Open. Implemented = feature status implemented/done; Not-implemented = every other feature.

## Acceptance Criteria

- [x] A bug with status 'fixed' or 'closed' appears under Closed and not under Open.
- [x] A feature with status 'done' appears under Closed and Implemented.
- [x] A feature with status 'rejected' appears under Closed and Not-implemented.
- [x] A feature or bug with a missing or unknown status appears under Open.
- [x] Implemented and Not-implemented filters never show bugs.
- [x] Status matching is case-insensitive.

## Status mapping as implemented

Agreed with the user (2026-09-26): the feature vocabulary also has `verified` and `archived`.
Implemented = implemented, verified, done. Closed = those plus archived, rejected, cancelled.
Everything else is Open. See `MarkView/Models/IssueListing.swift` and `tools/tests/issue-listing-tests.sh`.
