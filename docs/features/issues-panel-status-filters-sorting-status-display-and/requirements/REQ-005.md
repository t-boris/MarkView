## Statement

The selected filter and sort shall persist per project across app restarts, stored in user defaults keyed by the project root (like features.active.<hash>).

## Acceptance Criteria

- [x] After changing filter and sort and restarting the app, the same project reopens with the same filter and sort applied.
- [x] Two different projects keep independent filter and sort settings.
- [x] A project with no saved settings starts with the default: no filter, default sort.
- [x] When a restored filter is non-default, the funnel icon is highlighted and the active-filter summary with reset is shown.
