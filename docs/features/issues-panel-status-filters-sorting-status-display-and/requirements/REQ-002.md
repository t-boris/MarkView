## Statement

The Issues panel shall provide a sort menu next to the Filter field that sorts features and bugs by date or by priority, ascending or descending. Date = `updated` front-matter field, else `created`, else file modification time. Priority = feature `priority` / bug `severity` mapped onto one common scale; items without priority are placed last regardless of direction.

## Acceptance Criteria

- [x] Sort by date orders items by `updated`, falling back to `created`, then to file mtime.
- [x] Items with equal dates are ordered by id with numeric comparison, newest id first under Newest First and oldest id first under Oldest First; titles do not affect the order (DEC-016).
- [x] Sort by priority orders features and bugs on a single common priority scale.
- [x] Items without a priority value appear after all prioritized items in both ascending and descending order.
- [x] Ascending and descending directions are both available and reverse the order of items that have values.
- [x] Sorting requires no git access and no changes to feature/bug file formats.
