## Question

Должны ли выбранные фильтр и сортировка сохраняться после перезапуска приложения?

## Why it matters

REQ-005 содержит открытое допущение; от ответа зависят критерии приёмки.

## Options

- **A**: Да, для каждого проекта отдельно, между перезапусками (как features.active.<hash>).
- **B**: Только в пределах сессии; после перезапуска — по умолчанию.
- **C**: Сохранять сортировку, а фильтр сбрасывать.

## Answer

A. Да, для каждого проекта отдельно, между перезапусками (как features.active.<hash>).
