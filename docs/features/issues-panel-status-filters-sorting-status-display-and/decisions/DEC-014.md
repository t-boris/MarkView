## Context

It is unclear whether rows show the raw or mapped status, how missing status is shown, how values are normalized, and how status behaves at minimum width.

## Alternatives

1. Show raw normalized status
2. Show only mapped Open/Closed
3. Show both raw and mapped

## Decision

Rows show the item's own status as a compact badge: features via FeatureVocabulary labels, bugs via the raw value. Values are normalized by trimming whitespace, lowercasing and treating '_' and ' ' as '-' (so 'In Progress' = 'in-progress') for both display and DEC-005 mapping. Missing status displays as 'open' in muted style and maps to Open. At narrow widths the title truncates first; the badge keeps its full text up to 12 characters, then truncates with an ellipsis and a tooltip.

## Reason

The raw status is more informative than Open/Closed, which the filter already conveys; consistent normalization keeps display and filter in agreement.

## Consequences

REQ-003 gains criteria for normalization, missing status and truncation; DEC-005 references the same normalization.
