## Context

Filters need a mapping from feature.status values to Open, Closed and Implemented (Q-001, Q-004).

## Alternatives

1. A: Implemented = implemented/done; Closed = implemented, done, rejected, cancelled; Open = everything else (overlapping groups)
2. B: Three disjoint groups: Open (draft/in progress), Implemented, Closed (rejected/cancelled)

## Decision

Option A: Implemented = implemented/done; Closed = implemented/done/rejected/cancelled; Open = any other status. Not-implemented = all features that are not Implemented.

## Reason

Simple and intuitive: closed features include delivered ones; chosen by the product owner.

## Consequences

Implemented and Closed filters overlap; combining them yields implemented features. Unknown status values count as Open.
