## Context

The Issues panel is narrow; always-visible filter/sort buttons would consume vertical and horizontal space and wrap.

## Alternatives

1. A: Icon menus (funnel, sort) next to the Filter field
2. B: Row of toggle chips under the search field
3. A+: Icon menus plus active-state highlight and a one-line summary of the active filter with a reset action

## Decision

Use a funnel menu and a sort menu placed beside the Filter text field. When the filter is non-default, the funnel icon is highlighted and a single-line summary of the active filter with a clear/reset control is shown above the list.

## Reason

Keeps the panel compact at any width while fixing option A's main weakness, which is that an active filter is not visible.

## Consequences

Filter options are reached through a menu (one extra click). An active-state indicator and a reset action are required. Chips are not used.
