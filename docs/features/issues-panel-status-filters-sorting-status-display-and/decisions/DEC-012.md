## Context

The panel has separate collapsible Features and Bugs sections; sort scope, text-filter interaction and empty states are undefined.

## Alternatives

1. Sort within each section
2. Merge into one sorted list
3. Merge only when a sort other than default is active

## Decision

Sorting applies within each section; sections keep their order and collapse state. Items must match both the funnel filter (DEC-006) and the free-text Filter (AND). A section with no matching items is hidden (e.g. 'Bugs only' hides Features). If nothing matches, the list shows 'No matching items' with a reset control that clears the funnel filter and text filter.

## Reason

Keeps the existing panel structure and user mental model; the unified priority scale still makes cross-type comparison meaningful within the 'Open' view per section.

## Consequences

REQ-002 and REQ-001 gain acceptance criteria for section scope, AND combination and empty states.
