## Context

REQ-001 lists combinable filters (Open, Closed, Bugs only, Features only, Implemented, Not-implemented) but does not define how multiple selections combine. The source (SRC-001) leaves the semantics unspecified. DEC-002 implicitly assumes AND. Pure AND makes same-group pairs such as Open+Closed or Bugs+Features always empty, and single-select rules out useful combinations such as 'open bugs'.

## Alternatives

1. AND across all selections (same-group pairs yield empty results)
2. OR within a group (Status, Type, Implementation) and AND across groups
3. Single-select radio items

## Decision

Filters are organized into three groups in the funnel menu: Status {Open, Closed}, Type {Bugs, Features}, Implementation {Implemented, Not-implemented}. Each item is a multi-select toggle. Selected items in the same group combine with OR, and groups combine with AND. A group with no selection (or with all items selected) does not restrict results. Implementation filters apply only to features: any selection in the Implementation group excludes bugs, so Bugs + Implemented yields an empty list, which shows an empty-state message ('No items match the current filter') with a reset action. Default = no selections (all items shown). Add acceptance criteria to REQ-001: (1) Open+Closed shows all items; (2) Bugs+Open shows only open bugs; (3) Features+Not-implemented+Open shows open non-implemented features; (4) Bugs+Implemented shows the empty state with reset.

## Reason

This is the standard faceted-filter model that users expect. It keeps every combination meaningful, supports the key use cases ('open bugs', 'unfinished features') without extra UI, and matches the grouping already implied by DEC-002 and DEC-005.

## Consequences

REQ-001 statement and acceptance criteria must be updated. DEC-001's menu design must show group headers or separators. The persisted filter (REQ-005) is stored as a set of selected items per group. The active-filter summary line lists the groups, e.g. 'Open · Bugs'. Resolves F-001 and partly F-005 (default filter = none).
