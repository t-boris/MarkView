## Context

REQ-001/REQ-002 are approved but depend on DEC-001, which is still proposed; the summary line and reset control are not covered by acceptance criteria.

## Alternatives

1. Accept DEC-001 as is and extend REQ-001 acceptance criteria
2. Reopen REQ-001/REQ-002 until DEC-001 is reviewed
3. Drop the summary line and keep only the icon highlight

## Decision

DEC-001 (option A+) is accepted. REQ-001 gains criteria: the funnel icon is highlighted whenever the filter differs from the default (DEC-008); a single-line summary of active filters (e.g. 'Open · Bugs') is shown above the list; its reset control restores the default filter without changing sort or the text filter.

## Reason

The approved requirements already assume this design; making the indicator testable closes the gap without rework.

## Consequences

REQ-001 is updated; DEC-001 status becomes accepted; QA can verify indicator and reset.
