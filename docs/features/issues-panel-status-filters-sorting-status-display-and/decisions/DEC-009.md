## Context

The Issues panel has separate collapsible Features and Bugs sections. REQ-002 says it "sorts features and bugs by date or by priority" and does not say whether sorting works per section or merges both into one list. It also does not say how the status/type filter combines with the free-text Filter, or what empty sections and empty results look like.

## Alternatives

1. Sort within each section, keeping the Features/Bugs sections
2. Merge features and bugs into one sorted list when a sort is active
3. Add a user toggle between sectioned and merged views

## Decision

Sorting applies within each section independently: Features and Bugs stay separate collapsible sections in their current order, and each section's items are ordered by the selected sort key and direction. An item is shown only if it matches the status/type filter (DEC-006) AND the free-text Filter. A section with no matching items is hidden entirely; it is not shown as an empty header. The 'Bugs only' and 'Features only' type filters hide the other section. If no items match in any section, the panel shows a 'No matching items' message with a 'Reset filters' action that clears the status/type filter and the text filter.

## Reason

Keeping the sections preserves the panel's existing mental model and collapse state and needs no new layout mode. The unified priority scale (DEC-003) keeps priority sorting comparable across sections. The type filters already cover the case of looking at one type only. A merged list would duplicate that capability and make the collapsible sections meaningless. AND with the text filter is the conventional behavior users expect.

## Consequences

REQ-002 acceptance criteria should state that sorting is per section. REQ-001 should state that the status/type filter is ANDed with the text filter and specify the hidden-empty-section behavior and the global empty state with reset. A cross-type merged timeline is out of scope and can be revisited later. Collapse state of sections is unaffected by sorting or filtering.
