## Context

Q-006: whether the filter and sort should survive an app restart.

## Alternatives

1. A: Persist per project across restarts
2. B: Session only, reset to defaults on restart
3. C: Persist sort only, reset filter

## Decision

Option A: persist filter and sort per project across restarts, keyed like features.active.<hash>.

## Reason

Users don't have to set them up again, and this matches the existing per-project settings. The risk of a forgotten filter is handled by the highlighted funnel and the active-filter summary (DEC-001).

## Consequences

New per-project user-defaults keys, which need documenting in configuration.md. The restored filter state must be visibly indicated.
