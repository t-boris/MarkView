## Statement

The system shall draw an animated backdrop behind the welcome screen wherever there is no text or button, offer Matrix rain, Aurora, Bug swarm, Network, Shuffle and Off, and remember the choice.

## Acceptance Criteria

- [ ] A Background menu on the welcome screen lists Matrix rain, Aurora, Bug swarm, Network, Shuffle (a random one each time the screen appears) and Off
- [ ] The choice is stored once for the app (all windows) and is still the choice after a restart; the default is Matrix rain
- [ ] Matrix rain: columns of changing katakana, digits and Markdown symbols fall at different speeds, bright head and fading tail
- [ ] Aurora: slowly drifting coloured light bands in the theme's colours
- [ ] Bug swarm: ants and ladybugs crawl along curved paths, facing the way they go, some in a marching line
- [ ] Network: nodes joined by lines, with pulses of light running along the lines
- [ ] Off shows the flat theme background
