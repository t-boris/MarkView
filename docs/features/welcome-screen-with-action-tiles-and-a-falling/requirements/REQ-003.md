## Statement

The system shall animate backdrops without per-frame work on the main thread, shall not move anything when the system asks to reduce motion, shall not take mouse events, and shall keep text and buttons readable in every theme.

## Acceptance Criteria

- [ ] Animations are Core Animation animations (the render server moves them); a window showing a backdrop uses no timer that fires more than once a second
- [ ] With Reduce Motion on, the backdrop is a still picture of the same scene
- [ ] Clicks, hover and the context menu reach the tiles and the lists: the backdrop view never answers a hit test
- [ ] A backdrop is rebuilt when the window size or the theme changes, and its colours come from the theme palette (dark and light)
- [ ] Text and tiles sit on cards that are nearly opaque, so a backdrop never lowers the legibility of a label
