## Statement

The welcome screen shall offer five additional distinct animated scenes and an optional By Project mode that reflects the current project's platform, scale and open bugs.

## Acceptance Criteria

- [ ] Orbit, Device Lab, Circuit Flow, Code Garden and Launch are selectable alongside the existing backgrounds, Shuffle and Off, and have distinct visual compositions and real motion.
- [ ] By Project chooses a scene from local platform and issue evidence, uses a stable project composition and adapts visual density to project activity; the screen explains the selection.
- [ ] Many open bugs or multiple critical bugs select Bug Swarm; mobile projects select Device Lab; larger projects select Orbit; web/backend projects select Circuit Flow; completed work with no open bugs can select Launch.
- [ ] Project inspection runs off the main thread with a work budget, ignores generated/dependency trees and symbolic links, respects cancellation, retains no source text and makes no AI or network calls.
- [ ] Existing per-window selection and session restoration work for every new choice. Backgrounds follow window themes, respect Reduce Motion, remain bounded and never consume clicks or break Accessibility scrolling.
- [ ] Verify rendered dark/light/narrow scenes and actual changing frames for all nine animations, live context changes and project switching, then pass the Debug build and complete the PR/release workflow.
