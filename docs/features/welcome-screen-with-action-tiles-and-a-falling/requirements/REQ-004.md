## Statement

The welcome screen shall offer five additional distinct animated scenes and an optional By Project mode that reflects the current project's platform, scale and open bugs.

## Acceptance Criteria

- [x] Orbit, Device Lab, Circuit Flow, Code Garden and Launch are selectable alongside the existing backgrounds, Shuffle and Off, and have distinct visual compositions and real motion.
- [x] By Project chooses a scene from local platform and issue evidence, uses a stable project composition and adapts visual density to project activity; the screen explains the selection.
- [x] Many open bugs or multiple critical bugs select Bug Swarm; mobile projects select Device Lab; larger projects select Orbit; web/backend projects select Circuit Flow; completed work with no open bugs can select Launch.
- [x] Project inspection runs off the main thread with a work budget, ignores generated/dependency trees and symbolic links, respects cancellation, retains no source text and makes no AI or network calls.
- [x] Existing per-window selection and session restoration work for every new choice. Backgrounds follow window themes, respect Reduce Motion, remain bounded and never consume clicks or break Accessibility scrolling.
- [ ] Verify rendered dark/light/narrow scenes and actual changing frames for all nine animations, live context changes and project switching, then pass the Debug build and complete the PR/release workflow.

## Verification

Local implementation verified for 5.67.0: 1,082 welcome checks pass, including all nine animations, dark/light/narrow hosted renders, actual changing presentation frames, live context changes, window independence, Reduce Motion and Accessibility scrolling. The pure project context/scanner suite passes platform detection, scene priorities, stable seeds, excluded trees, symlinks, budgets and cancellation. Final Debug build passes.

The isolated real app shows Device Lab for an iOS project with zero open bugs, changes to Bug Swarm after eight fixture bugs are opened, and returns to Device Lab when the project's custom workflow marks them done. A separate backend window shows Circuit Flow with moving packets, while the iOS window retains its own context. No installed app or user session is changed. PR and signed/notarized release delivery remain pending.
