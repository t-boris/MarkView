## Statement

The system shall show, on the welcome screen of a project window with no file open, one tile per action (title, one-line hint, shortcut where the app has one) grouped as Start, Explore and Build & Run, instead of the four small buttons, and shall keep the "Ready to resume" list.

## Acceptance Criteria

- [ ] Tiles: Open Terminal (prominent), New Feature…, New Bug…, Discussions, Tasks, Open X-Ray, Search Project…, Show Files, Open File…, Git (only when the folder is a Git repository), Build & Deployment, UI Studio, Browser
- [ ] Each tile runs the same action as the menu item or command it names, and shows the menu's shortcut
- [ ] The tiles reflow with the window width and the app font scale; no tile is cut off at 700 pt width
- [ ] The empty-window state (no folder) keeps Open Folder…, Open File…, New Project…, drafts and recent projects, in the same tile style
