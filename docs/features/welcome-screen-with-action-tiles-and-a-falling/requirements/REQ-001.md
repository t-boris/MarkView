## Statement

The system shall show, on the welcome screen of a project window with no file open, one tile per action (title, one-line hint, shortcut where the app has one) grouped as Start, Explore and Build & Run, instead of the four small buttons, and shall keep the "Ready to resume" list.

## Acceptance Criteria

- [x] Tiles in three groups. Start: Open Terminal (prominent), New Feature…, Quick Feature…, New Bug…, Discussions, Tasks. Explore: Open X-Ray, I Need to Understand…, New Research…, Search Project…, Show Files, Open File…. Build & Run: Git (only when the folder is a Git repository), Build & Deployment, Workflow, UI Studio, Browser
- [x] Each tile runs the same action as the menu item or command it names, and shows the menu's shortcut
- [ ] The tiles reflow with the window width and the app font scale; no tile is cut off at 700 pt width
- [x] The empty-window state (no folder) offers Open Folder…, Open File…, New Project…, drafts and recent projects, in the same tile style
