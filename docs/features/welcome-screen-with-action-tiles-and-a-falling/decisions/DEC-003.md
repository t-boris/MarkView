## Context

Boris requested five more splash-screen animations and animations that express the project's platform, complexity and bug burden.

## Alternatives

1. Use an AI-generated raster/video per project (external calls, source privacy and latency).
2. Only add random decorative backgrounds (does not express project characteristics).

## Decision

Add Orbit, Device Lab, Circuit Flow, Code Garden and Launch as individual Core Animation scenes, plus an opt-in By Project choice. Derive scene selection from a bounded local scan and the existing live feature/bug store. Prioritize many/critical open bugs, then mobile platform, project scale, web/backend, completed work and growth. Use the root path as a stable composition seed, cap density, and display the detected scene and project evidence. Keep existing saved choices and per-window persistence.

## Reason

This makes projects visibly different and responsive to real issue state without AI calls, source uploads, frame timers or a new permission flow.

## Consequences

The platform/scale classification is a local heuristic, explained with its observed evidence; dependency/generated/test trees and symlinks are excluded, scans are cancellable and capped. Unknown or empty projects get Code Garden. Existing Matrix/Aurora/Bugs/Network and Shuffle/Off remain available.
