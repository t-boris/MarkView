## Context

Boris asked for several backgrounds to choose from. A theme is chosen per window, a backdrop is decoration of an empty screen.

## Alternatives

1. Per window, like the theme
2. Per project in .dde/
3. Only in DDE Settings

## Decision

The choice is one UserDefaults key (welcomeBackdrop) shared by all windows, changed from a small menu on the welcome screen itself; the default is Matrix rain. No per-project setting and no entry in DDE Settings for now.

## Reason

The menu is where the decoration is seen; a new UserDefaults key changes no stored project data.

## Consequences

Changing the backdrop in one window changes it in every open welcome screen at once.
