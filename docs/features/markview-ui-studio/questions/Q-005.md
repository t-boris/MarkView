## Question

Что делать с «Sync from code» и «Hand off to code» у ранее сохранённых реконструкций из кода?

## Why it matters

DEC-002 заменяет создание реконструкций из существующего кода на UI Studio и требует, чтобы ранее сохранённые реконструкции оставались доступными как исторические. В коде у таких прототипов есть «Sync from code» (пересобирает реконструкцию из текущего кода) и «Hand off to code» (переносит правки прототипа в код); спецификация не говорила, что с ними делать.

## Options

- **A**: «Sync from code» открывает UI Studio на настоящем приложении вместо пересборки реконструкции; «Hand off to code» остаётся; прототип помечен как историческая реконструкция.
- **B**: Обе кнопки работают как раньше; меняется только метка и создание новых реконструкций.
- **C**: Исторические реконструкции открываются только для просмотра; вместо Sync и Hand off — «Open in UI Studio».

## Recommended

A — Сохраняет перенос уже сделанных правок и не оставляет второго способа реконструировать существующий код.

## Answer

A. «Sync from code» ведёт в UI Studio; «Hand off to code» остаётся; прототип помечен как историческая реконструкция.
