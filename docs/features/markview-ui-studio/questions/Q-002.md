## Question

UI Studio добавляется к Prototype Studio или заменяет её режим реконструкции из существующего кода?

## Why it matters

Документ описывает новый цикл, но не определяет судьбу уже реализованного пользовательского процесса.

## Options

- **A**: Добавить UI Studio для реального приложения рядом с существующей Prototype Studio.
- **B**: Заменить создание прототипов из существующего кода новым режимом; прототипирование по требованиям сохранить.

## Recommended

A — Новый режим имеет более узкую совместимость, а существующий процесс реконструкции уже используется.

## Answer

B. Заменить создание прототипов из существующего кода новым режимом; прототипирование по требованиям сохранить.
