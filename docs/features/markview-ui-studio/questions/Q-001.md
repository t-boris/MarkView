## Question

Какую совместимость обещаем в первом релизе: предложенный React/TypeScript/Vite или стек конкретного вашего проекта?

## Why it matters

В документе стек прямо назван предложением, требующим подтверждения. Поддержка Preview Web App более широкого набора стеков не означает их поддержку в UI Studio.

## Options

- **A**: Первый релиз поддерживает только клиентские приложения React + TypeScript + Vite.
- **B**: Первый релиз ориентирован на один конкретный существующий проект; укажите его.

## Recommended

A — Документ уже подробно ограничивает этот вариант; нативная оболочка MarkView ему не противоречит.

## Answer

Any Web app including electron apps
