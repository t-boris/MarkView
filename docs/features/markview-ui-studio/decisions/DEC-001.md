## Context

The initial stack was a proposal rather than an established constraint.

## Alternatives

1. Limit the first release to React, TypeScript and Vite.
2. Support web applications across frameworks, including Electron applications.

## Decision

Target web applications across frameworks, including Electron applications.

## Reason

The owner explicitly requested broader compatibility.

## Consequences

The React/Vite-only proposal is superseded. The runtime and dependency boundary still needs clarification against the overview's explicit exclusions.
