## Context

Boris (2026-11-04) on vivaa: "In any situation I must be able to fill something in and get through — if I tell it to pass authentication, it passes. What we typed does not matter and must not be checked; it is purely a mock-up. It must fully simulate all the data: logins, database, everything." vivaa's login uses Supabase (password and Google OAuth), its data comes from HTTP services.

## Alternatives

1. Keep auth to AI-prepared rules only: slow, and tokens would not be valid JWTs
2. Ask the person to sign in with a real account: sends real credentials to real services and is not repeatable
3. Bypass the app's auth checks in code: changes the project under test

## Decision

Every simulated sign-in, sign-up, verification, password reset, payment and form submission succeeds with any input and signs in the scenario's test user. Supabase Auth gets a built-in mock (GoTrue endpoints with signed test JWTs). Other providers get AI-prepared rules under the same mock-up policy, with placeholders for consistent test tokens. Navigations to a simulated service are answered by the simulation; navigations to an external site (OAuth provider, checkout) show a local simulated page that returns to the app as if it succeeded. A rule rejects input only when the scenario asks for an error.

## Reason

UI Studio exists to see and change the interface in every state; a login or validation that cannot be passed blocks every screen behind it. Tokens must still have the shapes libraries check, or the application fails closed (BUG-073).

## Consequences

Built-in mock for Supabase Auth; mock-up policy in the preparation prompt; `{{studio.*}}` placeholders in fixed responses; simulated pages for external navigations. Direct database connections in server code (drivers, ORMs) stay outside the simulation for now; they need a decision of their own (for example a test database seeded from the scenario). OAuth that the app's own server completes against a real provider (NextAuth with Google) returns to the app, but its code exchange is only simulated when the provider's address is a simulated connection.
