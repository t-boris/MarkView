## Context

Saved code-mode prototypes offer "Sync from code", which rebuilds the reconstruction from the current code, and "Hand off to code", which carries the prototype's edits into the code. DEC-002 replaces the creation of reconstructions from existing code with UI Studio.

## Alternatives

1. "Sync from code" opens UI Studio instead of rebuilding the reconstruction; "Hand off to code" stays.
2. Keep both actions unchanged.
3. Make historical reconstructions view-only and offer only "Open in UI Studio".

## Decision

"Sync from code" on a saved reconstruction opens UI Studio on the real application instead of rebuilding the reconstruction. "Hand off to code" remains available. A saved reconstruction is labelled as a historical reconstruction.

## Reason

The owner selected this option: edits already made in a reconstruction can still reach the code, and existing code is no longer reconstructed a second way.

## Consequences

No code path creates or rebuilds a reconstruction from existing code. Saved reconstructions stay openable and are never presented as live application sessions.
