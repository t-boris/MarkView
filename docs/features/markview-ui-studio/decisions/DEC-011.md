## Context

On vivaa every package photo in the simulated records (images.unsplash.com) was blocked by the connection policy. The pages looked empty, and the session was "degraded" by 8 "unsupported dependencies".

## Alternatives

1. Local placeholders: nothing leaves the Mac, but the pictures are fake
2. Keep blocking: pages look broken

## Decision

The content rule list lets pictures load from any http(s) address (resource type image: `<img>`, CSS backgrounds, preloaded images). Documents, scripts, styles, fonts, sockets, fetch and XHR keep today's policy: the dev server, the simulation and the addresses the person allows.

## Reason

Boris chose it (2026-11-04, "Пропускать картинки"). A mock-up has to show its data's pictures. Only the picture's address leaves the Mac: no application data and no credentials.
