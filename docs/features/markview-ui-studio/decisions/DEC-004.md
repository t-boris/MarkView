## Context

Framework-independent support did not previously define the execution boundary.

## Alternatives

1. Include SSR execution and server or native dependency adapters in the first release.

## Decision

Support client-rendered web interfaces across frameworks, including Electron renderers, while retaining the first-release exclusions for SSR and server or native dependency adapters.

## Reason

The user explicitly selected this execution boundary.

## Consequences

Electron compatibility covers browser-executable renderer scenarios. Scenarios requiring excluded dependencies must disclose their limitations.
