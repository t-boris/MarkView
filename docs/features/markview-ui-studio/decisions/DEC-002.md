## Context

Prototype Studio currently supports separate HTML reconstructions of existing application code.

## Alternatives

1. Keep reconstruction from existing code alongside UI Studio.
2. Replace reconstruction from existing code while retaining requirements-based prototyping.

## Decision

Replace creation of reconstructions from existing code with UI Studio; retain prototyping from requirements.

## Reason

The owner selected replacement of the existing-code workflow.

## Consequences

Existing-code entry points must lead to UI Studio. Previously saved reconstructions must remain accessible without being presented as live application sessions.
