## Summary

This source is a draft technical specification for MarkView UI Studio, describing real application execution, managed dependency simulation, source-aware selection, reversible AI editing and reproducible review evidence. It provides candidate behavior, architecture, acceptance scenarios and a phased implementation plan, while explicitly leaving compatibility, hosting, editing workspace and isolation decisions unresolved. Its proposals are not confirmed implementation facts or accepted feature requirements.
