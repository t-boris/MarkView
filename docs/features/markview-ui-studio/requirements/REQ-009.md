## Statement

The system shall show the questions and changes of a UI Studio session as a conversation that stays visible while the assistant works, give follow-up requests the recent turns, and accept dictated input.

## Acceptance Criteria

- [ ] Earlier questions, answers and changes stay visible as a thread, each with its element.
- [ ] A sent request appears at once with the assistant's progress and a way to stop it.
- [ ] Questions and change requests carry the recent turns, redacted and bounded in size.
- [ ] The composer has dictation that inserts the transcript at the cursor.
- [ ] Repeated identical page events are shown once with a count and can be expanded to the full text.
