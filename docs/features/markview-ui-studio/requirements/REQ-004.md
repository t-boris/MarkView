## Statement

Apply AI-requested UI changes directly to working sources with operation history, conflict detection and selective undo.

## Acceptance Criteria

- [x] Questions about selected elements leave project files unchanged; UI change requests modify persistent project sources and respect existing styling conventions.
- [x] The affected scope is identified before editing, and material ambiguity is clarified.
- [x] Each operation records its request, changes and verification; concurrent edits are detected rather than silently overwritten.
- [x] Undo removes the selected operation while preserving independent changes, or exposes a conflict for resolution.
- [x] After editing, Studio waits for the updated application and restores the scenario; build failure is visible and the previous preview is marked stale.
