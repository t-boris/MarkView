## Statement

Run trusted local projects with explicit application, simulation and agent access boundaries, protect secrets and session integrity, and disclose that the first release does not isolate untrusted project code.

## Acceptance Criteria

- [x] Only trusted local projects are within the supported execution model; the interface states that project processes run with the user's permissions.
- [x] Application connections and model connections have separate explicit policies; unknown simulated requests never automatically reach real services.
- [x] Use test credentials, filter confidential context before model submission, and keep secrets out of logs and exported evidence.
- [x] Validate bridge message origin, session identity and payload; reject stale results after cancellation or Reset.
- [x] Stop only session-owned processes and release session resources on closure.
- [x] Do not claim operating-system isolation or safe execution of malicious projects based on HTTP interception.
