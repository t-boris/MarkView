## Statement

The system shall open UI Studio from a button in the window toolbar and show, from a button in the UI Studio toolbar, one log of what the session did: navigations and redirects, requests, rule preparations and their outcomes, page events and server output.

## Acceptance Criteria

- [ ] The window toolbar of a project window has a UI Studio button next to Deployments and Discussions; it opens UI Studio or focuses its tab and is highlighted while that tab is active
- [ ] The UI Studio toolbar has a Log button with the number of problems; it opens a log under the page with All, Problems, Requests and Server filters, newest first
- [ ] A server redirect (for example 307 to the login page), a blocked or simulated navigation, every request with its transport and outcome, and every rule preparation with its duration and outcome appear in the log
- [ ] The session log is also written to .dde/studio/session.log, rotated at 2 MB, with secrets and credentials redacted
