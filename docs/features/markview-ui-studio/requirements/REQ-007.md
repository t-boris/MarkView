## Statement

The system shall answer the HTTP requests a development server started by UI Studio makes to the project's backends with the session's simulation, and run that server on the scenario's test clock, time zone and locale.

## Acceptance Criteria

- [x] Backend URL variables found in the project's .env files and source are pointed at MarkView's loopback gateway when the session starts the server; each can be switched to the real service, which restarts the server.
- [x] A server request is matched, prepared and logged like a page request, keeps its original origin in the contract and is shown with transport "server".
- [x] The project's secrets reach the server as test values unless the person keeps one real; real secret values are never stored, logged or sent to the model.
- [x] Framework data requests (Next.js RSC and server actions, Remix, SvelteKit, Nuxt, Astro) reach the development server and bypass its development fetch cache.
- [x] Server-rendered text that depends on the date, time zone or locale matches the page: the server and the page share the scenario's test clock, and cookie expiry dates stay valid in real time.
- [x] Hard-coded hosts, non-HTTP connections, servers MarkView did not start, non-Node servers' clocks and webpack dev servers' clocks are disclosed as not simulated.
