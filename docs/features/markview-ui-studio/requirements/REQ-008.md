## Statement

The system shall answer the page's use of location, clipboard, camera and microphone, and notifications from the scenario instead of the Mac, and keep chosen cookies and storage across restores.

## Acceptance Criteria

- [x] A scenario sets location as denied, unavailable or a place; navigator.geolocation and permissions.query answer from it.
- [x] Clipboard writes are shown in Studio and never reach the Mac's clipboard; reads return the scenario's text.
- [x] getUserMedia answers with a denial or a test stream; the Mac's camera and microphone are never used.
- [x] Notification permission comes from the scenario; shown notifications are listed in Studio.
- [x] Each use is reported as a browser dependency of the session.
- [x] The person can keep the page's cookies and local storage; kept data survives Reset, scenario switches and changes, and confidential entries are not kept.
- [x] Saved scenarios and environments without these settings still load.
