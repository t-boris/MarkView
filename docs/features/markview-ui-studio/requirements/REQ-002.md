## Statement

Provide stateful dependency simulation with reusable handlers, bounded agent preparation and reproducible scenario state.

## Acceptance Criteria

- [x] Supported JSON REST requests through fetch/XHR use consistent shared entity state for lists, details and atomic CRUD operations.
- [x] Registered handlers serve requests without model calls; unknown requests trigger bounded, validated preparation and never fall through automatically to real services.
- [x] Invalid or timed-out preparation produces a controlled error without partial state changes; cancelled or obsolete results cannot mutate the active scenario.
- [x] Duplicate write operations do not repeat effects; Reset restores the scenario baseline.
