## Statement

Let users inspect visible UI elements and connect a selection to the actual project source.

## Acceptance Criteria

- [x] Interaction and selection modes are distinct; selecting an element does not execute its business action.
- [x] Selection supports highlighting and parent navigation with correct geometry under scrolling and zoom; zoom does not change the application viewport.
- [x] For the supported stack, selection identifies the source node and repeated component instance and provides the agent with source context, relevant styles, an image, route, scenario and code revision.
- [x] Unsupported selection boundaries are disclosed, and stale or ambiguous source mappings are revalidated or cleared.
