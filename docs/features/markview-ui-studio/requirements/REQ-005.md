## Statement

Preserve reproducible scenarios and revision-linked visual evidence for reviewing and exporting UI changes.

## Acceptance Criteria

- [x] Saved scenarios reproduce populated, empty, loading, error, detail and editing states without changing production UI code.
- [x] Scenarios preserve baseline data and restoration steps separately from mutable session state, and disclose incompatibility after contract changes.
- [x] Before and after captures use the same baseline scenario and rendering conditions, with side-by-side and image-difference views.
- [x] A feature package includes the description, code changes, baseline and final revisions, scenario, rendering metadata, captures and verification results.
- [x] Subsequent baseline code changes mark the package as requiring revalidation while retaining historical captures.
