## Statement

The system shall visibly identify every executed input in QA videos, including its player, target when available, click, text entry, selection, key, scrolling direction, direct navigation and failed attempt.

## Acceptance Criteria

- [ ] Clicks show a marker at the actual control before the page changes; fields are outlined for typing and selection.
- [ ] Scrolling has a direction indicator; key input and direct navigation have distinct labels.
- [ ] Markers are attached to the correct player's image, scale correctly for multiple players and different window sizes, and remain readable in exported MP4 files.
- [ ] Failed actions are labelled as failed rather than successful; unavailable target geometry never invents a position.
- [ ] Annotations do not change the tested application or contaminate screenshots supplied for review.
