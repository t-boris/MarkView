# Visible actions in QA recordings

## Idea

Show every QA player's actions in recorded videos: clearly mark the clicked control and text-entry field, scrolling direction, selection, keyboard input and direct navigation. Viewers must be able to follow what a client or administrator did. Mark the actual target before the screen changes and distinguish failed attempts. Keep annotations out of the application under test and its review screenshots.
