## Question

Какую силу имеют ручные закрытие и повторное открытие GitHub issue для связанных записей MarkView?

## Why it matters

Существующий Sync односторонний, а исследование не устанавливает правило обратного влияния.

## Options

- **A**: MarkView определяет локальные статусы; изменения GitHub учитываются как свидетельства и расхождения для проверки.
- **B**: Закрытие и повторное открытие GitHub автоматически меняют связанные локальные issues.
- **C**: При расхождении GitHub и MarkView всегда спрашивать человека.

## Recommended

A — Состояние GitHub не доказывает само по себе, что все связанные работы выполнены.

## Answer

A. MarkView определяет локальные статусы; изменения GitHub учитываются как свидетельства и расхождения для проверки.
