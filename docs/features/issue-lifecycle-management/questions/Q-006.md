## Question

Должна ли функция автоматически закрывать и повторно открывать связанные GitHub issues?

## Why it matters

Исследование предлагает поэтапное включение, но текущее поведение поддерживает только ручное закрытие.

## Options

- **A**: Автоматически закрывать и повторно открывать GitHub issue по проверенному состоянию всех связанных работ.
- **B**: Сначала только предлагать закрытие и повторное открытие GitHub issue человеку.
- **C**: Оставить изменения GitHub только в ручном Sync.

## Recommended

A — Автоматическая синхронизация соответствует цели запроса; её можно включать после проверки надёжности.

## Answer

A. Автоматически закрывать и повторно открывать GitHub issue по проверенному состоянию всех связанных работ.
