## Statement

Make current issue context and lifecycle guidance available to AI during supported work sessions.

## Acceptance Criteria

- [ ] A supported AI session can discover the project's issue workflow and retrieve the relevant issue and its current status.
- [ ] When the session changes tasks or resumes, the agent can refresh the relevant issue context.
- [ ] An unavailable issue-management connection is visible rather than presented as a successful connection.
