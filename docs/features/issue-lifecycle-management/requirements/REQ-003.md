## Statement

The system shall provide issue context and lifecycle guidance throughout supported MarkView AI work sessions and explicitly connected external sessions.

## Acceptance Criteria

- [ ] Supported MarkView sessions receive available issue operations, applicable lifecycle rules and the current issue context when work is linked to an issue.
- [ ] Issue context identifies the current status, outstanding work and conditions required for the next transition.
- [ ] Session guidance directs AI to manage issues through MarkView MCP and does not authorize AI to impersonate human approval or override authority.
- [ ] External sessions enter the guaranteed context and automation scope only after explicit connection; registration alone is not treated as proof of workflow compliance.
