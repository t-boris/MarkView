## Statement

The system shall automatically close and reopen linked GitHub issues according to the verified lifecycle state of all linked work.

## Acceptance Criteria

- [x] An open linked GitHub issue closes automatically only when completion is verified for every linked feature and bug.
- [x] A closed linked GitHub issue reopens automatically when a linked issue is confirmed reopened for unfinished work.
- [x] A human status override alone does not constitute verified completion for automatic GitHub closure.
- [x] Unknown state or cancellation without verified completion does not qualify an issue for automatic closure.
- [x] Before changing GitHub state, the system checks current links, linked work and access; retries reconcile the actual remote outcome.
