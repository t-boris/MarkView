## Statement

The system shall enforce evidence-based lifecycle transitions while preserving separate feature and bug vocabularies and an explicitly justified human override.

## Acceptance Criteria

- [ ] A failed handoff does not leave an issue marked implementing or fixing; successful handoff provides start evidence.
- [ ] Automatic implementation completion requires evidence that all associated implementation work is merged, required checks passed and any project-required release was delivered.
- [ ] Features use implemented for implementation completion and verified for separately evidenced acceptance verification; bugs retain their existing status vocabulary.
- [ ] A human can force a status transition only with a non-empty reason; AI cannot exercise this override.
- [ ] A confirmed regression reopens the original issue into its applicable unfinished stage; independent new work is tracked as a linked issue.
