## Statement

The system shall preserve trustworthy lifecycle state and reconcile uncertainty, conflicting changes and partial failures without treating missing evidence as success.

## Acceptance Criteria

- [ ] Missing, unavailable, stale or ambiguously associated evidence does not cause automatic completion.
- [ ] Repeated or delayed observations do not duplicate transitions or overwrite a newer valid state.
- [ ] External Markdown status edits are detected and reconciled; their presence alone does not prove that lifecycle conditions were met.
- [ ] GitHub closure or reopening alone does not change local lifecycle status; any discrepancy remains visible for reconciliation.
- [ ] After interruption or dependency recovery, the system reconciles pending work against current state before retrying changes.
