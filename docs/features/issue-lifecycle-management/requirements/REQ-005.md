## Statement

Preserve a trustworthy issue state when lifecycle evidence or a dependent service is unavailable.

## Acceptance Criteria

- [ ] When available evidence is insufficient or sources conflict, the system does not silently present an unconfirmed automatic transition as fact.
- [ ] A failed status change or synchronization is visible and can be retried or resolved.
