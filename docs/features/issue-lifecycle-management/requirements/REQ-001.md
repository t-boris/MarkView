## Statement

The system shall provide consistent lifecycle management for features and bugs through MarkView UI and project MCP.

## Acceptance Criteria

- [x] People can inspect and request lifecycle changes for both features and bugs in MarkView; AI can do so through the project MCP.
- [x] UI, MCP and automatic workflows apply the same lifecycle conditions and actor permissions.
- [x] Rejected requests return an explanation without changing the issue status.
