## Context

REQ-006 and Q-006 close a linked GitHub issue only on verified completion of all linked work. Current manual Sync also counts archived-without-implementation features and duplicate bugs as done. Answered by Q-009.

## Alternatives

1. Only acceptance: features verified and bugs closed after a fix (Q-009 B).

## Decision

An item has verified completion when it is a feature in implemented or verified, or a bug in fixed or in closed after a fix, and the transition that completed it was made on delivery evidence (merge, required checks, required release) or its delivery evidence is confirmed again now. A human override, archived without implementation, a bug closed as duplicate or invalid, an externally edited status and an unknown status are not verified completion. A GitHub issue closes automatically only when every feature and bug linked to it has verified completion; it reopens when a linked item is reopened after the issue was closed. Manual Sync uses the same rule.

## Reason

Boris chose "implementation with evidence" (Q-009 A), consistent with DEC-007.

## Consequences

Manual Sync stops closing issues for archived features and duplicate bugs; those stay open for a person to close.
