## Context

REQ-002 keeps the bug vocabulary (open, fixing, fixed, closed) and the feature one; REQ-006 excludes cancellation from verified completion. The records do not say which bug status is completion and which is cancellation.

## Alternatives

1. Add a new cancelled status.

## Decision

Bugs: open is unstarted, fixing is under way, fixed is implementation completion (delivery evidence), closed is either acceptance after a fix (fixed → closed) or a close without a fix (duplicate, invalid, already fixed on main by evidence, withdrawn); the second kind is a cancellation unless the validity check recorded that the bug is already fixed on main. Features: archived after implemented or verified keeps the completion; archived from an earlier stage is a cancellation. A transition record states which of completion or cancellation it is.

## Reason

This reuses the existing meaning of the statuses and gives REQ-006 criterion 4 a testable form.

## Consequences

No stored-vocabulary change, so no migration of docs/ records.
