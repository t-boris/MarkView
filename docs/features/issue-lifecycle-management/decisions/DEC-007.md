## Context

Implementation completion needs an explicit threshold.

## Alternatives

1. Complete implementation after merge and required checks.
2. Use human or agent progress declarations as transition evidence.

## Decision

Implementation is complete only after merge, required checks and any release required by the project's rules.

## Reason

The user selected the release-inclusive completion threshold.

## Consequences

Merged work remains in progress until required release evidence is available. Acceptance verification remains separate.
