## Finding

The spec does not say whether research runs in the Claude terminal (BUG-002 shows long prompts being truncated there) or through an API. It also does not cover how progress is shown, how the user cancels a run, or what 'interrupted' means for DEC-004. Large repositories raise context-size limits that are not addressed.

> Research can be interrupted, fail due to an AI error, or lose web search access mid-run.

## Possible interpretations

- Terminal-based AI tool
- Background API job

## Resolution

AI: Исследование запускается как фоновая задача через Claude Code в неинтерактивном режиме: prompt передаётся через файл, а не вставкой в терминал (обход BUG-002). Прогресс показывается в индикаторе задач, есть кнопка Cancel. Отмена считается прерыванием по DEC-004. На больших репозиториях агент сам ищет и читает файлы, а не загружает весь репозиторий. — see DEC-012.
