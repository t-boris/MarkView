## Finding

REQ-004 requires every finding to carry one of four labels, with URLs and file paths. The document template is not defined: sections (question, findings, recommendations, sources), label syntax, the incomplete marker and the follow-up section delimiter. As a result, the acceptance criteria cannot be tested.

> Each finding is labelled as project fact, external fact, AI inference or open assumption.

## Resolution

AI: Задать фиксированный шаблон: front-matter; разделы Question, Summary, Findings, Recommendations, Sources. У каждого вывода префикс-метка [Project fact]/[External fact]/[AI inference]/[Open assumption]. Каждый follow-up — раздел «## Follow-up N: <вопрос>» после разделителя `---`. Для незавершённой работы — callout-блок «> ⚠️ Incomplete: <причина>». — see DEC-008.
