## Finding

Scope and SRC-001 mention reviewing a specific document and 'free-text question plus attachments'. No requirement covers how the user selects a target document, whether the currently open document is used, or how attachments are handled.

> IN: new intake kind "Research" in the New… menu; free-text question plus attachments

## Possible interpretations

- Pick a file in the intake dialog
- Use the currently opened document
- Attachments only

## Resolution

AI: В диалоге приёма есть необязательное поле «Target documents»: по умолчанию туда подставляется открытый сейчас документ, пользователь может убрать его или добавить файлы. Вложения (файлы или изображения) передаются как дополнительный контекст, копируются в docs/research/assets/ и указываются в Sources. — see DEC-009.
