## Finding

The spec does not define which files are in scope (ignored, binary or generated files; size limits), what happens when the repository is empty, or how large repositories are sampled.

> The research is performed over the current repository's code and documentation

## Resolution

AI: В анализ входят отслеживаемые git текстовые файлы с учётом .gitignore. Бинарные, сгенерированные и vendor-файлы, а также файлы больше ~1 МБ исключаются. Большие репозитории исследуются через поиск агентом (DEC-012), а не целиком. Для пустого репозитория (или репозитория без подходящих файлов) исследование всё равно выполняется, но в документе явно указано, что проектных фактов нет. — see DEC-016.
