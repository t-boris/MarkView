## Finding

The user may edit the Markdown between follow-ups, or it may have unsaved changes open in the editor. The spec does not say whether an append uses the current file content, and it does not cover conflicts with unsaved edits. It also does not say whether earlier sections are sent to the AI as context.

> Previously written sections remain unchanged after a follow-up.

## Resolution

AI: Перед дозаписью несохранённые правки в редакторе сохраняются (или пользователь подтверждает сохранение); дозапись всегда идёт к текущему содержимому файла на диске, весь текущий документ передаётся AI как контекст, а при изменении файла во время работы новая секция всё равно добавляется в конец без перезаписи. «Без изменений» означает, что AI не переписывает прежние секции; правки пользователя сохраняются. — see DEC-014.
