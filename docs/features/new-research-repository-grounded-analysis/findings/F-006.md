## Finding

DEC-003 allows web search without user approval. Queries built from private code or docs may leak secrets or confidential names. There is no requirement for query sanitisation, disclosure to the user, logging of the queries sent, or an opt-out for sensitive repositories.

> queries derived from the repository may leave the machine, and the user does not approve them individually.

## Resolution

AI: Веб-поиск остаётся автоматическим (DEC-003), но с ограничениями: в запросах запрещено передавать код, секреты и внутренние идентификаторы (только обобщённые темы); все отправленные запросы записываются в front-matter web_queries; в настройках проекта есть переключатель «Disable web search for this repository». — see DEC-011.
