## Statement

The New… entry points offer 'New Research' as a separate intake kind alongside New Feature, New Bug and I Need to Understand, with its own prompt text that distinguishes it from I Need to Understand. I Need to Understand keeps its current behaviour.

## Acceptance Criteria

- [x] 'New Research' appears as its own item in every New… entry point.
- [x] Its prompt text describes open analytical questions producing a saved research document.
- [x] Choosing 'I Need to Understand' still runs X-Ray search and creates no document.
