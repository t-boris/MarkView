## Statement

The result is saved as a single Markdown research document in the workspace and opened after creation. An existing research document offers a 'Continue / deepen' action: the user enters a follow-up question and the answer is appended to the same document as a new, clearly delimited section, without altering earlier content.

## Acceptance Criteria

- [x] After research completes, one Markdown document is created in the workspace and opened.
- [x] An opened research document exposes a 'Continue / deepen' action.
- [x] Invoking it with a follow-up question appends a new section containing the question and its answer to the same document.
- [x] Previously written sections remain unchanged after a follow-up.
- [x] A failed follow-up appends a section marked incomplete, per DEC-004.
