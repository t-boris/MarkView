## Statement

The research document distinguishes project facts, external facts, AI inferences and open assumptions. The AI may use web search whenever it deems it necessary; every external fact cites its source (URL), and every project fact cites the repository file it comes from.

## Acceptance Criteria

- [x] Each finding is labelled as project fact, external fact, AI inference or open assumption.
- [x] Every external fact includes a source URL.
- [x] Every project fact references the repository file path it is based on.
- [x] Model-knowledge claims without a verifiable source are labelled as AI inference, not as external fact.
