## Statement

In an open research document the user can select a section, subsection or phrase and write a comment on it. The AI reflects on the comment and revises that passage in place, keeping the fact/inference rules of REQ-004. This is the one deliberate exception to REQ-003's rule that earlier content stays unchanged.

## Acceptance Criteria

- [x] With text selected in a `type: research` document, the selection menu offers a comment action; other documents do not show it.
- [x] Submitting a comment revises the smallest section that contains the selection; the rest of the document is unchanged.
- [x] The revised section follows the DEC-008 labels and citation rules (REQ-004).
- [x] Unsaved edits are saved or the comment is cancelled first; if the section changed on disk while the AI worked, nothing is overwritten and the user is told.
- [x] A failed or cancelled comment leaves the document unchanged.
