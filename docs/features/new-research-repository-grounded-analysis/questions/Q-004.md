## Question

Результат исследования — это одноразовый отчёт или живой объект, как фича (с вопросами, уточнениями, итерациями)?

## Why it matters

Определяет модель данных, основной сценарий и критерии приёмки: один файл-отчёт или папка с жизненным циклом.

## Options

- **A**: Одноразовый отчёт: один Markdown-документ, при необходимости запускается новое исследование
- **B**: Отчёт с возможностью дозапроса: пользователь может задать уточнение, документ дополняется
- **C**: Живой объект как фича: вопросы, решения, статус

## Answer

B. Отчёт с возможностью дозапроса: пользователь может задать уточнение, документ дополняется
