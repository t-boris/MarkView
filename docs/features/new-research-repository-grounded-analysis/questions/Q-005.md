## Question

Может ли исследование использовать внешние знания (веб-поиск, знания модели о рынке и конкурентах) или только репозиторий?

## Why it matters

От этого зависят источники в отчёте, разметка «внешние факты», зависимости (веб-доступ) и приватность: уходит ли что-то из репозитория во внешний поиск.

## Options

- **A**: Только репозиторий (код и документы), без внешних знаний
- **B**: Репозиторий + знания модели, без веб-поиска
- **C**: Репозиторий + веб-поиск, включаемый пользователем для каждого исследования
- **D**: Репозиторий + веб-поиск всегда, когда AI сочтёт нужным

## Answer

D. Репозиторий + веб-поиск всегда, когда AI сочтёт нужным
