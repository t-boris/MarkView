## Question

Что должно происходить, если исследование не удалось завершить (прервано, ошибка AI, веб-поиск недоступен)?

## Why it matters

Определяет, появляется ли в рабочем пространстве неполный документ и как пользователь узнаёт о проблеме: это задаёт критерии приёмки для сценариев сбоя.

## Options

- **A**: Сохранить частичный документ с пометкой «неполное» и указать, что не удалось (например, веб недоступен → только репозиторий)
- **B**: Документ не создаётся, показывается ошибка с возможностью повторить
- **C**: Если недоступен только веб, продолжить по репозиторию с пометкой; при прочих сбоях документ не создавать

## Answer

A. Сохранить частичный документ с пометкой «неполное» и указать, что не удалось (например, веб недоступен → только репозиторий)
