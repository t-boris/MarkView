## Summary

The user asks for a way to do open-ended research grounded in the current repository, such as how to replace one application with another, how to make the app more widely adopted, or which features are needed. Some repositories contain only documents, so the research may analyse an existing document or produce a research result from the current documentation and/or code. The user wants this as something beyond "New Feature" and "I Need to Understand", either as a new intake kind or as an extension of "I Need to Understand".
