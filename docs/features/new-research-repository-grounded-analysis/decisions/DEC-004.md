## Context

Research can be interrupted, fail due to an AI error, or lose web search access mid-run.

## Alternatives

1. Save a partial document marked incomplete, stating what failed
2. Create no document; show an error with retry
3. Continue repository-only if only web is unavailable; create no document on other failures

## Decision

On any failure the research document is still saved with whatever was produced, clearly marked as incomplete, and states what failed (e.g. web search unavailable → repository-only findings).

## Reason

Completed work is not lost and the document is honest about its limitations.

## Consequences

Incomplete documents may accumulate in the workspace; the incomplete marker must be clearly visible.
