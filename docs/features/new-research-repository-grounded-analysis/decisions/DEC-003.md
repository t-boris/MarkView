## Context

Research questions (e.g. replacing app A with app B, adoption, missing features) often need external facts beyond the repository.

## Alternatives

1. Repository only, no external knowledge
2. Repository plus model knowledge, no web search
3. Repository plus web search enabled by the user per research
4. Repository plus web search whenever the AI deems it necessary

## Decision

Research uses the repository and may run web searches whenever the AI deems it necessary, without a per-research toggle.

## Reason

Maximises completeness for strategic questions with no extra settings; chosen by the product owner.

## Consequences

The AI needs web access; external facts must cite their web sources; queries derived from the repository may leave the machine, and the user does not approve them individually.
