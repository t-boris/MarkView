## Context

REQ-003 says the result is saved 'in the workspace' but gives no path, naming rule or collision handling.

## Alternatives

1. docs/research/<slug>.md
2. Next to the analysed document
3. User chooses the path

## Decision

Research documents are saved as docs/research/<YYYY-MM-DD>-<slug>.md, where the slug is derived from the question. On a name collision a numeric suffix (-2, -3, …) is appended. The intake dialog pre-fills this path, and the user may edit it.

## Reason

A predictable folder keeps research discoverable and consistent with the docs/features and docs/bugs conventions. The date prefix sorts documents and reduces collisions.

## Consequences

The docs/research/ folder is created on first use. Recognition does not depend on the path (see the F-002 decision), so moved files keep working.
