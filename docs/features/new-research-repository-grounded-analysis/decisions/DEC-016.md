## Context

REQ-002 does not define which files are analysed, what the size limits are, or how empty and large repositories are handled.

## Alternatives

1. Load the whole repository into context
2. Let the user select the files every time
3. Default scope of tracked text files with agent-driven search

## Decision

The scope is git-tracked text files, honouring .gitignore. Binary files, typical generated or vendor directories (for example build/, node_modules/, DerivedData/) and files over 1 MB are excluded. Target documents from DEC-009 are always included. Large repositories are explored through agent tool-based search and file reads (DEC-012) rather than full loading. The document's Sources section lists the files that were read. If there are no eligible files, the research still runs and the Summary states that no project facts were available.

## Reason

The rules are predictable and match the agent execution model. They scale to large repositories.

## Consequences

Add acceptance criteria to REQ-002: ignored and binary files are never cited, an empty repository produces a document stating that no project sources were available, and files that were read are listed.
