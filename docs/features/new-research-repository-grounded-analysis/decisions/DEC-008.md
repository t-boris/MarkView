## Context

REQ-004 acceptance criteria cannot be tested because the document structure, label syntax, incomplete marker and follow-up delimiter are not defined.

## Alternatives

1. Fixed template with inline label prefixes
2. Free-form document with a legend
3. Separate sections per label type

## Decision

The document has: front-matter (per the F-002 decision); '# <title>'; '## Question'; '## Summary'; '## Findings' as a list where each item starts with exactly one of [Project fact], [External fact], [AI inference], [Open assumption]; '## Recommendations'; '## Sources' listing the file paths and URLs used. A project fact cites its path inline (path or path:line); an external fact cites its URL inline. Each follow-up is appended after a '---' line as '## Follow-up N: <question> (<date>)' with its own Findings, Recommendations and Sources subsections. Incompleteness is shown as a '> ⚠️ Incomplete: <what failed>' callout at the top of the affected section, and front-matter status is set to incomplete.

## Reason

Machine-checkable prefixes make REQ-004 testable. Delimited, dated follow-ups meet REQ-003's append-only rule.

## Consequences

The prompt must enforce the template. A validator can check that every finding has a label and the required citation.
