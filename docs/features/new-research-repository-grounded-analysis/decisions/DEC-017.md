## Decision

A comment is written in the editor's selection menu ("Revise With Comment") on a `type: research` document. The job sends the whole on-disk document, the smallest heading-bounded section that contains the selection, the selected passage and the comment to the AI, which returns that section revised. The app replaces exactly that section, only if its on-disk text is unchanged since the job started, then applies the REQ-004 label check to it. Web queries of the run are added to `web_queries`. Follow-ups (DEC-005, DEC-013, DEC-014) stay append-only; only comments rewrite content.

## Reason

The product owner wants live comments that the AI acts on, rather than appended replies or separate threads. Limiting the rewrite to the enclosing section and refusing to write over concurrent changes keeps the user's other text and edits safe.
