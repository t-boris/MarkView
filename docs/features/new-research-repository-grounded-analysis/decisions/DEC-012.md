## Context

The execution model, progress, cancellation and context limits are undefined. BUG-002 shows long prompts being truncated when pasted into the terminal.

## Alternatives

1. Terminal-based AI tool
2. Background API job

## Decision

Research runs as a background, non-interactive agent job (Claude Code headless) with the prompt passed via a file. The agent uses tool-based search and file reads over the repository instead of loading it whole. The UI shows a running-task indicator with elapsed time and current step, plus a Cancel button. Cancel, a process error, a timeout (configurable, default 20 min) or loss of web access counts as interruption under DEC-004, and the partial output is saved.

## Reason

This avoids terminal truncation, scales to large repositories and gives a clear definition of 'interrupted'.

## Consequences

A job runner and progress UI are needed. The agent CLI must be available, otherwise the run fails with a clear error.
