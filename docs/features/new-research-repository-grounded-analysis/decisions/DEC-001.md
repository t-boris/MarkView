## Context

Both 'I Need to Understand' and 'New Research' analyse the project. Understand answers via X-Ray search without producing a document; Research produces a persistent analytical document.

## Alternatives

1. A: Separate 'New Research' menu item
2. B: Extend 'I Need to Understand' with a 'save as research' option

## Decision

Add 'New Research' as its own menu item in the New… entry points; 'I Need to Understand' stays unchanged (X-Ray search, no document).

## Reason

Clear purpose for each entry: code navigation/explanation vs open-ended strategic analysis with a saved result; avoids mixing the two in one flow.

## Consequences

The user must pick between Understand and Research; each needs a distinct label/prompt text so the choice is obvious. Understand's behaviour is not modified.
