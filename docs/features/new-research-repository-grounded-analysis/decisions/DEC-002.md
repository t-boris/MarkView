## Context

Q-004: should the research result be a one-shot report, an extendable report, or a living feature-like object?

## Alternatives

1. One-shot report; a new research is started for any follow-up
2. Report with follow-up questions that append to the document
3. Living feature-like object with questions, decisions and status

## Decision

The research result is a single Markdown report; the user can ask follow-up questions on it and the answers are added to the same document.

## Reason

Gives iteration without the heavy feature lifecycle and keeps a clear boundary with features.

## Consequences

The report must keep prior content when extended and show which follow-up each added section answers; no question/decision/status lifecycle for research.
