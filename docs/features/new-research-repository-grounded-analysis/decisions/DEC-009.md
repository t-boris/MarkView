## Context

The Scope mentions reviewing a specific document and attachments, but no requirement covers them.

## Alternatives

1. Pick a file in the intake dialog
2. Use the currently opened document
3. Attachments only

## Decision

The Research intake dialog has a free-text question, an optional 'Target documents' list pre-filled with the currently open document (removable, with more repository files addable), and optional attachments. Target documents are analysed as the primary focus, with the rest of the repository as context. Attachments are copied to docs/research/assets/<doc-id>/ and cited in Sources. Target documents are never modified (Scope OUT).

## Reason

Pre-filling covers the common 'review this document' case in one click and still allows repository-wide questions.

## Consequences

A new requirement is needed for intake fields. Attachments add files to the repository.
