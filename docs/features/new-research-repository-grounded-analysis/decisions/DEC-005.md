## Context

Q-001 asked whether the research result is a one-off report or a living, feature-like object. DEC-002 already settled a single report with follow-ups; this answer fixes the interaction.

## Alternatives

1. A: One-off single Markdown report, no follow-up
2. B: Living feature-like folder with questions, sources and iterations
3. C: Single report with a 'Continue / deepen' action that appends to it

## Decision

C: the research result is a single Markdown report; an existing research document offers a 'Continue / deepen' action where the user enters a follow-up question and the answer is appended to the same document.

## Reason

Keeps the simple, shareable single-file model while allowing iterative deepening without the overhead of the feature mechanism.

## Consequences

Follow-up sections must be clearly delimited in the document; no separate question/decision files for research; earlier content is preserved on append.
