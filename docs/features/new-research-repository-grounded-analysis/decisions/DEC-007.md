## Context

The 'Continue / deepen' action must appear only on research documents, but the spec defines no marker for them.

## Alternatives

1. Front-matter marker
2. Folder convention
3. Registry

## Decision

Every research document starts with YAML front-matter that includes type: research, id, question, created, status (complete|incomplete) and web_queries. The 'Continue / deepen' action is shown for any opened Markdown document whose front-matter has type: research, regardless of its location.

## Reason

This matches the existing front-matter conventions for feature artefacts and keeps working when files are moved or renamed.

## Consequences

The front-matter must be preserved on append. If a user deletes it, the action is no longer shown.
