## Context

The AI Tools menu already has '🌐 Deep Research' (runAITool 'research'). Two similarly named entry points would confuse users.

## Alternatives

1. Replace Deep Research
2. Reuse its prompt/engine
3. Keep both

## Decision

The 'Deep Research' AI tool is replaced by New Research. The AI Tools menu item stays for discoverability but opens the New Research intake dialog. The old 'research' prompt is retired, and useful parts of it are merged into the New Research prompt.

## Reason

One concept with one behaviour and one persistent output is simpler. The old tool produced no saved, structured document.

## Consequences

The AI Tools menu wiring changes. docs/plans/documents-actions.md should reference this feature.
