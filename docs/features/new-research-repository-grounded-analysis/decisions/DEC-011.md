## Context

DEC-003 allows web search without per-query approval, so private code or names could leak.

## Alternatives

1. Per-query approval
2. Sanitisation plus logging plus opt-out
3. No web search

## Decision

Web queries may contain only generic concepts, public product or library names and the user's question wording. They must not contain code, file contents, secrets, credentials, internal hostnames or identifiers. Every query sent is listed in the document's web_queries front-matter and in Sources. A per-repository setting 'Disable web search' (default off) forces repository-only research. When web search is disabled, the document states it.

## Reason

This keeps DEC-003's zero-friction default while making egress visible and controllable for sensitive repositories.

## Consequences

DEC-003 is refined, not reversed. The prompt must carry these rules. A new security requirement and a settings item are needed.
