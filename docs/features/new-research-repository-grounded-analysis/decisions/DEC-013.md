## Context

The spec does not say how Continue/deepen interacts with incomplete documents or whether the incomplete marker is ever cleared.

## Alternatives

1. Retry failed part
2. Only new follow-ups; marker stays

## Decision

When the latest section is incomplete, 'Continue / deepen' pre-selects a 'Retry incomplete part' option that re-runs the original or follow-up question with the earlier partial output as context. The result is appended as a new section referencing the incomplete one. Earlier sections, including their Incomplete callouts, stay unchanged. The front-matter status becomes complete once every incomplete section has a successful retry.

## Reason

Work can be recovered while keeping REQ-003's append-only guarantee. Front-matter status gives an accurate document-level state.

## Consequences

Front-matter status is the only mutable part of an existing document, and REQ-003 must note this exception.
