## Context

The X-Ray of a single Markdown file could also become a one-chapter book.

## Alternatives

1. A: Yes, a book of one document (H1/H2 chapters, H3+ sections).
2. B: No, folders and the project only.

## Decision

B. A single file keeps Explain; the Book exists for folders and the project.

## Reason

Keeps the scope to what was asked; a document's sections are already visible inside its chapter in a folder's book.
