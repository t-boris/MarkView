## Question

В описании issue указаны предпросмотр и выбор между закрытием и меткой, но существующие решения уже утвердили применение сразу и закрытие. Какой вариант считать действующим?

## Why it matters

От этого зависят основной сценарий и критерии приёмки.

## Answer

AI: Выбираю A: действуют уже принятые решения. Sync сразу применяет изменения, закрывает подходящие GitHub issues как completed и затем показывает отчёт; предпросмотр и метки исключаются из этой спецификации.
