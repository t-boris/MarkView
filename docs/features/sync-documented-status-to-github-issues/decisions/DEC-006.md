## Context

The accepted decisions conflict on cross-repository targeting and do not fully define explicit reference syntax.

## Alternatives

1. Require full URLs in every field
2. Allow cross-repository updates

## Decision

Resolve explicit references, but limit mutation to the project's GitHub origin repository; accepted DEC-005 supersedes DEC-004 on cross-repository targets.

## Reason

This supports common explicit links while keeping the immediate action within one repository.

## Consequences

Foreign repository references receive a skipped outcome; parsing, normalization, deduplication, and PR checks become testable requirements.
