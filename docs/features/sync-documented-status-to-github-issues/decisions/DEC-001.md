## Context

The original scope includes free-text “issue #n” mentions, while accepted DEC-005 excludes them. Sync applies changes immediately without a preview.

## Alternatives

1. A. Match only explicit issue fields and full issue URLs in the project repository.
2. B. Also match free-text “issue #n” mentions after validating every target.

## Decision

Use explicit issue fields and full issue URLs in the project repository. Ignore free-text “issue #n” mentions.

## Reason

This follows Boris’s answer and reduces the risk of closing an unrelated issue.

## Consequences

Items linked only by text mentions are reported as unlinked. Pull requests and links to other repositories are skipped.
