## Context

The `github` field named in REQ-002 exists only on implementation/plan.md entries (issues made by Create issues), next to the plan epic.

## Alternatives

1. Overview/bug fields, plan issues and the epic
2. Plan issues without the epic
3. Overview fields only

## Decision

Explicit fields are `issue`, `issues` and `github` in the overview or bug front matter, every plan issue's `github` and the plan `epic`. Full issue URLs count in the overview body, the feature's own folder documents and the bug body; object files (REQ, DEC, SRC…) are not searched.

## Reason

When a feature is implemented, its sub-issues and epic are done too. Object files often quote other material, which would risk closing unrelated issues.

## Consequences

Implementing a feature closes all its plan issues and its epic in one Sync.
