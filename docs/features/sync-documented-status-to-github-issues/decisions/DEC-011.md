## Context

DEC-005 names implemented, verified and archived, but bugs use open, fixing, fixed and closed and never reach those statuses.

## Alternatives

1. fixed or closed
2. Only fixed (closed may mean won't fix)
3. Bugs never drive closure

## Decision

A Bug is done when its status is fixed or closed. Features keep implemented, verified or archived.

## Reason

A fixed or closed bug report means the work is over; its linked issue should not stay open.

## Consequences

An issue linked to a bug closed as won't fix is still closed as completed; reopen it by hand if needed.
