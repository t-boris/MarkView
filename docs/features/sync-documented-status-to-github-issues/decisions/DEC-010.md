## Context

The report could otherwise double count items whose explicit references are rejected.

## Alternatives

1. Add both rejected-target rows and an unlinked row
2. Show only an unlinked row for rejected targets

## Decision

Report each rejected explicit target once; reserve unlinked for items with no explicit issue reference.

## Reason

Each row then identifies one actionable cause without duplicating the same absence of a valid target.

## Consequences

An item with only foreign repository or pull request links has specific skipped rows and no extra unlinked row; text-only mentions produce one unlinked row.
