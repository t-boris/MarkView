## Context

The reviewed requirements omit operational prerequisites; accepted DEC-004 defines gh-based access and preflight.

## Alternatives

1. Store a separate token
2. Attempt updates without preflight

## Decision

Use gh authentication and project origin. Abort before mutation if basic prerequisites fail; report later target-specific failures and continue other targets.

## Reason

The existing integration can be reused, while preflight reduces avoidable partial runs.

## Consequences

Add acceptance criteria for missing CLI, authentication, repository, permission, network, and per-issue failures; reconcile DEC-004 with the single-repository rule.
