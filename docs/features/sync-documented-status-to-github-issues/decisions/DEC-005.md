## Context

The reviewed requirement leaves eligibility undefined; accepted DEC-002 and DEC-008 define the status threshold and shared issue rule.

## Alternatives

1. Close when any linked item reaches implemented
2. Close each issue according to the first linked item found

## Decision

An issue is eligible only when every linked Feature and Bug has status implemented, verified, or archived.

## Reason

The conservative rule prevents premature closure that one-way sync cannot correct automatically.

## Consequences

Sync must collect all links before updating and report the blocking items.
