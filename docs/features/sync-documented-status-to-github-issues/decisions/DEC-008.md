## Context

One issue may occur in multiple fields or items; accepted DEC-008 limits updates to one per issue.

## Alternatives

1. Count item–issue rows as updates
2. Show only unique issues without item rows

## Decision

Deduplicate mutations by repository and issue number, retain item–issue rows, and count unique issues in the outcome summary.

## Reason

Users can trace each documented item without mistaking repeated rows for repeated GitHub changes.

## Consequences

The report needs separate row outcomes and issue-level summary counts so shared links do not inflate update totals.
