## Context

Accepted DEC-007 and DEC-009 define report persistence and run behavior absent from the reviewed requirements.

## Alternatives

1. Queue repeated runs
2. Persist report history to disk
3. Allow cancellation mid-run

## Decision

Carry DEC-007 and DEC-009 into the canonical requirements.

## Reason

These rules make repeated clicks and post-run review predictable.

## Consequences

REQ-001 and REQ-004 need acceptance criteria for progress, single-run behavior, report rows, counts, reasons, and lifetime.
