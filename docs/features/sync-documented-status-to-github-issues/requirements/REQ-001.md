## Statement

The Issues tab shall let the user manually start a one-way sync that immediately applies documented Feature and Bug lifecycle statuses to linked GitHub issues.

## Acceptance Criteria

- [ ] The Issues tab provides a manual Sync action.
- [ ] Starting Sync applies eligible changes without a preview or a separate confirmation step.
- [ ] Sync runs only in the documented-status-to-GitHub direction.
