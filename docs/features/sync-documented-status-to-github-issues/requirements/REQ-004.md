## Statement

After applying Sync, the Issues tab shall show a per-item and per-issue report of updated, unchanged, skipped, and failed outcomes, including reasons or errors where applicable.

## Acceptance Criteria

- [x] After Sync finishes, the Issues tab shows outcomes for each processed item and linked issue.
- [x] The report distinguishes updated, unchanged, skipped, and failed outcomes.
- [x] Skipped and failed outcomes include a reason or error.
