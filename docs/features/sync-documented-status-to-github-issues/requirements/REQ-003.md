## Statement

Sync shall close eligible linked open GitHub issues with reason completed, while leaving ineligible and already closed issues unchanged; it shall not change labels.

## Acceptance Criteria

- [x] An eligible linked open issue is closed with reason completed.
- [x] An ineligible or already closed issue is left unchanged.
- [x] Sync does not add or change labels.
