## Statement

Sync shall resolve Feature and Bug links only from explicit github, issue, or issues fields and full GitHub issue URLs in the project repository. It shall ignore free-text issue-number mentions and exclude pull requests and targets in other repositories.

## Acceptance Criteria

- [ ] An item linked through an explicit github, issue, or issues field, or a full GitHub issue URL in the project repository, resolves to the referenced issue.
- [ ] An item linked only through a free-text “issue #n” or bare “#n” mention is reported as unlinked.
- [ ] A link to another repository or fork is skipped with reason “other repository”.
- [ ] A target identified by GitHub as a pull request is skipped with reason “pull request”.
- [ ] An item linked to multiple eligible issues resolves each issue.
