## Finding

“Eligible” is undefined in the reviewed requirements. The related accepted DEC-002 and DEC-008 specify implemented, verified, and archived, and require every Feature or Bug linked to a shared issue to have reached that threshold. Without these rules, REQ-003 permits different closure decisions for the same issue.

> Sync shall close eligible linked open GitHub issues

## Resolution

AI: Закрывать открытую issue только тогда, когда все связанные с ней Feature и Bug имеют статус `implemented`, `verified` или `archived`. Если хотя бы один элемент не достиг этого порога, оставить issue без изменений и указать его в отчёте. — see DEC-005.
