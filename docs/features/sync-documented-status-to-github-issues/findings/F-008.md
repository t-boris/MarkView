## Finding

REQ-002 says an item linked only by a free-text mention is “unlinked,” while its next criteria distinguish skipped foreign-repository and pull-request links. The report requirement does not say whether items with only rejected explicit targets also receive an unlinked row, or only the specific skipped target rows.

> An item linked only through a free-text “issue #n” or bare “#n” mention is reported as unlinked.

## Possible interpretations

- Report only target-specific skipped rows for rejected explicit links.
- Report both target-specific skips and an unlinked item row when no valid issue remains.

## Resolution

AI: Если явная ссылка отклонена, показывать строку пропуска с конкретной причиной для этой цели. Строку `unlinked` показывать только элементу без явных целей; не добавлять её к уже показанным отклонённым ссылкам. — see DEC-010.
