## Finding

An issue can appear in multiple fields or be linked from multiple items. REQ-004 calls for per-item and per-issue outcomes, but no rule says whether GitHub receives one update per unique issue, how a shared result appears in several rows, or how summary counts avoid double counting. Related DEC-008 explicitly requires one update per issue.

> per-item and per-issue report of updated, unchanged, skipped, and failed outcomes

## Possible interpretations

- Count item–issue rows while updating each unique issue once.
- Count unique issues and show linked items underneath each issue.

## Resolution

AI: Обновлять каждую уникальную issue не более одного раза за запуск. Показывать результат для каждой пары «элемент–issue», а итоговые числа считать по уникальным issue; число элементов без связи указывать отдельно. — see DEC-008.
