## Finding

The report requirement does not define its row structure, summary counts, persistence, progress, or repeated-click behavior. Related accepted DEC-007 and DEC-009 specify one item–issue row, in-memory retention, progress, and one active run per project; the reviewed requirements omit those testable behaviors.

> After applying Sync, the Issues tab shall show a per-item and per-issue report

## Resolution

AI: Показывать ход выполнения и блокировать повторный Sync, пока для проекта идёт один запуск. После завершения сохранять в памяти отчёт с парами «элемент–issue», итогами и причинами до следующего запуска или закрытия вкладки/окна; отмену в эту версию не включать. — see DEC-009.
