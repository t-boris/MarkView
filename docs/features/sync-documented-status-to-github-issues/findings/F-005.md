## Finding

The reviewed requirements do not specify how Sync obtains the repository or credentials, what happens without `gh`, authentication, repository access, or a network connection, and whether failure occurs before or during a run. Related DEC-004 defines a preflight and per-issue handling but its cross-repository rule conflicts with DEC-005. These conditions need requirements and acceptance criteria.

> Starting Sync applies eligible changes without a preview or a separate confirmation step.

## Resolution

AI: Использовать существующую авторизацию `gh` и определять репозиторий по GitHub origin проекта. До изменений проверять наличие `gh`, вход, доступ на запись и доступность репозитория; при неуспехе завершать запуск без изменений с понятной ошибкой, а ошибки отдельных issue фиксировать в отчёте и продолжать обработку. — see DEC-007.
