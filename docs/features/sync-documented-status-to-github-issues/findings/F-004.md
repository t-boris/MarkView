## Finding

The accepted link rule names fields and full URLs but does not define valid field values, URL locations, duplicate references, or whether an explicit `owner/repo#n` reference is accepted. The existing DEC-004 allows explicit cross-repository references while DEC-005 skips other repositories, so the target resolution rule also needs a single authority.

> explicit github, issue, or issues fields and full GitHub issue URLs in the project repository

## Possible interpretations

- Accept issue numbers in explicit fields and resolve them against the origin repository.
- Require full issue URLs in every field.
- Accept `owner/repo#n` syntax but skip it when it names another repository.

## Resolution

AI: Принимать номер issue в явных полях относительно GitHub origin проекта, полный URL вида `https://github.com/owner/repo/issues/n` и явную ссылку `owner/repo#n`; обрабатывать только ссылки на репозиторий проекта. Искать полные URL в явно заданных полях и Markdown-содержимом, удалять дубли и проверять через GitHub API, что цель является issue, а не pull request. — see DEC-006.
