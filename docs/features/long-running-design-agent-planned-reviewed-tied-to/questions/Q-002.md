## Question

How does the agent write a chunk: as structured search/replace edits that MarkView applies and checks itself, or as a full-access terminal agent that edits files, builds and runs tests on its own?

## Why it matters

Structured edits keep the existing undo, conflict detection and verification of UI Studio, but the agent cannot run a build itself (MarkView does it between chunks). A terminal agent can build and test freely, but bypasses Studio operations, undo and checks.

## Options

- **A**: Structured edits per chunk, MarkView builds and checks between chunks and feeds the result back (keeps undo)
- **B**: A full-access terminal agent per chunk (more freedom, no Studio undo)

## Recommended

A
