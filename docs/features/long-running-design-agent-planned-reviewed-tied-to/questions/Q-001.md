## Question

Which design agent is meant: UI Studio (edits the real application's source, request box under the live preview) or Prototype Studio (edits the generated prototype)?

## Why it matters

Both are one-call agents with the same limit ("smallest set of changes"), but they write different things and have different undo and verification.

## Options

- **A**: UI Studio first, with the engine built so Prototype Studio can use it later
- **B**: Prototype Studio first
- **C**: Both in the first release

## Recommended

A

## Answer

Both at once: UI Studio and Prototype Studio get the long-running agent in the same release (Boris chose option C, 2026-11-05, answering in the conversation).
