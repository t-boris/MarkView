## Question

When is a feature opened: for every single request, or once per conversation, and does a one-element request ("change this button") also go through plan and review?

## Why it matters

Today UI Studio already opens one feature per conversation and adds each later change as a requirement. A feature per button change would bury the list; a plan and review for a one-line edit would make small changes slower than today.

## Options

- **A**: One feature per job or conversation; a small request is recorded in it as a requirement and takes the quick path; a big one becomes a job with the four gates
- **B**: A new feature for every request, all through the four gates

## Recommended

A
