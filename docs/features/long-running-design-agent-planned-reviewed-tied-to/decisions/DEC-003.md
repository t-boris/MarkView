## Context



## Alternatives

1. The agent continues alone when the plan review has no blocker

## Decision

After the plan review the person approves, edits or removes chunks and answers questions. After approving, the person may switch the run to unattended; deny-listed files (package.json, lockfiles, .env*, CI and dev-server configs) still need the person. The agent can only create draft requirements and open questions.

## Reason

Boris chose "always the person" (Q-004, 2026-11-05). The plan is the last cheap place to stop a wrong direction.

## Consequences

Unattended mode is built last (step 10 of the plan) and can be cut without breaking the rest.
