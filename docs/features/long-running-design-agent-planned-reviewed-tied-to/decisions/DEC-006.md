## Context



## Alternatives

1. A hard 2 h deadline inside every call

## Decision

A run has a soft 2 h limit: at the limit it asks the person whether to continue. Model calls stay unbounded where the studio already has no timeout (Prototype Studio), and keep 900 s in UI Studio.

## Reason

`tasks/lessons.md` (BUG-030) records that prototype deadlines are explicit and optional; a hard deadline would cut a long legitimate build. Part of plan v4 approved on 2026-11-05.

## Consequences

Elapsed time is a run-level clock; per-call stage timers are not used for it.
