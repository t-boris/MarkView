## Context



## Alternatives

1. A full-access terminal agent per chunk

## Decision

Each chunk is written as edits that MarkView applies, then MarkView builds or renders and checks, and the report goes to the agent for the next call. The agent runs no shell commands; work that needs one (npm install, config) is a question to the person.

## Reason

Boris chose edits through MarkView (Q-002, 2026-11-05). It keeps Undo, conflict detection and the studios' own verification.

## Consequences

UI Studio gets hash-guarded overwrite and delete edits; Prototype Studio overwrite becomes hash-guarded.
