## Context

Both studios make one model call per request and cannot do a big change. Plan v4 in tasks/todo.md.

## Alternatives

1. UI Studio first, Prototype later
2. Prototype Studio first, UI Studio later
3. Two separate implementations

## Decision

The long-running agent is one engine (`DesignRun*`: state, phases, planner, reviews, approval, checkpoints, questions, feature recording, pause/resume) that knows nothing about a studio; UI Studio and Prototype Studio each implement `DesignRunHost` (performChunk, verify, undo, conflicts, path rules).

## Reason

Boris chose "both at once" (Q-001, 2026-11-05). The studios differ in write format, undo unit and verification, so only the run logic is shared.

## Consequences

One lock and one run file location (`.dde/design-runs/`) for both; one run per project at a time across both studios.
