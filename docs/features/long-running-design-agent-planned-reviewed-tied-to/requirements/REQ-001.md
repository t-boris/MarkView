## Statement

The system shall run a big design request as a long-running job that splits the request into chunks, does them one after another, and keeps going until every chunk is done, stopped, or waiting for an answer.

## Acceptance Criteria

- [ ] A request that touches many elements or screens (for example a restyle of a whole page) becomes a job with a list of chunks instead of one edit
- [ ] Each chunk is applied, built and checked before the next starts, and the result of the check (build log, runtime errors, a picture of the result) is shown to the agent for the next step
- [ ] The job shows its chunks, the current one, elapsed time and a Stop button, and Stop keeps what is already applied and undoable
- [ ] A job interrupted by quitting the app can be resumed from the chunk it stopped at
- [ ] A request that needs one small edit still takes the quick path, without a job
