## Statement

The system shall open a feature automatically before something is changed, and add to it, as requirements and discussion, the request and everything the person says and decides while the job runs.

## Acceptance Criteria

- [ ] The first request of a job creates a feature, or attaches to the one the person names, before any file is written
- [ ] The request and every later message of the person is appended to the feature's discussion in the person's words
- [ ] Each chunk of the plan is linked to a requirement of the feature
- [ ] A requirement the agent adds is a draft until the person approves it
- [ ] The agent reads the feature again between chunks, so a changed or answered requirement changes the next chunk
