## Statement

The system shall let the person add images to a request in the input box by pasting, dropping or choosing a file, and give them to the agent with the request.

## Acceptance Criteria

- [ ] Pasting an image with the clipboard shortcut adds it to the request as a thumbnail that can be removed
- [ ] Dropping an image file on the input box adds it, and a file picker offers the same
- [ ] The images are sent to the agent with the request and kept with the feature as sources
- [ ] A paste of text only still pastes the text
- [ ] The images of a request that belongs to a job are shown again when the job is resumed
