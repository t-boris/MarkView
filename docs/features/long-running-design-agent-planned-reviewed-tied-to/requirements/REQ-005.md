## Statement

The system shall let the person add images to a request in the input box of UI Studio and of Prototype Studio by pasting, dropping or choosing a file, and give them to the agent with the request.

## Acceptance Criteria

- [x] Pasting an image with the clipboard shortcut adds it to the request as a thumbnail that can be removed, in both studios
- [x] Dropping an image file on the input box adds it, and a file picker offers the same
- [x] The images are sent to the agent with the request on every engine (an engine without an image option gets the file paths named in the prompt)
- [ ] The images are kept with the request and the job; adding one to the feature's sources is a choice of the person for each image
- [x] A paste of text only is inserted at the caret, not appended to the end of the draft
- [ ] The images of a request that belongs to a job are shown again when the job is resumed, and clearing the conversation does not delete the images of an active job
