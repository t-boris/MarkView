## Statement

The system shall take every big change through four gates in order: a plan, a review of that plan, the implementation, and a review of the implementation against the requirements.

## Acceptance Criteria

- [ ] No file is changed before a plan exists and its review has been shown to the person
- [ ] The plan review is made by a separate model call that sees the plan and the requirements, not the planner's reasoning
- [ ] The implementation review checks every acceptance criterion of the feature's requirements and records pass or fail with evidence for each
- [ ] A failed criterion produces a bounded number of fix chunks and then goes back to the person
- [ ] Each gate's result is saved in the feature so it can be read later
