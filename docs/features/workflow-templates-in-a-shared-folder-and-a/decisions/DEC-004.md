## Context

Projects with existing items keep adopting exactly what they adopt today.

## Alternatives

1. Always turn the requirements off for every new workflow
2. Always honour the old defaults (pull request and checks)

## Decision

The 'nothing required' default applies only to a new empty project that declares nothing: no Definition of Done with a pull request or CI item, and no explicit rule in its guide. A project that declares them keeps them. A template chosen for new projects is applied as it is, with the delivery settings it was saved with.

## Reason

DEC-022 of the project workflow makes the project's own declarations the source of its delivery rules; the new default must not silently contradict a project that said something. A person who saved a template with GitHub requirements on chose them knowingly, and the Done panel now warns when GitHub is off.
