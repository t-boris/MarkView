## Context

Boris cannot carry a long configuration from one project to another, nor from features to bugs and processes.

## Alternatives

1. Also a button that copies the feature setup to bugs
2. Templates for one process or one lifecycle only

## Decision

One template is the complete workflow: the features lifecycle, the bugs lifecycle, and every process with its delivery settings. There is no separate 'use the same for bugs' or 'copy this process' action.

## Reason

Boris chose 'only the whole template' when asked what one action should carry. It is the only unit he could name that moves a finished setup in one step, and it keeps the existing draft, Save and replacement machinery as the single way a workflow changes.
