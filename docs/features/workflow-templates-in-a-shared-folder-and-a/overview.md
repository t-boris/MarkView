# Workflow templates in a shared folder, and a default that works without GitHub

## Idea

Boris spent a long time setting up the workflow of one project (Kanban with the pull request, CI and release rules switched on) and cannot move that work to another project, nor to bugs and processes, without redoing it. He wants to save a configured workflow as a template that lives in a shared local folder of MarkView, so any project can take it. He also wants the new-project default to be his most configured scheme, but that scheme cannot work where GitHub or CI is not connected, so the pull request, checks and release must be OFF by default, with an instruction on how to switch them on. Whole template only (features, bugs and processes together); any saved template can be chosen as the default for new projects.
