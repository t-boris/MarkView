## Statement

The system shall let a person choose any saved template as the workflow that new, empty projects start with, and shall fall back to the built-in default when none is chosen or the chosen one cannot be used.

## Acceptance Criteria

- [ ] Settings > Workflow templates has 'Use for new projects' on each template and 'Use the built-in default' to clear the choice; the chosen one is marked
- [ ] A project that has no workflow file and no features or bugs adopts the chosen template as its first workflow (revision 1)
- [ ] A project that already has features or bugs, or already has a workflow file, is never changed by the choice
- [ ] If the chosen template was deleted or is unusable, a new project adopts the built-in default and nothing is lost or rewritten
- [ ] The choice is stored in the shared templates folder, so moving the folder moves the choice with it
