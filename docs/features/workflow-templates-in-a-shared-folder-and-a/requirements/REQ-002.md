## Statement

The system shall let a person load a saved template into the draft of any project's workflow, with the same safeguards as a classic flow: nothing is stored until Save, and work items that use a status or process the template does not have ask what replaces it.

## Acceptance Criteria

- [ ] The Flow popover lists 'My templates' under the classic flows, each with its note and outline, and a Use action
- [ ] Using a template replaces the draft's features, bugs and processes with the template's and keeps the project's revision, so a stale-revision check still works
- [ ] Nothing is written to the project until the person presses Save; Reload from file brings the old workflow back
- [ ] Save asks for a replacement for each status or process that work items still use and the template lacks (the existing replacement machinery)
- [ ] The Flow button shows the template's name while the draft equals it, and 'custom' once the draft is changed
- [ ] A template is a copy: changing the project afterwards does not change the template, and deleting the template does not change any project
