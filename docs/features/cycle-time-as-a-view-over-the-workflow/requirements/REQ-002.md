## Statement

The system shall show one project summary of the metrics (median, mean, items used and the share of items that have the metric) for features and bugs, limited by a Measure since date, ignoring items the owner excluded, and shall recompute everything from the journal on demand without deleting anything.

## Acceptance Criteria

- [x] Each row shows median, mean, the number of items used and the number of items it could have used (for example 104 of 309)
- [ ] Measure since limits the summary to items whose round started on or after the date; All time is the default
- [x] Exclude from statistics on an item (with a reason) removes it from every row and marks it; undoing it brings it back
- [x] Measure since and exclusions are stored in .dde/lifecycle/cycle-time.json, outside the journal and the workflow file
- [x] Recompute re-reads the journal and the workflow; no journal line is changed
- [ ] Delete cycle-time data of this project asks for a confirmation and only removes that project's lines from the per-Mac evidence log
- [x] A project with no history shows an explanation, not an empty table
