## Statement

The system shall keep the GitHub and git evidence (pull request opened, approval, checks, merge, CI queue, CI time, re-runs) as optional timings of an item, show only the evidence that the item's process asks for, and compare agents by a normalised model name with a minimum sample size.

## Acceptance Criteria

- [x] An item of a direct-to-the-default-branch process shows no 'CI before merge' ordering and no review row; an item of a pull-request process shows them
- [ ] With GitHub off, the evidence rows are absent and nothing is run or polled
- [x] Model names opus, claude-opus-5-5, Claude Opus 5.5 and anthropic/claude-opus-5.5 are one row (a bare family name takes the version of its family when the project has exactly one); an unknown name is kept as written
- [ ] A model row with fewer than 5 items is shown greyed with 'too few to compare', and every model table says that task size is not normalised
- [ ] The model of a feature is the one on its start evidence (the hand-off that started it), not a manual entry; bugs have no model yet, because 'Fix with AI' records none
