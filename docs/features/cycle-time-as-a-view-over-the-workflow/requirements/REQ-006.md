## Statement

The system shall no longer derive state changes by diffing statuses, no longer offer manual stage marks, and no longer read status-derived stages from the per-Mac stage log, so that exactly one record of state changes exists.

## Acceptance Criteria

- [x] observeLifecycle, recordSpecReadyIfMissing, the Mark stage sheet and the manual stage menu are deleted, not disabled
- [x] A flow change (statuses removed from the workflow) adds no event to any cycle-time source
- [x] The agent tool section 'lifecycle' of a feature reports the item's stays from the journal
- [x] Standalone checks under tools/tests run on a fixture that includes a flow replacement, a reopen, a baseline and an external edit, and one of them fails when the replacement rule is switched off
- [x] The architecture and README text about cycle time describe the new design
