## Summary

The original request provides the user’s motivation and desired direction for improving MarkView’s visual presentation. It asks for several configurable themes, including an IntelliJ-inspired option, with independent customization for each window.

## Origin

intake

## Content

Я хочу улучшить UI, как выглядит MarkView. И для этого мне хотелось бы использовать разные темы, которые я мог бы менять и настраивать. Я хотел бы, чтобы ты мне предложил несколько новых тем, но одну из них, например, что-нибудь из IntelliJ. Попробую, мне нравились их продукты. Какие-нибудь темы оттуда. В общем, придумай несколько, где-то до пяти разных тем, чтобы я мог поменять. И у меня выглядело все намного-намного более презентабельно, чем сейчас. Сейчас оно выглядит как-то так, ванило, так сказать. Очень все просто. Да, оно удовлетворяет моим запросам основным. Но выглядит так себе. Хотелось бы, чтобы каждое окошко я мог бы настраивать там по-своему. У каждого окошка своя тема и все остальное. В общем, такой заказ.
