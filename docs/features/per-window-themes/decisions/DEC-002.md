## Context

The specification did not define what happens to a window's custom accent when the user switches to another preset.

## Alternatives

1. Keep one window-level accent override when switching presets; use the current preset's default when no override exists.
2. Clear the accent override whenever a different preset is selected and use the new preset's default.

## Decision

Each preset remembers its own custom accent within each workspace window. When the user returns to a preset, restore that preset's previous override; if none exists, use the preset's default accent.

## Reason

This preserves a user's accent choice for each preset when switching between themes.

## Consequences

Store and restore accent overrides separately for each preset in each workspace window. Resetting the accent removes the override for the current preset and restores its default. Define separately whether a new window inherits the full collection of overrides or only the active preset and its accent.
