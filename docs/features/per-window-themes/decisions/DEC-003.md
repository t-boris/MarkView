## Context

implementation/plan.md (I-3) and discussion.md (2026-11-08) proposed palettes for Darcula-inspired, Midnight, Graphite and Paper and a single font family, but marked them unconfirmed and asked for a design decision before final visual implementation. The owner was asked on 2026-11-08 during implementation.

## Alternatives

1. Approve the palettes but let every window choose its own font (more configuration, may change line wrapping in documents).
2. Replace the proposed palettes or fonts with ones the owner describes.

## Decision

Approve the proposed palettes as the default tokens of the four presets: Darcula-inspired (editor #2B2B2B, panels #323232, text #E0E0E0, accent #E6A15C), Midnight (#151C2B, #1D2738, #E5EBF5, #79B8FF), Graphite (#202124, #2A2C30, #E8EAED, #B39DDB) and Paper (#FFFCF5, #F2EDE3, #292724, #315E9B). Use one font family in every theme and window: the system San Francisco for the interface and regular text, SF Mono with the system monospaced fallback for source Markdown, code blocks and the terminal. Per-window font selection is not offered. Exact shades may move by the smallest step needed to reach a 4.5:1 contrast for body text; any such move is recorded in the specification.

## Reason

The owner chose "approve as is" for the palettes and the single font family when asked to confirm them.

## Consequences

The theme tokens, syntax colors and terminal palette of each preset are defined from these values. No font selector is built; the interface and document text-size controls stay separate and unchanged. Adjustments for contrast are allowed within the stated limit.
