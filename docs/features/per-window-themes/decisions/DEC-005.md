## Context

DEC-002 left open whether a new window inherits the whole collection of per-preset accent overrides or only the active preset and its accent. Acceptance criterion 4 and implementation/plan.md (I-2) say a new window starts with the most recently selected theme and accent.

## Alternatives

1. Inherit only the active preset and its current accent; other presets start without overrides.

## Decision

A new window starts from the most recently selected theme together with the full collection of per-preset accent overrides of the window that was changed last. After it opens it is independent: later changes in it or in any other window do not propagate.

## Reason

The owner chose "the theme and all accents" so that a new window looks like the last one the owner customized, including accents of presets not currently active.

## Consequences

The remembered starting value for new windows stores the active theme and the per-preset accent map, not only one accent. Acceptance criterion 4 reads "the most recently selected theme and accent overrides". Restoring a window after relaunch restores its own theme and its own map.
