## Context

The specification retains System for existing users but does not define whether it remains selectable or how the existing theme toggle and keyboard shortcut work with four presets.

## Alternatives

1. Keep System selectable and make the existing toggle and shortcut switch between light and dark themes, choosing the opposite appearance when leaving System.
2. Keep System only as a legacy state until a preset is selected; make the toggle and shortcut switch between Paper and the last selected dark theme.

## Decision

Keep System as a selectable appearance mode that follows macOS. Repurpose the existing theme toggle and keyboard shortcut to open the theme picker.

## Reason

The team chose to preserve access to System while giving the existing controls a consistent way to reach all available theme choices.

## Consequences

The theme picker must include System alongside the four presets. The existing toggle and keyboard shortcut must open the picker instead of immediately changing the appearance. Users can return to System after selecting a preset.
