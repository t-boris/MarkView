## Finding

The specification does not define what happens to an existing accent override when a different preset is selected. This changes the appearance the user sees and what a subsequently opened window inherits.

> Each window offers an accent-color override and a reset to the selected preset’s default.

## Possible interpretations

- Keep the window's accent override when switching presets until the user resets it.
- Replace the override with the new preset's default when switching presets.
- Remember a separate override for each preset in the window.

## Resolution

Каждая тема запоминает свой пользовательский акцент в пределах окна. При возвращении к теме восстанавливается её прежний акцент; если его нет, используется цвет по умолчанию. — see DEC-002.
