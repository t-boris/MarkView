## Finding

The specification retains System only for users who have not selected a preset, while preserving existing functionality and replacing the current light/dark interaction with a four-preset picker. It does not say whether users can return to System after choosing a preset, or how the existing theme toggle and keyboard shortcut behave with four presets. These choices affect an established workflow and the available appearance modes.

> The existing system appearance preference is retained for users who have not selected a preset; explicitly selected presets have fixed light or dark appearances.

## Possible interpretations

- Keep System as a selectable mode and adapt the existing toggle or shortcut to the new choices.
- Retain System only as a legacy state until a preset is chosen, and redefine or remove the existing toggle behavior.

## Resolution

System остаётся доступным режимом. Существующие переключатель и сочетание клавиш открывают выбор темы вместо немедленной смены внешнего вида. — see DEC-001.
