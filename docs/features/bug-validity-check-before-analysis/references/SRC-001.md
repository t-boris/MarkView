## Summary

The original request establishes the user's intent to check whether a selected bug still exists before every analysis and to close it automatically when it has already been fixed and needs no further correction. It does not define the evidence needed for closure, the project state to verify, or whether closure should also update GitHub.

## Origin

intake

## Content

Я хочу, чтобы когда мы выбирали баг, то у нас в анализе была возможность проверить, валидный он еще или нет, и если он уже закрыт, то есть мы уже фикснули его и не надо ничего фиксить, то он должен автоматически закрываться. То есть это делать перед любым анализом на валидное существование.
