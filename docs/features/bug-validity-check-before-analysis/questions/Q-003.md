## Question

Автозакрытие должно затрагивать только локальный баг или также связанный GitHub issue?

## Why it matters

В проекте существуют два отдельных состояния, а слово «закрыть» не определяет, нужно ли менять оба.

## Options

- **A**: Автоматически закрывать локальный баг; GitHub обновлять существующей командой Sync.
- **B**: Также автоматически закрывать связанный GitHub issue с учётом существующих правил синхронизации.

## Recommended

A — В проекте уже принят ручной запуск синхронизации; запрос явно не меняет эту границу.
