## Question

В каком состоянии проекта баг должен быть исправлен, чтобы его можно было автоматически закрыть?

## Why it matters

Исправление в рабочей ветке, в main и в выпущенной версии означает разные результаты проверки.

## Options

- **A**: Проверять относительно текущего рабочего состояния проекта.
- **B**: Проверять относительно основной ветки main.
- **C**: Проверять относительно последней выпущенной версии.

## Recommended

B — В проекте завершение изменений связано со слиянием PR в main; это устойчивая граница для автозакрытия.
