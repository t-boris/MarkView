## Statement

Stop further investigation of the resolved problem after automatic closure.

## Acceptance Criteria

- [ ] A bug automatically closed by the validity check does not proceed to root-cause investigation in that run.
- [ ] The run does not request a new fix for the problem established as already resolved.
