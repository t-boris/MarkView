## Statement

Continue the existing analysis workflow when the bug still exists or validity remains inconclusive, without presenting uncertainty as confirmed validity.

## Acceptance Criteria

- [x] A still-present outcome continues the existing investigation workflow.
- [x] An inconclusive outcome preserves the current lifecycle status and continues investigation with the uncertainty and its reason made explicit.
- [x] Missing evidence, unavailable verification tools, or verification errors never cause automatic closure.
