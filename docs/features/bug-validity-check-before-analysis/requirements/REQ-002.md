## Statement

Automatically close the local bug report only when concrete evidence addressing the reported scenario establishes that its reported problem has already been fixed and requires no further correction. Inability to reproduce alone is insufficient for automatic closure. Leave GitHub updates to the existing manual Sync workflow.

## Acceptance Criteria

- [x] When concrete evidence addressing the reported scenario establishes that the reported problem has already been fixed and requires no further correction, automatically change the local bug report status to closed.
- [x] Do not automatically close the local bug report when concrete evidence of resolution is insufficient, including when the only evidence is inability to reproduce the reported problem.
- [x] Automatic closure changes only the local bug report and does not update or comment on GitHub issues.
- [x] A locally closed bug remains eligible for the existing manual Sync workflow under its existing issue-linking rules.
