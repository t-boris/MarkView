## Context

Нужно отличать доказанное исправление от неудачной попытки воспроизведения.

## Alternatives

1. Закрывать при конкретных доказательствах исправления в коде или проверках; одного отсутствия воспроизведения недостаточно.
2. Закрывать только после успешного выполнения исходного сценария.

## Decision

Automatically transition a bug to closed only when concrete evidence establishes that its reported problem has already been fixed and no further correction is needed. Evidence must address the reported scenario; inability to reproduce alone is insufficient.

## Reason

Выбрано конкретное подтверждение исправления: оно допускает проверку по коду, когда запуск сценария недоступен, но исключает закрытие по предположению.

## Consequences

Часть уже исправленных багов останется открытой до получения достаточных доказательств.
