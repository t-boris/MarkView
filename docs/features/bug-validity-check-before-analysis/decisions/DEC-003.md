## Context

В предоставленном описании проекта синхронизация статусов запускается вручную.

## Alternatives

1. Автоматически закрывать локальный баг; GitHub обновлять существующей командой Sync.
2. Также автоматически закрывать связанный GitHub issue.

## Decision

Automatic closure updates only the local bug report. Linked GitHub issues remain subject to the existing manually initiated status-sync workflow.

## Reason

Выбрано локальное закрытие: оно сохраняет существующую границу полномочий Sync и не добавляет фоновое изменение GitHub.

## Consequences

Связанный GitHub issue может оставаться открытым до запуска Sync пользователем.
