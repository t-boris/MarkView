## Finding

The scenario includes both user-selected branches and conditional options, but does not state what happens when a selected branch requires a condition that is not observed. This affects whether a branch is considered tested and whether the run should attempt to establish the condition.

> Scenarios can contain conditional options, including different actions, errors, and timing-related cases.

## Possible interpretations

- Preparation must establish the selected branch's condition; if it cannot, the branch is reported as not completed.
- The run follows the condition actually observed and reports the selected branch as not covered.
- The run forces the selected alternative independently of the observed condition.

## Resolution

До проверки система пытается создать условие выбранной ветви в рамках утверждённой подготовки. Если условие не достигнуто, ветвь не выполняется и отмечается как непокрытая. — see DEC-011.
