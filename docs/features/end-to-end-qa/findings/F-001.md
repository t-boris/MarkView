## Finding

The specification does not say whether scenarios and their edits must persist across MarkView sessions or be available for later runs. This determines whether QA scenarios are reusable project assets or temporary plans.

> The user can inspect, extend, and modify the scenario and select paths or options for testing.

## Possible interpretations

- Scenarios are saved and can be reopened, edited, and run again.
- Scenarios exist only for the current session; reuse is outside the first release.

## Resolution

Сценарии становятся постоянными материалами проекта и доступны для повторного использования. — see DEC-006.
