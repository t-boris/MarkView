## Finding

The native application scope does not specify how the user identifies the application under test or whether MarkView launches it or attaches to an already running instance. This is a user-visible entry point needed to execute a native check.

> A run can execute selected checks against a web application or a native macOS application.

## Possible interpretations

- The user selects an installed application and MarkView launches it.
- The user selects an already running application and MarkView attaches to it.
- Both launch and attach workflows are supported.

## Resolution

Пользователь выбирает установленное приложение, а MarkView запускает его перед проверкой. — see DEC-008.
