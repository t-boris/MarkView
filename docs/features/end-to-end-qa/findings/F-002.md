## Finding

The specification requires independent sessions for web actors and also supports native macOS applications, but does not define whether multiple actors in one check may use native applications, web applications, or both. These choices lead to materially different supported workflows.

> A run can execute selected checks against a web application or a native macOS application.

## Possible interpretations

- Multiple actors are supported only for web checks; native checks use one actor.
- A check may coordinate multiple native actors and web actors, including mixed web and native flows.

## Resolution

Несколько акторов могут участвовать как в веб-проверке, так и в проверке нативного macOS-приложения, но одна проверка не сочетает оба типа. — see DEC-007.
