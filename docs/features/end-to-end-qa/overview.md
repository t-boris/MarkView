# End-to-End QA

## Idea

Пользователь описывает цель проверки, а MarkView помогает построить и визуально изменить разветвлённый сценарий, подготовить окружение и учётные записи, выполнить действия нескольких акторов в браузере MarkView или нативном приложении macOS, записать видео и проанализировать ключевые веб-страницы и экраны нативного приложения macOS. Обнаруженные проблемы оформляются в MarkView.

## Problem

Сейчас из существующих возможностей браузера, сценариев UI Studio и учёта багов не следует наличие единого процесса, который превращает цель проверки в наглядный многопользовательский end-to-end сценарий, выполняет его и собирает результаты.

## Scope

Входит: подготовка окружения и акторов, создание и визуальное редактирование разветвлённых сценариев, выполнение в браузере MarkView, видео, AI-анализ ключевых веб-страниц и экранов нативных приложений macOS и создание багов. Первый выпуск поддерживает веб-приложения и нативные приложения macOS. Одна проверка должна быть направлена только на один тип приложения; смешанные проверки веб-приложений и нативных приложений macOS в первый выпуск не входят. Границы поддержки других типов приложений и браузерных движков остаются открытыми.

## Existing behaviour

- MarkView — нативное приложение macOS с браузером на WKWebView. Это определяет существующую среду, но не означает поддержку нескольких браузерных движков. (`CLAUDE.md`)
- Агент уже может открывать вкладки MarkView, переходить по адресам, читать страницу, кликать, вводить текст, ожидать условия, получать снимки и сообщения консоли. (`MarkView/Models/BrowserAgentTools.swift`)
- Вкладка браузера поддерживает управление агентом, снимки страницы и остановку доступа агента пользователем. (`MarkView/Models/BrowserSession.swift`)
- Браузер хранит сохранённые логины в macOS Keychain с привязкой к хосту и имени пользователя. (`MarkView/Models/BrowserPasswords.swift`)
- UI Studio уже позволяет записывать клики, ввод и Enter как шаги восстановления состояния, сохранять сценарии и делать снимки с привязкой к сценарию. Это близкая возможность, но её описание не устанавливает наличие запрошенного многопользовательского end-to-end QA. (`MarkView/Views/UIStudioView.swift`)
- В проекте уже есть создание пронумерованных bug reports и их отображение в списке задач. (`MarkView/Models/FeatureStore.swift`)
