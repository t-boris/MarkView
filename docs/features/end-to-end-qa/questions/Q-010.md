## Question

How are the recorded run videos and frames cleaned up as runs pile up?

## Why it matters

Today nothing deletes a run: each branch of each run leaves an .mp4 (1 to 3 MB measured) and a run.json in .dde/qa/runs/<id>/ for ever, and with many scenarios and branches this grows without a limit. Boris asked on 2026-11-10: "there will be very many over time".

## Options

- **A**: Keep the newest N runs per scenario and every run a filed bug points to; delete the others automatically when a new run starts
- **B**: Delete by age: videos older than N days, keep run.json and the key frames of bugs
- **C**: Manual only: Delete run and Delete all runs buttons, with the total size shown

## Recommended

Keep the newest N runs per scenario (default 5) plus any run that has a filed bug, delete the rest automatically when a run starts, and add "Delete run" and "Delete all runs of this scenario" in the Run panel.
