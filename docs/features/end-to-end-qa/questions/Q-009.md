## Question

Are the several applications of one scenario always the same type (all web or all native macOS), or does a flow need to cross both, for example a web user application and a native administration application?

## Why it matters

DEC-007 keeps web and native checks apart in the first release. Crossing both types in one flow reverses that decision and needs a run that drives a browser and a native application together.

## Options

- **A**: Same type within a scenario; web and native flows are separate scenarios (DEC-007 stays).
- **B**: A scenario may mix web and native applications (DEC-007 is reversed).

## Recommended

A — it keeps DEC-007, and three web applications with five players are covered without it.
