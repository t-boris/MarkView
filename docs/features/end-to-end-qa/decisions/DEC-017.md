## Context

Nothing records video today. The deployment target is macOS 13, where the recording output of ScreenCaptureKit (macOS 15) is not available. Screen Recording needs a user grant that Debug builds lose on every rebuild.

## Alternatives

1. Record the screen with ScreenCaptureKit for web checks too.
2. Record only on macOS 15 and later.

## Decision

Both kinds of player hand the run a picture at every step boundary. A web player takes a snapshot of its page. A native player takes the latest frame of its application window from an SCStream (ScreenCaptureKit with a desktop-independent window filter, which works on macOS 13). QAVideoWriter encodes the pictures with AVAssetWriter, with the subtitle band below the picture (DEC-022). One video per checked branch is stored in the run folder and linked from the run record.

## Reason

Both paths work on macOS 13, share one writer, and the web path needs no Screen Recording grant, so a browser check asks the person for nothing.

## Consequences

A video is a sequence of pictures taken at step boundaries, not a continuous screen capture. A native check needs the Accessibility and Screen Recording grants; they persist only for a signed (Developer ID) build, so a Debug build loses them on every rebuild. The Run panel shows the status of both and links to System Settings.
