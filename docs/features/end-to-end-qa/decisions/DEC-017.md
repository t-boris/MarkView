## Context

Nothing records video today. The deployment target is macOS 13, where the recording output of ScreenCaptureKit (macOS 15) is not available. Screen Recording needs a user grant that Debug builds lose on every rebuild.

## Alternatives

1. Record the screen with ScreenCaptureKit for web checks too.
2. Record only on macOS 15 and later.

## Decision

Web checks write video from per-actor page snapshots taken at a fixed rate, masked and encoded with AVAssetWriter, which needs no Screen Recording grant and works with web views that are not on screen. Native checks capture the application window with an SCStream, mask each frame and encode it the same way. The video is stored in the run folder and linked from the run record.

## Reason

Both paths work on macOS 13 and let masking happen before any frame is written; the web path avoids a permission the user would otherwise have to grant for a browser check.

## Consequences

Web video is a snapshot sequence, not a screen capture. Native recording and native verification need Screen Recording and a locally signed Developer ID build so the grant persists.
