## Context

DEC-006 makes scenarios persistent project assets. Runs hold large and sensitive material (frames, video). UI Studio already splits reusable scenarios from session data.

## Alternatives

1. Keep scenarios under docs/ like prototypes.
2. Keep everything under .dde/.

## Decision

Scenarios are JSON files in .markview/qa/scenarios, the material policy is .markview/qa/policy.json (patterns only), and runs are folders in .dde/qa/runs with a self-writing ignore-all .gitignore. Credentials never go into files: a scenario holds an actor name and a login reference (host and username) that resolves in the macOS Keychain store used by the browser.

## Reason

It follows the UI Studio convention, so reusable assets can be committed and run data stays local.

## Consequences

In this repository .markview/ and .dde/ are ignored, so scenarios are not shared through git here. A bug's video link works only on the Mac that made the run; masked key frames are stored beside the bug.
