## Context

A selected scenario branch may require a condition that is not observed at runtime, including an error or timing-related condition.

## Alternatives

1. Follow the branch matching the observed condition and mark the selected branch as uncovered.
2. Actively induce the selected condition during the check, such as by simulating an error or delay; mark the branch as uncovered if this is impossible.

## Decision

Before the check, the system attempts to establish the selected branch's condition within the approved preparation. If the condition is not achieved, the branch is not executed and is marked as uncovered.

## Reason

This approach attempts to make the selected branch testable while keeping condition setup within the approved preparation and preserving accurate coverage reporting.

## Consequences

The specification must define how preparation establishes and verifies branch conditions. A selected branch whose condition is not achieved is not executed and is reported as uncovered. Preparation remains subject to existing approval requirements.
