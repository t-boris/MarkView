## Context

A scenario generated from a goal in words has no selectors, so it cannot be replayed as fixed recorded steps. The request is a manual QA test performed automatically, like a human.

## Alternatives

1. Replay only recorded steps like UI Studio scenarios.
2. Start one long-lived interactive AI agent for the whole run through the browser MCP tools.

## Decision

For each action node a bounded observe-act loop runs: the AI receives the masked snapshot, the node and its expected check and returns one tool call or done/blocked; the expected check is verified by assertions plus the AI's reading of the masked screenshot. Steps that worked are cached so a re-run can replay them without the AI.

## Reason

It works from a scenario written in words, keeps each step under the run's gate and masking, and records structured per-node outcomes. A single long-lived agent cannot be gated per action or masked.

## Consequences

Each step costs one CLI AI call, so a first run is slow; the step cache and a step budget per node limit this. A node that exhausts its budget is blocked.
