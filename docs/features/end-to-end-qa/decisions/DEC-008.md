## Context

The first release supports QA checks against native macOS applications, but REQ-003 does not specify how the application under test is selected or started.

## Alternatives

1. The user selects an already running application, and MarkView attaches to it.
2. The user can either select an installed application for MarkView to launch or attach to an already running application.

## Decision

The user selects an installed macOS application, and MarkView launches it before the check.

## Reason

Команда выбрала этот способ; дополнительные причины выбора не указаны.

## Consequences

REQ-003 must define installed-application selection, launch failure handling, and how the prepared baseline is established before each selected branch. Attaching to an already running application is outside this entry point.
