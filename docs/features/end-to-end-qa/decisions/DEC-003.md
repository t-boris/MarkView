## Context

Branch coverage in a run

## Alternatives

1. Check one selected path per run.
2. Check multiple selected branches as separate checks in one run.
3. Let MarkView choose which branches to explore.

## Decision

Allow one run to check multiple user-selected branches as separate checks.

## Reason

The product owner selected multiple explicit checks per run.

## Consequences

A run must report the outcome of each selected branch separately.
