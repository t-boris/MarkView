## Context

The first release supports both web and native macOS applications, but REQ-005 refers only to pages, leaving analysis and bug reporting for native screens unclear.

## Alternatives

1. Analyze web pages only in the first release.
2. Analyze web pages for UI and UX quality and possible bugs, but limit native macOS screen analysis to possible visual bugs.

## Decision

In the first release, AI analyzes key web pages and native macOS application screens, and detected bugs are recorded in MarkView.

## Reason

The team selected analysis and bug reporting for both application types supported in the first release.

## Consequences

Update REQ-005 and its acceptance criteria to cover analysis of key web pages and native macOS screens for UI and UX quality and possible bugs, and creation of MarkView bug reports for detected bugs in both application types. The user's choices about material transmitted for AI analysis and the requirement to hide sensitive data continue to apply.
