## Context

The scenario design requirement allows users to inspect and modify branching QA scenarios, but does not specify whether scenarios persist or can be reused after a MarkView session ends.

## Alternatives

1. Keep scenarios and edits only for the current MarkView session.
2. Let users manually save selected scenarios for later reuse; unsaved changes remain temporary.

## Decision

QA scenarios and their edits are persistent project assets that users can reopen, edit, and run again across MarkView sessions.

## Reason

The team chose persistent project assets to make QA scenarios available for repeated use.

## Consequences

REQ-001 must require scenarios and their edits to persist across MarkView sessions and allow users to reopen, edit, and run them again.
