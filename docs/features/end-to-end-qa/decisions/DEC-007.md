## Context

The first release supports both web and native macOS applications, and web actors use independent MarkView browser sessions. The existing requirements do not define whether native checks can involve multiple actors or whether a single check can combine web and native actors.

## Alternatives

1. Support multiple actors only in independent web browser sessions; native macOS checks use one actor.
2. Allow a single check to coordinate web and native macOS actors in mixed flows.

## Decision

Support multiple actors in web checks and in native macOS application checks. A single check must not combine web and native application types in the first release.

## Reason

The team selected this scope to support multi-actor testing for both application types while excluding mixed web and native checks from the first release.

## Consequences

REQ-003 must cover coordination of multiple actors in both web and native macOS checks. Each check must target only one application type; mixed web and native checks are outside the first release. The isolation and execution model for native actors remains to be specified.
