## Context

Boris wants the video to explain itself: a line at the bottom saying what is done, where and why. A video is watched in QuickTime, attached to a bug and sent to colleagues, where a separate subtitle track is often not shown.

## Alternatives

1. A soft subtitle track in the movie file that a player can switch off.
2. A sidecar subtitle file next to the video.

## Decision

Each frame is extended with a band below the picture and the current subtitle is drawn into it before the frame is written, so every player shows it. The same lines, with the times they start and end, are stored in the run record and shown in the live feed, which also keeps them searchable and available for a soft track later. The line for an action comes from the runner's record of the action (the player, the control, the field) plus the one-line explanation the AI gives with each action.

## Reason

A burned-in line is visible wherever the video goes, and the band keeps the application fully visible. Keeping the lines as data costs nothing and leaves other uses open.

## Consequences

The action the AI returns carries a short reason, so the loop schema gains a field. The band cannot be turned off in the file; a run that should not carry it records without the video, or with subtitles off if that option is added later.
