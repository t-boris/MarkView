## Context

All browser tabs share one cookie store, so two users cannot be signed in to one host at once. Only the active tab is mounted in a window, and a page snapshot needs a mounted web view.

## Alternatives

1. Use a data store identified per actor (needs macOS 14, above the macOS 13 target).
2. Switch the visible tab between actors.

## Decision

Each web actor gets its own non-persistent website data store. The run view mounts every actor's web view side by side; checks in the app's probes mount them in an invisible window. The run owns an approval record, the production data-changing confirmation and Stop.

## Reason

It is the isolation pattern already used by UI Studio and works on macOS 13; nothing switches tabs, so snapshots stay reliable and the person can watch the actors.

## Consequences

The browser session gets an optional data store with the current default unchanged. The tab-level stop and tool toggles of the agent server do not apply to in-process calls, so the run enforces its own gate.
