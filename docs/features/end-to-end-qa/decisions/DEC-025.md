## Context

Each branch of each run leaves an .mp4 (1 to 3 MB) and a run.json in .dde/qa/runs/<run-id>/ for ever. Boris, 2026-11-10: "there will be very many over time" (Q-010).

## Alternatives

1. Delete by age: videos older than N days, keep run.json and the key frames of bugs.
2. Manual only: Delete run and Delete all runs buttons with the total size shown.

## Decision

When a new run starts, the older runs of the same scenario are deleted except the newest 5 (the run that is starting counts as one of them, so 4 older runs stay) and every run that a filed bug points to (the run id in the bug's qa_key). A run in progress, or one that has not ended, is never deleted. The Run panel also has "Delete run" for one earlier run and "Delete all runs of this scenario", each with a confirmation that says how many runs and how much disk.

## Reason

Boris chose option A on 2026-11-10: it bounds the disk use without a decision from the person, and keeps the evidence a bug rests on.

## Consequences

A run that is neither among the newest 5 nor named by a bug is gone for good (deleted, not moved to the Trash). A bug closed or deleted later releases its run to the next cleanup. Pruning happens off the main thread and never fails a run.
