## Context

DEC-004 lets the user choose what may be saved and transmitted and requires sensitive data to be hidden. The run sends page material to the AI at every step, not only at the end, and the existing agent screenshot is not masked.

## Alternatives

1. Mask only the finished video and the final analysis images.
2. Hide only known secrets automatically.

## Decision

Everything that is saved or leaves the Mac (video frames, screenshots and snapshot text sent to the AI, bug pictures) passes one preparation step that applies the user's policy: pages and screens are denied unless allowed, password fields are always masked, and the user's patterns and selectors apply. If masking cannot be applied, the item is dropped and the run reports it was not captured.

## Reason

The policy must hold for the step-by-step transmissions too, and a failed mask must never turn into an unmasked copy.

## Consequences

Masking is built before any run sends page material to the AI. Web pages are masked in the page before the snapshot; native frames are masked from Accessibility frames and user regions, which is best effort and drops what it cannot place. The existing browser agent screenshot tool is not changed.
