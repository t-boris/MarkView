## Context

First-release application coverage

## Alternatives

1. Limit the first release to web applications.
2. Include native or other applications in the first release.

## Decision

Include native or other applications alongside web applications in the first release.

## Reason

The product owner selected broader application coverage.

## Consequences

The first release must support web applications and at least one non-web application type; the supported non-web target remains to be defined.
