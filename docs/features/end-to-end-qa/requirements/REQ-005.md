## Statement

Analyze key web pages and native macOS application screens for UI and UX quality and possible bugs, and create MarkView bug reports for detected bugs in both application types. Automatically create a MarkView bug report for each failed, blocked, or interrupted check, identifying which outcome occurred, including when the issue may not be a product defect.

## Acceptance Criteria

- [x] Analyze key web pages and native macOS application screens for UI and UX quality and possible bugs.
- [x] Create MarkView bug reports for detected bugs in both web applications and native macOS applications.
- [x] Automatically create a MarkView bug report for each failed, blocked, or interrupted check.
- [x] Identify the outcome of each automatically created report as failed, blocked, or interrupted.
