## Statement

Record the execution of a scenario, for a web application and for a native macOS application, and associate each recording with its run.

## Acceptance Criteria

- [x] A run of a web application records one video per checked branch and links it from the run record.
- [x] A run of a native macOS application records one video per checked branch from the application's window and links it from the run record.
