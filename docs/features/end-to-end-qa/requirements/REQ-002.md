## Statement

Prepare the target environment, actor credentials, and selected branch conditions as part of the scenario, subject to user approval.

## Acceptance Criteria

- [x] The user can identify a local, development, or production target and define the actors and their credentials.
- [x] Preparation can use supplied credentials or create test accounts where possible.
- [x] The user can review and approve preparation before it begins.
- [x] Before the check, the system attempts to establish each selected branch's condition within the approved preparation and verifies whether the condition was achieved.
- [x] If a selected branch's condition is not achieved, the system does not execute that branch and marks it as uncovered.
