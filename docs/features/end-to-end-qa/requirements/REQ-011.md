## Statement

A person shall be able to duplicate a scenario and to write a new scenario based on an existing one, because scenarios are often alike and differ in a few things.

## Acceptance Criteria

- [ ] Duplicate (scenario list menu and editor header) makes a scenario with a new id and the title "<title> (copy)", the same steps, connections, players, applications, environments and chosen branches, and opens it
- [ ] Runs and the approval are not copied; the original is unchanged
- [ ] New scenario has a Based on choice (and the list menu has New Scenario Based on This…): the assistant receives the whole base scenario, keeps what the goal does not change and writes a new one; the original is unchanged
- [ ] Choosing a base fills the kind, applications and players, which can still be changed
