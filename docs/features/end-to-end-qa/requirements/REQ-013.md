## Statement

A person shall be able to give a player a site, user name and password directly in the scenario editor, without leaving it, and the editor shall stay on the tab and sections the person chose when they come back to it.

## Acceptance Criteria

- [ ] The player's login menu has Add login…: site (prefilled from the environment's address), user name and password; Save stores it in the macOS Keychain with the browser's saved passwords and selects it for the player
- [ ] The scenario file keeps only the site and the user name, never the password (DEC-014)
- [ ] A site may be typed as a bare name, with a port or as a whole address; text that is no site is refused before saving
- [ ] Logins of the player's own sites are listed before the other saved logins
- [ ] Branches/Step/Setup/Run and the Applications, Players, Environments and Baseline sections are per window: switching to another tab of the window and back leaves them as they were, and another window is not moved
