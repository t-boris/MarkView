## Statement

The system shall let a person enlarge any picture of a run (a player's live page and every screenshot of the feed) and decide what to do about each finding of a finished run (bug confirmed, not a bug, has a workaround, seen, dismissed), keep the decision on the finding and in the bug filed for it, and list a scenario's earlier runs so the same can be done after a restart.

## Acceptance Criteria

- [ ] A player's picture and every feed screenshot open in a resizable viewer window with Fit and 100% views, arrows between pictures, Esc to close and Open in Preview.
- [x] A defect offers Confirm bug, Not a bug and Has a workaround; a note or suggestion offers Mark seen and Dismiss; marks are offered only after the run has finished.
- [x] A mark is saved on the finding in run.json and an old run.json without marks still loads.
- [x] Confirm bug sets ready_to_fix on the bug filed for the finding; Not a bug closes it through the workflow's own cancelling step; Has a workaround (with its text) adds a Workaround section; Undo takes each back, reopening a bug this app closed.
- [x] The Run tab lists the scenario's earlier runs, newest first, with the outcome of each branch and the number of unmarked findings; opening one shows its branches, findings with pictures, marks and video.
- [x] A workflow with no cancelling step leaves the bug unchanged and says so on the run report, while the mark stays on the finding.
