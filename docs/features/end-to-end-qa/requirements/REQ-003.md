## Statement

Execute user-selected end-to-end checks for web and native macOS applications, coordinating multiple actors within each check, starting each selected branch from its prepared baseline state and obtaining the required user approvals. Before each selected branch, attempt to establish and verify its condition within the approved preparation; if the condition is not achieved, do not execute the branch and report it as uncovered. Report failed, blocked, and interrupted checks as distinct outcomes. For a native macOS application check, the user selects an installed application, and MarkView launches it before the check; attaching to an already running application is outside this entry point. In the first release, each check targets only one application type and cannot combine web and native macOS applications.

## Acceptance Criteria

- [x] A run can execute selected checks against a web application or a native macOS application.
- [x] A check can coordinate multiple actors for a web application.
- [x] A check can coordinate multiple actors for a native macOS application.
- [x] In the first release, each check targets only one application type; a check cannot combine web and native macOS applications.
- [x] For a native macOS application check, the user selects an installed application, and MarkView launches it before the check.
- [x] If MarkView cannot launch the selected native macOS application, the check is not reported as completed.
- [x] Attaching to an already running native macOS application is outside the supported entry point.
- [x] A run can execute multiple user-selected branches as separate checks.
- [x] A run reports the outcome of each selected branch separately.
- [x] Before each selected branch, its prepared baseline state is established.
- [x] If a branch's prepared baseline state cannot be established, the branch is not reported as completed.
- [x] Before each selected branch, the system attempts to establish its condition within the approved preparation.
- [x] Before each selected branch is executed, the system verifies whether its condition has been achieved.
- [x] If a selected branch's condition is not achieved, the branch is not executed.
- [x] If a selected branch's condition is not achieved, the branch is reported as uncovered.
- [x] Preparation and the scenario are approved before execution.
- [x] Production actions that change data require explicit confirmation.
- [x] A failed check is reported with the outcome failed.
- [x] A blocked check is reported with the outcome blocked.
- [x] An interrupted check is reported with the outcome interrupted.
