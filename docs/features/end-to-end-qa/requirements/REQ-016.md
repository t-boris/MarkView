## Statement

The system shall keep the newest 5 runs of each scenario (the run that is starting counts as one of them) and every run that a filed bug points to, delete the other runs automatically when a new run starts, and let the person delete one run or all runs of a scenario from the Run panel.

## Acceptance Criteria

- [x] When a run starts, the older runs of the same scenario are deleted except the newest 4 (with the starting run, the newest 5) and the runs named by a filed bug; the run being started is never deleted.
- [ ] The Run panel offers 'Delete run' for one earlier run and 'Delete all runs of this scenario', each after a confirmation that says how many runs and how much disk space.
- [x] A run in progress cannot be deleted; a run that a filed bug points to can be deleted by hand, and the confirmation says that the bug names it.
- [x] Deleting removes the run's folder (run.json, frames and videos) from .dde/qa/runs and nothing outside it; a run id that is not a plain folder name is refused.
- [x] A failure while cleaning up does not fail or delay the run that is starting.
