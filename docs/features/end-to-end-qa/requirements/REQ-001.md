## Statement

Generate and visually present an editable, branching QA scenario from a user-described goal, and persist the scenario and its edits as a reusable project asset across MarkView sessions.

## Acceptance Criteria

- [ ] The user can describe a testing goal in natural language.
- [ ] MarkView presents a scenario with actions, expected checks, alternatives, and possible failures related to the goal.
- [ ] The user can inspect, extend, and modify the scenario and select paths or options for testing.
- [ ] QA scenarios and their edits persist as project assets across MarkView sessions.
- [ ] The user can reopen, edit, and run a persisted QA scenario again.
