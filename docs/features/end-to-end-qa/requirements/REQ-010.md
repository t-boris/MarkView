## Statement

The New scenario sheet shall take the goal by voice, take images pasted with ⌘V, files dropped on it, files chosen from anywhere ("Add Files…") and files of the project ("From Project…", searched by name), and give the assistant every attached file to read.

## Acceptance Criteria

- [ ] The goal field has a mic with the same recording and status line as the other AI fields
- [ ] An image pasted with ⌘V, a dropped file, a chosen file and a project file each appear as a chip that can be removed
- [ ] A file of the project is named to the assistant by its path; a file from outside is copied under .dde/qa/inputs for the run and removed after it
- [ ] Images are passed to the assistant as images; at most 12 files, and a copied file over 25 MB is refused with its name
- [ ] While the assistant works the sheet names what it is doing (files read, commands run, searches) and shows the elapsed time
