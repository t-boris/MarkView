## Finding

The approved prototype's original brief says that the map and its properties are a Markdown file, while the current requirements only require persistence and say new research should not produce a Markdown research report. The prototype specification describes Markdown storage as a working assumption. The required artifact format and its relationship to the existing Markdown editing workflow therefore remain unclear; this affects portability and how users access the research outside the map.

> A saved research map can be reopened with its content and edits intact.

## Possible interpretations

- Store each map as a human-readable Markdown document, while presenting it as a map in MarkView.
- Store each map in another format, with no requirement for a Markdown representation.

## Resolution

Хранить каждую карту в человекочитаемом Markdown-файле, который можно открыть и редактировать как документ. — see DEC-003.
