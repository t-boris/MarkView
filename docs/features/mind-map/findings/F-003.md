## Finding

Independent branch layouts do not define what happens to an existing nested layout when a layout is applied to its parent. The discussion asks this question but records no answer. The choice determines whether a user's existing arrangement is preserved or overwritten.

> The user can apply a choice of multiple predefined layouts independently to each branch of a research map.

## Possible interpretations

- Reposition immediate child branches while preserving their internal layouts.
- Apply the selected layout throughout the subtree, replacing nested arrangements.
- Ask the user which behavior to use when applying the layout.

## Resolution

Новый лейаут применяется ко всей подветке, заменяя ранее выбранные вложенные лейауты. — see DEC-005.
