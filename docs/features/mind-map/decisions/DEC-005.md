## Context

Branch-specific layout presets require defined behavior when a user applies a layout to a parent branch that already contains independently configured nested layouts.

## Alternatives

1. Reposition immediate child branches while preserving their nested layouts and settings.
2. Ask the user whether to preserve nested layouts or replace them across the subtree whenever a layout is applied.

## Decision

Applying a layout to a branch applies it throughout the entire subtree, replacing previously selected nested layouts.

## Reason

The team chose consistent layout application across the subtree; the supplied decision does not state any further rationale.

## Consequences

REQ-003 must specify recursive application of the selected layout to the entire subtree, replacing previously selected nested layouts.
