## Context



## Alternatives

1. Keep prototype colours (rejected by Boris)
2. Store collapsed in the map file (changes DEC-006)
3. Drag a node onto another to reparent (offered, not chosen)

## Decision

The map page is styled with the application's own tokens (--bg-primary/secondary/tertiary, --text-*, --border-color, --accent-*) in both themes, keeping only the six branch colours as muted accents. Fold state (collapsed nodes) is view state next to zoom, pan and panel width, not part of the map file, so the format of DEC-006 is unchanged. The "Move to another branch" action is removed together with its Swift operation; a node can still be moved visually, and a node under a wrong parent is deleted and added again.

## Reason

Boris, 2026-11-04: the UI does not follow the application's design; move-to-branch is useless; fold state in view state (recommended). Prototype v10 fixes layout and behaviour, not colours.

## Consequences

Supersedes the "move to another branch" half of the Q-003 answer. REQ-003's reparenting criteria are removed. No change to the file format.
