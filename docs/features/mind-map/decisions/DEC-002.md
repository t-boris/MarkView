## Context

The user wants several existing mind-map layouts and the ability to apply a layout to any branch.

## Alternatives

1. A single layout applies to the entire map.
2. Users arrange all nodes manually without layout presets.

## Decision

Provide multiple predefined layouts that users can apply independently to individual branches of a research map.

## Reason

This lets users choose a suitable visual arrangement for each part of the research.
