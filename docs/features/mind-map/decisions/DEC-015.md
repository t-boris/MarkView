## Context



## Alternatives

1. Ask the AI to rewrite the whole Markdown file in the other language (a model can drop nodes or break the format, nothing is checkable)
2. Translate on export only (the shared document is translated, but the map itself cannot be shown in English)
3. Translate in place with no copy (fast, but one wrong run loses the original language)

## Decision

Translate map is an AI pass that sends the map's texts (map question and title, and for every node its title, tags, description and evidence text) and receives the same texts in the target language, keyed by node id. The app applies the received texts onto a copy of the parsed map, so ids, parents, order, links, numbers, colours, icons, shapes, sizes, positions, evidence labels and evidence sources cannot change whatever the model answers. Code checks the answer: every node id is present, titles are not empty and fit the title limit, a Mermaid block comes back with the same skeleton (same diagram type, same line count, only the label text differs) or is kept as it was, Markdown image addresses and links are kept, and a node that fails after two repair rounds keeps its original text and is counted in the result. The default result is a new map file next to the old one (name suffixed with the language code, a new id); "Replace this map" is the other choice and first writes a copy of the current file, so that nothing is lost. The language is chosen from a list (English, Russian, German, Spanish, French) or typed.

## Reason

A translation done by rewriting the map file would let a model break the format, lose evidence sources or drop nodes. Keyed texts applied by code keep the map valid and make "everything is translated" checkable. A new file by default keeps the author's own language version intact; Boris keeps one map for himself in Russian and one to show in English.

## Consequences

A new pure module and standalone suite for the translation (prompt, answer format, checks, apply); a job kind in the jobs bar; a Translate button on the map; the Mermaid skeleton check is the only syntax-aware part. Diagram nodes keep working in the other language because the skeleton guard falls back to the original block.
