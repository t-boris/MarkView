## Statement

The system shall choose the side of each child of a node with the balanced layout again on every layout run, from the branches that are visible, and shall store nothing about it; a node placed by hand or given a layout of its own keeps what the person set.

## Acceptance Criteria

- [x] Equal branches still alternate right, left, right, left, starting on the right
- [x] A branch goes to the lighter side instead when the side it would alternate to is already taller by more than 90 px
- [x] Folding a branch, unfolding it, adding a node or moving a node under another parent re-balances the sides, and unfolding gives the first picture back (nothing is remembered)
- [ ] A node with hand-placed x and y, and a branch with a layout of its own, are not moved by the balancing
- [x] No two node boxes overlap after the balancing; the layout suite stays green
