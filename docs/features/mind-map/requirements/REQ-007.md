## Statement

The system shall generate a linear Markdown report and a PDF from a research map.

## Acceptance Criteria

- [x] An Export menu in the map toolbar offers Markdown report and PDF.
- [ ] Markdown report writes <map name>-report.md next to the map file and opens it; exporting again replaces that file.
- [ ] PDF asks where to save and is made from the same report with the existing PDF pipeline.
- [x] The report holds the question, every node (also folded ones) as nested headings in map order, descriptions, evidence with its label and source, logical connections as See also, the web queries, and a note when the run is incomplete.
- [x] Exporting does not change the map file or the view.
