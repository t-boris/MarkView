## Statement

The system shall let the person choose the shape of each node (rounded rectangle, rectangle, pill, ellipse, diamond) and set its width and height with handles on the node, with Width and Height fields in the properties panel, or with the presets Auto, S, M and L, and shall keep every node at least as large as its text.

## Acceptance Criteria

- [ ] The properties panel has a Shape row (five buttons, the current one marked) and a Size row (Auto, S, M, L and the Width and Height fields); a node without these properties looks as before
- [ ] A selected node shows eight resize handles (four corners, four edges); dragging one changes the width and the height live, the layout and the connection lines follow, and releasing stores the size; a double click on a handle returns the node to Auto
- [ ] A given width makes the title wrap; a given height is a floor: the node is never smaller than its text, and a height at or below the height of the text is stored as Auto
- [ ] S, M and L set a width and a height; Auto removes both; an empty Width or Height field removes that value; a width outside 60 to 800 or a height outside 28 to 600 is refused in the page and again in Swift
- [ ] Ellipse and diamond keep the title inside the shape (the node is padded so that the text fits); pill, ellipse and diamond are outlined in the branch colour, rounded rectangle and rectangle keep the branch stripe
- [ ] The shape and the size apply to the selected node only, to the root as well; the node menu, the fold toggle and the selection ring work on every shape
- [ ] The shape and the size are stored as the node properties `shape`, `width` and `height` in the map file; maps without them read and write as before; bad values in a hand-edited file are dropped on read
- [ ] The layout never lets two nodes of different branches overlap when nodes have different sizes and shapes
- [ ] The AI actions leave the shape and the size of a node alone, and the Markdown report does not mention them
- [ ] The shape ids of the page and of Swift are the same list (checked by a test)
