## Statement

The system shall write the Markdown report and the PDF of a map through the AI as one narrative document that can be shared without the map: connected prose that accounts for every node, with the map's images and diagrams (and new diagrams where they help) placed where they belong, and a list of the sources.

## Acceptance Criteria

- [ ] Markdown report and PDF both start an AI job (shown in the jobs bar with its stages, stoppable); the map stays usable while it runs; nothing is written until the job succeeds, and a failed or stopped job leaves no partial file and says why
- [ ] The report is prose, not an outline: an introduction with the question and the answer in brief, sections that follow the map's branches, conclusions, open questions and assumptions; it is not one heading or bullet per node (a check in code rejects an answer whose bullet share or heading count shows a node-by-node list, and asks the model to rewrite it)
- [ ] Every node is accounted for: the model names the nodes each section covers, and code checks that every node id is covered; a missing node makes the model repair the report
- [ ] The sources are kept: code builds the list of sources from the evidence of the map (label, text, path or address) and checks that every source the report cites exists in the map; the model cannot add a source or a file path
- [ ] The images and diagrams of the map (REQ-012) are placed by code next to the text about their node, as Mermaid blocks and image links; where a diagram would help, the model asks for one with a placeholder and the Graph Creator's generator makes it with its checks; a request that fails is left out with a note, never as a broken block
- [ ] The Markdown file is written beside the map; image links in it are relative to it and the files exist; Mermaid blocks render on GitHub and in the app's preview
- [ ] The PDF is the same document rendered: diagrams as drawings, images embedded, saved through the save dialog after the job succeeds
- [ ] The report is written in the language of the map's question unless the app's output language says otherwise
- [ ] The one-to-one outline report is no longer offered in the Export menu; the map itself is the outline
- [ ] Checked on the app's own model and effort in several runs on a real map, not only on a stub
