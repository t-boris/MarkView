## Statement

The system shall write the Markdown report and the PDF of a map through the AI as one narrative document that can be shared without the map: connected prose that accounts for every node, with the map's images and diagrams (and new diagrams where they help) placed where they belong, and a list of the sources.

## Acceptance Criteria

- [x] Export > Markdown report and Export > PDF no longer write a node-by-node outline: both ask the AI for a narrative report of the whole map (introduction with the question and a short answer, thematic sections that follow the branches, conclusions, open questions and assumptions)
- [x] Export asks for the language of the report (the map's own language, English, Russian, German, Spanish, French or a typed one) and remembers the last choice; headings and text are in that language, node titles, source paths, URLs and code stay as they are
- [x] Everything is accounted for: every node of the map is covered by the report, checked in code; a report that leaves a node out is sent back to the AI (two repair rounds at most)
- [x] The report is prose, not a one-to-one list: bullet share and heading count are limited in code, and a report that mirrors the map node by node is rejected and rewritten
- [x] Every citation points to a source of the map; the Sources section is built by the app from the evidence of the nodes, never from text the AI wrote
- [x] Diagram and image nodes of the map are placed in the report where they belong, and the AI can ask for new diagrams in the places that need one (at most 8); each is drawn by the Graph Creator's generator with its checks
- [ ] The Markdown report is written next to the map as <map>-report.md (or with the language code when it is not the map's language) and opened; the PDF is made from the same Markdown, with diagrams drawn, through the usual save dialog
- [ ] The export runs as a job in the jobs bar with steps and Stop; nothing is written when it fails or is stopped; the map is not changed
- [x] A report is a document that can be shared without the map: it explains terms the map only names and does not refer to node ids or the map's own structure
- [x] Checked live on the app's own model and effort, several runs, on a real map: the result is read as a document, every node is in it, the sources are real
