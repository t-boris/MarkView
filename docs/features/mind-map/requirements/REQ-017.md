## Statement

The system shall let the person give any node a picture, shown small beside its icon, by choosing a file, dropping it on the node or the dialog, or pasting it; the file is saved in the project next to the map.

## Acceptance Criteria

- [x] Image… in the node menu and the Picture row in the properties panel open a dialog with a drop area: Choose file…, drag a file in, or paste (⌘V); PNG, JPEG, GIF or WebP up to 6 MB; other files and larger ones are refused with a one-line reason in the dialog
- [x] A file dropped on a node of the canvas goes onto that node; the node is marked while the file is over it; a drop on empty canvas is left alone
- [ ] Swift checks the bytes (not the name), refuses SVG, HTML and oversized files, saves the picture off the main thread into images/ beside the map under a safe unique name (the same bytes under the same name are reused, a different picture gets -2, -3) and sets it on the node through the single writer
- [x] The node stores one line `- image: images/<name>` (a relative path without .. or an https address); a hand-written bad value is dropped when the file is read; a refused address changes nothing
- [ ] The card shows a 30 px thumbnail between the icon and the title; the icon stays; a node without a picture keeps no gap; a picture that cannot be loaded leaves no gap
- [x] The panel shows the picture with a cross that removes it; Remove picture in the dialog does the same; both send one update with an empty image
- [ ] The picture follows the app theme and survives Source, View and translation (the translation keeps the image line)
- [x] The picture of a node is not used by the report or the PDF yet
