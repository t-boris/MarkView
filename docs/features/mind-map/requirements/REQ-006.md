## Statement

The system shall let a person run four labelled AI actions on the selected node: Expand description, Expand topic, Correct and Research, each changing only what its name says.

## Acceptance Criteria

- [x] Expand description rewrites and extends only the description (and evidence) of the node; no node is added or removed.
- [x] Expand topic adds child nodes under the node; the direction text is optional.
- [x] Correct asks for the person's note and rewrites only that node's title, description and evidence; its children, colour, tags and position stay.
- [x] Research searches the web (unless disabled) and the project for that node only and adds evidence with sources and the web queries; no child is added.
- [ ] Every action shows progress in the existing status pill, can be stopped, keeps what arrived when stopped or failed, and refuses to start while another run works on the same map.
- [x] The four actions are visible as labelled buttons in the properties panel and in the node menu.
