## Statement

The system shall let the person give a node an icon (one of the built-in icons, or any single emoji) and a number badge (1 to 999) that are drawn in the node card before the title, and shall let the person number all children of a node 1, 2, 3 in map order with one action.

## Acceptance Criteria

- [x] A node card shows its number as a round badge in its branch colour and its icon before the title; a node with neither looks as before
- [x] The properties panel has an Icon button (opens a picker with the 41 built-in icons, a field for one emoji, Remove) and a Number field; an empty Number field removes the number
- [x] A number outside 1 to 999 and text that is not one emoji or a built-in icon id are refused, in the page and again in Swift
- [x] The node menu has Icon... and Number children 1, 2, 3... (Remove numbers from children when the children are already numbered 1..n); the action is off for a node without children
- [x] The icon and the number are stored as the node properties `icon` and `number` in the map file; maps without them read and write as before; bad values in a hand-edited file are dropped on read
- [x] The AI may number sibling nodes (a NODE line may carry number) only when their order matters
- [x] The Markdown report writes the number as a fact line and the icon before the heading: a built-in icon as its name in brackets, an emoji as it is
- [x] The built-in icon ids of the page and of Swift are the same list (checked by a test)
