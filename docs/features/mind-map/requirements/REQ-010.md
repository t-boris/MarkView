## Statement

The system shall offer three views of a research-map file — Map, View (the file as ordinary Markdown, editable like any other document) and Source (the raw Markdown) — switched by one Map | View | Source control that is visible in all three views.

## Acceptance Criteria

- [ ] The control shows Map, View and Source with the current one marked; it is in the map toolbar while the map is shown and in the top bar while View or Source is shown; the old lone Source button and the Source/Map label do not exist for a map file
- [ ] View shows the map file as rendered Markdown (title, question, outline, node descriptions) and is edited like any ordinary document; ordinary documents keep their Preview/Source toggle unchanged
- [ ] The top-bar shortcut cycles Map, View, Source, Map for a map file and behaves as before for any other file
- [ ] Opening View and returning to Map without an edit leaves the file byte for byte unchanged (checked by a test on a fixture map with every node property)
- [ ] An edit in View that keeps the file readable as a map shows up in Map on return; an edit that makes the file unreadable as a map shows the existing problem notice, keeps the person in Source and loses no text
- [ ] The zoom, position, selection and folds of the map survive a trip through View or Source and back
