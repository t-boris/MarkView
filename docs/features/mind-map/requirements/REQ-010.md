## Statement

The system shall offer three views of a research-map file — Map, View (the file as ordinary rendered Markdown, read only) and Source (the raw Markdown) — switched by one Map | View | Source control that is visible in all three views.

## Acceptance Criteria

- [x] The control shows Map, View and Source with the current one marked; it is in the map toolbar while the map is shown and in the top bar while View or Source is shown; the old lone Source button and the Source/Map label do not exist for a map file
- [x] View shows the map file as rendered Markdown (front matter, title, question, outline, node descriptions) and is read only, with no formatting buttons: edits are made in Map or Source (Boris chose this on 2026-11-05 after the measurement: on a real 1327-line map one edit in the ordinary editable preview replaced the front matter by an HTML table, so the file stopped being a map, and escaped the evidence labels); ordinary documents keep their Preview/Source toggle and their editable preview unchanged
- [x] The top-bar shortcut cycles Map, View, Source, Map for a map file and behaves as before for any other file
- [x] Opening View and returning to Map leaves the file text byte for byte unchanged (checked by a test)
- [x] A Source text that is no longer readable as a map shows the existing problem notice and keeps the person in Source; no text is lost
- [x] The zoom, position, selection and folds of the map survive a trip through View or Source and back
