## Statement

Let the user review and edit the map using the prototype's core node, connection, and property interactions, including independent changes to layout and hierarchy. Provide multiple predefined layouts that users can apply independently to individual branches. Applying a layout to a branch applies it recursively to the entire subtree, replacing previously selected nested layouts. Preserve the map's hierarchy, properties, logical connections, evidence, and layout settings in its human-readable Markdown file.

## Acceptance Criteria

- [ ] The user can select a node, add a child manually, edit and delete nodes, and edit the node properties represented by the prototype.
- [ ] The user can move a node visually without changing its parent and can separately move it to another branch.
- [ ] The user can create logical connections between nodes as shown in the prototype.
- [ ] The user can choose from multiple predefined layouts and apply one to an individual branch.
- [ ] Applying a layout to a branch applies it recursively to the entire subtree, replacing any previously selected layouts within that subtree.
- [ ] Edits to the map preserve its hierarchy, properties, logical connections, evidence, and layout settings when it is saved as a human-readable Markdown file and reopened.
