## Statement

The system shall offer "Focus" in the node menu, which folds the map so that only the path from the root to the node and the node's children show, with the children's own children folded.

## Acceptance Criteria

- [x] The node menu has Focus; choosing it unfolds the root, every ancestor of the node and the node itself, and folds every other node that has children
- [x] After Focus the children of the node are shown one level deep, each folded when it has children (with its +N count)
- [x] Siblings of the nodes on the path stay on the map, folded; Focus hides nothing except by folding
- [x] The focused node is selected and brought into view; the selection never ends on a hidden node
- [x] Focus works on the root, on a leaf and on the deepest node; on the root it equals Collapse all
- [x] Expand all and the fold toggles undo or change the result as usual; Focus does not change the map file and is stored with the other fold state
