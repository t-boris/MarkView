## Statement

Present new research as an interactive, persistent mind map in its own tab, opening the tab when initial research starts and progressively displaying ready nodes and branches as research proceeds; store each map as a human-readable Markdown file that users can open and edit as a document, and retain access to existing Markdown research reports.

## Acceptance Criteria

- [x] New research started from the existing research entry points opens as an interactive map in a separate tab when initial research starts, rather than producing a Markdown research report.
- [x] Ready nodes and branches appear progressively in the map as initial research proceeds.
- [x] Each new research map is saved as a human-readable Markdown file that users can open and edit as a document.
- [x] A saved research map can be reopened from its Markdown file with its hierarchy, properties, logical connections, evidence, and layout settings intact.
- [x] Existing Markdown research reports remain accessible in their current form.
