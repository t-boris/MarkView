## Statement

The system shall let the person translate a research map into another language, as a new map next to the original or in place of it, so that the same map can be kept in Russian for oneself and in English to show to others.

## Acceptance Criteria

- [x] The map has a Translate action; it asks for the language (English, Russian, German, Spanish, French or a typed one) and for the result: a new map next to this one (the default) or replacing this map
- [x] The AI translates the question, the title and, for every node, the title, tags, description and evidence text; the structure is not touched: node ids, order, parents, links, numbers, colours, icons, shapes, sizes, positions, evidence labels and evidence sources are the same afterwards, checked in code
- [x] Every node is accounted for: the result reports how many nodes were translated and how many kept their text because the answer failed the checks after two repair rounds
- [x] A Mermaid diagram of a node is translated only when its structure stays the same (same diagram type, same lines, only label text differs); otherwise the original diagram is kept; image addresses and links are kept
- [ ] A new map gets a free file name with the language code (map-en.md), a new map id, opens in a tab, and the original is untouched
- [ ] Replacing first writes a copy of the current file next to it, then rewrites the map; the copy name is told in the result
- [ ] The translation runs as a job in the jobs bar, with steps, elapsed time and Stop; Stop leaves the map as it was; only one AI job works on a map at a time
- [ ] The language is not guessed from the app: the person always chooses it; the last choice is the default next time
