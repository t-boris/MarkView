## Statement

Let the user direct AI to develop a selected node into additional traceable branches.

## Acceptance Criteria

- [x] The user can select a node and request AI development in a specified direction.
- [x] When the user requests options, the generated options appear as separate branches under the selected node.
- [x] AI-generated additions retain their applicable sources, finding categories, and web-query history.
- [x] AI-generated additions are saved in the map’s human-readable, editable Markdown file and remain intact when the map is reopened, including their hierarchy, properties, logical connections, evidence, and layout settings.
