## Question

Should a branch line take the colour the person chooses for the node it leads to?

## Why it matters

In prototype v10 the node colour changes only the node's border; the line from its parent keeps the colour of the branch palette. SRC-002's SPEC lists "the line colour does not follow the chosen colour" as a part of the request the prototype does not cover (v9: "colours for branches").

## Options

- **A**: Yes: the line into a node uses the node's own colour when it has one, otherwise the branch palette colour.
- **B**: No: keep the prototype exactly; the node colour changes only its border.

## Recommended

A
