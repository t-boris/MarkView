## Question

Can a person remove a single logical connection in the map view?

## Why it matters

Prototype v10 creates connections but has no way to delete one; deleting a node removes its connections. SRC-002's SPEC says the product rules for deleting, labelling and storing connections are not defined. Without it a wrong connection can only be removed by editing the Markdown source.

## Options

- **A**: Yes: the properties panel lists the connections of the selected node, each with a small remove control.
- **B**: No: remove a connection only by editing the Markdown source or deleting a node.

## Recommended

A
