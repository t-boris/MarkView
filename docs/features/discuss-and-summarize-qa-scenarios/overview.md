# Discuss and summarize QA scenarios

## Idea

Before generating a new QA scenario, AI asks focused questions about the objective, actors, starting state, expected outcomes and missed failure cases. The person's answers guide generation. When a scenario is opened, show an AI-written summary of what it checks and why rather than the verbatim original request. Keep the original request in stored scenario data, and generate a cached summary for existing scenarios.
