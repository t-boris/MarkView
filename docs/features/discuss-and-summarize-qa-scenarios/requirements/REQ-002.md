## Statement

The system shall show an AI-written summary of the scenario's purpose and coverage below its title, while retaining the original request in stored data.

## Acceptance Criteria

- [ ] Newly generated scenarios include a concise summary grounded in their steps and checks.
- [ ] Existing scenarios receive a cached AI summary when opened; a stale or failed request never overwrites another scenario or a newer edit.
- [ ] The header does not fall back to displaying the original request while a summary is missing or being generated.
- [ ] Old scenario files remain readable and an existing summary can be refreshed after scenario edits.
