## Context

MCP service coverage

## Alternatives

1. Manage only MarkView MCP services.
2. Manage all MCP services available to Copilot.

## Decision

Manage all MCP services available to Copilot, including services configured outside MarkView.

## Reason

The owner selected the broader service coverage.

## Consequences

The service selection must include third-party services as well as MarkView services.
