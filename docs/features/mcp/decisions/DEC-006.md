## Context

markview-control is documented as a MarkView MCP server and can be registered separately with an external agent. It is not one of the two services automatically supplied by MarkView's terminal integration. Its inclusion in managed services was unclear.

## Alternatives

1. Manage markview-control only for Copilot as part of its full set of available MCP services.
2. Exclude markview-control from management for all agents, including Copilot.

## Decision

Manage markview-control individually for every supported agent where the service is configured.

## Reason

This follows the accepted decision to manage every available MCP service for each supported agent, including services configured outside MarkView.

## Consequences

REQ-001 explicitly includes markview-control for every supported agent where it is configured. REQ-002 covers prevention of direct connections to markview-control when it is disabled for that agent. Existing choices for newly discovered services continue to follow Q-006.
