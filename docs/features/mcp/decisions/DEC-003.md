## Context

The accepted agent coverage includes every supported agent, but the existing requirements limit third-party service coverage and the direct-connection guarantee to Copilot.

## Alternatives

1. Manage all MCP services for Copilot and only MarkView services for other supported agents.
2. Provide individual MCP service management only for Copilot.

## Decision

For every supported agent, manage all available MCP services individually, including third-party services, and prevent direct connections to services disabled for that agent.

## Reason

This resolves the coverage inconsistency and applies the chosen per-agent control consistently across supported agents.

## Consequences

REQ-001 and REQ-002 must cover all MCP services for every supported agent, including third-party services. Choices must apply to each agent’s own configuration on the current Mac, including launches outside MarkView. Implementation and verification must account for each agent’s configuration.
