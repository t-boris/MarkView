## Context

The Connect Agents to MarkView command registers MarkView services in agents’ own configurations. Registration could conflict with a service previously disabled for an agent.

## Alternatives

1. Register both MarkView services and explicitly enable them for the agent, updating the displayed selections.
2. Ask the user whether to preserve the disabled state or enable and register the affected services.

## Decision

For each agent, register only enabled MarkView services. Skip disabled services and inform the user which services were skipped.

## Reason

Preserving the user’s existing selection prevents registration from making a disabled service available again.

## Consequences

Registration preserves each agent’s saved selections. Skipped services are reported and must not become available through registration on a subsequent agent launch.
