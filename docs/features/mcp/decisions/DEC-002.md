## Context

Service choices are made independently for each supported agent on the current Mac.

## Alternatives

1. Apply third-party service choices only to agents launched from MarkView.

## Decision

Apply third-party MCP service choices to the agent's own configuration, including when the agent is launched outside MarkView.

## Reason

The user chose a consistent service setting across launch contexts.

## Consequences

Disabling a third-party service also affects the agent's own configuration and launches outside MarkView on the current Mac.
