## Context

The existing agent-wide MarkView tools switch may already be disabled, including following a Copilot policy block. The individual service settings need an initial state that accounts for this existing choice.

## Alternatives

1. Initialize each service from its current configuration without considering the existing agent-wide switch.
2. Keep MarkView services disabled for agents whose agent-wide switch is off until the user explicitly chooses their states.

## Decision

For each agent whose existing agent-wide switch is off, initially disable markview and markview-browser. For agents whose switch is on, preserve the existing state of each service.

## Reason

Preserving an existing disabled choice avoids automatically re-enabling the affected MarkView services during migration and respects the user's prior setting.

## Consequences

Migration must initially disable both MarkView services for each affected agent, including copies registered in the agent's own configuration. Third-party services retain their existing states. For agents whose existing switch is on, preserve the existing service states. Apply the migrated disabled states across launch contexts, and prevent direct connections to the disabled services.
