## Finding

The current registration command can write MarkView services into an agent's own configuration after the user has disabled them. The specification does not establish whether that command must honor existing selections or explicitly change them, so a disabled service could become available again on a subsequent launch.

> Команда Connect Agents to MarkView отдельно регистрирует markview и markview-browser в собственных настройках установленных агентов

## Possible interpretations

- Registration skips services disabled for that agent.
- Registration re-enables those services and updates the displayed selections.

## Resolution

Команда регистрирует только включённые сервисы MarkView; отключённые пропускает и сообщает об этом. — see DEC-005.
