## Finding

The specification does not establish whether the separately registered markview-control server is a managed MarkView service. It is documented as a MarkView MCP server but is not among the two services supplied by MarkView's terminal integration. This changes what users can disable and what the no-connection guarantee covers.

> Managed services include MarkView services for supported agents and all MCP services available to Copilot

## Possible interpretations

- Include markview-control whenever it is configured for a supported agent.
- Limit MarkView service management to markview and markview-browser, except where Copilot's broader coverage includes markview-control.

## Resolution

Управлять markview-control как сервисом MarkView у каждого поддерживаемого агента, если сервис настроен. — see DEC-006.
