## Finding

The existing agent-wide switch can already be off, including after a policy block. The specification does not say how that existing state maps to the new individual selections. A migration that enables previously blocked services could cause a new connection attempt; preserving the existing disabled state would change the default availability of individual services.

> The user can independently enable or disable each managed MCP service for each supported agent, with selections stored separately for each agent on the current Mac.

## Possible interpretations

- Preserve an existing disabled agent-wide setting by initially disabling its MarkView services.
- Initialize individual services from their existing configurations, regardless of the agent-wide switch.

## Resolution

Если общий переключатель агента выключен, первоначально выключить для него markview и markview-browser. Для включённого переключателя сохранить существующее состояние сервисов. — see DEC-004.
