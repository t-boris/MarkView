## Question

Где должен действовать выбранный набор сервисов?

## Why it matters

Политика может различаться между компьютерами или проектами; запрос не определяет область настройки.

## Options

- **A**: Один выбор на этом Mac для каждого агента.
- **B**: Отдельный выбор для каждого проекта и агента.

## Recommended

A — Текущая настройка уже привязана к агенту на Mac, а описанное ограничение относится к рабочему окружению.

## Answer

A. Один выбор на этом Mac для каждого агента.
