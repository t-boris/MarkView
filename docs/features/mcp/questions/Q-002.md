## Question

Для каких агентов нужен отдельный выбор сервисов?

## Why it matters

Сейчас проблема описана для Copilot, но интеграция MarkView общая для нескольких агентов.

## Options

- **A**: Только Copilot.
- **B**: Все поддерживаемые агенты, с отдельным выбором для каждого.

## Recommended

B — Существующее управление уже разделено по агентам, и такая настройка не навязывает ограничения Copilot другим агентам.

## Answer

B. Все поддерживаемые агенты, с отдельным выбором для каждого.
