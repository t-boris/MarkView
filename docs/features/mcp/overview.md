# Управление MCP-сервисами агентов

## Idea

Дать пользователю возможность отдельно включать и выключать MCP-сервисы, чтобы Copilot не обращался напрямую к выбранным отключённым сервисам.

## Problem

На рабочем компьютере политика организации запрещает Copilot использовать некоторые MCP-сервисы. Существующий переключатель инструментов MarkView действует на них вместе, поэтому не позволяет сохранить разрешённые сервисы и исключить только запрещённые.

## Scope

Входит: индивидуальное включение и выключение всех доступных MCP-сервисов для каждого поддерживаемого агента, включая сторонние сервисы, настроенные вне MarkView, и предотвращение прямого подключения к отключённым для этого агента сервисам. Выбор применяется к собственной конфигурации каждого агента, в том числе при запуске вне MarkView на текущем Mac. Вне предполагаемого объёма: изменение или обход политики организации; управление отдельными инструментами внутри сервиса.

## Existing behaviour

- При запуске агента из панели MarkView передаёт ему два собственных MCP-сервиса: markview для проекта и, когда включено открытие терминальных ссылок в MarkView, markview-browser. (`MarkView/Models/AgentTools/AgentToolServer.swift`)
- Существующий переключатель действует на инструменты MarkView целиком для выбранного агента на данном Mac. При обнаружении отказа политики именно для markview-browser MarkView выключает эти инструменты для Copilot и предлагает перезапустить сессию. (`MarkView/Models/Workspace/AITerminalsController.swift`)
- Меню Browser Tools for Agents содержит переключатели по агентам и сообщает, что после изменения агента нужно перезапустить. (`MarkView/Views/Workspace/ContentView.swift`)
- Для терминальной сессии Copilot сервисы MarkView передаются как дополнительная MCP-конфигурация. У Copilot также может быть собственная конфигурация сервисов. (`MarkView/Models/AI/Providers/CopilotProvider.swift`)
- Команда Connect Agents to MarkView отдельно регистрирует markview и markview-browser в собственных настройках установленных агентов; для инструментов проекта она также устанавливает Skill с доступом через команду MarkView. (`MarkView/Models/Browser/AgentBrowserRegistration.swift`)
- Проект уже фиксирует отказ политики Copilot для markview-browser и требование не обходить политику организации. (`docs/bugs/BUG-025-copilot-mcp-server-blocked-by-policy.md`)
- Третий сервис, markview-control, документирован для самостоятельной регистрации внешним агентом; он не входит в перечисленные выше два сервиса, автоматически передаваемых терминалу. (`README.md`)
