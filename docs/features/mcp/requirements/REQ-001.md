## Statement

Allow the user to independently enable or disable every available MCP service for each supported agent on the current Mac, including MarkView services and services configured outside MarkView. This includes separately registered markview-control for every supported agent where it is configured. Apply selections to each agent’s own configuration, including launches outside MarkView, and prevent direct connections to disabled services. Leave newly discovered services in their agent-configured state until changed by the user, except where migration of an existing agent-wide switch requires otherwise. For each agent whose existing agent-wide switch is off, initially disable markview and markview-browser, including copies registered in the agent’s own configuration, while retaining third-party services’ existing states. For each agent whose existing agent-wide switch is on, preserve the existing state of each service. For each agent, register only enabled MarkView services; skip disabled services and inform the user which services were skipped. Registration must preserve each agent’s saved selections, and skipped services must not become available through registration on a subsequent agent launch.

## Acceptance Criteria

- [x] The user can independently enable or disable each available MCP service for every supported agent, including MarkView services and services configured outside MarkView.
- [x] For every supported agent where markview-control is configured, the user can enable or disable markview-control independently.
- [x] Selections are stored separately for each supported agent on the current Mac.
- [x] A newly discovered service retains its agent-configured state until the user changes its selection, except where the migration of an existing agent-wide switch requires it to be disabled.
- [x] For each agent whose existing agent-wide switch is off, migration initially disables markview and markview-browser, including copies registered in the agent’s own configuration, and leaves third-party services in their existing states.
- [x] For each agent whose existing agent-wide switch is on, migration preserves the existing state of each service.
- [x] A disabled service cannot be connected to directly by the agent, including when the agent is launched outside MarkView on the current Mac.
- [x] Enabling a previously disabled service restores its availability without changing unrelated service settings.
- [x] For each agent, registration registers only enabled MarkView services and skips disabled MarkView services.
- [x] Registration informs the user which services were skipped.
- [x] Registration preserves each agent’s saved selections, and skipped services do not become available through registration on a subsequent agent launch.
