## Statement

Prevent every supported agent from connecting directly to MCP services disabled for that agent on the current Mac, including all services available to the agent, whether supplied by MarkView or configured outside MarkView, for subsequent launches both inside and outside MarkView. This includes markview-control for every supported agent where it is configured. Migrate existing agent-wide settings so that, for each agent whose switch is off, markview and markview-browser are initially disabled across launch contexts, including copies registered in the agent's own configuration. For agents whose switch is on, preserve the existing state of each service. Preserve the existing states of third-party services. For each agent, register only enabled MarkView services, skip disabled services, and inform the user which services were skipped. Registration must preserve each agent's saved selections, and skipped services must not become available through registration on a subsequent agent launch.

## Acceptance Criteria

- [x] For each supported agent, a service disabled for that agent on the current Mac is not supplied to a new session launched from MarkView.
- [x] For each supported agent, disabling a previously registered MarkView service applies to that agent's own configuration on the current Mac.
- [x] For each supported agent where markview-control is configured, disabling markview-control applies to that agent's own configuration on the current Mac.
- [x] For each supported agent, disabling any third-party MCP service available to that agent, including a service configured outside MarkView, applies to that agent's own configuration on the current Mac.
- [x] For each supported agent, a service disabled for that agent on the current Mac is not connected to directly by subsequent sessions launched outside MarkView on that Mac.
- [x] For each supported agent where markview-control is configured, disabling it prevents direct connections to it by subsequent sessions launched inside or outside MarkView on the current Mac.
- [x] For each agent whose existing agent-wide switch is off, migration initially disables both markview and markview-browser, including copies registered in the agent's own configuration.
- [x] For each agent whose existing agent-wide switch is off, the migrated disabled states apply to subsequent launches inside and outside MarkView on the current Mac and prevent direct connections to both services.
- [x] For each agent whose existing agent-wide switch is on, migration preserves the existing state of each service.
- [x] Migration preserves the existing state of each third-party service for every agent.
- [x] For each agent, registration registers only enabled MarkView services and skips disabled MarkView services.
- [x] Registration preserves each agent's saved service selections.
- [x] Registration informs the user which MarkView services were skipped.
- [x] A MarkView service skipped during registration does not become available through registration on a subsequent agent launch.
- [x] The user is informed when an already running agent session must be restarted for a change to take effect.
- [x] The feature does not alter or circumvent organizational policy.
