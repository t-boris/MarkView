## Question

Какой уровень параллельной работы должен поддерживать первый выпуск?

## Why it matters

В исследовании описаны делегирование внутри шага, одновременные проверки и параллельные правки. Они дают пользователю разные возможности.

## Options

- **A**: Оставить шаги Cockpit последовательными и разрешить делегирование независимой работы внутри шага, если режим агента это поддерживает.
- **B**: Также разрешить параллельные шаги Cockpit для проверок и ревью, сохранив одного исполнителя для изменения кода.
- **C**: Также поддержать параллельную реализацию независимых частей разными исполнителями.

## Recommended

A — Делегирование внутри шага позволяет проверить пользу параллельности без изменения принятой модели исполнения Cockpit.

## Answer

A. Оставить шаги Cockpit последовательными и разрешить делегирование независимой работы внутри шага, если режим агента это поддерживает.
