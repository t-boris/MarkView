## Question

На каком результате должен заканчиваться управляемый запуск в первой версии?

## Why it matters

Правила проекта определяют условия доставки, но не определяют, какую её часть должен вести новый сценарий.

## Options

- **A**: Закончить управляемый запуск проверенными изменениями и результатом ревью, затем передать доставку существующему процессу проекта.
- **B**: Доводить запуск до PR и обязательного CI там, где проект их требует, затем передавать дальнейшую доставку.
- **C**: Включить все применимые шаги доставки, вплоть до слияния и выпуска, с подтверждениями по правилам проекта и Definition of Done.

## Recommended

A — Проверенные изменения и ревью позволяют оценить новый сценарий, а существующие правила проекта определяют дальнейшую доставку.

## Answer

C. Включить все применимые шаги доставки, вплоть до слияния и выпуска, с подтверждениями по правилам проекта и Definition of Done.
