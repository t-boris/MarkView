## Question

Как пользователь должен выбирать между прямой передачей задачи и запуском через Cockpit из Build?

## Why it matters

Исследование описывает оба пути и оставляет открытым, кто выбирает режим запуска.

## Options

- **A**: Оставить прямую передачу задачи и добавить явный выбор запуска через Cockpit.
- **B**: MarkView рекомендует режим по спецификации и Definition of Done, пользователь может его изменить.
- **C**: Из Build всегда открывать план Cockpit.

## Recommended

A — Явный выбор даёт доступ к поэтапному запуску и сохраняет привычный путь для коротких задач.

## Answer

B. MarkView рекомендует режим по спецификации и Definition of Done, пользователь может его изменить.
