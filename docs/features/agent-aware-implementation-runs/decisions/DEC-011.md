## Context

Implement with AI currently submits a goal directly to an assistant terminal. Cockpit supports an approved multi-step plan.

## Alternatives

1. Offer both launch modes without a recommendation.
2. Always prepare a Cockpit plan from Build.

## Decision

Recommend direct handoff or Cockpit from the feature specification and selected Definition of Done, and let the user override the recommendation.

## Reason

The specification and checklist can reveal orchestration needs while the user retains control over how work starts.

## Consequences

Build shows the reason for the recommendation and lets the user override it before launch. Cockpit execution requires separate plan approval.
