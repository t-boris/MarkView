## Context

F-002 identified an ambiguity in REQ-004. Cockpit DEC-026 gates MarkView MCP calls, while direct shell actions use the permissions of the selected launch profile. An agent with sufficient permissions can merge a PR or publish a release while the corresponding Cockpit step is paused.

## Alternatives

1. Allow a managed run with Ask me only when the launch profiles prevent agents and their delegates from performing the protected action before approval.
2. When the launch profile enforces approval, let Cockpit perform the action after approval. Otherwise, pause before starting that profile and arrange for the user to perform delivery manually at the appropriate point, then verify the result.

## Decision

Ask me pauses the scheduled Cockpit delivery action until the user explicitly approves it. Agents and their delegates retain the permissions of their launch profiles, including any ability to perform the same action directly through the terminal.

## Reason

This gives the user control over when Cockpit performs a delivery action and allows managed runs to use existing launch profiles with their configured permissions.

## Consequences

Update REQ-004 to require a pre-launch warning that agents may perform Ask me actions directly if their profiles permit it. If Cockpit verifies that an action was already completed outside Cockpit without its approval, record it as externally completed without Cockpit approval and skip the duplicate action. Retain the evidence for the existing lifecycle checks.
