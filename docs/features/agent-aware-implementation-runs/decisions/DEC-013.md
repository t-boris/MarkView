## Context

Cockpit executes one step at a time. Its current MarkView tool policy refuses calls that start or drive other agents.

## Alternatives

1. Run independent verification and review as concurrent Cockpit steps, with one implementation agent.
2. Run independent implementation steps concurrently in separate working copies.

## Decision

Keep Cockpit steps sequential and allow delegation of independent work within a step when the selected agent's launch profile supports it.

## Reason

Supported agents can delegate independent work within Cockpit's existing execution model.

## Consequences

Cockpit keeps its sequential scheduler. Within-step delegation depends on the selected profile and approved controls.
