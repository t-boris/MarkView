## Context

The project workflow governs lifecycle transitions. The Definition of Done governs requested actions and their approval modes.

## Alternatives

1. End the managed run after verification and review.
2. End the managed run after the pull request and required CI.

## Decision

Include all applicable delivery steps in the managed run, through merge and release where applicable, subject to project rules and the selected Definition of Done.

## Reason

The managed run owns the approved path through the project's delivery endpoint.

## Consequences

The managed run handles delivery approvals, tracks partial delivery, and retains evidence for the project's existing lifecycle checks.
