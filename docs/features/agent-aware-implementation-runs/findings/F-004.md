## Finding

R-001 records that Cockpit reuses the existing session for the same project even during active execution. The Build flow does not establish whether a second feature can prepare a plan independently or must wait for the existing session. Reusing that session without a defined policy could replace another feature's draft or associate the launch with the wrong run.

> Choosing Cockpit prepares a plan from the specification, recorded answers, accepted decisions, and the same checklist.

## Possible interpretations

- Показать занятый Cockpit и сохранить текущий черновик или запуск. Новый план можно подготовить после освобождения сессии.
- Разрешить подготовить отдельный черновик для новой фичи, пока текущий запуск продолжается.

## Resolution

План новой фичи можно подготовить и проверить сразу. Черновик привязан к своей фиче, а выполнение ждёт завершения текущего запуска. — see DEC-031.
