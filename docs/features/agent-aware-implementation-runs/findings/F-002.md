## Finding

Cockpit DEC-026 gates MarkView MCP calls and explicitly leaves direct shell actions outside that gate. If an implementation agent has credentials for merge or release, pausing the scheduled delivery step does not prevent it from performing the same action directly. REQ-004 leaves it unclear whether Ask me is an enforced authorization boundary or a pause in the managed workflow. These guarantees require different execution profiles.

> The run pauses each Ask me action until the user explicitly approves it.

## Possible interpretations

- До подтверждения агент не получает возможности выполнить защищённое действие доставки.
- Подтверждение управляет шагами Cockpit, а доступные агенту внешние действия остаются в пределах прав выбранного профиля.

## Resolution

Приостанавливать шаг Cockpit до подтверждения. Агент сохраняет права своего профиля и может выполнить то же действие напрямую через терминал. — see DEC-028.
