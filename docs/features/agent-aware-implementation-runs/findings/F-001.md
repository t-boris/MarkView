## Finding

Cockpit DEC-016 explicitly allows starting at any selected step without verifying its prerequisites. REQ-002 requires dependency order, and REQ-004 makes verification and delivery approvals mandatory where applicable. The specification does not say whether a managed run can start at merge or release while prerequisite evidence is missing. Preventing a success verdict afterward would leave the external action already performed.

> Cockpit executes one approved step at a time in dependency order.

## Possible interpretations

- В управляемом запуске начинать с выбранного шага можно только после подтверждения его обязательных предпосылок.
- Сохранить свободный выбор стартового шага, но проверять предпосылки перед каждым действием доставки.

## Resolution

Cockpit сам выбирает первый шаг утверждённого плана, выполнение которого ещё не подтверждено. Актуальные доказательства позволяют продолжить после перерыва без повторения уже выполненной работы. — see DEC-027.
