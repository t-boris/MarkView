## Statement

Show a persistent, automatically assigned project color through a project-associated window icon, recognizable both in the window and when choosing among open windows. Let the user change the project's color by clicking the icon and choosing a color. Show the cue only in windows with an open project folder.

## Acceptance Criteria

- [x] A window with an open project folder displays a persistent, automatically assigned project color through its project-associated icon.
- [ ] The project-colored icon is recognizable both in the project window and when choosing among open windows.
- [x] Clicking the project-colored icon in the window opens a color picker for that project.
- [x] After the user chooses a color, the icon reflects the chosen color, which persists for that project.
- [x] Windows without an open project folder do not display a project color cue.
- [x] A window created by opening a single file (its root is the file's parent directory) displays no project color cue (DEC-012).
- [ ] The project color is recognizable in Mission Control window thumbnails on macOS 13 and later through a thin band in the project color below the toolbar (DEC-006, DEC-013).
- [x] Two open windows showing the same folder display the same color, and a change in one updates the other immediately (DEC-010).
- [x] When a window opens another folder, it displays that project's color; a restored window displays its folder's saved color (DEC-010).
