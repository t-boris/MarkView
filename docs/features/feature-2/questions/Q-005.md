## Question

Где пользователь должен менять автоматически назначенный цвет проекта?

## Why it matters

Возможность изменить цвет уже согласована; осталось определить, как пользователь к ней попадёт.

## Options

- **A. Через иконку**: Нажатие на цветную иконку открывает выбор цвета проекта.
- **B. Через меню проекта**: Цвет проекта меняется через команду в меню проекта.
- **C. Через настройки**: Цвет проекта меняется в настройках проекта.

## Answer

A. Через иконку. Нажатие на цветную иконку открывает выбор цвета проекта.
