# Discussion — Цветовая идентификация проектов

### Answer to Q-003 · 2026-09-28

Нужен ли цвет окнам с отдельным файлом или без открытой папки проекта?

Только папки проектов. Цвет получают окна с открытой папкой проекта.

### Answer to Q-002 · 2026-09-28

Как назначать цвет проекту?

Автоматически с заменой. MarkView предлагает постоянный цвет, который пользователь может изменить.

### Answer to Q-001 · 2026-09-28

Где цвет должен быть заметен в первую очередь?

Иконка окна. Менять цвет изображения, связанного с окном или проектом.

### Answer to Q-004 · 2026-09-28

Где именно цветная иконка должна помогать узнавать проект: в заголовке окна, при переключении между окнами или в обоих местах?

C. В обоих местах. Показывать цветную иконку в окне и при переключении между окнами.

### Answer to Q-005 · 2026-09-28

Где пользователь должен менять автоматически назначенный цвет проекта?

A. Через иконку. Нажатие на цветную иконку открывает выбор цвета проекта.

### Implementation question · 2026-09-28

Которые окна считаются окнами с папкой проекта, если при открытии одного .md его родительская папка становится корнем окна?

Opened as folder. Цвет получает только окно, чья папка открыта как папка (Open Folder, New Project, восстановление сессии). Окно, созданное открытием одного файла, цвета не показывает, пока после перезапуска не восстановится как окно с папкой. — see DEC-012.

### Implementation question · 2026-09-28

Где показывать цвет, если значок у заголовка слишком мал на миниатюрах Mission Control (запасной вариант DEC-006)?

Thin color band. Полоса 3 pt цвета проекта вдоль верхнего края содержимого окна, под панелью инструментов, вместе с нажимаемым значком у заголовка. — see DEC-013.
