## Context

The accepted decision requires recognition while switching windows, but does not identify a switching surface.

## Alternatives

1. The app's Window menu
2. Mission Control window overview
3. The Dock

## Decision

Target the Mission Control window overview and verify that each project window's color cue is visible in its thumbnail.

## Reason

Mission Control presents multiple application windows together and directly supports the stated window-finding workflow.

## Consequences

Acceptance criteria must cover the icon's visibility in Mission Control thumbnails on macOS 13 and later. If the title bar icon is not visible there, the design must place the same cue in a visible part of the window.
