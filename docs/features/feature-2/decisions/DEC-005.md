## Context

Q-005: where users change an automatically assigned project color.

## Alternatives

1. B. Change the color through a project menu command.
2. C. Change the color in project settings.

## Decision

Clicking the project-colored window icon opens a color picker for that project.

## Reason

The user chose to change the color where it is displayed.

## Consequences

The project-colored icon must be clickable and provide a clear way to choose a replacement color. The selected color persists for that project.
