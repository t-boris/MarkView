## Context

The automatic color hashed the full folder path and was saved on first show (DEC-008, DEC-009).
Clones and worktrees of one project got different colors, and saved colors did not tell automatic
assignments from colors chosen by hand.

## Alternatives

1. Hash the folder name
2. Hash the Git repository name from `origin`, falling back to the folder name
3. Keep hashing the path

## Decision

Select the automatic color by a stable hash (FNV-1a 64) of the folder name, ignoring case, over the
same eight-color palette. Compute it on display and never save it; save only a color chosen by hand,
keyed by the folder path (DEC-008). Choosing the automatic color clears the saved choice. On first
launch of this version, all previously saved colors are dropped once, so every project follows its
name.

## Reason

Boris asked for colors by project name, using the folder name, and for all projects to be
recalculated.

## Consequences

Same-named folders share an automatic color; a renamed folder changes color unless one was chosen.
Colors chosen before this version are reset once. Supersedes the path hash and the saved automatic
color in DEC-008 and DEC-009.
