## Context

Window sessions have separate identities even when they display the same folder.

## Alternatives

1. Update every open window for the project immediately
2. Update only the window where the color changed

## Decision

Synchronize color changes immediately across all open windows with the same project key. Recompute the displayed color when a window changes folders or is restored.

## Reason

A project-level setting should produce the same cue in every window showing that project.

## Consequences

The color store must notify active windows of changes. Acceptance criteria must cover simultaneous windows, folder changes, and session restoration.
