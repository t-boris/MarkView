## Context

The window already uses the project folder as its title bar proxy icon.

## Alternatives

1. Recolor or replace the folder proxy icon
2. Add a separate clickable project icon

## Decision

Add a separate clickable project-colored icon beside the title. Preserve the folder proxy icon and its existing interaction.

## Reason

This gives the color control an unambiguous action while preserving the existing folder affordance.

## Consequences

The title bar must accommodate both icons without obscuring the project name. The new icon owns the color-picker interaction.
