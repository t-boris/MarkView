## Context

DEC-001 gives a color only to windows with an open project folder. In the code, opening a single
`.md` file in an empty window makes the file's parent directory the window's root
(`WorkspaceManager.initSingleFileWorkspace`): the title and the folder proxy icon show that
directory, and after a relaunch the window is restored as an ordinary folder window.

## Alternatives

1. Only a window whose folder was opened as a folder (Open Folder, New Project, session restore) is a project folder window.
2. Any window with a root folder, including the parent directory of a standalone file.
3. Also remember in the window session that the window came from a single file, so it stays uncolored after a relaunch.

## Decision

Only a window whose folder was opened as a folder gets a project color. A window whose root comes
from opening a single file shows no color cue until it is restored as a folder window after a
relaunch, which is how the app already treats it.

## Reason

Boris chose alternative 1: it follows DEC-001 without changing the stored window session format.

## Consequences

The workspace records whether its root was opened as a folder. The session archive is unchanged.
