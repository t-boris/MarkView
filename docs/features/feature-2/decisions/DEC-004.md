## Context

The product owner chose option C for Q-004. A project-colored window icon is already the accepted visual cue.

## Alternatives

1. Show the colored icon only in the project window.
2. Show it only in the macOS window switching interface.
3. Show it in both places.

## Decision

Show the project-colored icon in the window and in the window switching experience.

## Reason

The color should help identify both the current project and the window to switch to.

## Consequences

The same project color must be recognizable in the project window and when choosing among open windows.
