## Context

Persistent color requires a project key and a storage location.

## Alternatives

1. Use a normalized local folder path
2. Store identity or color inside the project folder
3. Track a persistent filesystem identifier

## Decision

Key project colors by the standardized folder path after resolving symbolic links, and store assignments and overrides in local MarkView settings.

## Reason

The rule is deterministic, distinguishes same-named folders, and avoids writing application preferences into project content.

## Consequences

Colors remain local to the user and do not modify project files. A renamed or moved folder receives a new automatic color unless the user selects a color again.
