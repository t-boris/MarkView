## Context

Q-003 asked whether standalone-file windows and windows without an open project folder should receive a project color.

## Alternatives

1. Apply project colors only to windows with an open project folder.
2. Also color windows with a standalone file.

## Decision

Apply project colors only to windows with an open project folder.

## Reason

Boris selected project-folder windows as the scope of this feature.

## Consequences

Windows without an open project folder receive no project color cue. Color placement and assignment remain open.
