## Context

The product owner selected the window icon as the primary place for project color.

## Alternatives

1. Color marker next to the project title
2. Color accent within the window
3. Project-associated window icon

## Decision

Use a project-colored icon as the primary visual cue for windows with an open project folder.

## Reason

This is the option selected in response to Q-001.

## Consequences

The color cue must use an image associated with the project window. The project name remains visible as text.
