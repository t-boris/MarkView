## Context

Q-002 asked how projects receive colors. Boris chose automatic assignment with a user override.

## Alternatives

1. Users assign a color manually to each project.
2. MarkView assigns a persistent color automatically with no user override.
3. MarkView assigns a persistent color automatically and users can change it.

## Decision

Assign each project folder a persistent color automatically and allow the user to change it.

## Reason

The cue works immediately while users can correct an inconvenient assignment.

## Consequences

The specification needs an automatic assignment rule, a way to change the assigned color, and persistence of that change. The color palette and location of the cue remain open.
