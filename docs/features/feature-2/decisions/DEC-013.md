## Context

DEC-006 requires the color cue to be recognizable in Mission Control thumbnails and a visible
fallback if the title bar icon is not. A toolbar icon of about 16 pt shrinks to a 4–6 pt dot in
thumbnails. The fallback location was not specified.

## Alternatives

1. A thin (3 pt) band in the project color across the top of the window content, below the toolbar, in addition to the clickable icon.
2. Tint the whole title bar and toolbar background with a muted project color.
3. Icon only; accept a small dot in thumbnails.

## Decision

Show a 3 pt band in the project color across the top of the window content, directly below the
toolbar, in addition to the clickable icon beside the title (DEC-007). The band is shown and hidden
together with the icon.

## Reason

Boris chose alternative 1: the band spans the window width, so it stays visible in thumbnails,
and it does not cover the controls or the project name.

## Consequences

The band is decoration only; the icon remains the control that opens the color picker.
