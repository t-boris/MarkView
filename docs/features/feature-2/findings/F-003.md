## Finding

No rule identifies a project for color storage or automatic assignment. A folder can be renamed or moved, and two folders can share a name. Define the project key, behavior after a move or rename, and whether colors are local to the user or travel with the folder. The choice also determines where overrides persist.

> Assign each project folder a persistent color automatically and allow the user to change it.

## Possible interpretations

- Identify projects by absolute folder path
- Store an identifier or color inside the project folder
- Use another persistent local identifier

## Resolution

AI: Считать проектом локальный путь к папке после нормализации и разрешения символических ссылок; хранить цвет в настройках MarkView на этом устройстве. Переименование или перенос папки создаёт новую цветовую идентичность, а папки с одинаковым названием, но разными путями остаются разными проектами. — see DEC-008.
