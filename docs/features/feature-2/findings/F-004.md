## Finding

The automatic assignment rule and available colors are still open. Without a defined palette or generation rule, implementers cannot determine whether assignments stay stable, how similar colors are handled, or what the picker offers. Specify those rules and corresponding acceptance criteria.

> A window with an open project folder displays a persistent, automatically assigned project color

## Resolution

AI: Использовать фиксированную палитру из восьми различимых цветов; первоначальный цвет выбирать детерминированно по ключу проекта и сразу сохранять. В выборе цвета показывать ту же палитру; совпадения цветов у разных проектов допустимы, пользователь может их исправить. — see DEC-009.
