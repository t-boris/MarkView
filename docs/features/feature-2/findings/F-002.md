## Finding

The current window title uses the project folder as its proxy icon through `hostWindow?.representedURL = root` [Source: MarkView/Views/ContentView.swift, lines 257–259 and 291–296]. The specification does not resolve whether the colored icon replaces that proxy icon or appears beside it. This also affects whether clicking it retains the proxy icon's existing behavior. Specify the icon's relationship to the current title bar icon and its click behavior.

> Clicking the project-colored icon in the window opens a color picker for that project.

## Possible interpretations

- Recolor or replace the existing folder proxy icon
- Add a separate clickable project icon

## Resolution

AI: Добавить отдельную цветную иконку рядом с названием проекта. Существующую иконку папки и её поведение сохранить; нажатие на новую иконку открывает выбор цвета. — see DEC-007.
