## Finding

The app preserves separate window identities even when two windows show the same folder [Source: MarkView/Models/WindowSession.swift, lines 4–8]. The requirement says color belongs to the project, but does not explicitly require all such windows to show an override immediately. Add that behavior to the acceptance criteria, including folder changes and session restoration.

> After the user chooses a color, the icon reflects the chosen color, which persists for that project.

## Possible interpretations

- All open windows for the same folder update immediately
- Only the window where the color was changed updates until reopened

## Resolution

AI: Цвет принадлежит проекту, поэтому все открытые окна с той же папкой должны обновляться сразу после выбора цвета. При смене папки окно показывает цвет нового проекта, а восстановленные окна получают сохранённый цвет своей папки. — see DEC-010.
