# Цветовая идентификация проектов

## Idea

Пользователь хочет назначать проектам цвет, чтобы быстро узнавать нужное окно среди нескольких открытых окон MarkView. Цветовой элемент в заголовке или рядом с ним — возможный вариант, а не принятое решение.

## Problem

Когда одновременно открыто много проектов, одного текстового названия в заголовке окна недостаточно для быстрого поиска нужного проекта.

## Scope

Входит: визуальное различение одновременно открытых окон по проекту; цвет, связанный с проектом; сохранение текстового названия. За пределами текущего запроса: изменение цветов содержимого Markdown, тема всего приложения и окраска вкладок отдельных документов. Принятые решения: цвет получают только окна, чья папка открыта как папка проекта (DEC-001, DEC-012); MarkView назначает постоянный цвет из палитры восьми цветов по ключу проекта — нормализованному пути папки, пользователь может его изменить (DEC-002, DEC-008, DEC-009); цвет показывается нажимаемой цветной иконкой рядом с названием окна, иконка папки сохраняется (DEC-003, DEC-005, DEC-007), и тонкой цветной полосой под панелью инструментов, заметной в Mission Control (DEC-004, DEC-006, DEC-013); смена цвета сразу отражается во всех окнах этого проекта (DEC-010). Открытых вопросов нет.

Update (DEC-014): the automatic color is selected by the folder name, ignoring case, and is not saved; only a color chosen by hand is saved per folder. Colors saved before 3.5.0 are reset once.
