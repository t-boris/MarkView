## Summary

The original request is stakeholder input describing the problem and a desired outcome, not an implementation decision. The user wants color to help identify a project's window when many MarkView windows are open; the exact visual element remains open.

## Origin

intake

## Content

Я очень часто работаю с многими проектами параллельно, и у меня много MarkView будет открыто в одно и то же время. Я хочу их как-то различать. Ну, в Title написан, например, проект, над которым я работаю, но я хотел бы, чтобы это были какие-то еще цветовые различия. Может быть, Title, вернее, картинки, менялись бы по цвету в зависимости от проекта. Что-нибудь в этом роде, или там какое имление было, какого-то цвета. Мне нужно по цвету понимать, какой проект я, над каким проектом я работаю.
