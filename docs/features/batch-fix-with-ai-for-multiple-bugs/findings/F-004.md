## Finding

'Open' is not defined relative to the 'fixing' status. The spec does not say whether a bug that is already being fixed, alone or in another batch, can be added. It also does not say what happens if a batch is started while the AI terminal is busy.

> Each open bug in the Issues panel has an 'Add to basket' / 'Remove from basket' control.

## Resolution

AI: В корзину можно добавлять только баги в статусе 'open'. Кнопка 'Fix with AI' для пакета перед запуском заново проверяет статусы и отключается, пока AI-терминал занят. Баги, которые уже в 'fixing', показываются в корзине недоступными, и их нельзя запустить. — see DEC-010.
