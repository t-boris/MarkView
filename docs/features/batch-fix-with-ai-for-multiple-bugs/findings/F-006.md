## Finding

The spec does not say whether the per-bug Fix with AI stays as it is, or whether it should now also create a branch and use per-bug commits. It also does not say what a one-bug basket does.

> 'Fix with AI' for the batch is enabled only when the basket has at least 2 bugs.

## Resolution

AI: Fix with AI для одного бага остаётся как есть: без ветки и без отдельных коммитов. Пакетный запуск требует минимум 2 бага. Для корзины с одним багом предлагается использовать Fix with AI для одиночного бага. — see DEC-011.
