## Finding

The app only sends a prompt to a terminal (DEC-002). The spec does not say how the app learns the outcome or who writes the status. The AI could edit the bug files' frontmatter, the app could parse terminal output, or the user could confirm. The target statuses for fixed and not-fixed bugs are also unnamed.

> after the run, each bug's status is updated individually according to the AI's per-bug outcome

## Possible interpretations

- AI edits each bug file's status field directly
- App parses a structured report from terminal output
- User confirms statuses manually after reading the report

## Resolution

AI: AI сам меняет поле status во frontmatter файла каждого бага по инструкции в промпте: 'fixed' для исправленных (после коммита), 'open' с короткой заметкой о причине для неисправленных. Приложение ничего не парсит и просто показывает обновлённые статусы через обычное отслеживание файлов. — see DEC-006.
