## Finding

Nothing records which bugs formed the batch or which branch it used. If the run is cancelled, the bugs stay in 'fixing' status and there is no easy way to rebuild the batch or reset their statuses.

> After a batch starts, the basket is cleared.

## Resolution

AI: Запись о пакете не хранится: промпт уже содержит список багов, а статусы обновляются в самих файлах багов (DEC-006). Если запуск отменён, пользователь вручную сбрасывает 'fixing' на 'open' существующим способом смены статуса. — see DEC-013.
