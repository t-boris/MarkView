## Finding

The spec does not say what performs the suggestion (the AI terminal, a separate API call or local heuristics), what the search scope is (all features?), where the results appear, or how loading and errors are shown. The terminal-based AI cannot return a list to the UI.

> the user can ask the AI to suggest open bugs similar to those in the basket

## Possible interpretations

- Prompt sent to the AI terminal, results read back somehow
- Separate non-terminal AI call
- Local text-similarity heuristic

## Resolution

AI: Убрать «Предложить похожие» из этой фичи: REQ-006 перевести в deferred, пункт перенести в OUT. Ядро фичи (корзина, пакетный запуск, ветка, статусы) от этого не зависит. Подбор похожих багов лучше сделать отдельной фичей, когда будет решено, как AI возвращает результаты в интерфейс. — see DEC-007.
