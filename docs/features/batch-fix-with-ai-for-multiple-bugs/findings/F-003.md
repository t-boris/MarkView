## Finding

The spec does not say whether the basket survives an app restart or a workspace switch, or whether each window has its own basket. It also does not say what happens to a basket item when the bug is closed, deleted or already in 'fixing' status.

> persists while the user navigates between features

## Possible interpretations

- In-memory for the session only
- Persisted per workspace on disk

## Resolution

AI: Корзина хранится только в памяти, одна на окно рабочего пространства, живёт до закрытия окна или смены рабочего пространства; при каждом показе и перед запуском пакета из неё автоматически убираются закрытые или удалённые баги, а баги в статусе 'fixing' блокируются с пояснением. — see DEC-008.
