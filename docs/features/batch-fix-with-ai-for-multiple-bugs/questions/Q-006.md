## Question

Где пользователь выбирает баги из разных фич для одного пакета?

## Why it matters

Решение B означает, что Bug panel одной фичи уже не подходит. От ответа зависят основной сценарий и объём UI-работ.

## Options

- **A**: Отдельный общий список багов по всем фичам с множественным выбором и кнопкой «Fix with AI»
- **B**: Bug panel текущей фичи плюс кнопка «Добавить баги из других фич», которая открывает окно выбора
- **C**: Общая «корзина»: пользователь отмечает баги в Bug panel разных фич, выбор сохраняется при переходе между фичами

## Answer

Прямо в Issues panel сделай возможность добавить баги из списка в общую "корзину" при чем AI может посоветовать похожие для быстрой работы
