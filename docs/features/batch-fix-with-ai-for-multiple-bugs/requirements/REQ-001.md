## Statement

The user can add bug reports from the Issues panel to a shared basket and remove them from it. The basket may contain bugs from different features, persists while the user navigates between features, and its contents are always visible.

## Acceptance Criteria

- [x] Each open bug in the Issues panel has an 'Add to basket' / 'Remove from basket' control.
- [x] Bugs from different features can be in the basket at the same time.
- [x] Switching features does not clear the basket.
- [x] The basket shows the number of bugs and lists them with their features; the user can remove single bugs or clear the basket.
- [x] 'Fix with AI' for the batch is enabled only when the basket has at least 2 bugs.
- [x] After a batch starts, the basket is cleared.
