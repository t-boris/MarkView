## Statement

The batch fix runs on one dedicated git branch. The batch prompt tells the AI to create and check out this branch before it changes any code; the app runs no git operations. The AI chooses a descriptive branch name for the batch and reports it. Before it creates the branch, the AI checks for uncommitted changes and for an existing branch with the planned name; if either is found, it describes the situation and asks the user how to proceed.

## Acceptance Criteria

- [x] The batch prompt instructs the AI to create and check out a dedicated branch before making any code changes.
- [x] The app itself performs no git branch creation or checkout for the batch.
- [x] The prompt instructs the AI to report the branch name it used.
- [x] If the working tree is dirty or the planned branch already exists, the AI asks the user before continuing and makes no changes until the user answers.
