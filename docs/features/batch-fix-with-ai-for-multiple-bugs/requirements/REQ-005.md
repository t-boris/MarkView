## Statement

The batch prompt instructs the AI to create a separate commit for each fixed bug on the batch branch and to report a fixed/not-fixed outcome for each bug.

## Acceptance Criteria

- [x] Each fixed bug corresponds to exactly one commit on the batch branch that references the bug ID.
- [x] The AI returns an outcome for every bug in the batch, including those it could not fix.
- [x] No commit is created for a bug reported as not fixed.
