## Statement

When the basket is not empty, the user can ask the AI to suggest open bugs similar to those in the basket. The user can add suggested bugs to the basket with one click each. Nothing is added without the user's confirmation.

## Acceptance Criteria

- [x] With at least one bug in the basket, a 'Suggest similar' action is available in the Issues panel.
- [x] The AI returns a list of open bugs not already in the basket; each suggestion has an 'Add' control.
- [x] Suggested bugs are never added to the basket automatically.
- [x] If the AI finds no similar bugs, the panel says so and the basket stays unchanged.
