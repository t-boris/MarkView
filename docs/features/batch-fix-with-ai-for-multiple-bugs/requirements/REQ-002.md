## Statement

A single 'Fix with AI' action starts one AI run that covers all selected bugs.

## Acceptance Criteria

- [x] One prompt is sent to the AI terminal, and it references every selected bug file by workspace-relative path
- [x] The prompt asks the AI to reproduce each bug, find its root cause, fix it and verify the fix
- [x] The prompt respects the configured backend (claude /goal vs generic), as fixBugWithAI does
