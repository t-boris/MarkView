## Statement

Every bug in the batch gets status 'fixing' when the batch starts; after the run, each bug's status is updated individually according to the AI's per-bug outcome.

## Acceptance Criteria

- [x] When the batch starts, all selected bugs show status 'fixing'.
- [x] After the run, bugs reported as fixed and bugs reported as not fixed receive different statuses, each set individually.
- [x] A bug reported as not fixed does not change the status of other bugs in the batch.
