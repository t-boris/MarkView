## Summary

The user's original request: to fix several bugs in one go by grouping them (e.g., picking from 5 open bugs) and triggering a single "Fix with AI" action. The AI should create one git branch and fix all the grouped bugs in it (the example mentions two bugs).

## Origin

intake

## Content

Я хочу, чтобы у нас была возможность одним махом решать фикс нескольких багов. Например, у нас есть 5 багов, мы можем их объединить и сказать fix with AI. То есть он сделает один бренч, естественно, и в нем фиксит, допустим, два бага. Мне нужно такое объединение.
