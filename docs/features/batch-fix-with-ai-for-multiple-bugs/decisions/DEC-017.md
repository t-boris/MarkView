## Context

In an end-to-end run the AI stopped on the untracked .dde/ folder (MarkView's index state) as DEC-003 prescribes. Every repository that does not ignore .dde/ would stop every batch this way.

## Alternatives

1. Treat .dde/ like the batch's own report edits: expected, never committed
2. Keep asking

## Decision

1: the prompt lists .dde/ with the batch's own status edits as expected, and tells the AI to leave both out of every commit.

## Reason

DEC-003 protects the user's uncommitted work; the app's own state is not that.

## Consequences

Other untracked or modified files still make the AI ask first.
