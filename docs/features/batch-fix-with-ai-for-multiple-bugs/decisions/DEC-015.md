## Context

Bug reports live in the flat docs/bugs/ folder, not inside features, and their ids are not unique (two BUG-004 files exist). REQ-001, DEC-008 and DEC-012 assumed 'feature ID + bug ID'.

## Alternatives

1. Key by workspace-relative path; show a feature only from the report's `feature:` front matter
2. Add a mandatory feature link to bug reports

## Decision

1: the basket and the prompt identify a bug by its workspace-relative path and show id and title; a report's `feature:` front matter, when present, is shown next to it and passed in the prompt. 'Bugs from different features' means any bugs in docs/bugs/.

## Reason

It matches how bugs are stored today and needs no data-format change.

## Consequences

DEC-008's 'feature ID + bug ID' reads as 'path'; DEC-012's feature id is included when known.
