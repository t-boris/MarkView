## Context

A batch run may fix only some of the selected bugs, leaving the batch in an ambiguous state.

## Alternatives

1. A: One commit per bug; AI reports outcome per bug; statuses updated individually
2. B: One combined commit; user updates statuses manually

## Decision

A: The AI makes a separate commit for each fixed bug on the batch branch and reports a per-bug outcome; each bug's status is updated individually based on that outcome.

## Reason

Per-bug commits keep changes traceable and revertible, and partial success is represented precisely.

## Consequences

The combined prompt must instruct per-bug commits and a per-bug result report; the app must map reported outcomes to individual bug statuses. Prompt complexity increases.
