## Context

It is unclear whether the new branch and per-bug commit behaviour also applies to the existing fixBugWithAI, and what a basket with one bug does.

## Alternatives

1. Keep single-bug flow unchanged
2. Make the single-bug flow a batch of one (branch + commit)
3. Let a basket of one run the batch flow

## Decision

The existing per-bug Fix with AI (fixBugWithAI) keeps its current behaviour. Batch Fix with AI stays disabled for fewer than 2 bugs. With 1 bug in the basket, the UI points the user to the per-bug action.

## Reason

This keeps the scope minimal, does not change existing behaviour, and gives each action one clear purpose.

## Consequences

Changing the single-bug flow to create a branch can be proposed later as a separate feature.
