## Context

DEC-010 disables batch Fix with AI while the AI terminal has an active run, but the app had no busy signal.

## Alternatives

1. Output-activity heuristic (printed within ~3 s)
2. No guard; rely on the paste waiting for a quiet terminal

## Decision

1: WorkspaceManager.assistantIsBusy is true while the assistant terminal a prompt would go to is running and printed within the last 3 s; the basket re-checks it every second and explains the disabled button in its tooltip.

## Reason

Claude Code's spinner keeps printing while it works, so output activity tracks a run closely without new infrastructure.

## Consequences

A quiet assistant waiting for an answer counts as idle.
