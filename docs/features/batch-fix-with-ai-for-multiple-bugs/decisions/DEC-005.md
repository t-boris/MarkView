## Context

Batches may include bugs from different features (DEC-004); the user needs a place to collect them.

## Alternatives

1. A: Separate global bug list across all features with multi-select
2. B: Current feature's Bug panel plus an 'Add bugs from other features' picker dialog
3. C: Shared basket filled directly from the Issues panel, persisting across features, with AI suggestions of similar bugs

## Decision

C: The user adds bugs to a shared basket directly from the Issues panel. The basket persists while the user navigates between features, shows its current contents, and starts the batch 'Fix with AI'. The AI can suggest similar bugs to add.

## Reason

The user chose it: no new screen is needed, and AI suggestions speed up building related batches.

## Consequences

The Issues panel needs an add-to-basket control and a visible basket state (count, list, remove, clear). The basket must survive feature switches. A new AI suggestion step is added.
