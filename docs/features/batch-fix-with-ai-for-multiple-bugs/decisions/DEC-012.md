## Context

DEC-004 allows batches with bugs from several features, but REQ-002 does not require the prompt to identify each bug's feature.

## Alternatives

1. Add acceptance criterion to REQ-002
2. Rely on the path implying the feature

## Decision

Add to REQ-002: 'For each bug, the prompt includes its workspace-relative file path, its feature id and its title, and paths resolve correctly regardless of which feature is currently open.'

## Reason

The requirement becomes explicit and testable, and it removes path ambiguity for batches from several features.

## Consequences

REQ-002 gets one more acceptance criterion.
