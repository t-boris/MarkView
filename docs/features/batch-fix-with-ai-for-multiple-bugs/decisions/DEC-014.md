## Context

DEC-007 (rejected) assumed the app reaches AI only through the terminal. The app already makes one-shot, read-only structured calls (CLICompletion with a JSON schema, used by Investigate and New Bug) with a running state.

## Alternatives

1. Structured AI call (CLICompletion + JSON schema)
2. AI terminal writes a suggestions file that the app watches
3. Local text-similarity heuristic

## Decision

1: the basket's reports and up to 150 open candidates (excerpts) go to FeatureAssistant.structured; the answer is {suggestions: [{path, reason}]}, kept to known candidates, without repeats, at most 5. Results show in the basket with Add and dismiss per item, a spinner while running, the error on failure, and 'No similar open bugs found' for an empty answer.

## Reason

No new dependency or file watcher; the result reaches the UI structured, so each item gets a one-click Add.

## Consequences

REQ-006 is implemented as written. The call uses the backend chosen for AI in preferences.
