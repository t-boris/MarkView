## Context

The AI creates the batch branch per the prompt (DEC-002). Before it does, the working tree may have uncommitted changes, or a branch with the planned name may already exist. The prompt alone defines what happens in these cases.

## Alternatives

1. A: Stop without changing anything, report it in the terminal, and mark all bugs as not fixed
2. B: Stash the uncommitted changes and pick another branch name if the name is taken
3. C: Ask the user in the terminal and wait for an answer

## Decision

C: The batch prompt tells the AI to check for uncommitted changes and for an existing branch with the planned name before it creates the branch. If either is found, the AI describes the situation in the terminal, asks the user how to proceed, and makes no git or code changes until the user answers.

## Reason

The user keeps control over their own uncommitted work and over existing branches. Nothing is stashed or mixed into the batch commits without the user's consent.

## Consequences

The run is not fully autonomous: it can pause until the user answers. Bugs stay in 'fixing' status while the run waits.
