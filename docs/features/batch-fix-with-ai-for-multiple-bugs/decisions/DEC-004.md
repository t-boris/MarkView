## Context

The Bug panel belongs to one feature. Related bugs can come from several features. The Scope listed cross-feature batching as out of scope (an inference that was never confirmed).

## Alternatives

1. A: Only bugs from a single feature, selected in that feature's Bug panel
2. B: Bugs from any features

## Decision

B: A batch may include bugs from any features in the workspace. Cross-feature batching moves from OUT to IN scope.

## Reason

The product owner chose flexibility, so related bugs from different features can be fixed in one run on one branch.

## Consequences

Selecting bugs only inside the current feature's Bug panel is no longer enough; the feature needs a way to select bugs across features. Branch naming cannot depend on a single feature. The prompt must show which feature each bug belongs to.
