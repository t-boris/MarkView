## Statement

The system shall pause QA safely between actions, retain the players' sessions, and allow resuming the current step, continuing at a chosen step, starting at a selected step, and retrying a failed step.

## Acceptance Criteria

- [x] Pause does not start another action or request after the pause boundary; an in-flight action can finish, and Stop also works while paused.
- [x] Resume keeps live browsers, logins and application state. Continuing at another step skips earlier steps and identifies the new start point.
- [x] A selected scenario step can be used as the starting point and a failed result offers retry at its failure location.
- [x] Skipped earlier steps are recorded explicitly and never count as tested; partial executions remain distinct from full passing runs.
- [x] Approval and production confirmations still apply, invalid start points are refused, and old scenario and run files remain readable.
