# Pause and resume QA from a chosen step

## Idea

Allow a QA execution to pause between actions and resume with live player sessions intact. Let the person continue from a selected scenario step, start a new execution at a chosen step and retry from the failed step. Make the start point, skipped steps, retained state and outcome explicit, preserving execution approval and production confirmations.
