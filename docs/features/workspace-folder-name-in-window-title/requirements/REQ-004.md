## Statement

Each window shall show the folder name of its own workspace, independent of other windows, and shall expose the full workspace root path as the window's represented URL (proxy icon in the title bar). Folders with identical names in different windows are disambiguated only through the proxy icon; the title text itself is not changed.

## Acceptance Criteria

- [x] Two windows with different workspaces each show their own folder name in the title.
- [x] With a workspace open, the title bar shows a proxy icon; Cmd+click on the title shows the full path hierarchy of the workspace root.
- [x] Two windows with folders of the same name (e.g. two 'docs') show identical title text but different paths via Cmd+click.
- [x] When no folder is open, no proxy icon is shown.
- [x] When the workspace changes, the proxy icon path updates together with the title.
