## Statement

When a workspace folder is open, each workspace window's title shall be 'MarkView <marketing version> — <folder name>', where <folder name> is the Finder display name of the workspace root folder (`FileManager.displayName(atPath:)`, falling back to its last path component) and the separator is ' — ' (em dash with spaces). An empty version is left out (DEC-005). Auxiliary windows such as DDE Settings keep their own titles (DEC-008).

## Acceptance Criteria

- [x] With folder /x/my-project open in version 1.4, the title reads exactly 'MarkView 1.4 — my-project'.
- [x] The full path never appears in the title text.
- [x] The same title appears in Mission Control, Cmd+` cycling and the Window menu.
