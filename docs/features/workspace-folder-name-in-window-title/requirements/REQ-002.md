## Statement

The title and the proxy icon shall update immediately whenever the window's workspace root changes: Open Folder, drag-and-drop, Finder/Services open requests, restoring the last folder, and closing the folder (DEC-007).

## Acceptance Criteria

- [x] After switching from folder 'foo' to 'bar', the title shows 'bar' without restarting the app
- [x] Dropping folder 'bar' onto a window showing 'foo' shows 'bar'
- [x] Closing the folder shows 'MarkView <version>' with no proxy icon
- [x] When the saved last folder no longer exists at launch, the title is 'MarkView <version>' with no proxy icon (DEC-004)
