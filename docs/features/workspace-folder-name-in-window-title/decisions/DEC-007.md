## Context

The trigger 'opens a different folder' was ambiguous, and folder→no folder was not covered.

## Alternatives

1. Every path that changes WorkspaceManager's root
2. Only the explicit Open Folder command

## Decision

The title and represented URL observe WorkspaceManager's root state, so every entry point that changes it (Open Folder, drag-and-drop, Finder Service/open requests, last-folder restore, closing the folder) updates them. Add acceptance criteria: drag-and-drop of 'bar' onto a window showing 'foo' shows 'bar'; closing the folder shows 'MarkView <version>' with no proxy icon.

## Reason

Binding to state rather than commands is simpler and can't miss an entry point.

## Consequences

REQ-002 is reworded to 'whenever the window's workspace root changes' and gets the extra criteria.
