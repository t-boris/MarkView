## Context

Self.version can be an empty string in some debug or test builds, which would produce double or trailing spaces.

## Alternatives

1. Omit the version and its space when empty
2. Declare empty version impossible

## Decision

The formatter joins the non-empty parts: 'MarkView', then the version if it is non-empty, then ' — <folder>' if a workspace is open. With an empty version the title is 'MarkView — <folder>' or 'MarkView'.

## Reason

Cheap to handle in the pure formatter, and it avoids a malformed title in test builds.

## Consequences

Unit tests cover empty-version cases. REQ-003 and REQ-001 apply to their non-empty-version form.
