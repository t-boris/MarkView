## Context

The window title currently shows a static 'MarkView <version>'. The folder name must be added so that windows can be told apart. We had to choose the order of the two parts.

## Alternatives

1. A: 'MarkView <version> — <folder>' (version first)
2. B: '<folder> — MarkView <version>' (folder first, macOS document convention)

## Decision

A: the title format is 'MarkView <version> — <folder>', with an em dash separator surrounded by spaces.

## Reason

The product owner chose the format that matches the original request literally and keeps the version first.

## Consequences

When the title is truncated (for example in the Window menu or in narrow title bars), the folder name may be cut off first. The represented URL and proxy icon (DEC-001) remain an extra way to identify the window.
