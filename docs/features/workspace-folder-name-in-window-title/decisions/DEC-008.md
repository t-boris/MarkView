## Context

'Main window' was undefined, and the Scope excludes DDE Settings without a general rule.

## Alternatives

1. Every WindowGroup ContentView window
2. Only workspace windows; auxiliary windows keep their own titles

## Decision

'Main window' means any window whose root is ContentView (a workspace window). All such windows use the folder-name title. Auxiliary windows (DDE Settings and any other non-ContentView scenes) are unchanged.

## Reason

Each ContentView window is its own workspace (README), and owning the title in ContentView (F-001) naturally scopes it this way.

## Consequences

REQ-001 wording replaces 'main window' with 'each workspace window'. No changes to other scenes.
