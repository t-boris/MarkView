## Context

Raw lastPathComponent yields '/' for the root volume and ignores localized names, which leaves special roots unspecified.

## Alternatives

1. Raw URL.lastPathComponent
2. FileManager.default.displayName(atPath:)

## Decision

<folder name> is FileManager.default.displayName(atPath: root.path). If that is empty, fall back to lastPathComponent. REQ-001 is updated to reference the display name.

## Reason

Matches what users see in Finder and in the proxy icon, and handles '/' and volume roots gracefully.

## Consequences

Folder extensions may be hidden per Finder settings. The formatter takes the display name as input, so it stays testable.
