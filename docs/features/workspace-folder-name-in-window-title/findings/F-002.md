## Finding

Nothing covers renaming, moving or deleting the workspace root while it is open, or restoring a workspace.lastFolder that no longer exists at launch. It is unclear whether the title keeps the stale name, follows the rename, or falls back to REQ-003.

> When the workspace changes, the proxy icon path updates together with the title.

## Possible interpretations

- Keep the name captured when the folder was opened
- Follow the rename or fall back to 'MarkView <version>' when the folder is missing

## Resolution

AI: Заголовок и прокси-иконка всегда отражают текущий rootURL WorkspaceManager; отслеживание переименований на лету не делаем. Если lastFolder при запуске не существует, папка не восстанавливается и показывается запасной заголовок 'MarkView <version>'. — see DEC-004.
