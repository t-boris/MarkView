## Finding

Self.version falls back to "" when CFBundleShortVersionString is missing (for example in some debug or test builds). The result would be 'MarkView  — foo' with a double space, or 'MarkView ' with a trailing space. The spec does not define the format in that case.

> the title shall show 'MarkView <version>' only, with no dangling separator

## Possible interpretations

- Omit the version and its space when it is empty
- Treat it as impossible and state that assumption explicitly

## Resolution

AI: Если строка версии пустая, опускать её вместе с пробелом: 'MarkView — foo' или просто 'MarkView'. Двойных и висящих пробелов быть не должно. — see DEC-005.
