## Finding

The Scope excludes the 'DDE Settings' window, but none of the requirements define 'main window' or list other auxiliary windows. The existing code sets the title for every WindowGroup window. If other windows exist (for example opened via openWindow), it is unclear whether they get a folder-name title.

> the main window title shall be

## Possible interpretations

- Every WindowGroup ContentView window
- Only workspace windows; auxiliary windows keep their own titles

## Resolution

AI: Правило применяется ко всем окнам WindowGroup с ContentView (окнам рабочих пространств). Вспомогательные окна, включая DDE Settings, сохраняют свои заголовки. — see DEC-008.
