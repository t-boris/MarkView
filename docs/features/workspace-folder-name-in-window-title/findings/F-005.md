## Finding

'Opens a different folder' could mean Open Folder, drag-and-drop, a Finder Service or closing the folder back to the welcome screen. The acceptance criterion covers only foo→bar, not the move from a folder to no folder (which should trigger the REQ-003 fallback and clear the proxy icon).

> The title shall update immediately when the user opens a different folder in the same window.

## Possible interpretations

- Every path that changes WorkspaceManager's root, including closing the folder
- Only the explicit Open Folder command

## Resolution

AI: Обновление срабатывает при любом изменении корня WorkspaceManager (Open Folder, drag-and-drop, Services, восстановление, закрытие папки). Закрытие папки возвращает 'MarkView <version>' и убирает прокси-иконку. — see DEC-007.
