## Finding

The spec does not say what to show for the volume root '/' (last path component is '/'), a mounted volume root, or bundle-like folders. It also does not say whether to use the localized display name (FileManager.displayName, e.g. 'Documents' vs a localized name) or the raw lastPathComponent.

> <folder name> is the last path component of the workspace root folder

## Possible interpretations

- Raw URL.lastPathComponent
- FileManager.default.displayName(atPath:)

## Resolution

AI: Использовать FileManager.default.displayName(atPath:), чтобы имя совпадало с Finder (локализованные папки, имя тома для '/' и точек монтирования). — see DEC-006.
