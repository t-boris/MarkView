## Summary

The original request from the user: MarkView is used across many projects, so the window title should show not only "MarkView <version>" but also the name of the folder currently being worked in. It establishes the motivation (multi-project use) and the core desired title content.

intake

## Content

Поскольку этот MarkView будет использоваться везде, так сказать, во многих проектах, я хочу, чтобы в тайтле MarkView писалась не просто MarkView-версия, а MarkView-версия и название фолдера, в котором мы работаем.
