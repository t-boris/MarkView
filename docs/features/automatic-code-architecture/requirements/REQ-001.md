## Statement

Provide the Code/Architecture experience for projects that contain source code as an extension of the existing X-Ray Code view (Q-001 A).

## Acceptance Criteria

- [x] A user who opens a project containing supported source code can reach the architecture result through X-Ray without any additional tab.
- [x] The Code view presents the analysis of that project's codebase: layers, components and sequences.
