## Statement

Automatically inspect project source code and derive its structure without requiring a manual architecture description.

## Acceptance Criteria

- [ ] Analysis starts automatically when a code project folder is opened, with no Analyze command (Q-004 A, DEC-001).
- [ ] After code changes the result is refreshed in the background: a local rescan after 60 seconds of quiet, an AI run at most once per 15 minutes per project (DEC-003).
- [ ] Projects with more than 5000 source files are not analyzed automatically; the manual Refresh still works (DEC-003).
- [ ] The user does not need to supply an architecture description, select source documents or compose an analysis prompt to obtain the initial diagrams.
- [ ] A settings switch turns automatic analysis off; with it off no CLI agent is started and only the local layers are shown (DEC-001).
- [ ] When no CLI agent is available or it is signed out, the Code view shows the local layers and one status line; no dialog appears (DEC-004).
