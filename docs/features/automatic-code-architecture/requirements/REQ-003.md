## Statement

Render diagrams covering architecture layers, components and interaction sequences.

## Acceptance Criteria

- [x] The result shows the architectural layers identified in the codebase.
- [x] The result shows the main components and their relationships.
- [x] The result includes sequence diagrams (Mermaid sequenceDiagram) for 3 scenarios, at most 5, that the agent chooses itself from the project's entry points; no manual scenario selection is required (Q-002 A, DEC-003).
- [x] The manual Refresh and Trace a scenario actions stay available beside the automatic result; manually traced scenarios are kept apart from automatic ones and survive an automatic refresh (DEC-002).
- [x] Every language MarkView recognizes is analyzed; a "What was understood" section reports per language whether it was fully, partially or not analyzed, with file counts and reasons (Q-003 B).
- [x] Everything lives inside the existing X-Ray Code view; there is no separate Code/Architecture tab (Q-001 A).
