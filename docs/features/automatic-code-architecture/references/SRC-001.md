## Summary

The original request expresses the user's desired automatic architecture-discovery experience through a Code/Architecture tab in MarkView. It identifies three diagram types derived from source code and removes the need for a user-written architecture description, while leaving supported codebases, analysis triggers, sequence selection, and the relationship to X-Ray unspecified.

## Origin

intake

## Content

Add a Code/Architecture tab to MarkView. When a project folder contains code, this tab should automatically analyze it and render diagrams derived from the actual code: architecture layers, components, and sequence diagrams. The goal is for the agent to understand the codebase structure and draw these diagrams without the user describing the architecture manually.
