## Context

Q-004 was answered A: analysis starts when a project folder opens and refreshes after code changes. The analysis sends up to 90 KB of source excerpts to the configured CLI agent, which the project treats as sensitive content, and other integrations are opt-in. Two options were put to Boris: off by default with a one-time consent question, or on by default.

## Alternatives

1. Off by default plus a one-time question at the first opening of a code project (recommended by the planner for privacy).

## Decision

Automatic code analysis is enabled by default for every code project. A switch in settings (`xray.autoAnalyze`) turns it off; there is no one-time consent dialog. With the switch off only the local, AI-free layers are shown and no CLI is started.

## Reason

Boris chose "enabled by default" in the conversation of 2026-11-02: the feature's point is understanding a project without any action, and the agent is already the user's own signed-in CLI.

## Consequences

Settings and docs gain the switch. The prompt still excludes files the scanner skips (bundles, files over 512 KB, ignored paths). Logs never contain prompts or sources.
