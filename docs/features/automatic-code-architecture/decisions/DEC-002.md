## Context

Q-002 A makes the agent choose the sequence scenarios itself and Q-004 A removes the need for an Analyze command. The existing Code view has a manual analyze action and a "Trace a scenario" field.

## Alternatives

1. Automatic only: remove the manual actions.

## Decision

The automatic pipeline does the regular work, and the manual "Refresh" (re-run the analysis now) and "Trace a scenario" (trace a user-written scenario) actions remain available in the Code view.

## Reason

Boris chose to keep them on 2026-11-02; automatic scenarios do not cover every question a reader has, and a forced refresh is useful after large changes within the quiet period.

## Consequences

Manually traced scenarios are kept apart from automatic ones (`auto: false`) and are never discarded by an automatic refresh.
