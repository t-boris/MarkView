## Context

Automatic analysis needs a configured, signed-in CLI agent. It may be absent on a machine that uses MarkView only as a viewer; the project rule is that integrations stay silent when unavailable.

## Alternatives

1. Show a dialog at project open suggesting to configure an agent.

## Decision

When no CLI agent is available or it is signed out, MarkView shows the local, AI-free layers and one status line in the Code view saying that AI analysis is unavailable. No alert or dialog is shown.

## Reason

Boris chose the quiet behaviour on 2026-11-02, in line with the optional-integrations rule.

## Consequences

The status line is part of the "What was understood" section; the manual Refresh stays available and reports the same reason when pressed.
