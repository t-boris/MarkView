## Question

Как запрошенная вкладка должна соотноситься с существующим X-Ray?

## Why it matters

Это определяет границы новой возможности и то, где пользователь будет искать результаты.

## Options

- **A**: Расширить существующий X-Ray до запрошенной вкладки Code/Architecture.
- **B**: Добавить отдельную вкладку Code/Architecture рядом с X-Ray.

## Recommended

A — X-Ray уже решает значительную часть задачи; расширение даст единый путь изучения кода.

## Answer

A: extend the existing X-Ray into the requested Code/Architecture experience instead of adding a separate tab beside it.
