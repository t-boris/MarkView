## Question

Какие сценарии должны попадать в автоматически построенные sequence-диаграммы?

## Why it matters

Для слоёв и компонентов объект анализа — проект, а для последовательности нужен конкретный сценарий взаимодействия.

## Options

- **A**: Агент сам выбирает несколько основных сценариев по точкам входа и показывает их последовательности.
- **B**: Агент автоматически предлагает найденные сценарии; пользователь выбирает, какие последовательности раскрыть.

## Recommended

A — Автоматический начальный набор лучше соответствует запросу на понимание проекта без ручного описания.

## Answer

A: the agent chooses a few main scenarios itself, from the project's entry points, and shows their sequences. No manual scenario selection is required.
