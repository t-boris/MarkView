## Question

Для каких кодовых баз первый выпуск должен гарантировать все три вида диаграмм?

## Why it matters

Распознавание файла существующим просмотрщиком ещё не гарантирует понимания его компонентов и цепочек вызовов.

## Options

- **A**: Сначала гарантировать результат для Swift и JavaScript/TypeScript, включая смешанные проекты.
- **B**: Сразу анализировать все распознаваемые MarkView языки с явно обозначенной неполнотой результата.
- **C**: Ограничить первый выпуск другим набором языков, который вы укажете.

## Recommended

A — Это предложение для проверяемого первого выпуска: репозиторий MarkView сам содержит Swift и JavaScript/TypeScript.

## Answer

B: analyze every language MarkView recognizes from the first release, and mark the incompleteness of the result explicitly (what was and was not understood) instead of guaranteeing all three diagram types for a fixed language list.
