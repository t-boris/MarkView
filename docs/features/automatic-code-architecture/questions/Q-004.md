## Question

Когда должен запускаться и повторяться автоматический анализ?

## Why it matters

Запрос задаёт автоматичность, но не момент запуска и ожидаемую актуальность диаграмм; сейчас AI-анализ X-Ray запускается вручную.

## Options

- **A**: Запускать анализ при открытии папки проекта и обновлять после изменений кода.
- **B**: Запускать анализ при первом открытии вкладки; обновлять после изменений, пока вкладка открыта, и при возвращении к ней.
- **C**: Автоматически анализировать при открытии вкладки; изменения учитывать при следующем открытии.

## Recommended

B — Сохраняет автоматичность без отдельной команды Analyze и ограничивает фоновую работу моментами изучения архитектуры.

## Answer

A: start the analysis when the project folder is opened and refresh it after code changes (background work whenever a project is open), with no separate Analyze command.
