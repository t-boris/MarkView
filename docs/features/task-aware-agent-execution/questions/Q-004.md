## Question

Когда допустимо сделать обычный запуск медленнее или дороже ради качества результата?

## Why it matters

Без этого правила сравнение покажет выигрыш и цену, но не определит, какой вариант считать оптимальным.

## Options

- **A**: В режиме по умолчанию отдавать приоритет скорости и расходу. Более дорогой режим включать по явному запросу.
- **B**: Применять более дорогой режим по умолчанию только в тех сценариях, где сравнение показывает существенный выигрыш в качестве.
- **C**: Отдавать приоритет качеству при любом подтверждённом улучшении, даже если растут время и расход.

## Recommended

B — Ценность дополнительного вызова различается для короткого объяснения, исследования и проверки реализации.

## Answer

B. Применять более дорогой режим по умолчанию только в тех сценариях, где сравнение показывает существенный выигрыш в качестве.
