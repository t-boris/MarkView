## Question

Кто выбирает глубину нового исследования?

## Why it matters

Существующий пункт Deep Research открывает обычный ввод Research, а правила выбора глубины пока нет.

## Options

- **A**: Оставить быстрый запуск по умолчанию и дать пользователю явно выбрать глубокий режим в существующем окне Research.
- **B**: Предлагать глубину по характеру вопроса и позволять изменить её перед запуском.
- **C**: Запускать глубокий режим по умолчанию для каждого нового исследования.

## Recommended

B — Один вход в Research сохраняется, а пользователь видит и может изменить выбранную глубину.

## Answer

C. Запускать глубокий режим по умолчанию для каждого нового исследования.
