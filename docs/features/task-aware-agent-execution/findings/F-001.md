## Finding

Existing Research documentation defines Continue / deepen, Retry incomplete part, and Revise With Comment as distinct agent-backed operations on an existing document (`docs/features/new-research-repository-grounded-analysis/decisions/DEC-013.md`, `DEC-014.md`, and `DEC-017.md`). The phrase “new Research run” could include those calls or mean only the creation of a new research document. That boundary determines which workflows must adopt the deep default and pass the mandatory release gate.

> Every new Research run in the first release uses the deep workflow by default, including launches from the Deep Research menu through the shared Research intake.

## Possible interpretations

- Глубокий режим обязателен при создании нового документа Research. Продолжение, повтор и правка по комментарию проходят общий аудит и меняются только при подтверждённой пользе.
- Глубокий режим обязателен для каждого нового вызова Research, включая продолжение, повтор неполного раздела и правку по комментарию.

## Resolution

Глубокий режим по умолчанию применяется при создании, продолжении, повторе неполной части и правке по комментарию. — see DEC-020.
