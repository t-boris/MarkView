## Finding

The attached research map lists a handoff that stages PR-review tasks in a terminal with `submit: false` (`docs/research/2026-11-25-proanaliziruem-vezde-li-my-v-marku-ispol-zuem.md`, node n18). REQ-005 includes terminal handoffs, but the feature describes its subject as agent invocations. It is unclear whether a staged prompt with no agent execution belongs in the mandatory inventory and first-release verification.

> The inventory covers background CLI and ACP operations, terminal handoffs, managed Cockpit steps, MarkView-initiated inter-agent actions, and Remote Work across all registered providers and applicable profiles.

## Possible interpretations

- Включить подготовленные MarkView терминальные черновики в аудит промптов и проверять их по фактическому профилю терминала, сохраняя ручную отправку.
- Включать только передачи, которые MarkView сам отправляет агенту на исполнение. Терминальные черновики оставить вне обязательного аудита.

## Resolution

Считать терминальную передачу частью аудита с момента, когда MarkView сам отправляет промпт агенту. Это сужает объём аудита до запусков, которыми управляет приложение. — see DEC-019.
