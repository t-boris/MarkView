## Finding

REQ-009 explicitly allows unavailable measurements but leaves their effect on approval undefined. A candidate can match baseline latency while adding work through a profile without comparable cost data. The acceptance criteria do not establish whether that candidate needs to demonstrate a material quality gain before becoming the default. For deep Research, the interpretation can determine whether the whole feature ships.

> Record unavailable measurements and assess result acceptance separately from process success.

## Possible interpretations

- Если сопоставимых данных о стоимости нет, зафиксировать пробел и применить критерий существенного прироста только при измеренном ухудшении.
- Если стоимость сравнить нельзя, выпускать новый режим по умолчанию только при подтверждённом существенном приросте качества или при наличии других доказательств, что стоимость не выросла.

## Resolution

При неизвестной стоимости требовать существенного прироста качества, если заранее согласованные косвенные данные не подтверждают отсутствие роста стоимости. При измеренном росте длительности прирост качества обязателен в любом случае. — see DEC-018.
