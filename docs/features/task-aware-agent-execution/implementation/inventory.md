# MarkView Agent Invocation Inventory (I-1)

Exhaustive source-code and live-CLI inventory of every MarkView-initiated agent invocation across all 5 registered providers (`MarkView/Models/AI/Providers/AssistantProviderList.swift:5-12`) and all applicable launch profiles: background CLI/ACP calls, automatically submitted (`submit: true`) terminal handoffs, managed Cockpit steps, MarkView-initiated inter-agent MCP actions, and Remote Work.

> **Scope boundary (DEC-019 / REQ-005 / REQ-006 / REQ-009)**: Terminal handoffs enter this mandatory inventory and first-release verification **only when MarkView itself submits the prompt (`submit: true`)**. Manually submitted drafts — including PR-review task lists staged with `submit: false` (`MarkView/Models/Architecture/CodeAndXRayCoordinator.swift:559`), browser element-picker pastes (`BrowserHost.swift:183`), dictation pastes (`TerminalSession.swift:271`), and dropped file paths (`TerminalSession.swift:596`) — are explicitly excluded even if the user later submits them manually.
