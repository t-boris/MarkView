## Context

DEC-012 makes deep research the default for every new Research run. DEC-014 requires a demonstrated material quality gain for slower or more expensive defaults.

## Alternatives

1. Apply the existing release gate to Research. Revise and retest a slower or more expensive deep workflow if the comparison fails to demonstrate a material quality gain.
2. Exempt Research from the release gate and ship deep research as the default even when it increases latency or cost without a demonstrated material quality gain.

## Decision

Apply the release gate in DEC-014 to the deep Research default required by DEC-012.

## Reason

The owner chose to make both decisions release conditions.

## Consequences

If deep research is slower or more expensive and the comparison fails to demonstrate a material quality gain, the feature release waits for a revised workflow to pass a repeat comparison.
