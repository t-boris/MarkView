## Context

Capabilities can differ across launch profiles of the same provider.

## Alternatives

1. Keep the explicitly selected provider and show the available reduced mode.
2. Offer a compatible provider and switch after explicit confirmation.
3. Automatically switch to a compatible configured provider and identify it afterward.

## Decision

Offer a compatible provider when the explicitly selected provider's launch profile lacks a needed capability. Switch only after the user confirms the proposed provider.

## Reason

The owner chose to let users obtain the needed capability while controlling which provider receives their context.

## Consequences

MarkView must confirm the proposed provider before sending task context to it.
