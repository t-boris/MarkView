## Context

F-003 identified an ambiguity in REQ-005. The requirement covers terminal handoffs, and MarkView can stage PR-review tasks for manual submission.

## Alternatives

1. Include all terminal drafts prepared by MarkView in the audit and verify each prompt against the actual terminal profile while preserving manual submission.
2. List terminal draft entry points and mark them as manually submitted, with mandatory prompt and profile verification limited to automatically submitted handoffs.

## Decision

Include a terminal handoff in the audit only when MarkView itself submits the prompt to the agent for execution.

## Reason

Submission by MarkView provides a clear audit boundary based on who initiates agent execution.

## Consequences

REQ-005 limits its terminal handoff inventory to prompts submitted by MarkView. A PR-review task staged with `submit: false` remains outside the mandatory inventory and first-release verification, even if the user later submits it manually. REQ-006 and REQ-009 continue to apply to in-scope handoffs.
