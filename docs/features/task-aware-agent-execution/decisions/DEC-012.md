## Context

The Deep Research menu already opens the New Research intake.

## Alternatives

1. Default to quick research and let users explicitly choose deep research.
2. Suggest depth based on the question and let users change it before launch.
3. Default every new Research run to deep research.

## Decision

Use deep research by default for every new Research run.

## Reason

The owner selected a consistent default across new Research runs.

## Consequences

All new Research entry points use the deep workflow by default. Research depth can shape the execution strategy without prescribing the same number of calls for every question.
