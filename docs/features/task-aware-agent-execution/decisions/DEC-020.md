## Context

F-001 identified an ambiguity in the phrase “every new Research run” in DEC-012 and REQ-008. Research defines Continue / deepen, Retry incomplete part, and Revise With Comment as distinct agent-backed operations on an existing document.

## Alternatives

1. Default to deep research only when creating a document through Research or Deep Research. Keep the current behavior for existing-document operations until verification demonstrates a benefit from changing it.
2. Default to deep research when creating a document or using Continue / deepen. Keep the current behavior for Retry incomplete part and Revise With Comment until verification demonstrates a benefit from changing it.

## Decision

In the first release, use the evidence-backed deep workflow by default when creating a research document through Research or Deep Research and when using Continue / deepen, Retry incomplete part, or Revise With Comment on an existing document. Each operation uses the sources and tools permitted and available to its actual launch profile.

## Reason

The team chose a consistent default for all four Research operations. Verifying each scenario separately ensures that evidence from broad research questions alone cannot qualify the default for focused retries and comment-driven revisions.

## Consequences

Update DEC-012 and REQ-008 to enumerate all four scenarios. Under DEC-015, each scenario must meet the REQ-009 release gate against its current behavior. If a scenario fails the gate, refine the deep workflow for that scenario and repeat verification before release.
