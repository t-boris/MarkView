## Statement

Use direct execution, bounded parallel work, or an additional review pass according to the workflow's needs and existing controls.

## Acceptance Criteria

- [x] A straightforward implementation or bug fix can use a direct execution path without extra agent calls solely for orchestration.
- [x] An eligible workflow can run independent work concurrently, while dependent work respects prerequisites. Managed Cockpit steps remain sequential under the existing approved plan.
- [x] Additional review is evaluated against the relevant artifact and the workflow's existing verification criteria.
