## Statement

Audit every MarkView-initiated agent invocation across registered providers and applicable launch profiles. Include terminal handoffs only when MarkView itself submits the prompt to the agent for execution. Ship all confirmed improvements together in the first release.

## Acceptance Criteria

- [x] The inventory covers background CLI and ACP operations, terminal handoffs where MarkView itself submits the prompt to the agent for execution, managed Cockpit steps, MarkView-initiated inter-agent actions, and Remote Work across all registered providers and applicable profiles.
- [x] Each entry identifies its entry point, prompt, selected and actual launch profiles, task type, applicable capabilities, and evidence-backed disposition.
- [x] A PR-review task staged with `submit: false` is outside the mandatory inventory and first-release verification, even if the user later submits it manually.
- [x] Terminal handoffs in scope satisfy REQ-006 and REQ-009.
- [x] The first release includes every improvement confirmed by the audit and REQ-009. Retained behavior and unconfirmed candidates have a documented rationale.
