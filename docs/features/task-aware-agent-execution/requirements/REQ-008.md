## Statement

In the first release, use the evidence-backed deep workflow by default in four scenarios: creating a research document through Research or Deep Research, using Continue / deepen, using Retry incomplete part, and using Revise With Comment. The last three operations apply to existing research documents. Each operation uses the sources and tools permitted and available to its actual launch profile. Under DEC-015, each scenario must pass the REQ-009 release gate against its own current behavior. If a scenario fails the gate, refine the deep workflow for that scenario and repeat verification before release.

## Acceptance Criteria

- [x] Creating a research document through either Research or Deep Research uses the evidence-backed deep workflow by default through the shared Research intake.
- [x] Continue / deepen on an existing research document uses the evidence-backed deep workflow by default.
- [x] Retry incomplete part on an existing research document uses the evidence-backed deep workflow by default.
- [x] Revise With Comment on an existing research document uses the evidence-backed deep workflow by default.
- [x] Each of the four scenarios uses only sources and tools that are both permitted and available to its actual launch profile under the repository settings.
- [x] Under DEC-015, each of the four scenarios passes the REQ-009 release gate against its own current behavior before the first release.
- [x] If a scenario fails the release gate, refine its deep workflow and repeat verification against its current behavior until it passes before release.
- [x] A representative broad question produces a synthesis across distinct lines of inquiry using the sources and tools available under the repository settings and actual launch profile.
- [x] Key factual claims are checked against cited source content. Project facts, external facts, AI inferences, and open assumptions remain distinguishable.
- [x] When a run is interrupted or a source is unavailable, the result preserves usable evidence and identifies the gaps.
