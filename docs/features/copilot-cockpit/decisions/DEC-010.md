## Context

The user wants long-running goals to be decomposed into sequential steps that may use different agents and existing MarkView capabilities.

## Alternatives



## Decision

Use a separate agent session for each plan step. The plan assigns an agent and describes the assignment for every step; Temporal coordinates the sequential execution of those steps.

## Reason

Different steps, such as research, implementation and code review, may require different agents.
