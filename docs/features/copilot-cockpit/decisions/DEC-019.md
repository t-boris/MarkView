## Context

Implement with AI was invoked while the feature was in backlog, but the project's Standard feature process allowed starting only from ready.

## Alternatives



## Decision

When the user starts implementation through the UI, the successful handoff should move the feature to in-progress through the workflow with start evidence.

## Reason

Boris requested that starting implementation from the UI immediately put the feature in progress.

## Consequences

The project workflow must permit the start from backlog; an unsuccessful handoff must not start work.
