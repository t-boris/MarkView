## Context

Implement with AI was invoked while the feature was in backlog, but the project's Standard feature process allowed starting only from ready.

## Alternatives



## Decision

When the feature passes Review, move its status to ready. When the user starts implementation through the UI, a successful handoff moves the feature from ready to in-progress with start evidence.

## Reason

Boris clarified that passing Review should put the feature in ready and that starting implementation through the UI should put it in progress.

## Consequences

The Review completion path must make the ready transition through the lifecycle. An unsuccessful implementation handoff must not start work; the existing ready-to-in-progress start rule retains its evidence requirement.
