## Context

A proposed flow may depend on a prerequisite whose availability is not yet known.

## Alternatives

1. Require a separate preliminary run and renewed approval before creating the main plan.

## Decision

Allow Copilot to include an initial prerequisite check in the proposed flow. If the check fails, the flow does not proceed to its subsequent steps.

## Reason

A prerequisite can be checked as part of the approved flow without requiring a separate preliminary run.
