## Context

REQ-001 currently promises that disabled capabilities cannot be used. Existing agent terminals have full user permissions and can perform actions outside an MCP action gate.

## Alternatives

1. Restrict cockpit agents to controlled actions that enforce the run policy, with no direct access to shell, files, browser, or network.
2. Allow general-purpose tools only within an isolated environment that independently enforces the run policy.

## Decision

Use the existing full-access agent terminal and pass cockpit capability controls to the agent as instructions.

## Reason

The team chose this approach for its simpler use of the existing agent terminal.

## Consequences

REQ-001 must be revised: capability controls are instructions, not enforced restrictions. Before launch, the cockpit must clearly disclose that the agent has full user permissions and can perform actions disabled in the controls. In particular, disabling fixes or deployment cannot guarantee that those actions will not occur.
