## Context

A user may select any step as the starting point, including when earlier steps have not run or their results are unavailable.

## Alternatives

1. Block execution when prerequisites are unmet or unknown.
2. Allow execution only after an explicit warning about unmet or unknown prerequisites.

## Decision

Allow the user to start execution from any selected step without requiring prerequisite verification or successful completion of earlier steps.

## Reason

The user prefers the freedom to choose the starting step and accepts responsibility for checking whether it is appropriate.
