## Context

Different stages may require different agents, such as one for research, another for implementation, and a third for code review.

## Alternatives

1. Use one persistent agent session for the entire run.

## Decision

Use a separate agent session for each process stage. Allow different agents to be assigned to different stages.

## Reason

Separate sessions support choosing an agent suited to each stage and make stage boundaries explicit.
