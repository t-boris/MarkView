## Context

Users need to correct a proposed plan by describing the desired changes in natural language.

## Alternatives

1. Support only direct editing of individual plan blocks.
2. Support both direct block editing and conversational plan refinement.

## Decision

Allow users to request plan changes by voice or text. Copilot revises the plan as a whole and updates the graph to match.

## Reason

Natural-language refinement lets users describe changes that may affect multiple steps.
