## Context

QA cleanup retains only the five most recent runs per scenario and runs linked to filed bugs. A cockpit result can therefore lose the detailed QA evidence associated with its plan and build.

## Alternatives

1. Keep existing QA retention and manual deletion rules; preserve a cockpit summary and indicate when the underlying run is unavailable.

## Decision

While a linked cockpit result exists, exclude its QA run from automatic cleanup. Allow manual deletion after warning the user about linked cockpit results. Preserve the cockpit result context and indicate that detailed QA data has been deleted.

## Reason

Preserving linked QA runs maintains detailed evidence for cockpit results while still allowing users to remove runs deliberately.

## Consequences

REQ-005 must protect cockpit-linked QA runs from automatic cleanup, define the warning shown before manual deletion, and specify the preserved result context and unavailable-details state. Retained runs may consume additional storage.
