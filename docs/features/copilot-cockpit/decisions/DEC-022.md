## Context

The person asked to reduce CI time and temporarily stop producing x86 macOS builds.

## Alternatives



## Decision

Build, test and release the macOS application and its bundled cockpit runtime for Apple Silicon arm64 only; do not run or ship an x86_64 build for now.

## Reason

The person explicitly requested an arm-only macOS build and no x86 build at present.

## Consequences

The CI build matrix and application Release architecture must contain arm64 only; the release installer must include the arm64 runtime.
