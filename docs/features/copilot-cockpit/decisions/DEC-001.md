## Context

The proposed plan can include actions governed by the run's capability controls.

## Alternatives

1. Start automatically after plan generation.

## Decision

Require explicit user approval of the proposed plan before starting a run.

## Reason

The user chose to review the plan, limits, and success criteria before execution.

## Consequences

Execution must not begin until the user explicitly approves the proposed plan.
