## Context

The user needs to refine the proposed plan while keeping the graph synchronized with it.

## Alternatives

1. Support direct editing of individual graph blocks in the first version.

## Decision

In the first version, users request plan changes by voice or text. Copilot revises the plan as a whole and updates the graph to match. Direct editing of individual graph blocks is deferred.

## Reason

This preserves voice and text refinement while keeping individual graph-block editing outside the first-version scope.
