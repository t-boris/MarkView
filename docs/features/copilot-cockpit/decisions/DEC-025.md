## Context

MarkView supports macOS 13; the previously selected PostgreSQL 17 ARM archive requires macOS 15. The user requested Apple Silicon-only builds and short CI times.

## Alternatives

1. Keep PostgreSQL 17 and drop support for macOS 13–14
2. Compile PostgreSQL from source in CI

## Decision

Package the pinned Postgres.app PostgreSQL 16 distribution, thin it to arm64, verify its minimum OS during packaging, and run Temporal against it.

## Reason

PostgreSQL 16 supports the local Temporal persistence requirements and its ARM binaries support macOS 11; using a pinned distribution preserves supported macOS versions without source compilation in CI.

## Consequences

Cockpit persistence uses PostgreSQL 16; the packaged distribution is checksum-pinned and tested with the local server.
