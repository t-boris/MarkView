## Context

The user clarified that there is one cockpit inside each window.

## Alternatives

1. Open a new cockpit each time the toolbar button is pressed.

## Decision

Provide at most one Copilot Cockpit interface per MarkView window. The toolbar button opens it or returns to the existing instance in that window.

## Reason

The user explicitly described the cockpit as a single instance within a window.
