## Context

The Copilot Cockpit is opened from a button in the top toolbar.

## Alternatives

1. Open a new cockpit tab on every click.

## Decision

When the cockpit is already open, the toolbar button opens the existing cockpit rather than creating another one.

## Reason

The user stated that there should be one cockpit for everyone.
