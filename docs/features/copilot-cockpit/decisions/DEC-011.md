## Context

The first-version scope previously limited the cockpit to one test–fix–retest template. The user clarified that the cockpit should instead accept varied goals and construct a scenario based on available capabilities.

## Alternatives

1. Limit the first version to the test–fix–retest template.
2. Provide predefined templates as the only supported scenarios.

## Decision

Support user-defined scenarios in the first version. Copilot assesses the goal against available capabilities and proposes a sequential plan with an agent and assignment for each step. If it cannot perform the requested goal, it explains that it cannot do so.

## Reason

The user wants the cockpit to support varied long-running assignments rather than a single predefined workflow.
