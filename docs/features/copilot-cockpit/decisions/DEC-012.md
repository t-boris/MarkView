## Context

Users may request goals that exceed the capabilities available to Copilot.

## Alternatives

1. Reject the entire goal when any part is infeasible.
2. Offer an executable partial plan only when it is useful, with unavailable outcomes clearly identified.

## Decision

Before execution, Copilot must clearly disclose any part of the goal it understands it cannot perform, explain the limitation, and help the user find a viable solution by offering options or alternatives where possible. It must not present an unavailable outcome as achievable.

## Reason

The user expects an honest explanation from the outset and help finding a practical way forward.
