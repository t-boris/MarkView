## Context

Runs may span an application closure or restart.

## Alternatives

1. Continue execution while MarkView is closed, provided the executor and required actions remain available.

## Decision

Pause an active cockpit run when MarkView closes and offer to continue it after reopening.

## Reason

The user selected option B.

## Consequences

Cockpit execution pauses when MarkView closes and can be continued only after the application reopens and the user chooses to continue.
