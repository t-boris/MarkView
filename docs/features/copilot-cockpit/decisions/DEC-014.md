## Context

A proposed flow may start with a prerequisite check that must pass before subsequent steps execute.

## Alternatives

1. End the run as failed and offer ways to resolve the prerequisite failure.

## Decision

When a prerequisite check fails, pause the run, show the reason, and allow the user to resolve the issue and retry the check. Proceed to subsequent steps only after the check passes.

## Reason

This allows a temporary obstacle to be resolved without creating a new run.
