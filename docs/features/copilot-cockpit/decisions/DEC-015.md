## Context

Users need to pause or stop a process and start execution from a selected step after some steps have already run.

## Alternatives

1. Restrict restart to the first incomplete step.
2. Allow restart from a selected step only when all preceding steps completed successfully.

## Decision

Provide controls to pause and stop a process, and allow the user to start execution from any selected step.

## Reason

This gives users control over long-running processes and avoids requiring every completed step to run again.
