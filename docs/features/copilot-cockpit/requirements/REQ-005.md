## Statement

Connect cockpit results to their existing MarkView artifacts and preserve their context, including when linked QA run details are deleted.

## Acceptance Criteria

- [x] Scenario results open the relevant E2E scenario, bugs open the bug section, and builds open their logs.
- [x] The final outcome distinguishes success against the stated criteria from remaining blockers.
- [x] Results remain associated with the plan and build under which they were produced.
- [x] While a cockpit result linked to a QA run exists, the run is excluded from automatic cleanup.
- [x] A user can manually delete a linked QA run after being warned that cockpit results are linked to it.
- [x] After a linked QA run is deleted, the cockpit result retains its plan and build associations and final outcome, and indicates that detailed QA data has been deleted.
