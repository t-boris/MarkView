## Statement

The system shall show a run as an instrument panel whose readings are real values of the run, let the person switch off what the approved plan allows while the run is going, and let the person send notes to the supervisor.

## Acceptance Criteria

- [ ] The run screen shows dials for altitude (steps passed or skipped of all steps), distance to destination (steps left and, once a step has passed, an estimate of the time left), fuel (agent time used against the time limit), turns (fix cycles used against their limit) and wind (refused calls, failed or interrupted steps, unanswered supervisor questions, silence, with the counts listed), and a pulse for the time since the agent's last sign of life; each dial says in words what it measures and has an accessibility label and value.
- [ ] A row of lamps shows paused, step failed, limit reached, silent and supervisor off; the banners of REQ-008 stay.
- [ ] The steps are shown as waypoints on a route with a marker at the current step; choosing a waypoint still filters the timeline to that step.
- [ ] While a run is active, levers for filing bugs, fixing bugs, deployment and the supervisor can be switched off; the cut is stored with the run, shows on the timeline, and the gate refuses the matching call from the agent's next call on, even in the middle of a step.
- [ ] A lever can be put back up only as far as the approved plan allows; a control that is off in the plan shows as locked, and create scenarios, build, checks and the limits show as fixed by the plan.
- [ ] Pause and Stop are levers of the panel and keep their current behaviour; Pause says it interrupts the running step.
- [ ] The person can send a note to the supervisor while the run is active; the note is kept in the run, the supervisor's later answers take it into account, it is added to the briefing of the next step, and it does not interrupt the running agent or widen the controls.
- [ ] Each note shows whether it is still queued, was heard by the supervisor, or is in the briefing of a step; the note field has voice input.
- [ ] A saved run shows the same panel with its final values and with levers and notes disabled; runs saved before this feature still load.
- [ ] Two windows never share a run's levers, notes or readings, and the panel in both light and dark themes and at a large font scale is checked with pictures.
