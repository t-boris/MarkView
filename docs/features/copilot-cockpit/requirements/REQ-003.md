## Statement

Execute the approved run through the defined process using available MarkView MCP actions and advisory cockpit capability controls.

## Acceptance Criteria

- [ ] A saved process definition specifies the stages and constraints for the run.
- [ ] Temporal executes the approved process and selects subsequent stages according to process conditions and results.
- [ ] MarkView provides a local Temporal service with the application on supported macOS versions.
- [ ] Each sequential step runs in a separate session of its assigned agent.
- [ ] A plan can include an initial prerequisite check; if it fails, the run pauses, shows the reason and allows the user to retry, and subsequent steps do not run until it passes.
- [ ] MarkView MCP supplies available actions, and the agent may investigate within an assigned task.
- [ ] The run uses the existing full-access agent terminal and passes the selected cockpit capability controls to the agent as instructions; those controls are advisory and are not enforced restrictions.
- [ ] Before launch, the cockpit clearly discloses that the agent has the user’s full permissions and can perform actions disabled in the capability controls, including fixes and deployment.
