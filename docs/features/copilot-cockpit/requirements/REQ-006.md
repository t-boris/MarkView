## Statement

Provide controls for an active run, require approval of changes to its remaining plan, preserve plan and result history, pause execution when MarkView closes with user-initiated continuation after reopening, and require a user decision before continuing a step that was interrupted with unknown partial effects.

## Acceptance Criteria

- [ ] The user can pause and stop an active run and start execution from any selected step.
- [ ] A change of goal or limits during a run shows the resulting changes to the remaining plan and is applied only after user approval at a safe stage boundary.
- [ ] Results already obtained remain linked to the plan version and build they were produced with.
- [ ] When MarkView closes, the active run is paused and the agent terminal and its process group are stopped; after reopening, the user is offered to continue it and warned that separately detached background processes may still be running.
- [ ] When a step was interrupted before reporting completion, the cockpit marks it as interrupted, shows its known results and evidence, states that its effects may be incomplete, and does not repeat or continue it automatically.
- [ ] Execution after an interrupted step resumes only after the user explicitly chooses how to proceed.
