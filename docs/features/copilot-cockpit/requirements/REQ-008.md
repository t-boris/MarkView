## Statement

The system shall show a run on a screen of its own that says who does what, how far the run is, what happened and what needs the person, and shall tell the person when a long run needs them.

## Acceptance Criteria

- [ ] A list of the project's runs is shown beside the run; the run that is going and runs waiting for the person come first.
- [ ] The run screen shows the coordinator, the step agent with its agent, model and working time, the supervisor with its agent, model and question counts, and the guard with its limits and refusals.
- [ ] The run records a dated timeline (start, each step's start and end, reports, bugs and fixes, supervisor questions and answers, refusals, limits, pauses, resumes, stops, finish) in its file, bounded in size; runs saved earlier still load and say they have no timeline.
- [ ] The screen shows a banner for a paused run, a failed step, an interrupted step (with the way to continue), a reached limit, and a running step with no sign of life for 20 minutes (with a way to open the agent terminal).
- [ ] The person receives a macOS notification when a run pauses, a step fails, a limit is reached, the run finishes, or a step has been silent for 20 minutes; each moment is announced once and none is sent while the person is looking at the Cockpit.
- [ ] Pause is described as interrupting the running step.
