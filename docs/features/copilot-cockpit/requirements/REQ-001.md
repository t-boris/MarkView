## Statement

Let the user define a goal and select permitted actions and limits for each run as advisory instructions to an agent running in the existing full-access agent terminal.

## Acceptance Criteria

- [ ] The user can enter a goal and configure scenario creation, checks, bug handling, builds, deployment and run limits.
- [ ] The cockpit passes the selected capability controls and run limits to the agent as instructions in the existing full-access agent terminal.
- [ ] Before launch, the cockpit clearly discloses that the agent has full user permissions and can perform actions disabled in the controls.
- [ ] When fixes are disabled, the cockpit instructs the agent to report findings without fixing them, while disclosing that this does not guarantee fixes will not occur.
- [ ] When deployment is disabled, the cockpit instructs the agent not to deploy, while disclosing that this does not guarantee deployment will not occur.
- [ ] Before launch, the cockpit identifies checks of the new version that are unavailable because building is disabled.
