## Finding

Existing QA requires an acknowledgement of data-changing actions for production. The cockpit requires approval of the plan but does not say whether that approval replaces or preserves the existing production acknowledgement. This affects whether an approved cockpit run can proceed to production actions and what the user must review.

> The user can review the plan, permitted actions, limits, and success criteria before explicitly approving the plan.

## Possible interpretations

- Cockpit plan approval also satisfies the production acknowledgement when it presents the required action list.
- The existing production acknowledgement remains a separate gate for cockpit-initiated QA.

## Resolution

Одно подтверждение плана cockpit также подтверждает действия production QA, если пользователь видит их точный список и явно подтверждает выполнение в production. Шагов меньше, но потребуется связать утверждение cockpit с конкретным планом QA. — see DEC-008.
