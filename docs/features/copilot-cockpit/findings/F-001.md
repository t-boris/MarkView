## Finding

The requirement promises enforcement, but the existing AI terminals run with full user permissions and can perform operations outside an MCP action gate. The specification does not establish whether cockpit agents must be confined to controlled actions or whether another enforcement boundary is intended. Without such a boundary, disabled repair or deployment could still be performed through shell, filesystem, browser, or network access. The existing security documentation describes the full-access behavior in docs/architecture/security.md, S4.

> Disabled capabilities cannot be used by the run.

## Possible interpretations

- Cockpit agents may use only controlled actions that enforce the run policy.
- Cockpit agents may use general-purpose tools, but those tools must be independently restricted to enforce the same policy.

## Resolution

Использовать существующий агентский терминал с полным доступом и передавать переключатели как инструкции. Это проще, но агент технически сможет выполнить запрещённые пользователем действия. — see DEC-006.
