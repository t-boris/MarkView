## Question

Какую роль релиз или развёртывание должны играть в завершении работы?

## Why it matters

Без этого нельзя определить условия перехода в завершённые состояния для разных проектов.

## Options

- **A**: Проект отдельно выбирает для feature и bug, нужен ли релиз и какое доступное событие считается доставкой.
- **B**: Если релиз обязателен, считать доставкой только опубликованный GitHub release.
- **C**: Оставить релизы вне условий переходов в первой версии.

## Recommended

A — Исследование показывает, что опубликованный релиз и фактическое развёртывание означают разные результаты.

## Answer

A. Проект отдельно выбирает для feature и bug, нужен ли релиз и какое доступное событие считается доставкой.
