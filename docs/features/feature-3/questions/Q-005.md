## Question

Какие правила должен содержать стандартный процесс, автоматически применяемый к существующим проектам?

## Why it matters

Выбор автоматического применения ещё не определяет, изменятся ли действующие условия переходов.

## Options

- **A**: Стандартный процесс воспроизводит нынешнее поведение для feature и bug.
- **B**: Стандартный процесс сразу применяет единые правила доставки к feature и bug.

## Recommended

A — Автоматическое применение безопаснее начать с привычного поведения, сохранив возможность настройки.

## Answer

A. Стандартный процесс воспроизводит нынешнее поведение для feature и bug.
