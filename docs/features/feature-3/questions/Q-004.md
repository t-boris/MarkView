## Question

Может ли человек разово обойти условие перехода, заданное политикой проекта?

## Why it matters

Разрешение пользователю менять политику не определяет, допустимы ли исключения для отдельной задачи.

## Options

- **A**: Разрешить человеку разовый обход условий с причиной, не меняя политику проекта.
- **B**: Не разрешать обход: сначала пользователь меняет политику проекта.

## Recommended

A — Это продолжает существующее поведение и не меняет правила для остальных задач.

## Answer

A. Разрешить человеку разовый обход условий с причиной, не меняя политику проекта.
