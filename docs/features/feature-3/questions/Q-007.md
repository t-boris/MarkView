## Question

Как выбирать разные правила для отдельных работ внутри одного проекта?

## Why it matters

В MarkView документационные и прикладные изменения следуют разным правилам, но способ выбора правил для задачи ещё не определён.

## Options

- **A**: Человек выбирает для задачи один из настроенных вариантов правил.
- **B**: MarkView выбирает правила автоматически по составу изменений.
- **C**: MarkView предлагает правила по составу изменений, а человек может выбрать другой вариант.

## Recommended

A — Явный выбор доступен до начала работы и не зависит от ещё неизвестного состава файлов.

## Answer

A. Человек выбирает для задачи один из настроенных вариантов правил.
