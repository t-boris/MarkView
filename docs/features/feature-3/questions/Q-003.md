## Question

Какие полномочия должна иметь новая политика на действия в GitHub?

## Why it matters

Решение использовать GitHub для синхронизации ещё не определяет полномочия на новые внешние изменения.

## Options

- **A**: Сохранить текущую синхронизацию issues; новые действия политики в GitHub выполнять после подтверждения.
- **B**: Разрешить политике автоматически выполнять заранее выбранные действия в GitHub.
- **C**: Сохранить текущую синхронизацию issues, а новые действия в GitHub только предлагать.

## Recommended

A — Так можно использовать существующую синхронизацию и явно согласовывать новые виды внешних действий.

## Answer

A. Сохранить текущую синхронизацию issues; новые действия политики в GitHub выполнять после подтверждения.
