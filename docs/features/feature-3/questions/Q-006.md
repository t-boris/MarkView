## Question

Какие подтверждения доставки должны поддерживаться в первой версии?

## Why it matters

Настройка события доставки требует определить доступные варианты и способ их подтверждения.

## Options

- **A**: Поддержать опубликованный GitHub release с автоматической проверкой и ручное подтверждение человеком другого события доставки.
- **B**: В первой версии поддержать только опубликованный GitHub release.

## Recommended

A — Это позволяет выразить доставку без GitHub и не приравнивать публикацию к развёртыванию.

## Answer

A. Поддержать опубликованный GitHub release с автоматической проверкой и ручное подтверждение человеком другого события доставки.
