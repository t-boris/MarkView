## Context

A person can change a project's workflow and selects a rule variant for each work item.

## Alternatives

1. Keep the previous rules for work items already started and apply new rules only to new work items.

## Decision

Apply changes to the selected rule variant to all subsequent transitions, including transitions of work items already started.

## Reason

A single current policy governs subsequent transitions without rewriting transition history.

## Consequences

Conditions for an ongoing work item can change, while previously recorded transitions remain in its history.
