## Context

Existing projects automatically adopt a backward-compatible standard workflow, but DEC-019 requires a person to select a rule variant for each work item. Existing work items therefore need an assignment when the workflow is adopted.

## Alternatives

1. Leave existing work items without a rule variant and require a person to select one before the next transition.
2. Apply standard rules temporarily without explicitly assigning a variant, allowing a person to select one later.

## Decision

When the standard workflow is adopted, automatically assign every existing work item a standard rule variant that preserves the previous behavior for its work-item type. A person may subsequently select another configured variant.

## Reason

This preserves existing feature and bug behavior while allowing existing work to continue without requiring a separate selection for every item.

## Consequences

Update REQ-001 and REQ-005 to permit automatic assignment during migration. Clarify DEC-019 with an exception for existing work items: their initial variant is assigned automatically, and a person may change it afterward. Subsequent transitions use the assigned variant under the current workflow.
