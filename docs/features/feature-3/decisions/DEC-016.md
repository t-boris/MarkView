## Context

Introducing project workflows to existing projects.

## Alternatives

1. Preserve existing behavior until a workflow is explicitly selected.

## Decision

Automatically apply a standard workflow template to existing projects.

## Reason

The product owner selected automatic adoption.

## Consequences

Existing projects receive a default workflow automatically; its contents still need to be defined.
