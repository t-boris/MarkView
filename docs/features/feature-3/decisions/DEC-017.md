## Context

A standard workflow is automatically adopted by existing projects.

## Alternatives

1. Apply uniform delivery rules to features and bugs immediately.

## Decision

The standard workflow reproduces existing feature and bug behavior.

## Reason

Avoid unexpected changes to transition conditions in existing projects.

## Consequences

The default workflow preserves existing feature and bug transition conditions, including their current delivery-rule differences, until a user changes the workflow.
