## Context

Work items can reference statuses and rule variants that a project user changes.

## Alternatives

1. Prevent deletion while the status or rule variant is in use.
2. Allow deletion and resolve affected work items at their next transition.

## Decision

Require a person to choose a replacement for affected work items when deleting an in-use status or rule variant.

## Reason

This permits workflow changes while keeping affected work items assigned to valid statuses and rules.

## Consequences

Deleting an in-use status or rule variant requires a human-selected replacement for affected work items.
