## Context

Different work within one project can follow different development and delivery rules.

## Alternatives

1. Select rules automatically from changed files.
2. Suggest rules from changed files and allow a person to change the selection.

## Decision

A person selects a configured rule variant for each work item.

## Reason

The choice can be made before the changed files are known.

## Consequences

A person selects a configured rule variant for each work item; selection does not depend on automatically classifying changed files.
