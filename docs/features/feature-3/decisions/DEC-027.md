## Context



## Alternatives

1. One variant for both work-item types (the standard behaviour of a feature and a bug differs, so each needs its own).
2. Free-form conditions per transition (flexible, but the evidence for each condition then has to be defined per transition).

## Decision

A rule variant belongs to one work-item type (feature or bug) and sets: (1) start evidence: an agent session only (hand-off or attached session), or an agent session or a person's note; (2) integration path: direct to the default branch (a direct commit or a pull request both count) or pull request (every unit of work must be a pull request that GitHub confirms merged: presence and merge); (3) checks: successful checks of the head commit required or not; (4) delivery event: none, a published GitHub release containing the work (verified automatically), or a named event that a person confirms; (5) acceptance: an AI may accept with evidence (as today), or only a person accepts. Statuses, transitions and who may make each transition stay in the lifecycle of the work-item type; the variant sets how the start, delivery and acceptance conditions of those transitions are met. The standard variants reproduce today: the feature variant is direct, without checks, without delivery event, agent start, AI acceptance with evidence; the bug variant takes pull request, checks and release from the project's Definition of Done and guide as they are when the workflow is adopted. Ready-made variants (pull request with checks, direct to main, manual work with a note) can be added from templates.

## Reason

These are exactly the four condition groups of DEC-025, the delivery choice of DEC-018 and the human start note, expressed as data the existing policy, collector and evaluator can read; the standard variants keep the current behaviour (DEC-017).

## Consequences

The collector reads the variant instead of the Definition of Done and the project guide. A human note is accepted as the start of manual work only in a variant that allows it; the standard variants keep requiring an agent session, and a person can still force a start with a reason.
