## Finding

Existing work items have no specified rule-variant selection, yet every subsequent transition must use one and the decision requires a person to select it. Automatic adoption and continued operation of existing work therefore need a defined assignment or selection behavior.

> A person selects a configured rule variant for each work item.

## Possible interpretations

- Existing items automatically receive a compatible standard variant, which a person may subsequently change.
- A person must select a variant for each existing item before its next transition.

## Resolution

Всем существующим задачам назначается стандартный вариант, сохраняющий нынешнее поведение для их типа. Человек может затем выбрать другой вариант. — see DEC-024.
