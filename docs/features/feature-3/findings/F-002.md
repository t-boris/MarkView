## Finding

The standard workflow must preserve existing behavior, some of which is derived from the project Definition of Done and instructions. The specification does not establish how those settings relate to an edited workflow afterward. A user can therefore receive conflicting instructions and transition decisions, or changes to existing settings may unexpectedly stop affecting transitions.

> The standard workflow reproduces existing feature and bug behavior.

## Possible interpretations

- Existing settings remain inputs to the workflow and changes continue to affect transition rules.
- Existing settings are migrated into the workflow, which becomes authoritative for transition rules.
- Both remain editable, with an explicit precedence or conflict resolution rule.

## Resolution

При принятии стандартного процесса существующие проверяемые правила переносятся в него. После этого процесс становится источником условий переходов; Definition of Done и инструкции остаются руководством для работы. — see DEC-022.
