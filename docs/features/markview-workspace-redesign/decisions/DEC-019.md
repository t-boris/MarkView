## Context

REQ-005 describes a common AI action lifecycle, but existing actions include read-only generation, file edits, long-running X-Ray analysis, and unrestricted assistant terminals. Their inputs, outputs, cancellation behavior, and review surfaces differ, so the current criteria cannot verify preservation of each workflow.

## Alternatives

1. Define shared lifecycle rules by action type, with explicit exceptions for individual actions.
2. Keep REQ-005 as the shared lifecycle requirement and add linked requirements for file changes, X-Ray, and terminals.

## Decision

Inventory every AI action, including read-only generation, file edits, X-Ray, and assistant terminals. Specify each action’s inputs, outputs, stop behavior, and review surface.

## Reason

The full inventory makes action-specific behavior and edge cases visible and gives QA a concrete basis for checking every existing capability.

## Consequences

Inventory every existing AI action. Extend REQ-005 with testable acceptance criteria for each action’s input scope, output location, partial output, failure, cancellation, review surface, and changes made outside MarkView. Resolve F-007 when the inventory and criteria are complete.
