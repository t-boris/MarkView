## Context

Q-002 clarified what preserving existing functionality means during the workspace redesign.

## Alternatives

1. Preserve all existing capabilities, commands, modes, integrations, and keyboard shortcuts while allowing controls to move.
2. Preserve the outcomes of existing workflows; allow changes to commands and keyboard shortcuts only through separate decisions.

## Decision

Preserve the outcomes of all existing workflows. Commands and keyboard shortcuts may change only after a separate decision.

## Reason

This reflects Boris's answer while making changes to familiar entry points explicit and reviewable.

## Consequences

The migration needs an inventory of existing workflows and outcome-based checks. Any proposed command or shortcut change requires a separate decision before implementation.
