## Context

The redesign includes project identity. feature-2 is verified and already specifies a persistent project color, a clickable icon beside the window title, and a thin color strip below the toolbar. The redesign has not defined how these elements fit its three-workspace shell.

## Alternatives

1. Redesign project identity independently, including its presentation and persistence.
2. Exclude project identity from the redesign and leave its placement in the new shell unspecified.
3. Adopt feature-2 as the source of truth and integrate its existing identity elements across the three workspaces.

## Decision

Adopt feature-2 as the source of truth for project identity. Retain its color assignment, persistence, clickable icon, project name, and color strip while integrating their placement into the Files, Project Map, and Work shell.

## Reason

This resolves the overlap without reopening verified product decisions or creating competing persistence rules. It also makes preservation of project identity a concrete part of the redesign migration review.

## Consequences

The migration map must show where the project name, clickable color icon, and color strip appear in the new shell and verify that switching workspaces preserves their behavior. Any later change to those feature-2 decisions requires an explicit cross-feature decision. No duplicate color persistence is planned.
