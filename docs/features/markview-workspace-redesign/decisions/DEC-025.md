## Context

Boris rejected the short lower terminal pane. Reading and interacting with a
running coding assistant requires substantially more height and width.

## Decision

The labelled Terminal control in the full-width header opens a terminal view
that fills the entire content area below the header. The file navigation,
document Contents, workspace content, and their dividers are hidden while it
is shown. Selecting Files, Project Map, or Work restores that workspace;
selecting Terminal again returns to it. Switching views keeps terminal
sessions, output, selected profile, and process state alive. `⌘3` remains the
terminal route. Keep Claude Code, Codex, Cline, Copilot, and shell profiles
and collapse prompt shortcuts by default to prioritize terminal output.

The right panel remains optional Markdown heading navigation. It is hidden by
default and never appears over the terminal.

## Consequences

Verify the terminal at the 900 × 600 point minimum and at 200% interface
text, including complete input/output visibility and row/column refitting.
Confirm that opening a file from a terminal returns to Files with the
terminal session preserved.

## Supersession

DEC-026 adds a full-height side-by-side mode so the terminal and an active
document or code view can be visible together. The focused terminal mode
remains available.
