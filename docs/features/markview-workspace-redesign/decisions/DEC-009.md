## Context

A specification stays ready and is visibly flagged when edited after handoff. The flag needs a defined clearing action.

## Alternatives

1. B. Clear the flag when the developer acknowledges the revised specification.
2. C. Keep the flag for the rest of the handoff.

## Decision

Clear the changed flag when any participant with project access marks the current specification ready again.

## Reason

This uses the existing ready action and records acceptance of the current text without adding a separate acknowledgment.

## Consequences

Marking the current specification ready again clears the changed flag. The specification remains ready throughout.
