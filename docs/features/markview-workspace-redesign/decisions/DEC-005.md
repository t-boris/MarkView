## Context

The primary journey passes from a specification author to a developer.

## Alternatives

1. Start by reviewing the specification, then move to Git work.
2. Start with Git work while keeping the specification available in Work.
3. Open the relevant files first and return to the specification through Work.

## Decision

After handoff, the developer starts in Files with the relevant project files and can return to the specification through Work.

## Reason

The product owner selected option C for Q-005.

## Consequences

The developer's handoff path should lead to Files, with a clear route back to the related specification in Work.
