## Context

F-010 found that “every existing user workflow” lacked a bounded, testable baseline. REQ-001 requires preservation of workflow outcomes, and DEC-010 requires a complete migration map.

## Alternatives

1. Check outcomes only for workflows inventoried and approved before migration.
2. Preserve documented intended outcomes, with separate decisions for known bugs and undocumented behavior.

## Decision

Preserve the outcome of every user-accessible function in a fixed version of the application throughout the workspace migration.

## Reason

A fixed release and the complete DEC-010 map provide an objective preservation boundary consistent with the team's choice to retain all existing capabilities.

## Consequences

Use a fixed application release as the REQ-001 baseline. Add an acceptance criterion to verify every item in the DEC-010 migration map, including integrations and undocumented behavior. Record any exception in a separate decision. This broadens the verification effort.
