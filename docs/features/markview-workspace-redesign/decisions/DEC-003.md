## Context

Q-001 asked which workflow should guide the first design evaluation. DEC-001 already commits to planning the full migration.

## Alternatives

1. Prioritize developers exploring an unfamiliar project.
2. Prioritize documentation authors reading and editing documents.
3. Prioritize users moving from an idea through questions and decisions to implementation.

## Decision

Prioritize the journey from an idea through questions and decisions to implementation.

## Reason

Boris selected the task and specification workflow.

## Consequences

The Work journey guides navigation and start-screen priorities for the full three-workspace migration. It does not introduce a prototype-first phase.
