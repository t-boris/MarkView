## Context

The primary user of the idea-to-implementation journey was unresolved.

## Alternatives

1. One maintainer writes the specification and implements it.
2. A specification author and a developer share the journey.
3. A developer receives a completed specification and implements it.

## Decision

Design the primary journey for a specification author and a developer.

## Reason

Boris selected the author-and-developer scenario.

## Consequences

Work should make the handoff between the specification author and developer clear while keeping both stages connected.
