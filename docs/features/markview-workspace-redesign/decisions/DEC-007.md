## Context

The author-to-developer journey uses an explicit ready handoff. The product owner selected shared project permissions for that action.

## Alternatives

1. A. Any participant with project access can mark a specification ready.
2. B. Only the assigned author can mark a specification ready and hand it to a developer.
3. C. No explicit ready state; developers infer readiness from the specification.

## Decision

Any participant with access to the project may mark a specification ready for handoff.

## Reason

This preserves a simple collaborative workflow without introducing role management.

## Consequences

Author and developer remain workflow descriptions rather than permission roles. MarkView does not restrict the ready action to an assigned author.
