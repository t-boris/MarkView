## Context

Boris clarified that the intended window has the same direct three-column
model as before: navigation on the left, active content in the center, and
the coding assistant terminal on the right. Focus and side-by-side mode
controls made the panels unnecessarily coupled. Opening the left panel must
never close the terminal.

## Decision

Put the left navigation, center workspace content, and right terminal in
independently visible, resizable columns below the full-width header. Each
column has a direct toggle. Any one, any pair, or all three may be shown.
Prevent hiding the last visible column. Toggling one column leaves the other
two visible states unchanged. Choosing Files, Project Map, or Work changes
the center's content and reveals it if hidden, without hiding the terminal.
The right column shows the assistant terminal by default and can expand to
the available window width when the other columns are hidden. `⌘3` remains
the terminal route; `⌘1` remains left navigation.

Document Contents remains an optional view in the right column, selected by
its document-specific control or `⌘2`. Returning to Terminal restores the
same assistant session. Preserve Claude Code, Codex, Cline, Copilot, shell,
Stop, Restart, transcript, selected profile, and terminal refitting. Prompt
shortcuts start collapsed to prioritize output height.

## Consequences

Remove Focus and Side by side controls. Verify every column combination,
especially left navigation opening or closing while the terminal remains
visible; verify that a single visible column cannot be hidden. Check the
right terminal at the 900 × 600 point minimum and 200% interface text.
