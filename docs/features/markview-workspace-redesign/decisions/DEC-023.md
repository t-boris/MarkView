## Context

Boris found the window controls visually detached from the tabs, the project
name cramped, and the floating left and right panels unacceptable. He asked
for a clear header above the panels with the controls placed inside it.

## Decision

Use one full-width workspace header above all content columns. Place the
navigation and context toggles, workspace destinations, project identity,
search, and common actions in that header. Give the project name comfortable
horizontal padding and enough width to read ordinary names. The left
navigation and right context panels are docked columns below the header.
At constrained widths, collapse a column behind its header toggle; opening
it restores a docked column and resizes the center. Do not float either panel
over the workspace content.

## Consequences

Update the compact layout and its 900 × 600 point checks. Keep pane toggles
and keyboard shortcuts visible or discoverable in the header and View menu.
