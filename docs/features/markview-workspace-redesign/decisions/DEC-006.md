## Context

The author-to-developer journey needs an unambiguous point at which implementation may begin.

## Alternatives

1. Explicit handoff: the author marks the specification ready and hands it to the developer.
2. No in-app handoff: the developer starts after agreeing with the author outside MarkView.

## Decision

Use an explicit handoff: the author marks the specification ready and hands it to the developer.

## Reason

Boris selected option A for Q-006.

## Consequences

Work needs a visible handoff step. The developer can then begin in Files and return to the specification in Work.
