## Context

F-001 identifies a blocker: the planned migration to Files, Project Map, and Work lacks a complete map of existing capabilities. REQ-001 requires a workflow inventory, but the inventory and its approval point are not yet defined.

## Alternatives

1. Set workspace ownership rules first, then derive and review the migration table. REQ-001 remains blocked until the mapping is complete.
2. Assign a primary workspace to each capability and document cross-workspace exceptions with an owner, entry point, and preservation check.

## Decision

Inventory each existing tab type, panel, command, menu action, and workflow. Assign its destination in Files, Project Map, or Work, including secondary entry points. Review and approve the complete migration table before implementation begins.

## Reason

A complete, approved map gives implementers a defined destination for each capability and gives QA a basis for checking preservation under REQ-001 and workspace organization under REQ-002.

## Consequences

Before implementation, approve a migration table covering every existing tab type, panel, command, menu action, and workflow, including secondary entry points. Add acceptance criteria to REQ-001 and REQ-002 that verify every mapped capability remains reachable. Existing command and keyboard shortcut changes still require separate decisions under REQ-001.
