## Context

F-006 identifies an ambiguity in REQ-003: shared search combines file names, content, and commands, but their coverage and readiness are unspecified. The current content index covers Markdown, while file navigation and commands use other sources.

## Alternatives

1. Search file names project-wide, but search content only in indexed Markdown; show context-available commands.
2. Search within the active workspace by default, with a scope selector and context-available commands.

## Decision

Search file names and content across supported readable text files in the open project. Show commands available in the current context.

## Reason

The team selected project-wide search across supported readable text files. This gives shared search consistent coverage while keeping command results relevant to the user's current context.

## Consequences

REQ-003 must define supported readable text types and exclusions, indexing progress, behavior for stale or missing results, result scope labels, and tests for coverage and index freshness. Commands are shown only when available in the current context. In-document search and local filters remain available.
