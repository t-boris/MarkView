## Question

Что должно происходить со статусом «готово», если спецификацию изменили после передачи разработчику?

## Why it matters

Разработчик должен понимать, относится ли подтверждение готовности к текущему тексту спецификации.

## Options

- **A. Keep ready**: Keep the specification marked ready when it changes. A participant explicitly changes its status if needed.
- **B. Reset ready**: Any change to a ready specification returns it to a draft state until a participant marks it ready again.
- **C. Flag changed**: Keep the ready state but visibly flag that the specification changed after handoff.

## Answer

C. Flag changed. Keep the ready state but visibly flag that the specification changed after handoff.
