## Finding

The boundary of the handed-off specification is undefined. A feature consists of an overview, requirements, questions, decisions, findings, discussion, sources, research, and possibly a plan. The spec does not say which edits set the changed flag, how deletions and external Git changes are detected, or how the developer sees the handed-off version. This also conflicts with the overview's claim that no data-model decision is needed.

> The developer can distinguish the current specification from the version that was handed off.

## Possible interpretations

- Any file change under the feature folder counts, with a snapshot of the entire folder.
- Only normative requirements and accepted decisions count.
- A handoff records a Git commit or content hashes, and the UI compares against that revision.

## Resolution

AI: При передаче сохранять неизменяемый снимок всего каталога спецификации и сравнивать его с текущим содержимым. Любое добавление, изменение или удаление файла после передачи включает отметку об изменениях; разработчик может открыть обе версии. — see DEC-012.
