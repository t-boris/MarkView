## Finding

The start-screen criteria assume a developer can resume from a handoff and reach relevant files, but no link or selection rule connects the specification to those files. They also do not define the empty state for a new project or a feature with no file links.

> A developer resuming after handoff can reach relevant files in Files.

## Resolution

AI: Выбираю явные ссылки на файлы проекта в спецификации. При возобновлении работы MarkView открывает в Files только связанные файлы; если ссылок нет или файл недоступен, показывает понятное пустое состояние и путь к спецификации в Work. — see DEC-016.
