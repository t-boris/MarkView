## Finding

“Every existing user workflow” has no bounded baseline. The original request concerns capabilities the stakeholder currently uses, while REQ-001 extends preservation to all existing workflows. The scope of third-party integrations, known bugs, and undocumented behavior is therefore unclear, making the preservation gate impossible to close objectively.

> Preserve the outcomes of all existing user workflows throughout the full interface migration

## Possible interpretations

- Preserve every user-visible capability in the current release.
- Preserve only the stakeholder's inventoried workflows.
- Preserve documented intended outcomes, allowing known bugs to be corrected.

## Resolution

Сохранять результат каждой доступной пользователю функции в зафиксированной версии приложения. — see DEC-013.
