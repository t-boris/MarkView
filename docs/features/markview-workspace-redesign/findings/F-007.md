## Finding

The AI lifecycle criterion treats actions as one type, but existing actions include read-only generation, file-changing edits, long-running X-Ray work, and unrestricted assistant terminals. Their input exposure, cancellation behavior, and review surfaces differ. The spec needs an action inventory and explicit behavior for partial output, failure, cancellation, and external file changes.

> A running action shows progress and provides a stop control.

## Resolution

Inventory every AI action, including read-only generation, file edits, X-Ray, and assistant terminals. Specify each action’s inputs, outputs, stop behavior, and review surface. — see DEC-019.
