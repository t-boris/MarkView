## Finding

The full migration has no mapping from existing screens, tab types, commands, panels, and workflows to the three workspaces. REQ-001 calls for an inventory but does not supply one or define when it must be approved. The current shell includes file, image, X-Ray, terminal, GitHub, and Insight tabs, plus specialized panels. Without a mapping, teams cannot determine what to build or verify that capabilities remain reachable.

> Organize the existing interface into Files for reading and writing, Project Map for understanding the project, and Work for specification and Git work.

## Resolution

Inventory each existing tab type, panel, command, menu action, and workflow. Assign its destination in Files, Project Map, or Work, including secondary entry points. — see DEC-010.
