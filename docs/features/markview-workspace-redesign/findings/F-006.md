## Finding

The shared search combines file names, content, and commands without specifying scope, ranking, indexing readiness, unsupported file types, or command availability. Existing full-text search is backed by the Markdown index, while file navigation and commands use different sources. The acceptance criterion therefore permits materially different implementations and cannot be tested consistently.

> A keyboard-accessible search entry point finds files, content, and commands and labels each result's scope.

## Possible interpretations

- Search all files by name but only indexed Markdown by content.
- Search all readable text files by content.
- Search only the current workspace, with commands filtered by context.

## Resolution

Search file names and content across supported readable text files in the open project. Show context-available commands. — see DEC-018.
