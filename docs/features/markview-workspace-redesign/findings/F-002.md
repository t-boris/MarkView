## Finding

The specification does not define whether handoff is a state change, an assignment to a named developer, a notification, or a navigable work item. It also does not define how relevant files are selected for the developer. These interpretations lead to different data and UI designs.

> A participant with project access can mark a specification ready and hand it to a developer.

## Possible interpretations

- Handoff only marks the feature ready, and the developer finds it independently.
- Handoff records a recipient and presents the specification and linked files to that person.
- Handoff creates a persistent work item without assigning a person.

## Resolution

AI: Выбираю постоянную запись о передаче без назначения конкретного разработчика: она доступна участникам проекта в Work и открывает для разработчика текущую спецификацию и связанные файлы в Files. Уведомления и назначение получателя не входят в эту передачу. — see DEC-011.
