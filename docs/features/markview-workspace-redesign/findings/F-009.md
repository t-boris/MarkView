## Finding

The adaptive-interface criteria name narrower windows and 200% text scale but do not define a minimum supported window size, what panels collapse, how users reach hidden actions, or whether terminal and editor content can remain usable simultaneously. The current terminal already has documented clipping bugs, so this is a concrete migration risk rather than a visual-detail choice.

> The layout keeps primary content and actions available in narrower windows and at 200% interface text scale.

## Resolution

AI: Поддерживать окно от 900 × 600 пунктов. Когда для редактора и терминала не хватает места рядом, показывать их поочерёдно на всю доступную ширину; скрытые панели и действия должны оставаться доступны через навигацию и меню. Проверять этот режим, включая масштаб текста 200%, в работающем приложении. — see DEC-015.
