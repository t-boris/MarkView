## Statement

Preserve the outcomes of all existing user workflows throughout the full interface migration, including workflows whose controls move to a different workspace. Changes to existing commands or keyboard shortcuts require separate decisions.

## Acceptance Criteria

- [ ] Inventory existing user workflows and their expected outcomes before migration.
- [ ] For every inventoried workflow, verify that the expected outcome remains achievable in the redesigned interface, including when its controls move to another workspace.
- [ ] Record a separate decision before changing an existing command or keyboard shortcut.
- [ ] Approve the complete migration map against fixed release `v2.27.0` before UI implementation; verify every mapped outcome, including integrations, menus, and undocumented user-accessible behavior.
- [ ] Record a separate decision for any preservation exception.
