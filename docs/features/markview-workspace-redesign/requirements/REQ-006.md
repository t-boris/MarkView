## Statement

Use a consistent visual system across the native window and embedded editor that remains readable across supported appearance and scale settings.

## Acceptance Criteria

- [ ] The redesigned controls and content remain usable in light, dark, and increased-contrast appearances.
- [ ] The layout keeps primary content and actions available in narrower windows and at 200% interface text scale.
- [ ] Project identity and task status remain understandable without relying on color alone.
- [ ] Frequent icon-only controls have a tooltip, accessibility label, and an alternate menu or keyboard route; ambiguous states and consequential actions retain visible text.
- [ ] At 900 × 600 points and 200% interface text, each workspace keeps primary content usable, collapsed panels/actions accessible, and editor/terminal switching explicit; terminal rows and columns refit on every visible resize.
