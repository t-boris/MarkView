## Statement

Provide a shared search entry point without removing existing specialized search and filtering tools.

## Acceptance Criteria

- [ ] A keyboard-accessible search entry point finds files, content, and commands and labels each result's scope.
- [ ] In-document search remains available.
- [ ] Existing local filters remain available where they apply.
- [ ] Search works without a configured AI assistant.
- [ ] Supported readable text types, excluded directories/files, indexing progress, stale results, and missing-file behavior are explicit and testable.
- [ ] Commands appear only when available in the current context.
