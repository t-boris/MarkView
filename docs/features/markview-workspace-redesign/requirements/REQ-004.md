## Statement

Make the first screen explain how a specification author can begin and how a developer can resume after handoff by opening relevant files, with a route to the related specification in Work.

## Acceptance Criteria

- [ ] The start screen shows a specification author how to begin.
- [ ] A developer resuming after handoff can reach relevant files in Files.
- [ ] The start screen provides a route back to the related specification in Work.
- [ ] Participants can add and inspect explicit project-relative file links before handoff.
- [ ] Resume opens available linked files, shows missing links by path, and provides browse-files and return-to-Work actions when no files are linked.
