## Statement

Make AI actions understandable at launch, during execution, and after completion.

## Acceptance Criteria

- [ ] Before an AI action starts, the interface identifies its input scope, selected assistant, and output location.
- [ ] A running action shows progress and provides a stop control.
- [ ] Actions that change files expose the resulting changes for review.
- [ ] The interface explains unavailable AI actions when no assistant is configured.
- [ ] Every action in the AI action inventory has a testable input scope, output location, progress, stop behavior, partial result, failure/retry state, and review surface.
- [ ] File changes made by an assistant outside MarkView appear for review, including after cancellation or failure.
