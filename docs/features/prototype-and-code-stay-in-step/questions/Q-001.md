## Question

How does sync know which unit of the prototype was built from which source files?

## Why it matters

Incremental sync is only as good as this mapping. The planner already names the evidence files and component files of each screen, but that list comes from the model and may be incomplete; a missed dependency leaves a stale unit.

## Options

- **A**: Take the evidence and component paths the planner already returns, verify that the files exist, and fall back to a wider rebuild when a changed file is not covered by any unit.
- **B**: Compute the mapping from the sources themselves (imports of each component file), independent of the model.

## Recommended

A, after a spike that measures on a real large application how often the named evidence misses a file that matters; B only if the spike shows A is unreliable.
