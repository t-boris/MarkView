## Question

Where does the hand-off brief go: into a new agent session of the window, into one that is already open, or onto the clipboard only?

## Why it matters

An agent that is already working in the window has context, but sending text into a running session can interrupt it; a new session is clean but starts without context.

## Options

- **A**: Start a new agent session in the window's AI panel with the brief as its first prompt.
- **B**: Let the person pick an open agent session of the window to send it to.
- **C**: Clipboard only.

## Recommended

A as the default with C always available; B only if sending into a running session is already supported safely by the app.
