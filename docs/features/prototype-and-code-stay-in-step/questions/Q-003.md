## Question

Should sync always stop and show the list of units it will rebuild, or only when the list is large?

## Why it matters

Each rebuilt unit is a paid assistant run on the person's provider. A stop on every sync adds a click for the common one-file case.

## Options

- **A**: Always show the list with Start and Cancel.
- **B**: Start at once when up to a few units are affected, ask when more (for example above five) or when a fallback or a conflict applies.

## Recommended

B, with the list always visible in the progress view while it runs.
