## Context

REQ-012 asks for a hand-off to an agent of the window; Q-004 asks where the brief goes. The implementation needed an answer to ship the action.

## Alternatives

1. Send the brief into an agent session that is already open (Q-004 option B)
2. Clipboard only (Q-004 option C)

## Decision

"Hand off to code" shows the brief for editing, lets the person pick the agent, and on "Send" opens a NEW session of that agent in the window's AI panel with the brief as its first prompt. "Copy brief" puts the same text on the clipboard instead. It never writes into an agent session that is already running.

## Reason

This is the recommended answer of Q-004 (A with C always available). A running session may be in the middle of other work, and sending text into it can interrupt it; a new session is clean, and the brief carries all the context it needs. Proposed, not settled: Q-004 is still open for Boris.

## Consequences

If Boris prefers option B, the Send button gets a session picker and the app must first prove that pasting into a busy session is safe (WorkspaceManager.assistantIsBusy exists for that).
