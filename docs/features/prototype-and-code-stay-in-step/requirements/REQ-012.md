## Statement

Prototype Studio shall offer a "Hand off to code" action that gives an agent in the window's AI panel a brief of the prototype changes since the sync baseline, so the agent changes the application code on a branch and opens a pull request.

## Acceptance Criteria

- [ ] The action is available only when the prototype changed since the baseline; otherwise it says there is nothing to hand off.
- [ ] The brief names the prototype reference, the prototype files that changed, the source components they reproduce (from the component markers), and the review instructions and summaries that led to the changes.
- [ ] The brief says that the prototype is a reconstruction with simulated data, so the agent applies the intent of the change to the real code and does not copy the prototype's markup.
- [ ] The brief is shown to the person, who can edit it and choose the agent, before anything is sent.
- [ ] Nothing is written to the project by Studio itself: the agent works under the repository's own rules (its own branch, a pull request).
- [ ] After the agent's change is in the code, an incremental sync (REQ-010) rebuilds only the components that changed and moves the baseline.
- [ ] A copy of the brief can be put on the clipboard instead of being sent.
