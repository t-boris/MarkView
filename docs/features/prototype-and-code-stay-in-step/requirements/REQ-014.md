## Statement

Prototype Studio shall show, for every unit of a prototype made from code (screen and source component), whether it matches the code, and a one-line summary, computed locally without an assistant run.

## Acceptance Criteria

- [ ] Each unit has one state: in sync (its sources and its prototype files are as at the baseline), code changed, prototype edited, both changed, or unknown (no baseline or an incomplete mapping).
- [ ] The Components list shows the state of each component, and a Sync panel lists the units by state; the states are explained in words, not only by color.
- [ ] A summary line counts the units per state, for example 9 in sync, 2 code changed, 1 prototype edited.
- [ ] The check reads and hashes the sources and compares files; it makes no assistant run and no network request, and it can be run again at any time.
- [ ] It names the changed source files of a unit and the prototype files that differ from the baseline version.
- [ ] A prototype saved before the baseline existed shows every unit as unknown and says why.
