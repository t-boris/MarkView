## Statement

"Sync from code" shall compare the current sources with the baseline of the latest version and rebuild only the units whose sources changed or are new, keep every other file exactly as it is, and save the result as a new version with a new baseline.

## Acceptance Criteria

- [ ] When no source changed since the baseline, sync says so, makes no assistant run and saves no new version.
- [ ] Before it runs, sync shows the units it will rebuild (for example 3 of 12) and why each one is affected; the person can start or cancel.
- [ ] Files of units that are not rebuilt are byte-identical after the sync, including edits made in Studio.
- [ ] A rebuilt unit replaces its files, and the reply lists the units whose Studio edits were overwritten; the earlier version stays restorable.
- [ ] A source component that is new gets its unit built; a unit whose only sources were removed is dropped, and the screen list and component list are updated to match.
- [ ] On failure or Stop the previous version, its files and its baseline are restored and nothing else changes.
- [ ] The sync does not modify application source code and makes no network request.
