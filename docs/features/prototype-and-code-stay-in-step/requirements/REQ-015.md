## Statement

An incremental "Sync from code" shall send to the assistant only the changed and new source files and the stored plan of the units it rebuilds, never a run over the whole project, and Studio shall offer a separate, explicit full rebuild.

## Acceptance Criteria

- [ ] The plan of a build (screens, purposes, routes, components, the files each was built from) is saved with the version, so a unit can be rebuilt without planning the whole project again.
- [ ] An incremental sync makes no run that reads the whole project; the files it gives the assistant are the changed or new sources of the units it rebuilds and the foundation files those units need.
- [ ] A source component that is new is planned from the new files alone and added to the stored plan.
- [ ] "Rebuild everything" is a separate action with its own name; it asks for confirmation, runs the full build as today and writes a new baseline.
- [ ] The sync reply says how many files it read and how many units it rebuilt, and the progress view names them.
- [ ] The number of assistant runs of a one-file change is bounded by the units that depend on that file, not by the size of the project.
