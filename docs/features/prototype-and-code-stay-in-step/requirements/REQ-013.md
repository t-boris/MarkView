## Statement

markview_get_prototype shall report the changes of the prototype since its sync baseline, so an agent that is given only the prototype reference can find out what changed and in which source components.

## Acceptance Criteria

- [ ] The result has a section with the prototype files changed since the baseline, the source components they reproduce, and the review instructions and summaries since then.
- [ ] When nothing changed, or the prototype has no baseline, the section says so in one line.
- [ ] The result tells the agent whether the source components named in it changed in the code since the baseline.
- [ ] Reading the prototype changes nothing on disk.
