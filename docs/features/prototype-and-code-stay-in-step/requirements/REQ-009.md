## Statement

A prototype built from code shall record, with every saved version, a sync baseline: a fingerprint of each source file it was built from and, for each unit of the prototype (foundation, screen, component page), the source files that unit was built from.

## Acceptance Criteria

- [ ] The baseline is written when the prototype is created and when it is synced, and is stored in the prototype folder next to the version it belongs to, so it is committed with the project.
- [ ] Restoring an earlier version restores that version's baseline as well.
- [ ] A review edit made in Studio changes the prototype files but not the baseline of the sources.
- [ ] A prototype saved before this feature has no baseline; this is detected and reported, never guessed.
- [ ] The baseline holds no source text, only paths and fingerprints.
- [ ] A unit's source list is checked against the files that exist; a path the assistant named that does not exist is dropped and the unit is marked as having an incomplete mapping.
