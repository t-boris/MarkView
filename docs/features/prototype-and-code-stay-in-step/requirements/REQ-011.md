## Statement

When the changed sources cannot be mapped to units reliably, or a component changed both in the code and in the prototype since the baseline, sync and hand-off shall say so before they run and fall back to the wider, safe action instead of guessing.

## Acceptance Criteria

- [ ] A prototype without a baseline, or whose mapping is incomplete for a changed file, gets a full rebuild on sync, with the reason stated before it starts.
- [ ] A change to an input shared by many units (global styles, theme, entry or shell file) rebuilds the foundation and the units that depend on it, or the whole prototype when that cannot be told, with the reason stated.
- [ ] When a component's source changed since the baseline and its unit also holds Studio edits since the baseline, sync and hand-off warn about that component by name before they run.
- [ ] The person can continue after a warning or cancel; nothing is changed by the warning itself.
- [ ] The text of every fallback and warning names the files or components that caused it.
