## Context

REQ-001 requires immutable events, while manual marks (DEC-002) may be wrong (wrong feature, wrong time, duplicate mark). Q-007 asked how users correct such mistakes.

## Alternatives

1. Void event: append a 'voided' record that excludes the original from calculations while keeping it in the log
2. Allow editing and deleting manual events only
3. Corrections are not supported

## Decision

Corrections are not supported. Recorded events, automatic or manual, cannot be edited, voided or deleted through MarkView.

## Reason

Chosen by the product owner. It keeps the model and UI minimal and fully preserves immutability.

## Consequences

Mistaken manual marks stay in the log and may distort durations and averages. Users should be careful when marking events manually. A void mechanism can be added later without breaking the append-only log.
