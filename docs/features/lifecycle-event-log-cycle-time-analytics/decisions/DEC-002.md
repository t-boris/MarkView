## Context

Lifecycle transitions happen in MarkView, git and AI agents; not all are observable by MarkView.

## Alternatives

1. Fully automatic capture from MarkView, git and AI agent actions
2. Manual marking of every transition by the user
3. Hybrid: automatic where possible plus manual marking for the rest

## Decision

Events are captured automatically for transitions MarkView can observe; remaining transitions are marked manually by the user. Each event records whether it was captured automatically or manually.

## Reason

Gives full coverage of lifecycle steps while keeping accurate timestamps where automation exists.

## Consequences

Mixed data precision; events must carry a capture-source flag so analytics can distinguish them. Manual marking UI is needed.
