## Context

DEC-005 forbids corrections, so mistakes are permanent; timestamp source and guards for manual marks were undefined.

## Alternatives

1. Current time only
2. User-entered past time
3. Block duplicates and out-of-order marks
4. Warn and confirm

## Decision

A manual mark is timestamped with the current time; back-dating is not supported. Marking shows a confirmation dialog summarising feature, stage, actor and AI model. If the stage already has an event, or a later canonical stage already has one, the dialog shows an explicit warning; the user may still confirm.

## Reason

Current-time stamps are trustworthy and simplest; confirmation plus warnings reduce permanent mistakes without blocking legitimate rework.

## Consequences

Users must mark stages when they happen; late marks inflate durations. Adds acceptance criteria to REQ-001 for confirmation and warnings.
