## Context

Users need to see step durations for one feature and compare models/steps; the scope excludes dashboards beyond basic reports.

## Alternatives

1. Only a per-project summary table, no feature-page view
2. Feature timeline + per-project table + summary across all projects on the machine

## Decision

Show an event timeline with step durations on the feature page, plus one per-project summary table of average durations by step and AI model. No charts, no cross-project summary.

## Reason

Covers both inspecting/verifying a single feature and comparing models/steps with minimal UI work, without mixing different processes across projects.

## Consequences

No cross-project model comparison for now; data volume for comparisons is limited to a single project.
