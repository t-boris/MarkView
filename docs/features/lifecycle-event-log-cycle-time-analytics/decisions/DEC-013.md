## Context

Features created before rollout, or on another machine, lack automatic early events.

## Alternatives

1. Allow manual 'idea created' mark
2. Exclude such features entirely
3. No backfill; partial data counts per step

## Decision

No backfill: automatic stages are never marked manually. Such features record events from rollout onward and contribute only steps where both boundary events exist; total idea-to-verified is not shown for them.

## Reason

Keeps automatic events trustworthy (no back-dating, consistent with F-004) while still using partial data.

## Consequences

Early analytics are sparse; AI implementation step data is available immediately for in-flight features.
