## Context

Event types, duration pairs and the automatic/manual split needed to be fixed (Q-005).

## Alternatives

1. A: Minimal six stages; automatic for idea created and spec ready, rest manual
2. B: A plus review started/finished; merge to main captured automatically via git
3. C: Fixed base list A plus user-defined custom stages

## Decision

Use the fixed list: idea created → spec ready → implementation started → implementation finished → merged to main → verified. Idea created and spec ready are captured automatically in MarkView; the others are marked manually.

## Reason

Simplest option that answers the main question (AI implementation speed per model) without git integration or custom stages that hurt comparability.

## Consequences

No review-stage visibility; four stages depend on manual marking, so data completeness relies on user discipline. Git-based capture and extra stages may be added later.
