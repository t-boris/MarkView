## Context

Actor format for automatic events and model naming were undefined; free-text model names would fragment per-model averages.

## Alternatives

1. Free text
2. Fixed configured model list
3. Pick-or-add list with normalisation

## Decision

Actor for automatic events is the git user.name of the project repository, falling back to the OS user name. Manual marks record the same human actor. The AI model is chosen from a combo list of previously used model names (trimmed, case-insensitive dedup) with an option to add a new one. The only AI-performed step for REQ-004 breakdown is 'implementation started → implementation finished'; the model is required when marking 'implementation started' and prefilled on 'implementation finished'. The step's model is the one on its start event.

## Reason

Consistent names without maintaining a fixed catalogue; one clearly defined AI step keeps the comparison meaningful.

## Consequences

Review done by AI is not broken down per model for now. REQ-002 and REQ-004 acceptance criteria need updating.
