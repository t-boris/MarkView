## Finding

The spec does not say how features that existed before this feature shipped are handled. They have no 'idea created' event. Can the user mark it manually, or are these features excluded from the analytics?

> Creating a feature records an 'idea created' event automatically.

## Resolution

AI: Для существующих фич и фич, созданных на другой машине, события не восстанавливаются; пользователь может вручную отметить любые последующие этапы, а шаги без обоих граничных событий просто не попадают в расчёт. — see DEC-013.
