## Finding

The spec does not define which MarkView state change counts as 'spec ready'. Feature statuses include 'exploring', but the transition to ready is not named. For 'questions resolved', it is unclear whether a question reopened later, or a new question added afterwards, triggers a second event.

> When a feature's spec becomes ready, a 'spec ready' event is recorded automatically.

## Possible interpretations

- Feature status changes to a specific status
- All requirements are approved
- It fires on every transition into the state, or only the first time

## Resolution

AI: 'spec ready' фиксируется при переходе статуса фичи в 'ready' (статус спецификации готова к реализации), 'questions resolved' — когда число открытых вопросов становится 0; оба события пишутся при каждом таком переходе, а для расчётов берётся правило из F-003. — see DEC-008.
