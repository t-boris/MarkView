## Finding

Events are stored outside the repository, so the spec must say how events are keyed to a project and a feature: by path, by repo remote, or by feature id. It also does not cover what happens when a repository is moved or renamed, when a feature id is renamed or the feature is deleted, when a feature is created on another machine (no 'idea created' event exists there), or when app data is reset or backed up. None of these data-loss scenarios is covered.

> Lifecycle events are stored in MarkView's local application storage (per machine)

## Resolution

AI: События ключуются по абсолютному пути корня проекта и id фичи; при перемещении/переименовании репо или id фичи история теряет связь (осознанное ограничение); удаление фичи не удаляет события; сброс данных приложения = потеря журнала, бэкап не предусмотрен. — see DEC-012.
