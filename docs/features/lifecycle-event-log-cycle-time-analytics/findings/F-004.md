## Finding

Mistakes are permanent, yet no criterion requires a confirmation step, prevents duplicates or enforces order checks when marking. The spec also does not say whether a manual mark uses the current time or lets the user pick a past timestamp. That choice decides how the 'implementation started' time is captured.

> Corrections are not supported.

## Possible interpretations

- Timestamp is the time the user clicks
- User enters a past time

## Resolution

AI: Ручная отметка ставит текущее время без выбора прошлого времени, требует подтверждения с показом фичи/этапа/модели и предупреждает (но не блокирует) при повторе или нарушении порядка. — see DEC-010.
