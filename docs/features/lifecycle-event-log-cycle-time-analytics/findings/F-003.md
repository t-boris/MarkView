## Finding

Nothing prevents duplicate marks, and corrections are impossible (DEC-005). Automatic events can repeat when questions reopen. The spec does not say whether the first or last event of a type is used, or what happens when an end event comes before its start event, which would give a negative duration. The same applies to REQ-004 averages. Another open point is whether 'consecutive' means adjacent in the canonical order or the nearest recorded stage when a stage is skipped.

> Each pair of consecutive canonical stages that both have events shows the elapsed duration between them.

## Possible interpretations

- Use the first occurrence
- Use the latest occurrence
- Block duplicate manual marks

## Resolution

AI: Для длительностей берём первое событие начала этапа и последнее событие конца; шаг — между соседними каноническими этапами, пропуски не сшиваются; если конец раньше начала — длительность не показывается и шаг исключается из средних. — see DEC-009.
