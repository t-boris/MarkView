## Question

Какой список этапов жизненного цикла считать каноничным (и какие из них фиксируются автоматически)?

## Why it matters

Определяет типы событий, пары для расчёта длительностей и что именно автоматизировать, а что отмечать вручную (Q-002).

## Options

- **A**: Минимум: идея создана → спека готова → реализация начата → реализация завершена → смержено в main → проверено; авто — создание идеи и статус спеки в MarkView, остальное вручную
- **B**: Как A, плюс «ревью начато/завершено»; авто также merge в main через git
- **C**: Фиксированный базовый список A, плюс пользователь может добавлять свои этапы

## Answer

A. Минимум: идея создана → спека готова → реализация начата → реализация завершена → смержено в main → проверено; авто — создание идеи и статус спеки в MarkView, остальное вручную
