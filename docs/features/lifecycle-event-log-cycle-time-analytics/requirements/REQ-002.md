## Statement

Each event shall carry metadata identifying at least the project, the feature, the event type, the actor (human or AI agent), the capture source (automatic or manual) and, when an AI performed the step, the AI model/agent name.

## Acceptance Criteria

- [ ] Every stored event has project, feature, event type, actor and capture source
- [ ] Events for AI-performed steps include the model/agent name
- [ ] Manually marked events let the user specify the AI model/agent when relevant
