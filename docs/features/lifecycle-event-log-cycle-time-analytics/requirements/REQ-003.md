## Statement

The system shall compute elapsed time between events of the same feature, including per-step durations and total idea-to-verified time, and show them on the feature page as a chronological event timeline with the duration of each step.

## Acceptance Criteria

- [ ] The feature page shows all recorded lifecycle events in chronological order with timestamp, actor, AI model (if any) and capture source (automatic/manual).
- [ ] Each pair of consecutive canonical stages that both have events shows the elapsed duration between them.
- [ ] When both 'idea created' and 'verified' events exist, the total idea-to-verified duration is shown.
- [ ] Steps with a missing start or end event show no duration rather than a guessed value.
