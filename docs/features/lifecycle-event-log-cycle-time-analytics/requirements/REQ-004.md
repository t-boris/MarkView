## Statement

The system shall provide one per-project summary table showing average step durations aggregated by lifecycle step and by AI model, to reveal faster models and bottleneck steps. Cross-project aggregation and charts are out of scope.

## Acceptance Criteria

- [ ] The project summary table lists each canonical step with its average duration across the project's features that have both boundary events for that step.
- [ ] For AI-performed steps, averages are additionally broken down per AI model.
- [ ] Each average shows the number of features it is based on.
- [ ] Only features of the current project are included; no cross-project summary is offered.
