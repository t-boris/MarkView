## Statement

The system shall record an immutable, timestamped event in MarkView's local application storage whenever a feature passes one of the canonical lifecycle stages: idea created, questions resolved, spec ready, implementation started, implementation finished, review done, CI passed, merged to main, verified. Idea created, questions resolved and spec ready are recorded automatically; the other stages are marked manually by the user.

## Acceptance Criteria

- [ ] Creating a feature records an 'idea created' event automatically.
- [ ] When the last open question of a feature is resolved, a 'questions resolved' event is recorded automatically.
- [ ] When a feature's spec becomes ready, a 'spec ready' event is recorded automatically.
- [ ] The user can manually mark implementation started, implementation finished, review done, CI passed, merged to main and verified for a feature.
- [ ] Only the nine canonical event types can be recorded.
- [ ] Recorded events cannot be edited or deleted through MarkView.
