## Context

GitHub has no 'Implemented' state. Sync must map implemented/verified/archived doc statuses onto the linked issue, and there is no preview step (DEC-001).

## Alternatives

1. Close the issue (state closed, reason completed)
2. Only add an 'implemented' label without closing
3. Label for implemented, close for verified/archived

## Decision

Sync closes linked open issues with reason 'completed' for items whose status is implemented or later. Already-closed issues are left as they are; sync never reopens issues.

## Reason

Closing is GitHub's standard signal that work is done and removes the drift entirely; a single rule keeps sync and its report simple.

## Consequences

A wrong close notifies subscribers and is visible; the result report must clearly list closed issues so they can be reopened manually. No labels are managed. Q-001 is superseded by this decision.
