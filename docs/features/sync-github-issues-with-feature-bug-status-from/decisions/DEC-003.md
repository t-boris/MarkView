## Context

Sync could either push doc status to GitHub only, or also pull GitHub issue state back into Markdown front matter.

## Alternatives

1. Two-way sync with conflict resolution rules and writes to Markdown files

## Decision

Sync only propagates Feature/Bug status from the docs to linked GitHub issues. It never reads GitHub state back into the docs and never modifies Markdown files.

## Reason

Docs remain the single source of truth; no conflict-resolution rules are needed.

## Consequences

Issues closed manually on GitHub are not reflected in the docs; users update doc status themselves.
