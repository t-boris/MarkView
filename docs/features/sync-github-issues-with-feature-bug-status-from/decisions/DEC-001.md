## Context

Sync changes GitHub issues in bulk; mis-matched links could update wrong issues. The scope originally mentioned a preview.

## Alternatives

1. Preview the list of changes and require confirmation, with per-item deselection
2. Apply immediately, then show a result report

## Decision

Sync applies changes immediately without a preview; a detailed result report is shown afterwards. The preview is removed from scope.

## Reason

Speed and a single-click workflow were preferred by the product owner over an extra confirmation step.

## Consequences

Wrong matches become visible only after the fact, so the report must name each changed issue and the change; link-matching must be conservative (the review should check that PR references are not treated as issues).
