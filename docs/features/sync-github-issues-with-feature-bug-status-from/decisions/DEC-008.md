## Context

One GitHub issue may be linked from several Features/Bugs with different statuses, making REQ-003 contradictory.

## Alternatives

1. Close if any linked item is implemented
2. Close only if all linked items are implemented or later

## Decision

Sync aggregates all items linking to the same issue. The issue is closed as completed only if every linked item has status implemented, verified or archived. Otherwise it is left untouched and reported as skipped with reason 'linked to item(s) not yet implemented', listing those items. Each issue is updated at most once per run.

## Reason

Conservative rule consistent with 'never change issues linked to items with an earlier status' and with sync never reopening issues — a premature close cannot be auto-corrected.

## Consequences

REQ-003 needs an acceptance criterion for shared issues; sync must build an issue→items index before applying changes.
