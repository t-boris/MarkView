## Finding

The spec doesn't say which credentials are used (the gh CLI or a token), which write scope they need, how the target repository is determined, or what happens when the user isn't authenticated or lacks write access. There is also no requirement covering rate limits or retries.

> The Issues tab shall provide a manual Sync action

## Resolution

AI: Использовать существующую интеграцию через gh CLI и её авторизацию (без отдельного токена). Репозиторий берётся из origin-remote проекта, а явные ссылки на другой owner/repo используются как есть. Перед запуском проверяются вход в gh и право записи: без них Sync блокируется с подсказкой `gh auth login`/`refresh`. Ошибки по отдельным issue, включая rate limit, попадают в отчёт как failed без автоматических повторов, кроме одного повтора при secondary rate limit. — see DEC-004.
