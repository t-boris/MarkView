## Finding

If one linked item is implemented and another is still planned, the rule gives contradictory results for the same issue.

> Sync never reopens issues and never changes issues linked to items with an earlier status.

## Possible interpretations

- Close the issue if any linked item is implemented
- Close only if all linked items are implemented or later

## Resolution

AI: Закрывать issue, только если все связанные с ним элементы в статусе implemented или позже; иначе пропускать с причиной «связан с незавершённым элементом». — see DEC-008.
