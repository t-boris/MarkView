## Statement

After sync the user shall see a report listing each processed item with its linked issue and outcome: updated, unchanged, skipped (with reason) or failed (with error).

## Acceptance Criteria

- [ ] The report is shown after every sync run, including runs with failures.
- [ ] Each updated entry names the issue and the change applied, so wrong matches can be spotted and corrected manually.
- [ ] A failure on one issue does not stop processing of the remaining issues.
