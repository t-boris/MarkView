## Statement

Sync shall match each Feature/Bug to its GitHub issue(s) using the existing link sources (github field, front matter issue/issues, issue links, 'issue #n').

## Acceptance Criteria

- [ ] Items with no linked issue are skipped and counted as 'unlinked'
- [ ] An item linked to several issues updates all of them
