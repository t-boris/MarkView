## Statement

The Issues tab shall provide a manual Sync action that immediately applies one-way updates from Feature and Bug statuses in the docs to their linked GitHub issues, without a preview or confirmation step. Sync shall never modify Markdown files or doc statuses.

## Acceptance Criteria

- [ ] Triggering Sync updates linked GitHub issues without a preview or confirmation dialog.
- [ ] After Sync, no Markdown file in the project has changed.
- [ ] A GitHub issue closed manually does not change the status of its linked Feature/Bug.
