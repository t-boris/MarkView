## Statement

For each Feature/Bug whose status is implemented, verified or archived, sync shall close every linked open GitHub issue with state 'closed' and state_reason 'completed'. Issues that are already closed are left untouched and reported as unchanged. Sync never reopens issues and never changes issues linked to items with an earlier status.

## Acceptance Criteria

- [ ] Given a feature with status implemented and a linked open issue, when Sync runs, then the issue is closed with reason 'completed' and the report shows 'updated'.
- [ ] Given the same item with status verified or archived, the same closing behaviour applies.
- [ ] Given a linked issue that is already closed (any reason), when Sync runs, then it is not modified and the report shows 'unchanged'.
- [ ] Given an item with status planned or implementing, when Sync runs, then its linked issues are not modified.
- [ ] Given an item linked to several issues, each open linked issue is closed and reported separately.
