## Finding

The app implementation and automated verification are complete, but the required
signed, notarized release cannot currently be produced on this Mac:

```text
security find-identity -v -p codesigning
0 valid identities found

xcrun notarytool history --keychain-profile markview-notary
Error: No Keychain password item found for profile: markview-notary

gh secret list --repo t-boris/MarkView --json name
[]
```

Only the login keychain is configured. The existing Publish Release workflow is
an alternative signing path, but no repository signing secrets are configured.
Its documented fallback would publish an unsigned prerelease, which does not
satisfy the requested deployment and must not be used as if it did.

## Required resolution

Make the project's Developer ID Application signing identity (including its
private key) and `markview-notary` keychain profile available locally, or configure
the existing CI signing/notarization secrets. Credentials must not enter this
specification, logs, source control or an assistant message.

Continue the verified feature PR, green CI, merge and local Release compilation.
Keep deployment explicitly incomplete until the signed, notarized installer can
be built, published, installed and verified. Do not replace the installed signed
application with an unsigned build or report the overall objective complete.
