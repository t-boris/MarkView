## Statement

The reader shall support in-document search, text selection and copying using existing PDF text layers, and activation of internal and external links; OCR is excluded.

## Acceptance Criteria

- [x] Search locates embedded text across pages and navigates to matching content.
- [x] Users can select and copy embedded text where document permissions permit.
- [x] Image-only pages provide no recognized-text search, selection, or copying; mixed documents retain these capabilities on pages with text layers.
- [x] Internal links navigate to their document destinations; external links follow the application's applicable URL-safety conventions.
- [x] No OCR is offered or started automatically.

Verification: `implementation/verification.md`, `tools/tests/pdf-reader-tests.sh`.
