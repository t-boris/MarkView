## Statement

Users shall be able to open and read PDFs, including multipage documents, inside MarkView using a read-only reader with essential reading controls, thumbnails, document outlines when present, in-document text search, text selection and copying, and internal and external links. Scanned pages shall be displayed without OCR; search, selection, and copying shall use existing text layers only. Reader OCR, saved highlights and notes, and new PDF workspace-search or AI integration are excluded from this release. Existing PDF feature-source ingestion shall remain unchanged.

## Acceptance Criteria

- [x] Opening a PDF displays its rendered pages in a MarkView tab; reopening the same file selects its existing tab.
- [x] The reader supports multipage PDFs and provides essential reading controls for navigating their pages.
- [x] The reader displays page thumbnails that users can select to navigate to the corresponding pages.
- [x] When a PDF contains a document outline, the reader displays it and supports navigation to its destinations.
- [x] Users can search existing text layers within the open PDF and navigate to matching results.
- [x] Users can select and copy text from the PDF where an existing selectable text layer is available.
- [x] The reader displays scanned pages without performing OCR; image-only pages provide no text-search matches or selectable or copyable text.
- [x] Users can follow internal PDF links to their destinations within the document.
- [x] Users can activate external links contained in the PDF.
- [x] Reading does not modify the source PDF.
- [x] The reader does not provide saved highlights or notes in this release.
- [x] This release adds no PDF workspace-search or AI integration; opening a PDF does not initiate AI processing or add its contents to workspace search.
- [x] Existing PDF feature-source ingestion remains unchanged and continues to extract embedded text without OCR.
