## Statement

The reader shall render every page of multipage PDFs, including image-only scans, preserving visual content and page order without performing OCR.

## Acceptance Criteria

- [x] Users can navigate from the first page to the last page in text-based, scanned, and mixed-content PDFs.
- [x] Scanned pages remain readable through page rendering even when they contain no text layer.
- [x] Reading controls include zoom, fit-to-page, page navigation, thumbnails, and navigation through the document outline when present.

Verification: `implementation/verification.md`, `tools/tests/pdf-reader-tests.sh`.
