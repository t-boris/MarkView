## Statement

If the answer cannot be produced (AI error, timeout, empty result), the right panel shall show a clear message with the reason and a retry action, and X-Ray highlights shall still be shown if available.

## Acceptance Criteria

- [x] An empty or failed answer never results in a silently blank panel
- [x] The message includes a retry action that re-runs the question
- [x] Highlights already computed remain visible

Implementation and verification: [2.23.0 verification](../implementation/verification.md).
