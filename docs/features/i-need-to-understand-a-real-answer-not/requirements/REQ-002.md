## Statement

For questions about a project part, the answer shall explain what the part is, why it exists, how it works, and where it came from, drawing origin from current documents (features, decisions, requirements, research), code, git history and pull requests, and citing them.

## Acceptance Criteria

- [x] Answer contains what/why/how/origin sections or equivalent content
- [x] Origin cites at least one document, commit or PR when such exist
- [x] If no origin source is found, the answer states so explicitly instead of omitting it
