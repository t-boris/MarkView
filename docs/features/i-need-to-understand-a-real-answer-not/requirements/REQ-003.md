## Statement

The code, documents, components and deployment nodes the answer relies on shall be highlighted in X-Ray, and every source cited in the answer shall be a link that reveals that place in X-Ray or opens the document.

## Acceptance Criteria

- [x] Every cited source in the answer is clickable
- [x] Clicking a code/component/node source selects it in X-Ray
- [x] Clicking a document source opens it
