## Statement

The answer shall offer a Save action that creates a new research document in the existing docs/research RES-nnn format with the question, answer and cited sources; answers are not saved automatically.

## Acceptance Criteria

- [x] Save creates a new RES-nnn file without overwriting existing ones
- [x] The file contains the question, the answer and the source list
- [x] Nothing is written to docs/research unless the user saves
