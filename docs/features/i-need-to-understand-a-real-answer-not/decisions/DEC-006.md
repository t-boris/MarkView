## Context

REQ-003 needs a concrete reachability rule.

## Alternatives

1. Separate evidence list only
2. Highlights only, no links

## Decision

Each cited source in the answer is a clickable link that selects/highlights that place in X-Ray or opens the document/commit.

## Reason

Makes the answer verifiable in one click.

## Consequences

Answer schema must carry source references.
