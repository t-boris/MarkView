## Context

The user reported getting only the visual 'where'. XRaySearch already requests an `answer` field shown in the details panel, so the likely gap is content focused on location rather than meaning and origin. The user asked the facilitator to decide.

## Alternatives

1. A: No answer at all — focus on generation reliability
2. B: Answer present but not noticed — focus on visibility only
3. C: Answer present but location-only — focus on content (what/why/origin/how)

## Decision

C as the primary fix: the answer prompt and context must produce what/why/how/origin, not location. Visibility (DEC-002) and an explicit failure state cover A and B.

## Reason

The schema already produces an answer, so a missing answer is less likely than a weak one. Fixing content is the change the user feels, and cheap safeguards for visibility and failure remove the need for further diagnosis.

## Consequences

The prompt for I Need to Understand must be changed and git/PR history supplied (DEC-001). A location-only answer counts as a defect. Answer generation failures must be surfaced to the user.
