## Context

Q-001/Q-005 asked which symptom the user saw; the cause is unknown (inference). Q-002 duplicates the already answered Q-004.

## Alternatives

1. Reproduce first and fix only the observed cause
2. Fix only visibility

## Decision

Fix all three possible causes: the answer must always be present (or an explicit error shown), be visually primary, and cover meaning and origin, not only location. Q-002 is resolved by DEC-002 (expanded answer in the X-Ray right panel).

## Reason

Covering all three is cheap relative to further discovery and removes the uncertainty; each on its own would still be a defect.

## Consequences

Needs an explicit empty/failed-answer state and content guidance in the prompt; slightly larger scope.
