## Summary

The user's original request asks to rework "I Need to Understand" so that its result is an actual answer to the question the person is trying to understand, not only an X-Ray view. Today the question is passed to the AI and X-Ray highlights where things are, but no explanatory answer is visible to the user. The example given: asking what a certain part of the application is and where it came from in the documentation did not produce an answer.

## Origin

intake

## Content

Я хочу, чтобы ты переделал функциональность I need to understand. То есть результат этой функциональности должен быть ответ на тот вопрос, который человек пытается понять. И это не просто x-ray. Это x-ray с ответами на вопрос, что это такое, почему оно там находится. То есть если есть вопрос про что-то. Пока что ты делаешь просто такой же вопрос в AI и задаешь x-ray, но ответа, кроме визуального, где это, например, находится, ты не видишь. То есть я, например, задал вопрос, что такое вот там часть какая-то аппликация у нас есть, откуда она взялась в документации и все остальное. И ответа пока не получил.
