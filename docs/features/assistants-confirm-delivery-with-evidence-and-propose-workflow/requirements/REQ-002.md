## Statement

The system shall let any assistant started in a MarkView window read the project's workflow through MCP and learn its format from MarkView itself, with the same tool list for every assistant that Connect Agents registers.

## Acceptance Criteria

- [ ] markview_get_workflow returns the project's workflow in the file format with its name and revision, and says in words what each status, transition and process allows
- [ ] The guide has a topic that documents the format: statuses and their roles, transition rules (kind, from, to, what each of person, AI and MarkView needs), processes (start, integration, checks, delivery event and who confirms it, acceptance), with examples; a check fails when an allowed value in the code is missing from the guide
- [ ] The workflow tools are in the project MCP server, which is registered for Claude Code, Codex, Copilot, Cline and Antigravity; a check fails when one of them is not covered
- [ ] The guide says what the model cannot express today (MarkView moving an item by itself on an event, other than completion on delivery evidence) so that an assistant says so instead of inventing a field
