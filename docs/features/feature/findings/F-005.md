## Finding

Persistence is required, but the specification does not say whether the preference is application-wide or per workspace, what happens before the user chooses a size, or how an invalid stored value is handled. The repository documents an existing editor-size value in web `localStorage` (`docs/architecture/configuration.md`), so separating the new preference from that value should be explicit.

> Persist the selected font size as an application preference.

## Resolution

AI: Хранить общий масштаб как настройку всего приложения, общую для окон и рабочих пространств, отдельно от существующего размера редактора. При отсутствии значения использовать 100%; некорректное или выходящее за диапазон сохранённое значение сбрасывать к 100%. — see DEC-011.
