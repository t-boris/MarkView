## Finding

“Interface text” does not distinguish application chrome from document content rendered outside the editor, such as Markdown preview and code preview. The current editor slider affects the rendered view and code view (`markview-edit.js` and `markview-code.js`); the requirement only exempts “editor text.” Define which control owns those reading surfaces.

> Exclude editor text, whose size remains controlled independently by the existing editor slider.

## Possible interpretations

- Markdown and code previews follow the editor slider as they do today.
- Markdown and code previews follow the application setting.
- The two previews have different ownership rules.

## Resolution

AI: Оставить Markdown preview и code preview под управлением существующего ползунка редактора. Общая настройка меняет элементы интерфейса вокруг них, но не текст документа в этих представлениях. — see DEC-009.
