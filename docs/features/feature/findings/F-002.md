## Finding

The specification gives no default, minimum, maximum, step, or unit for the application setting. Without these, the control, stored value, and large-text acceptance checks cannot be specified consistently.

> Provide an application font size setting for interface text

## Resolution

AI: Задать общий размер как масштаб в процентах: 100% по умолчанию, диапазон 80–200%, шаг 10%. Масштабировать исходные размеры текста каждой области, сохраняя их относительную иерархию. — see DEC-008.
