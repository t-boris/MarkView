## Finding

The accepted rule requires wrapping or scrolling whenever the selected size does not fit. The embedded terminal uses xterm.js with fixed character cells and PTY sizing (`MarkView/Resources/Editor/terminal.html`); wrapping terminal output as ordinary interface text can change terminal program output. Specify terminal-specific behavior, including reflow and resizing, while preserving the selected glyph size.

> The selected size is preserved in constrained areas; text wraps or the area scrolls when needed.

## Possible interpretations

- Resize terminal rows and columns and let the terminal or running program handle wrapping.
- Allow horizontal scrolling of terminal output.
- Require visual wrapping without changing PTY columns.

## Resolution

AI: В терминале менять размер символов по общему масштабу и пересчитывать число строк и столбцов PTY при изменении размера терминала или шрифта. Перенос строк оставить терминалу и запущенной программе; не добавлять отдельный визуальный перенос. — see DEC-010.
