## Context

DEC-003 excludes editor text from the application font size setting, while DEC-004 includes it. Q-006 asked the owner to resolve the conflict.

## Alternatives

1. A. Use the application font size as the editor base, with the existing slider adjusting editor text relative to it.
2. B. Keep editor text independent; only the existing editor slider changes its size.

## Decision

Choose B. The application font size setting applies to interface text, including AI responses, settings, terminal, sidebars, labels, and buttons, but does not change editor text. The existing editor slider alone controls editor text size.

## Reason

Boris selected option B in response to Q-006.

## Consequences

REQ-001 excludes editor text from the application setting. The editor-specific clauses of DEC-002 and DEC-005, and the behavior specified by DEC-004, are superseded by this resolution. DEC-003 remains consistent with it.
