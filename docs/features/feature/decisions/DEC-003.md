## Context

The application font size must cover AI responses, settings, terminal, sidebars, labels, and buttons. The existing editor slider needs a defined relationship to that setting.

## Alternatives

1. A. One size: replace the editor slider with the application setting.
2. B. Separate editor: keep the editor slider independent of the application setting.
3. C. Override: use the application setting as the editor default, with a separate editor override.

## Decision

Keep the editor font size independent. The application font size setting does not change editor text; the existing editor slider controls it.

## Reason

The product owner selected option B to preserve separate control of editor text.

## Consequences

The application setting controls text outside the editor. The existing editor slider continues to control editor text independently.
