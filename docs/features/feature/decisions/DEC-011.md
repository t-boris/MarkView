## Context

REQ-003 requires persistence but does not define scope, initialization, or invalid-value handling. The editor size already has a separate web localStorage value.

## Alternatives

1. Store a separate value per workspace
2. Store the value alongside the editor size in web localStorage
3. Clamp invalid stored values to the nearest bound

## Decision

Store the application font scale as an application-wide preference, separate from the editor's localStorage size. Use 100% when no valid in-range value exists.

## Reason

A single application preference matches the feature's scope and prevents coupling to the independent editor slider.

## Consequences

The setting behaves consistently across windows and restarts; invalid saved data cannot produce an unsupported scale.
