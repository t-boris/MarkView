## Context

The embedded xterm.js terminal uses fixed character cells and reports its dimensions to a PTY.

## Alternatives

1. Allow horizontal scrolling of terminal output
2. Visually wrap terminal output without changing PTY columns

## Decision

Scale terminal glyph size with the application setting, refit terminal rows and columns, and report the resulting dimensions to the PTY. Leave line wrapping to normal terminal and program behavior.

## Reason

PTY resizing preserves terminal semantics while accommodating larger character cells.

## Consequences

Terminal glyphs retain the selected size, while available rows and columns may change and running programs receive the new PTY dimensions.
