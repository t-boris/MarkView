## Context

The user selected full interface coverage for Q-001.

## Alternatives

1. Scale text throughout the application, including the editor, AI responses, settings, terminal, sidebars, labels, and buttons.
2. Scale only main content and AI responses, leaving utility text and controls at their current sizes.

## Decision

Apply the application font size setting throughout the interface, including the editor, AI responses, settings, terminal, sidebars, labels, and buttons.

## Reason

This matches the user's answer to Q-001.

## Consequences

The selected size must be supported across dense interface areas as well as reading surfaces.
