## Context

Q-002 asked how the new setting should interact with the existing editor font-size slider.

## Alternatives

1. One shared size controlled by the application setting
2. An application-wide base size with a separate editor adjustment

## Decision

Use the application font size as the base size throughout the interface, including the editor. Keep the editor slider as a local adjustment that affects only editor text.

## Reason

The product owner chose to retain editor-specific control while giving the application setting an effect there.

## Consequences

This supersedes DEC-003 and the editor exception in REQ-001. The application setting provides the base size for editor text; the editor slider changes only editor text.
