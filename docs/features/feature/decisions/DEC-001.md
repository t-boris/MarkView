## Context

The application contains narrow panels and controls where larger text may not fit.

## Alternatives

1. Keep the selected font size and wrap text or allow scrolling when space is limited.
2. Automatically reduce font size in narrow panels and controls.

## Decision

Preserve the selected font size. Wrap text or allow scrolling when necessary.

## Reason

Boris selected this behavior for text that does not fit.

## Consequences

Text remains at the user's selected size; some areas may need wrapping or scrolling.
