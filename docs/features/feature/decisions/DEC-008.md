## Context

The application setting has no defined default, unit, range, or increment.

## Alternatives

1. Use one absolute point size for all interface text
2. Use named presets such as Small, Medium, and Large

## Decision

Use a percentage scale with a 100% default, an 80–200% range, and 10% increments. Apply it to each covered text style's existing base size.

## Reason

A relative scale supports one control across interface areas that currently use different text sizes.

## Consequences

The setting and stored value have a defined range and unit; existing typographic differences remain proportional.
