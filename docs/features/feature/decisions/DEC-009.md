## Context

The existing editor slider affects rendered Markdown and code views, while REQ-001 excludes only editor text explicitly.

## Alternatives

1. Make both previews follow the application setting
2. Give Markdown preview and code preview different controls

## Decision

Treat Markdown preview and code preview text as document content controlled by the existing editor slider. Treat their surrounding controls as interface text controlled by the application setting.

## Reason

This preserves the current slider behavior and gives document content a consistent owner.

## Consequences

Document content has one size control across editing and preview modes; surrounding interface text follows the application setting.
