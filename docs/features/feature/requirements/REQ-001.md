## Statement

Provide an application font size setting for interface text, including AI responses, settings, terminal, sidebars, labels, and buttons. Exclude editor text, whose size remains controlled independently by the existing editor slider. Preserve the selected size in constrained areas by wrapping text or allowing scrolling.

## Acceptance Criteria

- [ ] Changing the application font size changes text in AI responses, settings, terminal, sidebars, labels, and buttons.
- [ ] Changing the application font size does not change editor text.
- [ ] Changing the existing editor slider changes editor text size without changing the application font size or text elsewhere.
- [ ] The selected size is preserved in constrained areas; text wraps or the area scrolls when needed.
