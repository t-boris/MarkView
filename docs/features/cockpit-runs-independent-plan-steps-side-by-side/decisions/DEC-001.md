## Context

The planner must say which steps are independent. A plan is a sequence: the workflow walks one index (state.Current), and starts, revisions and the prerequisite checks are index based (workflow.go:139-146, :258; CockpitPlan.selectingStart).

## Alternatives

1. An `after` list per step (a dependency graph)
2. Steps run side by side whenever the planner sets a flag, wherever they are

## Decision

A step may carry an optional group label; adjacent steps with the same label run together as one stage of the sequence. The plan stays a sequence of stages, and every index-based start, revision and prerequisite check stays valid at a group boundary.

## Reason

The planner gives no step ids (the app assigns UUIDs after parsing), indices shift when steps move, and a graph would replace the linear walk, the start step, the revision step and the prefix-based prerequisite checks.

## Consequences

Independent steps that are not adjacent are not run together; the planner orders them next to each other.
