## Statement

The system shall show a "Parallel steps" switch in the plan's guardrails, on in every new plan, and run no steps together while it is off.

## Acceptance Criteria

- [ ] Every new plan (a feature draft or a goal of the person's own) starts with "Parallel steps" on; controls that cannot be read and plans saved before the switch existed have it off.
- [ ] With the switch off the planner is not told about groups, every group label is removed and the managed review is a single review.
- [ ] The switch shows in the guardrails and in the approval summary; changing it changes the plan's steps, so the plan must be checked again.
- [ ] A plan with the switch off encodes as before (the switch is left out of the JSON when off).
