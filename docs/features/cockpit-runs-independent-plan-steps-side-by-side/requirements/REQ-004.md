## Statement

The system shall run each member of a group as an attempt of its own and show every running member on the run screen.

## Acceptance Criteria

- [ ] Each member opens its own agent terminal, one-use ticket and watchdog; one member's continuation, progress or answer never replaces another's.
- [ ] Progress, quiet time, questions to the supervisor and log events are attributed to the member's own step.
- [ ] The run screen, the flight path and the run list show every running member at once.
- [ ] A member's answer is saved against its own step whatever order the answers arrive in, and two answers arriving together are both saved.
