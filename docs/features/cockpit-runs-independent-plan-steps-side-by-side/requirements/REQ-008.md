## Statement

The system shall compose a managed run's review as a group of two reviews by different agents that run together, when the project has two agents to review besides the implementer's choice.

## Acceptance Criteria

- [ ] With "Parallel steps" on, the composed managed plan has two adjacent review steps in one group, by two different available agents; the first is the chosen reviewer.
- [ ] Both reviews are prerequisites; after the group, a failed review pauses the run as a failed prerequisite does today, and a retry runs the failed review again.
- [ ] The fix step receives the findings of both reviews, and the re-verification checks every fix from either review.
- [ ] When only one agent can review, or the switch is off, the plan keeps one review step as today.
