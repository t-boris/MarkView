## Statement

The system shall start every member of a group at the same time, wait for all of them, and then go on with the plan by the rules it uses for one step.

## Acceptance Criteria

- [ ] All members of a group are started before any of them ends, and the next step starts only after every member has ended.
- [ ] Each member receives the results recorded before the group; the group's results are recorded in plan order, whatever order the members end in.
- [ ] A member that fails does not stop the others; after the group a failed prerequisite member pauses the run as a failed prerequisite does today (a retry runs the failed members again), and a failed member that is not a prerequisite lets the run go on.
- [ ] Stop or pause while a group runs cancels every running member; the run then stops or waits as it does today after an interrupted step.
- [ ] A revision that arrives while a group runs waits for the group's end.
- [ ] The behaviour is behind a new workflow version marker, and a run started before it behaves as today.
