## Statement

The system shall hold every member of a group read-only, whatever the Fix bugs control says, and fail the group's members when the project changed during the group.

## Acceptance Criteria

- [ ] Each member's prompt says it runs beside other steps and must not change source files, commit or create scenarios.
- [ ] MarkView compares the project before and after the whole group; a source change, a commit or a new scenario fails every member and names what changed.
- [ ] The Fix bugs control does not loosen this check for group members.
