## Finding

The Whisper API rejects uploads larger than 25 MB, and long recordings cost money on the user's key. DEC-003 encourages long dictation, but the spec sets no cap and does not say how too-long audio is handled (auto-stop, chunking or error). The existing Terminal limit, if any, should be checked and documented.

> suits long dictation

## Resolution

AI: Переиспользовать лимит Terminal, если он есть; иначе ограничить запись 10 минутами с автоостановкой и последующей транскрипцией, с показом таймера и предупреждением за 30 секунд; без разбиения на части. — see DEC-008.
