## Finding

The spec does not say where the error appears (inline on the field or as an alert). It also does not cover what happens when the transcript is empty or silent, or when the user denied permission earlier and must go to System Settings. It should also note that the app needs NSMicrophoneUsageDescription, which Terminal likely already has.

> shows an error and leaves the existing field text unchanged

## Resolution

AI: Ошибки показывать inline под полем (не alert); пустой транскрипт — ничего не вставлять и показать «Речь не распознана»; при ранее отклонённом доступе — сообщение со ссылкой на Системные настройки → Конфиденциальность → Микрофон; проверить наличие NSMicrophoneUsageDescription. — see DEC-011.
