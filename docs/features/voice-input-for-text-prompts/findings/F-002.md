## Finding

The spec does not say what happens in these cases: the user closes or cancels the intake sheet mid-recording, focus moves to another field, the user starts the mic on a second field, the key is removed during recording, or the user edits the text or moves the cursor while transcription is in progress. It also does not define which cursor position is used for insertion (at start or at stop) or how to cancel without inserting text.

> the first click starts recording, the second click stops it

## Possible interpretations

- Stop recording and discard audio on close
- Only one recording can run at a time across fields
- Insert at the cursor position captured when recording stops

## Resolution

AI: Одновременно идёт только одна запись; закрытие/отмена intake или удаление ключа останавливает запись и отбрасывает аудио без вставки; Esc или повторный старт на другом поле отменяет текущую запись; смена фокуса запись не прерывает; текст вставляется в исходное поле в позицию курсора на момент завершения транскрипции (если поле не в фокусе — в конец), поле остаётся редактируемым. — see DEC-007.
