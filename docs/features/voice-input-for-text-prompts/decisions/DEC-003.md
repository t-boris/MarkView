## Context

Whisper returns text after recording ends; the Terminal already has a dictation control.

## Alternatives

1. Push-to-talk: record while the button is held, insert on release
2. Toggle with incremental chunked insertion during speech

## Decision

Click to start, click again to stop; the full transcript is inserted at the cursor after transcription completes, matching Terminal dictation.

## Reason

Consistent with the existing Terminal behavior, simple on Whisper, suits long dictation.

## Consequences

No live text while speaking, so a clear recording/transcribing indicator is required (REQ-003). Chunked streaming is not planned.
