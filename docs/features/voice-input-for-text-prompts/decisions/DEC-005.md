## Context

Voice input in the intake fields needs a speech-to-text engine. The Terminal tab already transcribes speech with OpenAI Whisper, using the key from Settings.

## Alternatives

1. Apple Speech framework (SFSpeechRecognizer)
2. macOS system dictation (Fn Fn) with a hint button
3. Cloud service (OpenAI Whisper API), same as Terminal

## Decision

Use the same OpenAI Whisper transcription as the existing Terminal dictation.

## Reason

The user chose to keep dictation consistent with the Terminal. This reuses existing code and the existing OpenAI key setting, and is consistent with DEC-001 through DEC-003.

## Consequences

Audio is sent to OpenAI and needs a configured key (the control is hidden without one, DEC-002). Dictation does not work offline. Transcription is billed to the user's key.
