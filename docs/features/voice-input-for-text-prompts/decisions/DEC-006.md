## Context

Scope IN and accepted fact SRC-001 promise voice input in all text prompts, contradicting DEC-004.

## Alternatives

1. Expand DEC-004 to all text prompts
2. Update Scope and mark fact superseded

## Decision

Scope IN lists only intake-flow fields; 'other text prompts' moves to OUT as future work; the SRC-001 fact about all text prompts is marked superseded by DEC-004.

## Reason

DEC-004 is the later, explicit user decision; the spec must be internally consistent.

## Consequences

Scope text and fact list are edited; no requirement changes.
