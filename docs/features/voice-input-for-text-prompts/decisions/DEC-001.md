## Context

Users may dictate in Russian or English while specifications are kept in English. Terminal dictation already detects language automatically.

## Alternatives

1. System language with a switch in Settings
2. Language picker next to the microphone button
3. Automatic detection, as in Terminal dictation

## Decision

Detect the spoken language automatically, matching the existing Terminal dictation behavior; no language setting or picker.

## Reason

The user chose consistency with the Terminal and zero configuration.

## Consequences

No language UI is needed. Transcripts are kept in the spoken language; no translation. Short or mixed-language utterances may be misdetected — the user fixes them by editing.
