## Context

Error placement, empty transcript and previously denied permission were undefined.

## Alternatives

1. Inline message on field
2. Modal alert

## Decision

Errors appear inline below the field and do not block typing. An empty or silent transcript inserts nothing and shows 'No speech recognized'. If mic access was previously denied, the message includes a button opening System Settings > Privacy > Microphone. The app must have NSMicrophoneUsageDescription (verify the existing Terminal entry).

## Reason

Non-blocking feedback suits a sheet with multiple fields.

## Consequences

REQ-004 gains acceptance criteria for these cases.
