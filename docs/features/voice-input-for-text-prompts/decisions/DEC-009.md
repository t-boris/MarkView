## Context

'Answers to intake questions' could include Q-doc answers, resolution dialogs and chat.

## Alternatives

1. Only FeatureIntake answer inputs
2. All spec-answer fields

## Decision

Only free-text answer inputs rendered inside FeatureIntake (including custom answer text) get the mic. Q-document custom answers, resolution dialogs and chat reply are out of scope. REQ-001 lists the fields by view name.

## Reason

Consistent with DEC-004 and the narrowed scope.

## Consequences

REQ-001 acceptance criteria are updated with an explicit field list.
