## Context

DEC-009 gives the mic to "free-text answer inputs rendered inside FeatureIntake". The intake
sheet (`IntakeSheet`) has no answer inputs: it has one text field shared by New Feature, New
Bug and I Need to Understand. Questions are answered later in the Feature tab and on bug
question cards, which DEC-009 already excludes.

## Alternatives

1. The intake sheet's text field only
2. Also the "answer in your own words" fields on feature and bug question cards
3. The intake sheet for New Feature and New Bug, but not I Need to Understand

## Decision

The mic goes on the intake sheet's text field, for all three kinds (they share the field). No
other field gets it.

## Reason

The user chose the literal reading of DEC-009. The intake flow has no separate answer fields.

## Consequences

REQ-001's "intake question-answer fields" means nothing extra. Feature-tab and bug question
answers stay without voice input. Adding voice input there later is a separate change.
