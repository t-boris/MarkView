## Context

Dictation (as in Terminal) uses Whisper, which requires an OpenAI API key in Settings. Text prompts need defined behavior when the key is missing.

## Alternatives

1. Hide the mic control until the key is set
2. Show the control; on click explain the key is required and link to Settings
3. Show a disabled control with a hover tooltip

## Decision

The mic control is hidden on all text prompts while no OpenAI key is configured in Settings; it appears once a key is set.

## Reason

Keeps the UI uncluttered and avoids a control that can only fail; consistent with the key being an opt-in setting.

## Consequences

Discoverability relies on Settings/README documentation. Implies the Whisper engine (the same one as Terminal) is used, pending formal closure of Q-001. Controls must react to the key being added or removed.
