## Context

Audio goes to OpenAI; disclosure and temp-file cleanup were unspecified.

## Alternatives

1. Document only
2. Document and require cleanup

## Decision

README and the OpenAI key help text in Settings state that dictated audio is sent to OpenAI for transcription. Temporary audio files are deleted immediately after transcription completes, fails or is cancelled.

## Reason

Informed consent and consistency with 'OUT: audio storage'.

## Consequences

New acceptance criteria in REQ-004; README update.
