## Statement

The free-text input of the intake sheet (new feature description, new bug description, and the I Need to Understand question, which share one field; the sheet has no separate answer fields, DEC-012) shall offer a voice input control, shown only when an OpenAI (Whisper) API key is configured in Settings. Other text inputs, including the Markdown editor, are out of scope.

## Acceptance Criteria

- [ ] With an OpenAI key configured, the intake sheet's text field (New Feature, New Bug, I Need to Understand) shows a mic control.
- [ ] Without an OpenAI key, the intake sheet shows no mic control.
- [ ] The Markdown editor, code-editor and terminal inputs do not get a new mic control from this feature.
