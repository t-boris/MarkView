## Statement

The free-text inputs of the intake flow (new feature description, new bug description, and answers to intake questions) shall offer a voice input control, shown only when an OpenAI (Whisper) API key is configured in Settings. Other text inputs, including the Markdown editor, are out of scope.

## Acceptance Criteria

- [ ] With an OpenAI key configured, the new-feature description, new-bug description and intake question-answer fields each show a mic control.
- [ ] Without an OpenAI key, none of these fields show a mic control.
- [ ] The Markdown editor, code-editor and terminal inputs do not get a new mic control from this feature.
