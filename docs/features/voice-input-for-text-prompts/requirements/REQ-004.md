## Statement

The app shall request microphone permission and degrade gracefully when access is denied or transcription fails; a missing API key is handled by hiding the control (REQ-001), not by an error.

## Acceptance Criteria

- [ ] Denied microphone permission shows a clear message explaining how to grant it
- [ ] A transcription failure (network, API error, invalid key) shows an error and leaves the existing field text unchanged
- [ ] The user can keep typing in the field after any failure
