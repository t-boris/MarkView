## Statement

Dictated speech shall be transcribed by the same OpenAI Whisper transcription used by the existing Terminal dictation, with the spoken language detected automatically and no translation, and inserted at the cursor position in the active field, where it remains editable.

## Acceptance Criteria

- [ ] Transcription uses the same Whisper-based service and OpenAI key as Terminal dictation.
- [ ] Russian speech yields Russian text and English speech yields English text, with no language setting.
- [ ] Transcribed text is inserted at the cursor position, not appended to or replacing the whole field.
- [ ] The inserted text can be edited like typed text.
