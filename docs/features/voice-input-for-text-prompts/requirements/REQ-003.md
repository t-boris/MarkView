## Statement

The mic control shall work as a toggle: the first click starts recording, the second click stops it. While recording, the UI shall clearly indicate that the microphone is listening; after stop, a transcribing state is shown until the text is inserted.

## Acceptance Criteria

- [ ] Clicking the mic control while idle starts recording and shows a visible recording indicator on that field
- [ ] Clicking the mic control again stops recording and shows a transcribing state
- [ ] No partial text is inserted while recording; the full transcript is inserted once after transcription completes
- [ ] Behavior matches the existing Terminal dictation control
