## Question

Кому и в каком окружении должна быть доступна ссылка на изменённое превью?

## Why it matters

Передача ссылки уже запрошена, но её получатель и необходимость доступа вне проекта не определены.

## Options

- **A**: Ссылка предназначена AI-агенту с доступом к тому же проекту.
- **B**: Получатель должен открывать превью в браузере без локального проекта и MarkView.
- **C**: Нужны оба сценария.

## Recommended

A — Это продолжает существующий процесс передачи контекста агентам; внешняя публикация пока не заявлена явно.
