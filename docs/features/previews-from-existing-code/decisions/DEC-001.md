## Context

The feature needs a defined relationship between existing code and the editable preview.

## Alternatives

1. Execute the existing application interface.

## Decision

AI shall reconstruct the existing interface and its scenarios as a standalone editable prototype.

## Reason

The user explicitly selected reconstruction.

## Consequences

The preview is an independent artifact; reconstruction limitations must be disclosed.
