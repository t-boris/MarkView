## Context

REQ-003 asks for a copyable preview reference that an AI agent with access to the same project can resolve to the saved prototype. Plan item I-5 left open whether the reference follows the latest saved version or identifies a fixed one.

## Alternatives

1. Latest by default with an optional version in the reference.
2. Always a fixed version number in the reference.

## Decision

The reference identifies the prototype only, not a version. Resolving it always returns the latest saved version of the prototype with its files, assumptions, review history and SPEC.md when available. The reference carries no version number; older versions stay reachable through the existing prototype tools.

## Reason

Boris chose "always the latest version" on 2026-11-03: the reference is a pointer to the ongoing review, and an agent working from it should see the current state of the preview without needing a new link after every accepted edit.

## Consequences

A reference stays valid across edits and reopenings as long as the prototype exists. A missing prototype is reported explicitly. Studio shows and copies one reference per prototype.
