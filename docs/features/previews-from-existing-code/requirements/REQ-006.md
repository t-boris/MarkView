## Statement

A code-derived prototype shall offer a "Sync from code" action that reconstructs the preview again from the current state of the selected sources and saves the result as a new version.

## Acceptance Criteria

- [x] Studio offers "Sync from code" for prototypes created in code mode; it is not offered for requirements-driven prototypes.
- [x] Sync runs the same reconstruction as creation (same scope, mode and prompts) against the current source files and saves the result as a new version with its own assumptions and gaps.
- [x] Edits accepted before the sync stay in the version history and can be restored as before; the sync never discards them silently.
- [x] The review conversation is kept and records the sync as an entry in the review history.
- [x] Sync does not modify application source code and performs no network requests.
