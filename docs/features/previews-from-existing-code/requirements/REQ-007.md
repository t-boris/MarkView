## Statement

A code-derived prototype shall keep a link between its parts and the source components they reproduce, so that the user can go from a selected preview part to the component and from a component to its places in the preview, and view a component on its own.

## Acceptance Criteria

- [x] A component is a component file in the sources (React, Vue, Svelte, Angular component files; a template or HTML file for plain pages). The reconstruction marks prototype elements with the component file they reproduce.
- [x] When the user points at an element in Studio, the source component (file path) of that element or its nearest marked ancestor is shown, with an "Open source" action that opens the file in a MarkView editor tab.
- [x] Studio has a Components list for the prototype; selecting a component highlights its instances in the preview, and pointing at an element selects its component in the list.
- [x] A component can be shown on its own: an isolated view that renders only that component with simulated data, inside the prototype, which can be reviewed and edited like a screen.
- [x] Links survive saving, reopening and version restoration, and are available to connected agents through the prototype tools.
- [x] Where the reconstruction could not attribute an element to a component, no link is shown and the gap is disclosed; no link is invented.
