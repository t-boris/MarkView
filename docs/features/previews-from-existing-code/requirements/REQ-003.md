## Statement

The user shall be able to pass a link identifying the edited preview to an AI agent with access to the same project as a reference for implementation changes.

## Acceptance Criteria

- [ ] The user can copy a preview reference link for an AI agent with access to the same project.
- [ ] Using that reference, the connected agent can identify and retrieve the saved prototype, its version, files, assumptions, review history and SPEC.md when available.
- [ ] The reference remains usable after closing and reopening the prototype.
- [ ] Handoff requires no external publication and does not automatically apply preview changes to application source code.
