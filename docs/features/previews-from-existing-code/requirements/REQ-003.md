## Statement

The user shall be able to pass a link to the edited preview as a reference for changing the implementation.

## Acceptance Criteria

- [ ] The user can obtain a reference to the edited preview and include it in an implementation change request.
- [ ] The intended recipient can access the preview referenced by that request within the agreed access scope.
