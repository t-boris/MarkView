## Statement

MarkView shall support creating an interactive preview from existing project code.

## Acceptance Criteria

- [ ] A user can initiate preview creation using existing project code as the source.
- [ ] A separate requirements document is not required to initiate creation.
- [ ] The resulting preview represents the interface implemented by the supplied code; the required fidelity is subject to the product decision.
