## Statement

MarkView shall use AI to reconstruct an interactive, standalone editable prototype from existing project web-interface code.

## Acceptance Criteria

- [ ] The user can select existing project files or folders as reconstruction sources; selecting none uses the whole project, following the existing source-selection convention.
- [ ] The first version supports web interfaces, including Electron browser renderers.
- [ ] Generation uses the existing implementation as the reference for layout, styling, navigation and interactions within the selected scope, rather than designing a new interface from requirements.
- [ ] The result is a standalone interactive prototype using simulated data and requiring neither the original application nor its backend to run.
- [ ] Unresolved assumptions and known reconstruction gaps are disclosed; unavailable behavior is not presented as verified reproduction.
- [ ] Creating the preview does not modify application source code.
