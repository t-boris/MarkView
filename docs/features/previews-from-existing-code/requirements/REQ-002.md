## Statement

A code-derived preview shall support the established Prototype Studio editing, review, versioning and approval/export workflow.

## Acceptance Criteria

- [x] Code-derived previews support the existing Studio workflow: chat and voice requests, element pointing, screenshots and image attachments.
- [x] Accepted edits create saved versions; version restoration and conversation persistence work as for existing prototypes.
- [x] Approval produces SPEC.md and the existing implementation ZIP with the prototype and review history.
- [x] Preview edits remain confined to the prototype and do not automatically update or synchronize application source code.
