## Statement

A preview created from code shall support the established prototype editing and review workflow.

## Acceptance Criteria

- [ ] The user can request changes through the existing preview review workflow.
- [ ] Accepted changes are visible in the preview.
- [ ] The generated preview supports the established Studio capabilities for element pointing, saved conversation, version history, reopening, and approval.
