## Summary

The user requests a MarkView workflow that starts with a preview generated from existing code and continues with familiar preview editing. The user also wants to share a preview link to guide implementation changes; the source does not specify execution versus reconstruction, supported application types, or recipient access.

## Origin

intake

## Content

Я хочу, чтобы у нас была возможность генерить превью из существующего кода. То есть, чтобы он сделал буквально из этого кода превью. И дальше мы могли бы работать с превью из кода прямо как обычно. То есть, редактировать его, потом отсылать ссылку на превью для изменения имплементации и так далее. Я хочу, чтобы в MarkView появилась такая функциональность.
