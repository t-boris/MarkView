## Finding

The current browser excludes files that MarkView cannot open. The new “all” category could preserve that behavior or expose every filesystem item, producing materially different browsing and file-management capabilities.

> filter by name and by file category: all, folders, or openable files

## Possible interpretations

- “All” means folders and openable files, matching the current browser.
- “All” means all filesystem items, including files MarkView cannot open.

## Resolution

«Все» показывает папки и все файлы, включая те, которые MarkView не умеет открывать. — see DEC-003.
