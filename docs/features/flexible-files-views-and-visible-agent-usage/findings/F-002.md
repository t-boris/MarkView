## Finding

The tree is described as expandable and based on a lazily loaded model, but “displayed hierarchy” does not establish whether a name search discovers matches inside collapsed or not-yet-loaded folders. Retaining ancestors does not resolve how those matches are found.

> Name search is scoped to the browsed directory in Icon and List views and to the displayed hierarchy in Tree view.

## Possible interpretations

- Search recursively across the project root and linked folders, including collapsed folders.
- Search only nodes currently loaded or visible in the tree.

## Resolution

Искать по имени рекурсивно в корне проекта и всех подключённых папках, включая свёрнутые и ещё не загруженные каталоги. — see DEC-001.
