## Statement

The system shall let the user hide the files and folders that Git ignores, as a filter of Files next to the hidden-items filter.

## Acceptance Criteria

- [x] The Files filter menu has a Hide Git-ignored toggle, offered when the project folder is inside a Git repository. It is off by default, so ignored items stay visible (dimmed) as they are today.
- [x] With the toggle on, every ignored file and folder (for example node_modules or build output) is absent from the Icon, List and Tree views, and from Tree search results; folders that only contain non-ignored items stay.
- [x] The toggle is independent of the hidden-items toggle: dot-prefixed items are hidden by the hidden filter whether or not Git ignores them, and ignored items without a dot stay visible while only the hidden filter is on.
- [x] The toggle persists across app restarts together with the other filter choices, and an active filter is visible in the filter control.
- [x] Linked folders outside the project's repository have no ignore data, so the toggle does not affect them.
