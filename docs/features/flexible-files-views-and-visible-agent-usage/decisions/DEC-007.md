## Context

AC-3 lists the categories all, folders and openable files but does not say whether folders stay visible under Openable files. Without folders, Icon and List views could not be navigated and Tree view would lose its ancestors.

## Alternatives

1. Openable files shows only openable files and hides folders.

## Decision

All shows folders and every file (DEC-003). Folders shows only folders. Openable files shows folders and the files that have a viewer (DEC-004). A name query applies on top of the category.

## Reason

DEC-003 says the openable category narrows the view, and folders are needed for navigation in every view.

## Consequences

An empty folder under Openable files still appears. Proposed by the AI; Boris has not confirmed it.
