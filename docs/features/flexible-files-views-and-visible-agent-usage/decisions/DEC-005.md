## Context

DEC-003 makes All show every file, and its Consequences require the specification to define how unsupported files (see the decision on openable files) are displayed and which actions they have. Today a click opens any file in the viewer as text, and a binary is refused. Boris answered on 2026-11-08.

## Alternatives

1. A click opens the file with the system default app (risk: a single click launches an .app, .command or script).
2. Unchanged: a click tries the text viewer and a binary is refused.

## Decision

An unsupported file shows a generic document icon and is slightly dimmed. A click only selects it (nothing opens). Its context menu offers Open with Default App and the file-management actions that apply to any file: rename, move, move to Trash, compress, copy path, show in Finder, open Terminal here, and the Git stage and ignore actions. X-Ray, Discuss, New from This Document, Implement with AI and Export PDF Book are not offered. Drag and drop, multi-selection and the selection bar work as for any file.

## Reason

Boris chose it: nothing is launched by accident, and the file is still visible and manageable.

## Consequences

Opening an unknown text file as text needs a separate step (rename it or use the editor's Open command); this is accepted by Boris.
