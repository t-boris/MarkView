## Context

Tree view uses an expandable, lazily loaded hierarchy. The previous search scope did not establish whether matches inside collapsed or unloaded folders could be found.

## Alternatives

1. Search only previously loaded tree nodes, including nodes inside collapsed folders.
2. Search only nodes visible under the current expansion state.

## Decision

Search recursively by name across the project root and all linked folders, including collapsed and not-yet-loaded directories.

## Reason

The team chose a complete workspace-wide search rather than results that depend on which folders have already been loaded or expanded.

## Consequences

Search must traverse unloaded directories and retain the ancestors needed to reach matches. Searches may take time in large directories or encounter inaccessible locations.
