## Context

The Files category filter includes an “All” option, but its scope was ambiguous because the current browser excludes files that MarkView cannot open.

## Alternatives

1. Show only folders and files that MarkView can open.
2. Show folders and all files, including files that MarkView cannot open.

## Decision

The “All” category shows folders and all files, including files that MarkView cannot open.

## Reason

The team chose to make all files visible in the Files browser.

## Consequences

The specification must define how unsupported files are displayed and which actions are available for them. The openable-files category remains available to narrow the view.
