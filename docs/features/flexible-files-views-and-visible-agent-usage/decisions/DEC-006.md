## Context

DEC-002 moves access to Project Cycle Time to the top bar but does not say how it is presented. The AI asked in discussion.md whether to show a button or a value; plan item I-5 listed it as an open product choice. Boris answered on 2026-11-08.

## Alternatives

1. A button with a value (for example the median cycle time): needs a choice of which value, and takes more width.

## Decision

Add one compact icon button to the workspace top bar, beside the agent usage indicators. It opens the existing Cycle Time summary sheet. The Project Cycle Time item is removed from the Features panel menu.

## Reason

Boris chose the button: it costs no width in narrow windows and reuses the existing summary.

## Consequences

No value is visible without opening the summary.
