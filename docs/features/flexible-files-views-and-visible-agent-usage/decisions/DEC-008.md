## Context

AC-5 says view, filter and sort choices persist across restarts. A name query is typed text, not a setting, and Reveal in File Tree can ask for an item that the active filters hide.

## Alternatives

1. Persist the name query too (a restart could open an apparently empty list).
2. Reveal refuses to show an item the filters hide.

## Decision

Persist the view mode (Icon, List, Tree), the hidden-items toggle, the category and the sort field and direction, globally like the sort today. Do not persist the name query. Reveal in File Tree clears the name query, resets the category to All when it would hide the item, and turns the hidden toggle on when the item is hidden or inside a hidden folder.

## Reason

A reveal request means the person wants to see that item; the settings are restored by the person afterwards.

## Consequences

Reveal can change a persisted setting. Proposed by the AI; Boris has not confirmed it.
