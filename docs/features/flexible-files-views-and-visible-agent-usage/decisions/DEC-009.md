## Context

AC-2 asks for a virtual top level where the project root and the linked folders are siblings, and AC-5 keeps creation in the chosen destination. The virtual level has no filesystem location, so nothing can be created there.

## Alternatives

1. Open the browser at the virtual level every time (an extra click for projects without linked folders).

## Decision

Files still opens inside the project root. The breadcrumb starts with a Workspace crumb, and ".." from the project root or from a linked folder's root goes to the Workspace level, which lists the project root and every linked folder as sibling folders. At that level the New File, New Folder and New Graph buttons are replaced by Link Folder. In Tree view the Workspace level is the top of the tree, and new items are created in the selected folder (the folder of a selected file), or in the project root when nothing is selected.

## Reason

Keeps the common case (no linked folders) one click shorter while giving linked folders the same rank as the root.

## Consequences

Proposed by the AI; Boris has not confirmed it.
