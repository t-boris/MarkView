## Summary

The original request describes a date-first workflow for choosing a historical commit and comparing it with the current code in X-Ray. It also expresses the desired focus on highlighted changes while retaining existing overlays such as complexity and size.

## Origin

intake

## Content

У нас в X-Ray есть возможность сравнить код с открытым пиаром, то есть сделать пиар-ревью. Я хочу, чтобы была еще возможность сравнить текущий код с любой датой. Если ты выбираешь дату и смотришь, какие у тебя есть коммиты, ты выбираешь, с каким коммитом ты хочешь сравнить. И весь X-Ray будет сосредоточен именно на этой разнице. Выделены именно хайлайты те части, которые были изменены. Мы можем накладывать все остальное, сложность, размер и так далее. Но сравнивать это, например, с какой-нибудь датой. Датой выбирать, а потом выбирать коммит.
