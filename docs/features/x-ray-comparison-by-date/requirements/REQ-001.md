## Statement

Provide a date-first workflow for selecting a baseline commit from the history of all locally available branches, limited to commits whose committer timestamps, converted to the user's local time zone, fall on the selected calendar day.

## Acceptance Criteria

- [ ] The user selects a calendar day before selecting a baseline commit.
- [ ] The picker offers commits from all locally available branches whose committer timestamps, converted to the user's local time zone, fall on the selected calendar day.
- [ ] When no commits match the selected day, the picker communicates that no commits are available for that day.
