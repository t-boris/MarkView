## Statement

Highlight the historical comparison in X-Ray and provide both a focused map and a full architectural map, including clearly marked deleted files with access to their diffs.

## Acceptance Criteria

- [ ] The comparison highlights changed parts.
- [ ] The user can switch between a focused map of affected parts and their necessary context and a full map with changes highlighted.
- [ ] The user can inspect the changes for an affected file.
- [ ] Both maps show deleted files as clearly marked nodes with access to their diffs.
- [ ] The focused map includes the necessary context for deleted files.
