## Statement

Allow existing applicable X-Ray overlays to be used alongside the historical comparison without losing the identification of changed parts.

## Acceptance Criteria

- [ ] Existing applicable overlays, including complexity and size, can be used while examining the historical comparison.
- [ ] Changed parts remain identifiable when an overlay is applied.
