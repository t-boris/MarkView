## Question

Из какой истории выбирать коммиты?

## Why it matters

Одна и та же дата может содержать разные коммиты в разных ветках.

## Options

- **A**: Показывать историю текущей ветки.
- **B**: Показывать коммиты всех доступных локально веток.
- **C**: Дать выбрать ветку и показывать её историю.

## Recommended

A — Для сравнения текущего кода история текущей ветки даёт наиболее понятный исходный контекст.

## Answer

B. Показывать коммиты всех доступных локально веток.
