## Context

The commit picker needs a history scope.

## Alternatives

1. Show only current-branch history.
2. Let the user choose a branch first.

## Decision

Offer commits from all locally available branches.

## Reason

The user selected all locally available branches.

## Consequences

The baseline can come from a branch other than the current one.
