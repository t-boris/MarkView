## Context

The date determines which historical commits are offered.

## Alternatives

1. Show commits up to and including the selected day.

## Decision

Show commits associated with the selected calendar day only.

## Reason

The user selected the exact-day interpretation.

## Consequences

A selected day can have no matching commits.
