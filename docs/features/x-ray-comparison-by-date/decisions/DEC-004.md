## Context

The comparison needs to make changes visible in architectural context.

## Alternatives

1. Show only a focused map.
2. Show only the full map with highlights.

## Decision

Provide both a focused map and a full map with changed parts highlighted.

## Reason

The user selected both viewing modes.

## Consequences

The comparison supports switching between a focused view and the full architectural context.
