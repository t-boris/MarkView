## Context



## Alternatives

1. Show the comparison as a lens inside the current project X-Ray instead of opening the comparison view

## Decision

The "Compare with a date…" button and its commit picker are shown in the project X-Ray toolbar as well as in the PR X-Ray. Choosing a commit opens the comparison view (the PR X-Ray tab) with the working copy against that commit, as a branch comparison does. Folder X-Rays do not offer it because they have no comparison view.

## Reason

DEC-009 placed the button only in the PR X-Ray toolbar, which is reached through an entry labelled "Pull request"; the person never found it (BUG-110). The comparison needs no pull request, so it must be reachable from the ordinary X-Ray. This supersedes the placement in DEC-009.
