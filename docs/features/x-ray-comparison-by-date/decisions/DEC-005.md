## Context

The date picker needs a consistent rule for determining which commits belong to a selected calendar day. Git commits contain both author and committer timestamps, and the calendar day depends on the time zone used.

## Alternatives

1. Use the author timestamp converted to the user's local time zone.
2. Use the committer timestamp in UTC.
3. Use the committer timestamp in the time zone recorded with the commit.

## Decision

Determine calendar-day membership using the committer timestamp converted to the user's local time zone.

## Reason

The selected day follows the user's local calendar and reflects when the commit was created in Git history.

## Consequences

REQ-001 must include a commit when its committer timestamp, converted to the user's local time zone, falls on the selected calendar day. The same commit may appear under different calendar days for users in different time zones.
