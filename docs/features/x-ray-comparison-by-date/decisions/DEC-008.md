## Context

The PR X-Ray tab drew only the focused map and hid the overlay menu; the full map with highlights existed only as the "Pull request" overlay of the project X-Ray tab, and one overlay at a time replaced the highlight. DEC-004 requires both maps and REQ-004 requires complexity and size alongside the comparison, on both maps.

## Alternatives

1. Offer the Focused / Full map switch and the overlays only for the comparison by date
2. Open the full map in the project X-Ray tab instead of the PR tab

## Decision

The PR X-Ray tab gets a Focused / Full map switch and a working overlay menu for every source (local changes, branch comparisons, pull requests and the comparison by date). The overlay starts as the change's own colours; the AI filters are not offered there. Changed parts carry a halo and a "+added -removed" count whatever overlay colours them, and a removed file a cross, a dashed red outline and "removed -N".

## Reason

One behaviour for every change is simpler to learn and to keep correct than a mode that exists for one source only, and the page code that draws a change is shared by all sources.

## Consequences

Existing PR X-Ray users also see the switch and the overlay menu. Without a loaded change nothing is dimmed. Pull requests, local changes and branch comparisons now show removed files on the full map too.
