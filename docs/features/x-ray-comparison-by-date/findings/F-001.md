## Finding

The specification does not define which Git timestamp and time zone determine whether a commit belongs to the selected calendar day. These choices can place the same commit on different days and change the picker results.

> The picker offers commits associated with that day from all locally available branches.

## Possible interpretations

- Use the author date or the committer date.
- Interpret the day in the user's local time zone, the commit's recorded time zone, or UTC.

## Resolution

Использовать время создания коммита в истории Git и часовой пояс пользователя. Список соответствует местному календарю, но может различаться у пользователей в разных поясах. — see DEC-005.
