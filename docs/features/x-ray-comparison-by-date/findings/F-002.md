## Finding

A current architecture map may have no node for a file deleted since the baseline. The specification requires changed parts to be highlighted and affected files to be inspectable, but does not establish how deleted files appear in either map. This affects whether the comparison can represent the full difference.

> The comparison highlights changed parts.

## Possible interpretations

- Add historical or placeholder nodes for deleted files to both maps.
- Show deleted files only in a separate changes list while keeping the maps based on current architecture.

## Resolution

AI: Показывать удалённые файлы на обеих картах с явной пометкой об удалении и возможностью открыть их diff. На сфокусированной карте также показывать необходимый контекст. — see DEC-006.
